STYLE CLONE · PROOF

这个页面就是答案：样式可以整体搬走。

本页没有写一行 CSS。它直接链接 handbook 的 styles.css 原文件，HTML 结构复用其语义类名，换内容即为你的站点。

看复用步骤 源仓库（Apache-2.0）
1 个文件 styles.css · 2981 行 · 全站唯一样式表
17 个令牌 :root 设计变量驱动明暗双主题
0 个 webfont 系统字体栈，无外部依赖

01 · 设计令牌

视觉好的原因：一套收敛的设计系统

色板 低饱和绿 背景 #eef5f1，强调 #0d7c55，暗色自动切换为 #5fd0a0
形状 柔和大圆角 --radius: 14px，阴影 0 24px 70px 低透明度长投影
排版 系统字体 正文 ui-sans-serif，代码 ui-monospace，零字体下载
响应式 116 个断点 明暗主题由 prefers-color-scheme 变量覆盖实现

02 · 组件

复用类名即得组件

HEADER site-header / brand / brand-mark 本页顶部导航即原组件，改 logo 与链接即可
HERO hero / eyebrow / hero-actions 首屏左文右卡布局，按钮分 primary / secondary 两级
CARDS runtime-domains / evidence-strip 网格卡片与证据条，适合教程的要点陈列
TERMINAL command-panel / command-label 带复制按钮的命令面板，教程站刚需

03 · 怎么复用

三个层次，按需取用

整站 fork 拷贝 site/ 目录（HTML + styles.css + favicon），保留 Apache-2.0 许可与出处声明，替换全部内容。
抽令牌 只取 :root 的 17 个变量与字体栈，套进你自己的 CSS，得到同款气质。
当模板 保留 header / hero / section-shell / 卡片骨架，正文换你的教程内容（本页做法）。
验证：本目录已可直接静态部署

样式源自 sandbaseai/deepseek-harness-handbook（Apache-2.0）。内容为本仓演示，与原站无关。
