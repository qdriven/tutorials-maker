# IF — 按判断返回标记

- **ID**：`if`　**动作**：按判断返回标记

> 把阈值翻译成一句人话标记，让每个数字都能直接读出“达标还是没达标”。

## 🎯 本课重点

- **重点用什么**：IF 的三段结构是「判断条件, 条件为真时的返回值, 条件为假时的返回值」；需要先算比率再判断时用 IFERROR 防除零，多个条件同时成立用 AND；分层规则用嵌套 IF 或 IFS。
- **完成什么**：把经营看板的三个指标变成可读状态——销售额达成率 0.92 显示“预警”、订单量达成率 1.2 显示“双达标”、退货率高于上限显示“高于上限”。

数据说明：KPI 数据为教学模型；状态阈值已在题目中明确。表头为 A 指标、B 实际、C 目标、D 达成率、E 预警等级；其中达成率与预警等级两列在数据文件里留空，正是要用公式填出的结果列。

## 🧱 基础操作

1. 语法：`=IF(判断条件, 条件为真时的返回值, 条件为假时的返回值)`，三段缺一不可，最后一个参数不能省略。
2. 检查点（易错）：多层嵌套 IF 难以审计；复杂规则可改用 IFS 或查找表。
3. 判断条件是布尔表达式：`B2>=C2` 表示实际 ≥ 目标；`B4>C4` 表示实际超过上限。
4. 比率为 0 或目标为空时先算比率会报 `#DIV/0!`，用 `=IFERROR(B2/C2,0)` 兜底。
5. 多个条件同时成立用 `AND(B3>=C3,D3>=1)`；只有一个成立用 `OR`。

## 🛠 实战操作

用例：把销售额不低于 ¥1,000 的订单标记为“大额订单”。原课程公式为 `=IF(G6>=1000,"大额订单","常规订单")` → 大额订单（原文统一订单表为 7 列，销售额在 G 列）。

配套看板上的判断链（每一步的公式、单元格与预期结果都来自 KPI 预警用例）：

| 单元格 | 公式 | 预期结果 | 说明 |
| --- | --- | --- | --- |
| 经营看板 D2 | `=IFERROR(B2/C2,0)` | 0.92 | 销售额达成率 = 92000 ÷ 100000 |
| 经营看板 E2 | `=IF(D2>=1,"达标",IF(D2>=0.90,"预警","未达标"))` | 预警 | 先判是否达标，再判 90% 预警线 |
| 经营看板 D3 | `=IFERROR(B3/C3,0)` | 1.2 | 订单量达成率 = 120 ÷ 100 |
| 经营看板 E3 | `=IF(AND(B3>=C3,D3>=1),"双达标","需改进")` | 双达标 | 实际 120 ≥ 目标 100，且达成率 1.2 ≥ 1 |
| 经营看板 E4 | `=IF(B4>C4,"高于上限","正常")` | 高于上限 | 退货率 0.08 高于目标上限 0.05，属反向指标，用“是否超上限”判断 |

注意 E2 是嵌套 IF：先问“达标了吗”，再问“到 90% 预警线了吗”。这类规则一旦叠加到三层就很难审计，写文档时应把每层阈值写清楚，或改用 IFS／查找表。

## ✅ 总结

- IF 的三段结构固定：判断条件、条件为真的值、条件为假的值。
- 先算比率再判断时用 IFERROR 兜底，多条件同时成立用 AND。
- 本课结果：达成率 0.92 → “预警”，1.2 → “双达标”，退货率 → “高于上限”。
- 反向指标（退货率）不看达成率，改判“是否高于上限”。
- 嵌套层数越少越好；复杂分层规则优先用 IFS 或查找表，让阈值可审计。
