# FILTER — 动态提取匹配行

- **ID**：`filter`　**动作**：动态提取匹配行　**版本**：Excel 2021／Microsoft 365

> 一条公式把符合条件的订单整行取出来，源数据一变，结果自动跟着变。

## 🎯 本课重点

- **重点用什么**：FILTER 的三个参数是「数据区, 条件, 未匹配时的返回值」；条件区域要和数据区逐列对应，多条件用 `*` 把布尔条件相乘；结果是动态数组会溢出成一片区域，所以输出区域必须留空。
- **完成什么**：提取出销售金额不低于 ¥500 的订单共 3 笔（SO-003 1200、SO-004 600、SO-006 800，首条是 SO-003），再加一个“华东”条件后收敛到 2 笔（SO-003、SO-006）。

## 🧱 基础操作

1. 语法：`=FILTER(数据区, 条件, [未匹配时的返回值])`；条件是一个与数据区同高的 TRUE／FALSE 数组。
2. 条件区域要和数据区逐列对应：数据区取 A:C 三列，条件就只能引用对应的 A:C 三列。
3. 多条件用 `*` 把两个布尔条件相乘，等价于“同时满足”。
4. 未匹配时给一个明确文本（如 `"无"`），避免空结果被读成 0。
5. 结果是动态数组，会溢出成多行多列；输出区域必须为空，否则会出现 `#SPILL!`。
6. 条件区域用绝对引用 `$` 锁定，源数据增加行时结果会自动扩展。

## 🛠 实战操作

用例：提取华东且销售额不低于 ¥500 的订单，源数据变化时结果自动扩展。

原课程公式（原文统一 7 列订单表口径）：`=FILTER(订单!A2:G8,(订单!C2:C8="华东")*(订单!G2:G8>=500),"没有匹配订单")` → 2 笔：SO-1001、SO-1003。

在本课配套的 6 行订单表上（地区在 B 列、金额在 C 列）：

| 单元格 | 公式 | 预期结果 | 说明 |
| --- | --- | --- | --- |
| 动态结果 D2 | `=FILTER(订单!A2:C7,订单!C2:C7>=500,"无")` | 3 行：SO-003 1200、SO-004 600、SO-006 800 | 首条结果是 SO-003；结果向下溢出 3 行 |
| 动态结果 D2（加地区条件） | `=FILTER(订单!A2:C7,(订单!B2:B7="华东")*(订单!C2:C7>=500),"没有匹配订单")` | 2 行：SO-003 1200、SO-006 800 | 与原课程公式同义，只是地区／金额换了列 |

两条公式的差别只在条件：先只按金额筛出 3 行，再叠加“华东”把 SO-004（华南）排掉，剩 2 行。

练习表 [practice.csv](../data/lessons/dynamic-arrays/practice.csv) 的三行题目中，“筛选≥500的订单”由上表第 1 行公式完成；“地区去重数量”“金额降序第一项”分别由 UNIQUE 与 SORT 完成，见 [../05-workspace-lessons/12-dynamic-arrays.md](../05-workspace-lessons/12-dynamic-arrays.md)。

检查点（易错）：输出区域必须为空，否则会出现 `#SPILL!`。

## ✅ 总结

- FILTER 的参数顺序是「数据区, 条件, 未匹配值」，条件区域必须和数据区逐列对应。
- 多条件用 `*` 相乘表示“同时满足”，本课两个条件相乘后从 3 行收敛到 2 行。
- 结果会溢出成动态区域，输出区域必须留空，否则 `#SPILL!`。
- 未匹配要显式给文本，不要让它变成 0 或空白。
- 本课成果：≥¥500 取出 3 笔（首条 SO-003），叠加“华东”后剩 SO-003、SO-006 两笔。
