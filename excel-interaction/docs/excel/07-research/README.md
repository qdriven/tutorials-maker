# 07 · GitHub 教程调研

> 调研 10 个公开 GitHub 教程／练习仓库，用它们校准课程知识覆盖、挑练习素材——不是 GitHub 官方排名。

来源：`src/data/course.ts` 中的 `repos`（10 个 GitHub 教程／练习仓库）与 `researchTopics`（高频主题归并）。调研目的是校准课程知识覆盖、挑选练习素材，不是 GitHub 官方排名；用例筛选优先考虑实际练习价值，不按 Star 机械排序。

## 🎯 本课重点

- **重点用什么**：去 GitHub 教程／练习仓库里查三类东西——可下载的练习工作簿与数据集（看是否含 `.xlsx`／`.csv`）、覆盖的函数与图表主题、以及各仓库的许可与出处。
- **完成什么**：为每个高频主题找到至少一个可直接动手的仓库出处，并记录它的原始链接与许可；引用素材时能把“仓库 → 文档 → 用例”串起来。

## ✅ 总结

- 调研目的有两个：校准课程知识覆盖（看有没有漏掉主题）和挑选练习素材（看有没有现成工作簿可用），不是排名。
- 10 个入选仓库都提供工作簿、数据集或项目材料；“练习文件／项目素材”命中 10 次是最稳定的共性。
