# 堆积柱形图（看构成变化）

> 堆积柱形图回答“整体增长时，渠道构成如何变化”，同一根柱子同时表示总量与内部构成。

- **ID**：`stacked`　**名称**：堆积柱形图　**短名**：堆积　**用途**：看构成变化

## 🎯 本课重点

- **重点用什么**：插入 → 堆积柱形图；只比较构成时选百分比堆积
- **完成什么**：产出一张能回答“整体增长时，渠道构成如何变化”的堆积柱形图，并写出结论：5 月完全由线上贡献，6 月门店占比明显上升

## 📦 配套数据

| 数据 | 文件 | 规模 | 用途 |
| --- | --- | --- | --- |
| 月度线上／门店构成 | [chart.csv](../data/lessons/chart-stacked/chart.csv) | 3 行 × 3 列 | 画堆积柱形图的类别轴与构成系列 |

数据说明：数据要求为“有序类别＋多个非负构成系列”。CSV 表头为 `month,online,store`，共 3 行，`month` 作有序类别轴，`online` 与 `store` 是两个非负构成系列，同一根柱子由它们上下堆叠而成；数据来源为 `src/data/course.ts` 的 `chartLessons`。

## 🧱 基础操作

1. **先确认问题类型**：堆积柱形图回答“总量之外，构成怎么变”，一根柱子同时承载总量与内部构成。
2. **数据要求**：有序类别＋多个非负构成系列。本课配套数据为 3 行 × 3 列（`month`、`online`、`store`）。
3. **选型依据**：同时看总量与内部构成，系列不宜过多。
4. **误用提醒**：非底层系列没有共同基线，不适合精确比较。
5. **Excel 插入路径**：插入 → 堆积柱形图；只比较构成时选百分比堆积。

## 🛠 实战操作

1. 打开 [chart.csv](../data/lessons/chart-stacked/chart.csv)：第 1 行为表头 `month,online,store`，其下 3 行数据。
2. 选中 `month`、`online`、`store` 三列（含表头）。
3. 依次点击 插入 → 堆积柱形图。
4. 确认堆叠顺序：底层是 `online`（线上），上层是 `store`（门店）；需要在“选择数据 → 系列”中拖动调整顺序时，保持月份沿横轴从 4 月到 6 月有序。
5. 只比较构成比例时改选百分比堆积：插入 → 堆积柱形图 → 百分比堆积，让各月柱子等高、只看构成比例。
6. 读图：4 月线上 960、门店 400；5 月门店为 0，柱子全部由线上构成；6 月线上 750、门店 1,440，门店段明显变高。

| 月份 | 线上 | 门店 |
| --- | --- | --- |
| 4 月 | 960 | 400 |
| 5 月 | 1,640 | 0 |
| 6 月 | 750 | 1,440 |

**读图结论**：5 月完全由线上贡献，6 月门店占比明显上升。

**误用对比**

| 用法 | 说明 |
| --- | --- |
| 同时看总量与内部构成 | 用堆积柱形图（数值堆积） |
| 只比较构成比例 | 改用百分比堆积 |
| 精确比较非底层系列 | 非底层系列没有共同基线，不适合精确比较 |
| 只看某一时点的占比 | 用饼图更直接（见 [04-pie.md](04-pie.md)） |
