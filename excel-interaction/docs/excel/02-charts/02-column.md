# 簇状柱形图（比类别）

> 簇状柱形图回答“不同地区的销售额相差多少”，把离散类别并排放在同一根基线上比高低。

- **ID**：`column`　**名称**：簇状柱形图　**短名**：柱形　**用途**：比类别

## 🎯 本课重点

- **重点用什么**：插入 → 簇状柱形图（横轴放地区、纵轴放销售额）
- **完成什么**：产出一张能回答“不同地区的销售额相差多少”的簇状柱形图，并写出结论：华东最高，但三个地区的差距并不悬殊

## 📦 配套数据

| 数据 | 文件 | 规模 | 用途 |
| --- | --- | --- | --- |
| 地区销售额汇总 | [chart.csv](../data/lessons/chart-column/chart.csv) | 4 行 × 2 列 | 画簇状柱形图的 X 轴与 Y 轴 |

数据说明：数据要求为“少量离散类别＋一个数值字段”。CSV 表头为 `region,revenue`，共 4 个地区，`region` 作横轴分类、`revenue` 作数值系列；数据来源为 `src/data/course.ts` 的 `chartLessons`。

## 🧱 基础操作

1. **先确认问题类型**：簇状柱形图回答“类别之间相差多少”，所有柱子共用一条基线，因此适合直接目测高低。
2. **数据要求**：少量离散类别＋一个数值字段。本课配套数据为 4 行 × 2 列（`region`、`revenue`）。
3. **选型依据**：比较类别高低，尤其适合短类别名称。
4. **误用提醒**：类别太多或文字太长时，改用横向条形图。
5. **Excel 插入路径**：插入 → 簇状柱形图。

## 🛠 实战操作

1. 打开 [chart.csv](../data/lessons/chart-column/chart.csv)：第 1 行为表头 `region,revenue`，其下 4 行数据。
2. 选中 `region` 与 `revenue` 两列（含表头）。
3. 依次点击 插入 → 簇状柱形图。
4. 确认每个地区对应一根柱子：只有一个数值系列时，4 个地区应渲染成 4 根柱子，而不是一根柱子配 4 个系列。
5. 给纵轴加上标题“销售额”，必要时开启数据标签，便于读出 2,000 / 1,600 / 1,590 / 980 这几个数值。

| 地区 | 销售额 |
| --- | --- |
| 华东 | 2,000 |
| 华北 | 1,600 |
| 华南 | 1,590 |
| 西南 | 980 |

**读图结论**：华东最高，但三个地区的差距并不悬殊。

**误用对比**

| 用法 | 说明 |
| --- | --- |
| 少量离散类别、标签较短 | 用簇状柱形图 |
| 类别太多或文字太长 | 改用横向条形图（见 [03-bar.md](03-bar.md)） |
