# 饼图／环形图（看占比）

> 饼图／环形图回答“线上与门店各占多少”，用一个扇区角度表达简单的部分—整体关系。

- **ID**：`pie`　**名称**：饼图／环形图　**短名**：占比　**用途**：看占比

## 🎯 本课重点

- **重点用什么**：插入 → 饼图或圆环图 → 添加百分比标签
- **完成什么**：产出一张能回答“线上与门店各占多少”的饼图，并写出结论：线上占 64.5%，接近整体的三分之二

## 📦 配套数据

| 数据 | 文件 | 规模 | 用途 |
| --- | --- | --- | --- |
| 渠道数值占比 | [chart.csv](../data/lessons/chart-pie/chart.csv) | 2 行 × 2 列 | 画饼图／环形图的扇区来源 |

数据说明：数据要求为“一个系列、非负值、合计为 100%，类别尽量不超过 5 个”。CSV 表头为 `channel,value`，共 2 个渠道，`channel` 作类别、`value` 作数值系列；数据来源为 `src/data/course.ts` 的 `chartLessons`。

## 🧱 基础操作

1. **先确认问题类型**：饼图／环形图回答“各占多少”，靠扇区角度表达占比，不是用来比高低的。
2. **数据要求**：一个系列、非负值、合计为 100%，类别尽量不超过 5 个。本课配套数据为 2 行 × 2 列（`channel`、`value`）。
3. **选型依据**：快速表达简单的部分—整体关系。
4. **误用提醒**：需要精确比较多个相近类别时，排序条形图更清楚。
5. **Excel 插入路径**：插入 → 饼图或圆环图 → 添加百分比标签。

## 🛠 实战操作

1. 打开 [chart.csv](../data/lessons/chart-pie/chart.csv)：第 1 行为表头 `channel,value`，其下 2 行数据。
2. 选中 `channel` 与 `value` 两列（含表头）。
3. 依次点击 插入 → 饼图或圆环图。
4. 确认只有 1 个系列：若出现两个系列，说明选区多带了列，回到“选择数据 → 系列”里删掉多余系列。
5. 添加百分比标签：在图表元素上右键 → 添加数据标签 → 勾选“百分比”，让占比直接写在扇区上。
6. 核对标签：线上 3,350、门店 1,840，对应 64.5% 与 35.5%。

| 渠道 | 数值 |
| --- | --- |
| 线上 | 3,350 |
| 门店 | 1,840 |

**读图结论**：线上占 64.5%，接近整体的三分之二。

**误用对比**

| 用法 | 说明 |
| --- | --- |
| 简单部分—整体、类别少 | 用饼图／环形图并加百分比标签 |
| 需要精确比较多个相近类别 | 用排序条形图更清楚（见 [03-bar.md](03-bar.md)） |

## ✅ 总结

- 饼图／环形图回答“各占多少”，靠扇区角度而非长度表达占比。
- 数据要求：一个系列、非负值、合计为 100%，类别尽量不超过 5 个。
- Excel 路径：插入 → 饼图或圆环图 → 添加百分比标签。
- 本课结论：线上占 64.5%，接近整体的三分之二。
- 误用：需要精确比较多个相近类别时，排序条形图更清楚。
