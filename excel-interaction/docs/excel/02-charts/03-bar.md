# 条形图（做排名）

> 条形图回答“哪些商品排在销售额前五名”，横向排布让长名称和排名顺序都读得顺。

- **ID**：`bar`　**名称**：条形图　**短名**：条形　**用途**：做排名

## 🎯 本课重点

- **重点用什么**：插入 → 簇状条形图 → 按数值排序（纵轴放商品、条长表示销售额）
- **完成什么**：产出一张能回答“哪些商品排在销售额前五名”的条形图，并写出结论：咖啡豆贡献最高，是首先需要核查的商品

## 📦 配套数据

| 数据 | 文件 | 规模 | 用途 |
| --- | --- | --- | --- |
| 商品销售额排名 | [chart.csv](../data/lessons/chart-bar/chart.csv) | 5 行 × 2 列 | 画条形图的类别轴与数值系列 |

数据说明：数据要求为“已排序类别＋数值；名称可以较长”。CSV 表头为 `product,revenue`，共 5 个商品，`product` 作纵向类别轴、`revenue` 作条长数值系列；数据来源为 `src/data/course.ts` 的 `chartLessons`。

## 🧱 基础操作

1. **先确认问题类型**：条形图回答“谁排名靠前”，横向排列让阅读顺序自然，也放得下较长的类别名称。
2. **数据要求**：已排序类别＋数值；名称可以较长。本课配套数据为 5 行 × 2 列（`product`、`revenue`）。
3. **选型依据**：排名和长标签比较，阅读顺序自然。
4. **误用提醒**：不排序会削弱排名信息；类别过多时只保留重点。
5. **Excel 插入路径**：插入 → 簇状条形图 → 按数值排序。

## 🛠 实战操作

1. 打开 [chart.csv](../data/lessons/chart-bar/chart.csv)：第 1 行为表头 `product,revenue`，其下 5 行数据。
2. 选中 `product` 与 `revenue` 两列（含表头）。
3. 依次点击 插入 → 簇状条形图。
4. 按数值排序：用 Excel 的排序功能对 `revenue` 列降序排列，再重画（或在图表数据中调整顺序），让条形从上到下由高到低，读图即是排名。
5. 检查类别顺序：条形图中最大条通常落在顶部，若排序方向不对，用“切换行/列”与排序修正。
6. 开启数据标签，核对 2,000 / 1,800 / 750 / 640 / 520 的条长。

| 商品 | 销售额 |
| --- | --- |
| 咖啡豆 | 2,000 |
| 冷萃咖啡 | 1,800 |
| 精品茶 | 640 |
| 保温杯 | 750 |
| 手冲壶 | 520 |

**读图结论**：咖啡豆贡献最高，是首先需要核查的商品。

**误用对比**

| 用法 | 说明 |
| --- | --- |
| 做排名、名称较长 | 用条形图并按数值排序 |
| 不排序 | 排名信息被削弱，应先排序 |
| 类别过多 | 只保留重点类别 |
| 少量短类别比较 | 用簇状柱形图（见 [02-column.md](02-column.md)） |
