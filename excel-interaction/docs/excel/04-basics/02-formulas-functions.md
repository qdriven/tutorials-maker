# 第 02 章 · 公式怎么写，函数怎么选

> 公式的三段式结构、常见函数类别，以及相对引用和绝对引用在"复制公式"时为什么会改口。

- **ID**：`basics-ch2`　**短标题**：公式与函数
- **学习目标**：理解公式结构、常见函数类别，以及相对、绝对和混合引用在复制公式时的差别。
- **核心概念**：Formulas、Logical、Text、Date、Lookup、Math、Statistical

## 🎯 本课重点

- **重点用什么**：`=` 开头的公式结构、`XLOOKUP` 的查找数组／返回数组／未匹配参数、`VLOOKUP` 的区域与列序号，以及 `F4` 在 `$A$2`（绝对）、`A$2`、`$A2`（混合）之间切换。
- **完成什么**：能在商品主数据上用两种查找函数取出同一个答案，并能说清"为什么把公式往下拖，区域不能跟着跑"。

## 🧱 基础操作

1. **公式结构**：`=函数(参数1, 参数2, …)`。等号开头；文本参数要加英文双引号（如 `"华东"`）；区域引用写成 `表名!$A$2:$A$6`。
2. **引用三种形态**：相对引用 `A2`（复制时列行都变）、绝对引用 `$A$2`（复制时不变）、混合引用 `A$2`／`$A2`（只锁一行或一列）。编辑引用时按 `F4` 循环切换。
3. **函数类别怎么选**：Math（求和、极值）、Statistical（平均、计数、中位数）、Lookup（按键取值）、Text（拆分与拼接文本）、Date（日期提取与格式化）、Logical（条件判断与组合）。
4. **错误处理的两种写法**：`IFERROR(公式, 兜底值)` 把错误变成可读结果；`XLOOKUP` 第 4 参数直接给"未匹配"文案。0 与"未匹配"含义不同，不要混用。
5. **区域要不要锁**：一个公式只在一个单元格里用（不复制），区域可以不锁；一旦要把公式拖到别的行，条件区域必须锁绝对引用，否则引用会跟着漂移。

## 🛠 实战操作

在 [products.csv](../data/lessons/alex-lookup/products.csv) 上练习（表中数据区为 A2:E6，行名记作"商品表"）：

1. **用 XLOOKUP 取商品名**：在 `商品表` 旁边的练习区写 `=XLOOKUP("P-103",商品表!$A$2:$A$6,商品表!$B$2:$B$6,"未匹配")` → **咖啡豆**。XLOOKUP 的查找数组（`$A$2:$A$6`）与返回数组（`$B$2:$B$6`）是分开的，第 4 参数写"未匹配"。
2. **用 VLOOKUP 取单价**：写 `=VLOOKUP("P-104",商品表!$A$2:$E$6,4,FALSE)` → **150**。商品表共 5 列，单价在第 4 列，所以列序号是 4；精确匹配要写 `FALSE`。
3. **处理不存在的编码**：写 `=XLOOKUP("P-999",商品表!$A$2:$A$6,商品表!$E$2:$E$6,"未匹配")` → **未匹配**。不要把缺失值一律写成 0；采购要确认"这个编码到底有没有库存"，"未匹配"才答得上这个问题。
4. **看懂引用在"拖动"时的变化**：把第 1 步的 XLOOKUP 公式从 `B2` 往下拖到 `B3`（查找值变成 `"P-103"` 不变或按需改成 `"P-104"`），区域 `$A$2:$A$6` 因为被锁死而保持不动；如果当初写成 `商品表!A2:A6`，拖到下一行就变成了 `A3:A7`，查找范围整体错位。
5. **同一件事的两种写法要能对上**：用 `INDEX＋MATCH` 也能取 P-103 的商品名 —— `=INDEX(商品表!$B$2:$B$6,MATCH("P-103",商品表!$A$2:$A$6,0))`，结果同样是 **咖啡豆**；第 05 章会把它和条件汇总连起来。
6. **Math 与 Statistical 类别速查**（在本表上直接算）：
   - `=SUM(商品表!$D$2:$D$6)` → **810**（5 个商品单价之和）
   - `=AVERAGE(商品表!$D$2:$D$6)` → **162**（810÷5）
   - `=MAX(商品表!$E$2:$E$6)` → **58**（精品茶库存最高）
   - `=MIN(商品表!$E$2:$E$6)` → **12**（手冲壶库存最低）
   - `=COUNT(商品表!$D$2:$D$6)` → **5**（5 个数值单价）
   - `=COUNTIF(商品表!$C$2:$C$6,"饮品")` → **2**（冷萃咖啡与精品茶）
7. **Logical 类别**：给单价加一个判断标签 `=IF(D2>=200,"高单价","常规")` —— P-103（200）、P-105（260）标为"高单价"，其余为"常规"；需要多个条件同时成立时用 `AND`，任一成立即可用 `OR`（例如 `=IF(AND(E2>0,D2>=200),"重点补货","常规")`）。
8. **Text 与 Date 类别**：Text 用 `=LEFT(A2,3)` 取 SKU 前三段得 `P-1`，`=TRIM(...)` 清多余空格；Date 用 `=TEXT(日期单元格,"yyyy-mm")` 把订单日期变成 `2026-10` 这样的月份文本（真实日期列见 [../05-workspace-lessons/01-free-excel.md](../05-workspace-lessons/01-free-excel.md)）。注意：格式化后的文本不能当日期再做计算。

## ✅ 总结

- 公式结构是 `=函数(参数…)`，区域引用写成 `表名!$A$2:$A$6`。
- XLOOKUP 与 VLOOKUP 能取到同一个答案（咖啡豆、150），差别在参数顺序与"未匹配"的处理方式。
- 相对引用会跟着复制走，绝对与混合引用不会——要拖公式就必须锁区域（`F4` 切换）。
- 函数按类别选：Math、Statistical、Lookup、Text、Date、Logical；缺失值用 `IFERROR` 或第 4 参数处理，不要用 0 顶替。
