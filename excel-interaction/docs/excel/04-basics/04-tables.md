# 第 04 章 · Excel 表不是一块带颜色的区域

> 选中一片区域、涂上底色，这只是"看起来像表"；`Ctrl＋T` 建出来的才是有名字、有结构化引用、会自动扩展的表对象。

- **ID**：`basics-ch4`　**短标题**：表格进阶
- **学习目标**：理解 Excel 表对象、结构化引用、条件格式、数字格式与协作边界。
- **核心概念**：Tables、Conditional Formatting、Formatting、Collaboration

## 🎯 本课重点

- **重点用什么**：`Ctrl＋T` 把当前区域创建为 Excel 表（并给它起名）、表内公式的结构化引用（如 `订单明细[行销售额（元）]`）、开始 → 条件格式 → 新建规则（用公式确定要设置的单元格）。
- **完成什么**：能在自己的一份明细表上完成"转表对象 → 补计算列 → 加条件格式预警 → 汇总核对"，并说出表对象比普通区域多出了哪三件事。

| 原始订单明细 | [raw.csv](../data/lessons/free-excel/raw.csv) | 24 行 × 12 列 | 本章操作用的练习明细表 |

## 🧱 基础操作

1. **区域与表对象的区别**：区域只是一段单元格引用；表对象（Table）额外带有表名、标题行、筛选按钮、自动扩展与自动填充，以及"结构化引用"这种按列名取数的写法。
2. **结构化引用**：`=SUM(订单明细[行销售额（元）])` 读起来就是"订单明细这张表的行销售额列"，比 `J2:J25` 更不容易被插行插列打断。
3. **条件格式的层次**：先用公式写清"哪一行算异常"，再决定怎么显示（红字／红底／数据条）；条件格式只负责"突出显示"，阈值与原始值仍要能复核。
4. **数字格式是口径**：金额用货币或两位小数，百分比用百分比格式，日期用日期格式——显示格式不改变底层数值，两者要分开核对。
5. **协作边界**：表名在同一工作簿内必须唯一；结构化引用指向表名，表被改名、删除或复制到别的文件都会断链；共享前先说清"谁是这张表的拥有者"。

## 🛠 实战操作

1. **把区域变成表对象**：在 Excel 中打开 [raw.csv](../data/lessons/free-excel/raw.csv)，选中 A1:L25，按 `Ctrl＋T`，勾选"表包含标题"，确定后把表名改成 `订单明细`。此后在表末行下任意一行录入数据，整张表会自动扩展。
2. **在表里补计算列**：先按 [../05-workspace-lessons/01-free-excel.md](../05-workspace-lessons/01-free-excel.md) 的做法补齐两列——`I2` 写 `=IF(OR(LEFT(A2,1)="C",F2<=0,G2<=0),0,1)`（有效行）、`J2` 写 `=I2*F2*G2`（行销售额），然后在表对象里把公式向下填充，Excel 会自动扩展到新行。填充完成后：有效行 = **20**，行销售额合计 = **4,810**。
3. **用结构化引用汇总**：在表外写 `=SUM(订单明细[行销售额（元）])` → **4,810**；再写 `=SUMIFS(订单明细[行销售额（元）],订单明细[地区],"华东")` → **1,790**。两式结果一致，说明结构化引用没有取错列。
4. **加条件格式预警异常行**：开始 → 条件格式 → 新建规则 → 使用公式确定要设置的单元格，填 `=OR(LEFT($A2,1)="C",$F2<=0,$G2<=0)`，格式设为红字加浅红底。确认命中 4 行：`C-013`（取消单）、`N-014`（数量 0）、`N-015`（单价 0）、`N-016`（数量 −2）。表对象里也可以写成 `=OR(LEFT([@[订单号]],1)="C",[@[数量]]<=0,[@[单价（元）]]<=0)`，插行后依然有效。
5. **统一数字格式**：把 `单价（元）` 与 `行销售额（元）` 设为货币格式（¥，两位小数），`有效行` 设为整数 0/1，必要时对 `行销售额（元）` 加一条数据条——显示层的美化不能替代第 2 步的公式，两边要能对上。
6. **做一次交叉核对**（用结构化引用 + SUMIFS 复现第 05 章的透视表）：按"行＝地区、列＝渠道、值＝行销售额合计"汇总，结果应当是下面这张表，且总计与第 3 步的 4,810 一致。

| 地区 | 线上 | 门店 | 合计 |
| --- | --- | --- | --- |
| 华东 | 1,000 | 790 | 1,790 |
| 华南 | 820 | 620 | 1,440 |
| 华北 | 200 | 700 | 900 |
| 西南 | 520 | 160 | 680 |
| 合计 | 2,540 | 2,270 | 4,810 |

7. **记住协作边界**：把这份工作簿发给同事前，先说明表名 `订单明细` 不能重名、不能被删；如果要把表复制到另一个文件，结构化引用需要在新文件里重建一次（Excel 会提示），而不是直接粘贴数值了事。

## ✅ 总结

- `Ctrl＋T` 建的是表对象：表名、结构化引用、自动扩展与自动填充，缺一不可。
- 结构化引用 `订单明细[行销售额（元）]` 让公式不再依赖行号，插行也不怕。
- 条件格式只负责"突出显示"，异常判定仍要由公式（`=OR(LEFT($A2,1)="C",$F2<=0,$G2<=0)`）给出。
- 本课数据核对结果：24 行中有效 20 行，行销售额合计 4,810，与地区×渠道交叉表的总计一致。
