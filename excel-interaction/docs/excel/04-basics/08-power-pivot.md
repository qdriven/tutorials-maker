# 第 08 章 · 当一张表不够时，建立数据模型

> 三张表放在同一个文件里不等于有了模型；模型要有关系、有度量值，还要能证明每一张表之间没有断链。

- **ID**：`basics-ch8`　**短标题**：Power Pivot
- **学习目标**：理解表关系、数据模型与 DAX，并能分清 Power Query、数据透视表和 Power Pivot。
- **核心概念**：Power Pivot、DAX、Data Models

> 本章为 Excel 桌面功能导览；网页演示不冒充 Power Pivot 或 DAX 引擎。

## 🎯 本课重点

- **重点用什么**：插入 → 数据模型 把多张表纳入同一个模型、Power Pivot 里的表关系（关系键必须唯一）、以及用 DAX 度量值（示例：`DIVIDE('利润表'[毛利润],'利润表'[净销售额])`）固化指标口径。
- **完成什么**：能在自己的三张财务表上完成"跨表引用 → 算比率 → 复算勾稽 → 校验平衡"，并说出数据模型比"多个工作表加公式"多了哪两件事。

## 🧱 基础操作

1. **三个工具的分工**：Power Query 负责把数据取进来并清洗好；数据透视表在工作簿范围内按字段汇总；Power Pivot 负责把多张表放进**数据模型**、建立表关系，并用 DAX 定义指标。
2. **数据模型比"多张工作表"多的两件事**：一是表之间可以建立关系（按唯一键连接），二是指标可以写成度量值（DAX），供多张透视表与图表复用同一套口径。
3. **表关系的前提**：关系键在一侧必须唯一。一对多关系里，"一"的那张表（维度表）的键不能重复，否则数据模型无法确定对应关系。
4. **DAX 与普通公式的差别**：普通公式写在某张表里、随单元格位置变化；DAX 度量值写在模型里、不占单元格、随数据刷新自动重算，可以被多张报表引用。
5. **校验位是最便宜的保险**：给关键结果配一个"能不能对上"的判断（`IF`＋`ABS`），比事后逐张表人工核对快得多，也更不容易漏。

## 🛠 实战操作

1. **把三张表摆在一起**：打开 [income.csv](../data/lessons/portfolio-dashboard/income.csv)、[balance.csv](../data/lessons/portfolio-dashboard/balance.csv)、[cash.csv](../data/lessons/portfolio-dashboard/cash.csv)。三张表结构相同（项目、FY2025），但是三个独立的来源——利润表回答"赚了多少"，资产负债表回答"家底如何"，现金流量表回答"钱怎么流的"。
2. **跨表引用取指标**：在"看板"表 B2 写 `=利润表!B2` → **416,161**。用引用而不是手填数字，指标才追得到源头。
3. **算比率**：在看板 B3 写 `=利润表!B3/利润表!B2` → 195,201÷416,161 ≈ **0.4690**（约 46.9%），再把单元格设成百分比格式。这就是"毛利率"这个指标的定义——毛利润÷净销售额。
4. **复算期末现金**：现金流量表 B3:B6 分别是经营、投资、筹资和期初现金，在看板 B4 写 `=SUM(现金流量表!B3:B6)` → 111,482＋15,195−120,686＋29,943 = **35,934**。这个数与资产负债表的"现金及现金等价物 35,934"完全一致——说明三张表之间没有断链。
5. **做资产负债平衡校验**：在看板 B5 写 `=IF(ABS(资产负债表!B2-资产负债表!B4-资产负债表!B5)<0.1,"Check","Error")` → **Check**，因为 359,241 = 285,508＋73,733。容差取 0.1 是为了避开浮点误差，不是为了放过对不上的账。
6. **在桌面版里做真正的数据模型**：Power Pivot → 管理数据模型（或插入 → 数据模型）把三张表加入模型 → 在"表关系"里用唯一键建立关系 → 在"新建度量值"里写 DAX，例如把第 3 步的比率固化成度量值 `毛利率 = DIVIDE('利润表'[毛利润], '利润表'[净销售额])`，把第 4、5 步的复算与校验也各写成一个度量值 → 再插入数据透视表或数据透视图，把这些度量值当字段拖进报表里。
7. **说明这一步的意义**：看板上的每个数字都不是孤立的——净销售额来自利润表，毛利率是利润表两行相除，期末现金是现金流量表四行相加再与资产负债表核对，平衡校验则确认了负债与权益之和等于资产。指标之间有勾稽关系，报表才可信。

| 看板指标 | 计算方式 | 结果 |
| --- | --- | --- |
| 净销售额 | `=利润表!B2` | 416,161 |
| 毛利率 | `=利润表!B3/利润表!B2` | 约 0.4690（46.9%） |
| 期末现金复算 | `=SUM(现金流量表!B3:B6)` | 35,934 |
| 资产负债校验 | `=IF(ABS(资产负债表!B2-资产负债表!B4-资产负债表!B5)<0.1,"Check","Error")` | Check |

## ✅ 总结

- Power Query 清洗数据，数据透视表按字段汇总，Power Pivot 用数据模型＋表关系＋DAX 固化指标口径。
- 数据模型比"多张工作表＋公式"多的两件事：表关系与可复用的度量值。
- 本课三表勾稽：毛利率约 0.4690，期末现金复算 35,934 与资产负债表现金一致，资产负债校验返回 Check。
