# 第 5 步 · 按问题选择图表，而非按外观

> 图表是比较关系的编码方式：先想清楚要让读者看见什么关系，再选图表类型，而不是挑好看的样式。

- **ID**：`visualize`　**短标题**：选择图表　**级别**：进阶　**时长**：12 分钟

## 🎯 本课重点

- **重点用什么**：按意图选型——趋势用折线图、类别比较用簇状柱形图、排名用簇状条形图、占比用饼图或圆环图、关系用 XY 散点图；Excel 路径是“插入 → 图表类型”。
- **完成什么**：得到一张只回答一个核心问题的图，并把标题写成结论、把单位、时间与数据来源补完整。
- **边界**：减少无意义的颜色、3D 和网格线；类别没有自然顺序时不要硬连成线，类别过多或名称太长时改用横向条形图。
- **判断标准**：读者需要在 5 秒内看见什么关系？看完这张图，他能复述出结论吗？

## 🧱 基础操作

1. 选区要包含标题行：先选中“月份／销售额”两列，再点“插入 → 折线图或带数据标记的折线图”，Excel 会自动把月份当作横轴。
2. 换图表类型：选中图表 →“图表设计 → 更改图表类型”；条形图要先按数值排序，否则排名信息会被削弱。
3. 加标题与标签：选中图表 →“图表设计 → 添加图表元素 → 图表标题”，标题直接写结论而不是“销售额图”。
4. 写清口径：在标题或副标题里补上单位、时间范围与数据来源，例如“2026 年 10–11 月样本销售金额（元）”。
5. 清理干扰项：删掉不需要的系列、网格线和 3D 效果；双轴图必须标清左右轴，不要随意截断坐标轴。
6. 判断选型是否正确：读一遍图表设计里的“数据要求”是否满足——折线图要一个有序时间字段，饼图要非负且合计为 100% 的少量类别。

## 🛠 实战操作

1. **按问题定图表类型**（本课检查清单）
   - 趋势：折线图
   - 排名：排序后的条形图
   - 占比：类别少且总和为 100% 时才考虑饼图
   - 其它类型与 Excel 路径：簇状柱形图（插入 → 簇状柱形图）、簇状条形图（插入 → 簇状条形图 → 按数值排序）、饼图或圆环图（插入 → 饼图或圆环图 → 添加百分比标签）、XY 散点图（插入 → XY 散点图，X 放折扣，Y 放毛利率）、直方图（插入 → 统计图表 → 直方图 → 设置箱宽度）、组合图（插入 → 组合图 → 柱形＋折线 → 利润率使用次坐标轴）、堆积柱形图（插入 → 堆积柱形图；只比较构成时选百分比堆积）。
2. **用折线示例数据出图**（chart.csv）
   - 选中 A1:B7 → 插入 → 折线图或带数据标记的折线图。
   - 预期读图结论：6 月达到 ¥2,190，连续第三个月上升。
   - 标题改写成结论，并补上单位与时间，例如“月度销售额持续上升，6 月达 ¥2,190”。
3. **在中文零售实战里按问题选趋势图**（第 4 步的月度汇总结果）
   - 要比较的是两个连续月份，不是地区排名，所以选折线图（干扰项：柱形图、条形图）。
   - 用刚在“月度汇总”算出的实际结果绘图，并同时看销售金额与订单均价是否同向。
   - 预期结论：折线图；销售金额上升（¥2,120 → ¥2,690，约 +26.9%），订单均价下降（¥265.00 → ¥224.17，约 −15.4%）。
4. **检查这张图是否合格**
   - 去掉 3D、装饰性颜色和无意义网格线。
   - 标题写成结论，补齐单位、时间范围与数据来源。
   - 5 秒测试：读者看完能否说出“哪个在涨、涨了多少”？
5. **产出**：一张只回答一个核心问题的图。

## ✅ 总结

- 选型顺序是“问题 → 关系 → 图表”，不是“好看 → 图表”：趋势折线、类别柱形、排名条形、占比饼图、关系散点。
- 折线示例数据读出的结论是“6 月达到 ¥2,190，连续第三个月上升”。
- 中文零售实战里销售金额上升（+26.9%）而订单均价下降（−15.4%），一张图能同时暴露这两件事。
- 标题写成结论，补齐单位、时间与数据来源，删掉 3D 和多余网格线。
- 下一步进入第 6 步，把图上的数字翻译成可复核的结论。
