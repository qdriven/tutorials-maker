# 03 · 商品主数据：VLOOKUP 与 XLOOKUP

> 一张 5 行的商品表，两种查找函数，三道业务问题——顺带看清"查不到"该怎么表达。

| 字段 | 值 |

| ID | `alex-lookup` |
| 顺序 | 3 |
| 分类 | 查找函数 |
| 级别 | 基础 |
| 时长 | 7 分钟 |
| 数据类型 | 教学模型 |
| 来源 | [AlexTheAnalyst/Excel-Tutorial](https://github.com/AlexTheAnalyst/Excel-Tutorial) |

**故事**：客服只拿到 SKU，需要快速说出商品名、单价；采购还要确认一个不存在的编码是否有库存。

**学习目标**：学完能向右查找、处理缺失值，并理解 XLOOKUP 与 VLOOKUP 的参数差异。

**技能**：`XLOOKUP`、`VLOOKUP`、`IFERROR 思路`

**摘要**：你用两种函数完成查找，并用 XLOOKUP 第 4 参数处理未匹配值。

## 🎯 本课重点

- **重点用什么**：`XLOOKUP`（查找数组、返回数组分离，第 4 参数写未匹配值）、`VLOOKUP`（列序号 + 精确匹配写 FALSE）、`IFERROR` 兜底思路。
- **完成什么**：在同一张商品表上答出三道题——P-103 的商品名是"咖啡豆"、P-104 的单价是 150、P-999 的库存显示"未匹配"（而不是 `#N/A` 或 0）。

## 🧱 基础操作

1. **XLOOKUP 语法**：`=XLOOKUP(查找值, 查找数组, 返回数组, [未匹配值], [匹配模式], [搜索方式])`。查找数组与返回数组彼此独立，所以既能向右查也能向左查；第 4 参数就是"查不到时返回什么"。
2. **VLOOKUP 语法**：`=VLOOKUP(查找值, table_array, 列序号, [匹配方式])`。查找值必须在 `table_array` 的第 1 列，列序号从 1 开始数。
3. **精确匹配写 FALSE**：不写第 4 参数会走近似匹配，可能返回一个"看起来合理"却错误的结果。
4. **列序号要数准**：商品表共 5 列（A SKU、B 商品、C 类别、D 单价、E 库存），单价在第 4 列，所以列序号写 4。
5. **未匹配值的表达**：0、空字符串、"未匹配"含义不同。本课统一用"未匹配"，不要把缺失一律写成 0。

## 🛠 实战操作

1. **xlookup｜用 XLOOKUP 查商品** —— 在查询练习 B2，用 SKU P-103 返回商品名：`=XLOOKUP("P-103",商品表!$A$2:$A$6,商品表!$B$2:$B$6,"未匹配")`（预期：咖啡豆）。XLOOKUP 的查找数组与返回数组是分开的，第 4 参数可写"未匹配"。
2. **vlookup｜用 VLOOKUP 查价格** —— 在查询练习 B3，返回 P-104 的单价：`=VLOOKUP("P-104",商品表!$A$2:$E$6,4,FALSE)`（预期：150）。商品表共 5 列，单价在第 4 列，精确匹配要写 FALSE。
3. **missing｜处理不存在的编码** —— 在查询练习 B4 查询 P-999 库存：`=XLOOKUP("P-999",商品表!$A$2:$A$6,商品表!$E$2:$E$6,"未匹配")`（预期：未匹配）。不要把缺失值一律写成 0；0 与未匹配含义不同。

| 单元格 | 业务问题 | 公式 | 预期结果 |
| --- | --- | --- | --- |
| 查询练习 B2 | P-103 的商品名 | `=XLOOKUP("P-103",商品表!$A$2:$A$6,商品表!$B$2:$B$6,"未匹配")` | 咖啡豆 |
| 查询练习 B3 | P-104 的单价 | `=VLOOKUP("P-104",商品表!$A$2:$E$6,4,FALSE)` | 150 |
| 查询练习 B4 | P-999 的库存 | `=XLOOKUP("P-999",商品表!$A$2:$A$6,商品表!$E$2:$E$6,"未匹配")` | 未匹配 |

**参数差异对照**：

| 比较点 | VLOOKUP | XLOOKUP |
| --- | --- | --- |
| 指定返回列 | 第 3 参数写列序号 | 返回数组写任意区域 |
| 精确匹配 | 要显式写 FALSE | 默认精确匹配 |
| 未找到处理 | 常配合 IFERROR | 第 4 参数直接指定 |
| 向左查找 | 不直接支持 | 查找数组与返回数组可各自指定 |

## ✅ 总结

- 两种函数的差别在参数：VLOOKUP 用"列序号"指返回哪一列，XLOOKUP 用"返回数组"指，两个数组可以独立。
- VLOOKUP 精确匹配必须写 FALSE；列序号要从查找列开始数（本课单价在第 4 列）。
- 查不到就写"未匹配"（XLOOKUP 第 4 参数），不要用 0 掩盖缺失。
- 本课产出：P-103 → 咖啡豆、P-104 → 150、P-999 → 未匹配，三题都能复核。
- 合并前先确认查找键（SKU）在主数据里唯一，否则结果不可预期。
