## 🎯 本课重点

- **重点用什么**：`FILTER`、`UNIQUE`、`SORT`（配合 `COUNTA`）
- **完成什么**：用一个 FILTER 公式得到全部 ≥500 的订单（首条 SO-003）、得到 3 个地区的去重计数、得到金额降序序列（首项 1,200）；学完能用 FILTER 提取记录、UNIQUE 去重、SORT 动态排序，并理解溢出结果

## 🧱 基础操作

- **FILTER 的语法**：`=FILTER(数据区, 条件, 无匹配时的值)`。本课数据区是 `订单!A2:C7`（6 行 × 3 列），条件区域与数据区行数一致。
- **比较条件**：`订单!C2:C7>=500` 返回一列 TRUE／FALSE 数组，配合 FILTER 提取整行。
- **UNIQUE 与 COUNTA**：`=COUNTA(UNIQUE(订单!B2:B7))`，UNIQUE 去掉重复地区，再用 COUNTA 数出种类。
- **SORT 的语法**：`=SORT(区域, 排序列序号, 排序方向)`，方向 `-1` 表示降序、`1` 表示升序。
- **溢出与留空**：动态数组结果会溢出到下方与右侧的多个单元格，溢出区域必须保持为空，否则会被 `#SPILL!` 拦截。

## 🛠 实战操作

1. **filter｜用 FILTER 提取目标订单** —— 在动态结果 D2 输入 `=FILTER(订单!A2:C7,订单!C2:C7>=500,"无")`（首条结果 SO-003，后续自动溢出）。第一个参数是整表 A2:C7，第二个参数是条件。
2. **unique｜用 UNIQUE 统计地区种类** —— 在动态结果 A3 输入 `=COUNTA(UNIQUE(订单!B2:B7))`（预期 3 个地区）。
3. **sort｜用 SORT 让金额自动降序** —— 在动态结果 A4 输入 `=SORT(订单!C2:C7,1,-1)`（首项 1,200）。`-1` 表示降序。

## ✅ 总结

- 一个公式就能出结果：FILTER 取记录、UNIQUE 去重、SORT 排序，不必复制三份辅助表。
- FILTER 的数据区是 `订单!A2:C7`，条件区域必须与数据区行数对齐，才能整行提取。
- `COUNTA(UNIQUE(订单!B2:B7))` 得到 3 个地区，`SORT(订单!C2:C7,1,-1)` 的首项是 1,200。
- 溢出区域要留空，否则动态数组无法展开。
- 你用一个公式生成一组动态结果，并理解了溢出区域需要留空。
