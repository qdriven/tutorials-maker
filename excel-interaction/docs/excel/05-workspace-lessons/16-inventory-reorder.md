## 🎯 本课重点

- **重点用什么**：`MAX`、`IF`、补货点模型（补货点＝日均销量×（补货周期＋安全天数））
- **完成什么**：在库存表 F／G／H 三列算出每个商品的补货点、建议补货量与状态——咖啡豆 96 / 16 / 补货，精品茶 48 / 0 / 观察；学完能计算补货点、建议补货量，并用 IF 输出补货或观察状态

## 🧱 基础操作

- **补货点公式**：`=C2*(D2+E2)`，日均销量 ×（补货周期＋安全天数）；三个因子在同一行，相对引用向下填充即可。
- **MAX 兜底**：`=MAX(0,F2-B2)`，库存充足时差额为负，用 `MAX` 强制不小于 0，避免出现“建议补货 −112”这种读不通的数。
- **IF 输出状态**：`=IF(G2>0,"补货","观察")`，直接引用建议补货量单元格 G2。
- **列与列的对应**：B 列当前库存、C 列日均销量、D 列补货周期、E 列安全天数，结果写在 F（补货点）、G（建议补货量）、H（状态）。
- **整行复制**：公式里全部用相对引用，从第 2 行复制到第 3、4 行即可复用同一套规则。

## 🛠 实战操作

1. **reorder-point｜先算补货点** —— 在库存表 F2 输入 `=C2*(D2+E2)`：12×(5＋3)＝96。
2. **suggest｜再算建议补货量** ——
   1. G2：`=MAX(0,F2-B2)`（96−80＝16）。MAX 防止负数。
   2. H2：`=IF(G2>0,"补货","观察")`（预期：补货）。
3. **compare｜比较不需要补货的商品** —— 精品茶第 3 行：F3＝`C3*(D3+E3)`＝48；G3＝`MAX(0,F3-B3)`＝0；H3 应为“观察”。

## ✅ 总结

- 补货点＝日均销量×（补货周期＋安全天数），咖啡豆 12×(5＋3)＝96。
- 建议补货量用 `=MAX(0,F2-B2)` 保证不为负：咖啡豆 96−80＝16，精品茶 48−200＝0。
- 状态用 `=IF(G2>0,"补货","观察")` 从建议量推出：咖啡豆“补货”，精品茶“观察”。
- 公式全部写在同一行、把第二行复制到第三、四行，就能让规则随数据更新而不是一次性结果。
- 你把库存规则写成了可更新公式：补货点＝日均销量×（补货周期＋安全天数），建议量不为负。
