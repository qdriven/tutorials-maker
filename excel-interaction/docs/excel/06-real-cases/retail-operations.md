# UCI 零售运营案例（Online Retail 样本）

> 用 20,000 行公开零售交易做一次完整复算：先定口径与清洗规则，再看月度趋势、市场结构与商品排行。

数据集：Online Retail，Daqing Chen / UCI Machine Learning Repository；本页为 `src/data/realCases.ts` 中 `retailMeta`、`retailPreview`、`retailMonthly`、`retailMarkets`、`retailProducts` 的整理。分析口径：有效行销售额 = `Quantity × UnitPrice`；单位英镑（GBP）。

## 🎯 本课重点

- **重点用什么**：SUMIFS＋COUNTIFS 按月汇总有效行销售额与发票数；数据透视表交叉核对国家／地区与商品结构；排序条形图看商品排名。
- **完成什么**：复算出样本销售额 380,271.22 英镑与 2011-11 的 51,989.37 英镑，并写出一句带数字的结论（例如“英国占样本销售额 85.05%，2011-11 是样本内销售额最高的月份”）。

## 🧱 基础操作

1. **导入原始样本**：Excel 中用“数据 → 从文本/CSV”打开 `零售真实样本_20000行.csv`；发票号等文本字段设为“文本”，避免前导零丢失或被转成科学计数。
2. **算出行销售额**：在明细表新增一列 `行销售额 = Quantity × UnitPrice`；取消单、非正数量／非正单价的行按 0 计入并单独标记为无效行。
3. **按月汇总**：用 `SUMIFS(行销售额, 月份, "2011-11", 有效标记, 1)` 得到某月销售额；发票数用 `COUNTIFS` 配合发票号去重后统计，避免重复计数。
4. **做交叉表**：选中明细表 → “插入 → 数据透视表”，把国家／地区放“行”、行销售额放“值”，得到市场结构表。
5. **交叉核对总数**：明细有效行求和应等于样本销售额 380,271.22；其中统一到商品编码的口径为 366,107.95，差额 14,163.27 要回到明细里逐条核对，不能直接抹平。

## ✅ 总结

- 口径先于计算：有效行销售额 = `Quantity × UnitPrice`，取消单与非正数量／单价行必须先剔除，再谈趋势。
- 20,000 行样本里有效行 19,560、无效行 440，样本销售额 380,271.22 英镑；缺客户 ID 行 5,078 条，做客户级分析时不能忽略。
- 2010-12 与 2011-12 是部分月份，环比要结合“期间”列解读；2011-11 的 51,989.37 英镑是样本内最高的完整月份。
- 结构上英国占 85.05%，但荷兰、澳大利亚客单价更高；头部商品份额都不到 2%，适合排序条形图而非饼图。
- 一切结论只适用于这 20,000 行公开样本，不能外推为该公司的完整经营结果。
