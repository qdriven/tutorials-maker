# task-05 · 公式输入全角自动转换（中文 IME 防错）

## 做什么

用户反馈：中文/英文输入法切换、中文符号输入容易把公式打错——IME 下输公式常见全角
符号（`＝（），：；＂０-９Ａ-Ｚ` 等），HyperFormula 解析必挂。做**公式上下文
全角→半角自动转换**：输入即转、提交即算，用户无感。

## 功能定义

1. **输入时自动转换**（formula-assist.js 输入监听）：编辑值以 `=`/`＝` 开头（公式意图）
   → 全角→半角实时转换（1:1 替换，光标天然不动）；转完继续走函数建议弹层。
2. **转换口径**：U+FF01–U+FF5E 全角块 → ASCII（=（），：；＂！＋－＊／＾％＜＞、
   全角数字/字母），全角空格 → 半角空格；**引号内字面量保真**（`＂价格，单位＂` →
   `"价格，单位"`，内层 `，` 不转）。
3. **提交路径兜底**（engine.setFormula）：写入前再过一次转换（自动化/练习路径）。
4. **文本格不受影响**：不以 = 开头的值（姓名/部门等中文文本）原样保留。

## 验证点

1. 全角公式输入自动转换并**真算**：输 `＝SUM（１２３，４５６）` → 编辑框实时变
   `=SUM(123,456)` → 回车 → E3 显示 579（实算）；`＝VLOOKUP（D2，A2:B5，2，0）` → 王五。
2. 文本格保真：B2 输 `销售部，市场部` → 不转换、原样保留。
3. 字面量保真：输 `＝＂价格，单位＂` → `="价格，单位"`（引号转、内层 `，` 留），
   提交后显示 价格，单位。
4. 回归：练习验收 ✓ 仍过、console 零报错、确定性 grep 干净。
