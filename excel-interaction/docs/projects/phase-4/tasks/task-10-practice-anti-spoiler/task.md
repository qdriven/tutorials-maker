# task-10 · 练习态防剧透 + 布局换边 + 删指南卡

## 背景（用户反馈）

用户原话：「选中手动练习之后所有的[内容]都要收起来，直到用户点击展开或者通过才展开，
然后手动练习这个放到左边栏，最下方内容可以不需要了」。

两处指代经 AskUserQuestion 澄清（带布局预览）：

- 「手动练习这个放到左边栏」= **全局统一换边**：步骤面板（验收框）在左、表格在右，
  自动播放/出片画面同样布局（用户明知出片画面会变仍选此项）。
- 「最下方内容可以不需要了」= **底部 4 张指南卡整行删除**（步骤已在折叠面板里，重复且剧透）；
  字幕条保留（未选字幕精简项）。

## 做什么

1. **练习态折叠语义（防剧透）**：进入手动练习后 4 步全部折叠（公式/参数/预期默认藏起）；
   用户点标题自行展开（peek）；**验收通过后自动全展开**（对照答案）。自动播放语义不变
   （当前步展开、完成态全折叠）。
2. **布局换边（全模式）**：`#result-area`（步骤面板/验收框）→ 左侧边栏 300px，
   `#table-area` → 右侧 1fr；字幕条仍通栏在底。
3. **删 `#guide-panel`**：4 张指南卡（HTML/CSS/渲染代码）整行移除，DOM 契约
   「三区一卡」→「两区一条」；`panelStep` 动效改挂折叠面板当前步。

## 功能

- 练习态：标题「✍ 手动练习 · 步骤提示」+ 目标 + 4 个折叠项（全关）+ 提示行；
  点标题展开单项；输入公式回车自动验收，✓ 后 4 项全展开 + 字幕「✓ 验收通过」。
- 自动播放：面板在左、表格在右；当前步展开（panelStep 入场）、其余折叠；验收回读行保留。
- 出片：布局同步变化（画面=面板左/表格右/无指南卡），plan/narration 不变。

## 验证点

1. 布局：`#result-area` bbox 在 `#table-area` 左侧；`#guide-panel` 不存在。
2. 练习态：4 步全折叠（folds=[f,f,f,f]）；点标题可展开；正确公式 → ✓ + 4 步全展开。
3. 自动播放回归：gotoStep(2) → 第 2 展开其余折叠（与 task-09 语义一致）。
4. 回归：练习真算 ✓、console 零报错、确定性 grep、`pnpm verify` EXIT=0。
5. 出片画面刷新：复用 plan.json → `pnpm video` + `pnpm qc`（新布局入片，漂移 <5%）。
