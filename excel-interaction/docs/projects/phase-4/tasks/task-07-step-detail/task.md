# task-07 · 验收框逐步展示（step-detail）

## 做什么

用户反馈：参数说明挤在底部 guide 小卡片里不够清楚——**在验收框（结果区）里逐步
展示每一个步骤会更方便让人看清楚**。把当前步的四要素 + 参数逐位说明以大字号
逐条显示在验收框顶部，随步骤推进逐步刷新；手动练习时显示练习目标/参考/参数。

## 功能定义

1. **验收框逐步展示**（#result-area 增 `#step-detail`）：当前步显示——
   标题（第 N 步 · menu）、单元格、公式、参数逐位（参数1..N + part + meaning，
   参数行仅公式步显示）、预期；步骤推进时全量刷新（随 render 状态机）。
2. **手动练习**：step-detail 显示练习目标（cell 显示 value）/参考公式/参数逐位/
   提示（回车自动验收）。
3. **空闲/完成态**：step=0 显示引导（▶ 自动播放逐步展示）；step=5 显示完成 + 
   指向下方验收回读。
4. **主题联动**：样式走主题 token（编辑风/green 都随 --accent/--soft），不引入
   第三套风格；guide 卡片的紧凑参数行保留（概览用）。

## 验证点

1. 逐步展示：gotoStep(1..4) 逐步截图/回读 `#step-detail`——第 2 步含
   `=VLOOKUP(D2,A2:B5,2,0)` 与参数 1..4 逐位（D2/A2:B5/2/0）。
2. 手动练习：practice() 后 step-detail 含 目标/参考公式/参数/提示。
3. 完成态：play() 全程 → step=5、step-detail 完成态、验收 ✓。
4. 回归：console 零报错、确定性 grep 干净、`pnpm verify` EXIT=0、
   双主题（?theme=green）渲染正常。
