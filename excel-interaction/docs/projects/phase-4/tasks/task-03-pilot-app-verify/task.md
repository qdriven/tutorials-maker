# task-03 · 试点出课与浏览器验收（验收四点）

## 做什么

用流水线生成试点课 `apps/vlookup-basic/`，起服务在浏览器真实跑完一课，
按 build-checklist **验收四点**逐条取证（截图 + 页面实测）。本 task 属 phase-4+5
合并里程碑，是「查看效果」的交付点。

## 功能定义

- `new.mjs` 生成 `apps/vlookup-basic/`（handsontable + kimi 主题）。
- 浏览器（Playwright 驱动）跑：自动播放 4 步动画 → 手动练习（输入公式 → 验收 ✓）。
- 双主题核对：kimi（契约主题）+ green（`?theme=green` 覆盖）各截图。

## 验证点（验收四点，逐条证据）

1. **4 步指南与画面对齐**：每步截图（指南卡当前步 + 焦点单元格 + 讲解卡一致）。
2. **公式真算真回读**：页面 readValue 实测 = 王五；手动练习输入 `=VLOOKUP(D2,A2:B5,2,0)`
   → 验收 ✓（值与公式双比对）。
3. **动效完整**：4 步全部走完到 done；状态机推进无卡死（截图序列 + 控制台无报错）。
4. **主题符合**：kimi / green 各一张全页截图（token 可见：背景/强调色差异）。

## 前置与依赖

- task-01（生成器与服务）；task-02（模板实现）。
