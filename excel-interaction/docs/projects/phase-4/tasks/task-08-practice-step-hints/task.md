# task-08 · 手动练习步骤提示（验收框 step hints）

## 做什么

用户反馈（贴出 4 步指南全文后）：「这部分内容也可以在验收框中展示，并且可以是一种
提示会更好，这样在手工练习的时候更清楚」。手动练习模式下，验收框展示**逐步提示**
——4 步指南（含公式/参数逐位/预期）以提示形态逐条列出，学员照着操作。

## 功能定义

1. **练习态逐步提示**（lesson.js stepDetailHTML practice 分支）：目标行（cell 显示
   value）→ 4 步提示（每步：`cell · menu` 标题 + 公式行（仅公式步）+ 参数逐位
   （公式步逐条挂，与 guide 卡同构）+ 预期行）→ 操作提示（回车自动验收）。
2. **提示形态**：区别于自动播放的"当前步细读"——练习态是**全步清单**（静态提示，
   不随操作推进），缩进分组、参数行沿用 task-06 逐位样式。
3. **自动播放态不变**（task-07 口径）：仍显示当前步四要素 + 参数。

## 验证点

1. practice() 后验收框含：目标 + 4 步提示（step 标题 ×4、公式行、参数 1..4、
   预期行）+ 操作提示；截图取证。
2. 回归：自动播放态逐步展示不变（step2 截图对照）、练习验收 ✓ 仍过、
   console 零报错、`pnpm verify` EXIT=0。

## 前置与依赖

- task-06（formulaArgs）、task-07（验收框 step-detail 挂载点）。

## 范围外

- 练习过程中逐步高亮/跟踪学员进度（静态提示即可）；录屏出片的提示文案派生。
