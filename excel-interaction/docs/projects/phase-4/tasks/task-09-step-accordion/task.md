# task-09 · 验收框全步折叠展示（accordion，非替换）

## 做什么

用户澄清（对 task-07/08 的细化）：「每一个步骤都需要在验收框展示，只是折叠的
问题，不是替换」。task-07 的逐步展示是**替换式**（只渲染当前步）——改为**全步
折叠面板**：4 步常驻验收框，当前步默认展开、其余折叠，点标题可任意展开/折叠
（折叠偏好记住）；手动练习默认全展开（提示形态）。

## 功能定义

1. **全步折叠面板**（details/summary）：4 步常驻；标题行=`N`+`cell · menu`；
   展开体=公式行（公式步）/定位说明 + 参数逐位（公式步）+ 预期行。
2. **默认折叠态**：自动播放=当前步展开（加当前标记），其余折叠；练习=全展开；
   完成/空闲=全折叠（标题仍可见）。点击切换后**记住偏好**（foldState），
   切步/重置回默认（reset 清偏好，出片确定性）。
3. **非替换**：验收回读行（验收/值/公式）保留在面板下方；guide 卡/字幕不动。

## 验证点

1. 自动播放态：4 个折叠项全在；gotoStep(2) → 第 2 项展开（含参数 1..4）、
   1/3/4 折叠；点第 3 标题 → 展开（截图取证）。
2. 练习态：4 项全展开（提示形态）+ 目标/操作提示行。
3. 回归：验收 ✓、console 零报错、确定性 grep 干净、`pnpm verify` EXIT=0。
