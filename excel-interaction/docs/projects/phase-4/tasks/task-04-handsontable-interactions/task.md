# task-04 · handsontable 模板交互增强（Excel 级编辑四件）

## 做什么

用户反馈试点课两处不像 Excel：①公式不能自动跳出；②不能像 Excel 那样选中范围操作。
经确认（路线 A），在 handsontable 模板补四项交互，八成 Excel 仿真度，试点课直接受益。

## 功能定义

1. **公式栏随选中联动**：点/选中任意格 → `#formula-echo` 自动显示该格内容
   （公式原样、字面值原样）——现状公式栏只在动画拍里更新。
2. **拖选/填充柄**：显式开启 Handsontable 选区模型（拖选范围、Shift 扩选、填充柄）。
3. **编辑公式时点选插引用**（Excel point mode）：双击进编辑态后，单击他格插入 `D2`、
   拖选区域插入 `A2:B5`（插到公式光标处，编辑不中断）。
4. **函数建议弹层**：公式编辑中输入 `=`/前缀 → 弹出函数名建议（HyperFormula 函数表
   喂数据），↑↓ 选择、Tab/Enter 插入 `FUNC(`、Esc 关闭。

## 验证点

1. 公式栏联动：点字面值格显示字面值、点公式格显示公式原文（截图）。
2. 范围拖选：鼠标拖 A2→B5 选区生效（`hot.getSelected()` 实测）；填充柄元素可见。
3. 点选插引用：编辑 E2 时拖选 A2:B5 → 编辑框值含 `A2:B5`；单击 D2 → 插入 `D2`。
4. 函数建议：输入 `=VL` → 列表含 VLOOKUP；选中插入 `VLOOKUP(`。
5. 回归：练习验收 ✓ 仍过、确定性 grep 仍干净、console 零报错。
