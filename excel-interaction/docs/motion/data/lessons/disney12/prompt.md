# 迪士尼 12 原则 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

给一个 UI 动效标注它用了哪几条迪士尼 12 原则：从"挤压拉伸、预备动作、跟随重叠、次级动作、舞台化、慢入慢出"中选 2-3 条，并说明每条的理由与实现方式。以一个按钮 hover 回弹为例：挤压拉伸用于回弹（scaleX 拉伸后回弹）、慢入慢出用于缓动曲线。要求说明原则如何服务于叙事，不要过度堆砌（2-3 条即可，堆砌反而显乱）。实现用 CSS/GSAP，并附 prefers-reduced-motion 降级。产出为一份原则标注说明（含实现代码片段）。验收：标注了所用原则、理由充分、实现正确、未过度堆砌、降级后可用。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
