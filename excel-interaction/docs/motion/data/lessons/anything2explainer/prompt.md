# 万物解释 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

请使用 anything2explainer skill，为抽象概念"缓存"制作一段解释动画。产出形态为一段可播放的动画短片，总时长 60–90 秒。动画结构必须遵循三段式：问题引入（提出缓存要解决的痛点）→ 核心机制演示（用图形化方式展示缓存命中与未命中的流程）→ 总结（一句话回扣概念）。动效类型：图形变形与流程动画，禁止使用大段文字，图形需简化到位，关键节点有清晰标注。验收标准：结构完整、图形化表达到位、标注清晰、能讲清缓存概念。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
