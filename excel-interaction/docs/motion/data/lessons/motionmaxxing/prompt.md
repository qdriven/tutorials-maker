# 动效质量打磨 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

用 motionmaxxing 对一个粗糙动效做质量打磨。产出形态：打磨前后对比报告（Markdown）+ 打磨后的 HTML demo；规模：1 个已有粗糙动效（如一个生硬的卡片入场）。请做质量打磨而非做新效果——关注细节：缓动是否达标、节奏是否自然、多元素动效是否一致、时长是否合适。记录打磨点与改进项，并把打磨前后的效果并列对照。验收标准见 checklist.md。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
