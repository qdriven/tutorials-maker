# 商业成片工具箱 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

用 motion-video-kit 工具箱跑一条 30 秒商业短片的成片流程。产出形态：1 条 30 秒成片（MP4）+ 成片流程记录；规模：30 秒、约 6–8 个镜头。请按该工具箱覆盖的成片环节逐段走：素材准备 → 节奏编排 → 渲染输出，记录每环节产物。成片偏"工程化"——关注输出规格（分辨率/帧率/码率）是否符合投放要求，成片可直接用于投放。验收标准见 checklist.md。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
