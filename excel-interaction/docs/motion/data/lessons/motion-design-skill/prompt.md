# 动效设计原则 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

使用 LottieFiles 的 motion-design-skill 对一段粗糙的按钮入场动效做设计原则评审。产出形态：一份评审文档，按 timing、easing、节奏三个维度逐条点评，并给出可落地的改进建议。时长/规模：评审覆盖一个约 500ms 的按钮入场动画。动效类型：UI 动效原则评审，不改代码，只输出评审与改进点。验收标准：timing/easing/节奏三项均有覆盖，改进建议可落地，评审有理有据，且考虑到低端设备上的降级场景。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
