# 第一个动画 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

这是我第一条动画 prompt，请严格按四要素执行。产出形态：一个独立可运行的网页动效，单个 HTML 文件，双击即可在浏览器打开。时长/规模：动效总时长 3 秒并无缝循环，全部内容收敛在单个文件内。动效类型：入场 + 循环，元素先依次入场，随后转入持续循环。验收标准：打开页面能同时看到入场段与循环段两段效果；循环点无跳帧；无外部依赖或已注明 CDN 来源；按 checklist.md 逐条验收。如果首轮有未通过项，请描述问题所在，让 Agent 迭代改进到全部通过。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
