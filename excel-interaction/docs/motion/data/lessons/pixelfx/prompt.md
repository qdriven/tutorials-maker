# 像素特效 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

用 pixelfx skill 制作一个像素风格按钮的点击爆炸特效。产出形态：一个可交互的 HTML 页面，内含一个像素风按钮和独立的爆炸特效层。时长/规模：单个特效 300-500ms，粒子 30-50 个，画面 4:3 即可。动效类型：8-bit 像素风格的粒子爆炸，带扩散、闪烁与下落，风格统一、有始有终，动画结束后回到按钮初始状态。验收标准：特效完成后按钮可再次点击复现；在不支持精细特效的浏览器下降级为简单闪烁，按钮依旧可用。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
