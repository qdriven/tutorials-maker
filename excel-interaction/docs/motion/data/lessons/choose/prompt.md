# 选 skill · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

需求：做一个产品页滚动入场动效。请基于五类选型表（网页动效 / 产品宣传片 / 口播视频 / 像素特效 / 动效原则 + 3D 横切）完成选型。产出形态：一份选型说明，写清所选 skill、选择理由、排除其余四类的原因，以及 3D 横切边界的说明。时长/规模：一次完整回答，200 字以内。动效类型：网页动效中的滚动入场（scroll-triggered entrance）。验收标准：选型落在网页动效类；理由结合需求充分；逐一说明为何排除产品宣传片、口播视频、像素特效、动效原则；并说明什么情况下才需要引入 3D 横切。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
