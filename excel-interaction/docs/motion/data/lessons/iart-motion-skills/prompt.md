# 动效 skill 合集 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

用 iart-motion-skills 合集选一个综合任务，综合运用前 14 课技能完成。产出形态：1 个综合动效 demo（网页动效 + 原则 + 手法）；规模：1 个完整页面动效（含入场 + 滚动驱动 + 至少 1 条原则 + 1 种技术手法）。请从合集里挑一个综合任务，把前 14 课学到的技能（选型、时长缓动、编排、原则、技术手法）综合运用到这个任务上，产出一个完整 demo。这是前 14 课的查漏补缺与综合演练。验收标准见 checklist.md。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
