# 动效原则库 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

用 design-motion-principles 原则库给一个产品页动效做对照审查。产出形态：审查报告（Markdown）+ 修正后的 demo；规模：审查 1 个已有产品页动效，对照 5 条以上原则。请逐条对照原则库，发现动效与原则的偏差并记录，给出修正建议，并把修正后的 demo 落进 HTML。原则库偏"原则推导与案例对照"，与 motion-design-skill 互补——本课重在对照与发现偏差。验收标准见 checklist.md。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
