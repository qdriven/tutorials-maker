# 口播视频 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

使用 video-talkcraft skill 为一段 60 秒的口播稿设计镜头序列并渲染成片。产出形态：一段可播放的 60 秒口播视频（MP4/WebM）。时长/规模：60 秒，镜头 6-10 个，随旁白节奏切换。动效类型：口播视频镜头序列 + 画面切换动效，镜头跟随旁白节奏切换，音画同步。验收标准：镜头切换卡在旁白节点上，音画同步，画面有动态运镜与动效，无静态 PPT 感，成片可直接播放。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
