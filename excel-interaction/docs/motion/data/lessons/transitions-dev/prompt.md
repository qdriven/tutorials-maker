# 页面转场 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

请使用 transitions.dev skill，为两个路由页面之间添加滑动 + 淡入过渡效果。产出形态为可运行的前端项目代码，过渡动画时长控制在 300–450 毫秒之间，保证视觉连续性，让用户感知不到"断层"。动效类型：水平滑动叠加透明度淡入，方向与路由前进/后退语义一致。请确保动画在低端设备上不闪烁，并提供 prefers-reduced-motion 降级守卫。验收标准：过渡流畅无卡顿、无闪烁、降级后页面仍可正常跳转使用。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
