# 产品宣传片 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

请使用 video-shotcraft skill，为一个产品落地页撰写一段 30 秒的产品宣传片方案。产出形态为镜头序列表，每一镜标注：主体、运镜动线、转场方式、时长（秒）。全程使用反 PPT 镜头语言：禁止静态整屏切换，镜头之间必须有推拉、横移或跟随等运动，转场必须服务于叙事节奏而非炫技。请控制总时长为 30 秒，镜头数量不少于 6 个。完成后需给出可播放的成片验收标准。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
