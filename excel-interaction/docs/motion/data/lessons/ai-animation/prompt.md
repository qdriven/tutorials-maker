# HTML动画合集 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

从 AI_Animation 效果合集中挑选 3 个动画效果进行复现。产出形态：一个 HTML 页面，包含 3 个独立分区的复现效果，每个分区附关键参数说明。时长/规模：3 个效果，每个 5-10 秒循环展示。动效类型：HTML/CSS/JS 动画复现（如粒子、渐变、3D 翻转等），尽量接近原效果。验收标准：复现效果接近原效果，每个效果记录关键参数（如时长、缓动函数、粒子数量），并提供降级守卫，防止浏览器不支持时页面崩溃。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
