# 编排与镜头 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

为一段约 30 秒的产品口播稿设计镜头序列：旁白讲到功能时镜头切到界面。要求给出 5-6 个镜头，每个镜头标注主体、动线（从哪到哪）、转场、时长。用"反 PPT"镜头——每个镜头都有生长过程（元素逐个出现、镜头推进），而不是整屏静态切换。转场为叙事服务（同主体硬切、主体变化淡入淡出、强调对比缩放），不要炫技。节奏要有卡点：镜头切换与旁白关键句对齐。产出为镜头序列表（含分镜描述）。验收：每个镜头有主体与动线、转场服务叙事、无静态整屏切换、节奏有卡点。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
