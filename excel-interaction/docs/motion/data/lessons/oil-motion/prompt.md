# 网页交互动效 · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

请使用 oil-motion skill，为一组卡片组件添加 hover 抬升和入场 stagger 动效。产出形态为前端组件代码，动效规模覆盖 3–6 张卡片。动效类型：hover 时卡片轻微抬升并带阴影变化，入场时卡片依次淡入上浮，stagger 间隔控制在 80–150 毫秒之间。动效不可喧宾夺主，以服务内容阅读为先。请确保在不支持动画的环境下有降级守卫，卡片内容仍可正常访问。验收标准：交互响应及时、动效克制、降级后内容可用、stagger 间隔合理不拖沓。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
