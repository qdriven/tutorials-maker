# 3D/WebGL · 练习 prompt

> 给 Agent 的练习指令。用四要素：产出形态、时长/规模、动效类型、验收标准。

## prompt

用 React Three Fiber 搭一个可旋转的三维卡片 demo，单页一个 Canvas，规模一个区块。动效类型：卡片随鼠标拖拽旋转，并带缓慢自动自转；须有 ambientLight 与 directionalLight 光照，卡片用 meshStandardMaterial 材质。请一句话说明为何选 R3F 而非 Three.js 原生或 Babylon.js。移动端做降级：关停自动自转或降低光照与几何体复杂度。验收标准：代码可直接运行、无缺失依赖，旋转交互流畅，光照正常。

## 使用方式

1. 装好对应 skill（见课程文档）。
2. 把上面的 prompt 发给 Agent。
3. 按 checklist.md 验收。
