# 13 · 动效质量打磨

> 这个仓库不生产新效果，而是"把 AI 生成的动效整容成设计师水准"：关键帧度量 + 打分质检——1,257 颗星，是动效质量的反向工作流。

**故事**：AI 生成的动效常常"能看但粗糙"：缓动生硬、节奏均匀、细节不一致。这个 skill 的工作流是反向的——先有素材，再度量关键帧、打分、逐项打磨。它教 Agent 像质检员一样审视已有动效，把质量从"感觉"变成可打分的清单。

**学习目标**：学完能拿一个粗糙动效做质量打磨，产出前后对比并记录改进项。

**技能**：质量打磨，关键帧度量，缓动优化，节奏调整，前后对比

**摘要**：质量打磨 = 度量 + 打分 + 逐项优化。本课拿一个粗糙动效打磨，验收打磨点明确、提升可感知、改进有记录。

## 🎯 本课重点

- **重点用什么**：动效质量的度量维度（缓动、节奏、一致性）与"度量 → 打分 → 优化"的打磨循环。
- **完成什么**：一个打磨前后的动效对比页 + 一份改进项清单。

## 🛠 实战操作

### 打磨一个粗糙动效

1. **备素材**：准备一个粗糙动效（如按钮入场：线性缓动、等间隔、无细节），作为打磨对象。
2. **度量打分**：让 Agent 按 skill 的度量维度逐项打分（缓动曲线、节奏分布、与其他组件一致性），输出得分表。
3. **逐项打磨**：按得分从低到高优化——线性改 `cubic-bezier(0.2, 0, 0, 1)`、等间隔加 stagger、补入场前的视觉准备，每项给出改动说明。
4. **前后对比**：做一页并排对比（打磨前/后），附改进项清单（改了什么、为什么）。

### 验收

1. 打磨点明确：每项改进都对应一个度量维度与得分变化，不是泛泛的"更好看了"。
2. 质量提升可感知：缓动自然、节奏有层次、与页面其他动效一致，对比页肉眼可辨。
3. 记录了改进项：每项改动有"改动内容 + 理由 + 对应维度"的记录，可复现。

## ✅ 总结

- 打磨的关键是"先度量再动手"：没有打分就没有优先级，优化会变成随机试错。
- 打磨不是重做，而是逐项修复：每项改动都对应明确的质量维度。
