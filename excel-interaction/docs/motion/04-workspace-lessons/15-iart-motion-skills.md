- **重点用什么**：合集中的综合任务与前 14 课技能的组合方式；"渲染一帧 → 截图 → 自检"的 deliver-and-verify 循环。
- **完成什么**：一个综合任务成品 + 一份说明（用了哪些课的哪些技能）。

## 🧱 基础操作

1. **装 skill**：`npx skills add iart-ai/motion-skills`（或该仓库的实际安装方式）。
2. **读 skill 文档**：装完后让 Agent 读该 skill 的 SKILL.md，理解它约束了什么（任务范围、自检循环、输出规范）。
3. **发第一条 prompt**：用四要素（产出形态、时长/规模、动效类型、验收标准）。

## 🛠 实战操作

### 选一个综合任务并综合完成

1. **选任务**：从合集挑一个综合任务（如"动态字卡 + 数据图表 + 讲解片段"），写清产出形态与验收标准。
2. **组合技能**：让 Agent 标注每个子环节对应的前序课技能（字卡 → 第 3/9 课转场，图表 → 第 5 课原则，渲染自检 → deliver-and-verify），缺哪课补哪课。
3. **deliver-and-verify**：每完成一个子环节，渲染一帧 → 截图 → 自检，不达标立即回修，再进入下一环节。
4. **汇总产出**：合并子环节产出为一个成品，附"技能使用说明"（哪些环节用了哪课的技能、为什么）。

### 验收

1. 综合运用得当：每个子环节都标注了对应的前 14 课技能，没有凭感觉硬凑。
2. 产出符合 prompt：产出形态、时长、动效类型、验收标准四要素逐条核对通过。
3. 回到 README 汇总成果：15 课的 demo 齐备，成果集完整。

- deliver-and-verify 循环是合集任务的质检底线：渲染一帧、截图、自检，再推进。
