**故事**：像素风不是把图片放大加马赛克，而是一套完整的美学约束：有限调色板、量化动作帧、复古音效。pixelfx 把 244 个游戏级特效（火焰、爆炸、魔法、天气）写成可调用的代码，并沉淀了"起草 → 渲染 → 看 → 精修"的迭代方法。本课用它做一个按钮点击爆炸特效，感受像素美学与现代动效的碰撞。

**学习目标**：学完能调出像素风特效、理解像素美学约束（调色板/帧量化/尺寸档位），并能给 Agent 写出带像素风格约束的 prompt。

**技能**：像素化滤镜，8-bit 过渡，像素粒子，精灵图导出，风格约束

**摘要**：像素特效 = 有限调色板 + 量化帧 + 复古音效；pixelfx 提供 244 个可调用特效与"起草-渲染-精修"迭代法。

## 🎯 本课重点

- **重点用什么**：像素化滤镜、8-bit 风格过渡、像素粒子三类特效，以及像素美学约束。
- **完成什么**：用像素风格做一个按钮点击爆炸特效，可验收、可降级。

## 🛠 实战操作

### 像素按钮点击爆炸

1. **给约束**：prompt 里写明"8-bit 像素风、调色板限 16 色、动作帧量化"。
2. **定产出**：产出形态为一个按钮组件，点击时在按钮上方炸开像素碎片。
3. **看渲染**：让 Agent 渲染成静态帧截图，检查像素颗粒是否统一。
4. **精修**：重复"渲染 → 看 → 改"，直到爆炸有始有终（起爆 → 扩散 → 消散）。

### 验收

1. 像素风格统一：全片共用同一调色板与像素尺寸，没有"高清碎片混入像素风"。
2. 特效有始有终：起爆、扩散、消散三段齐全，时长符合 prompt 设定。
3. 降级后仍可用：`prefers-reduced-motion` 时退化为静态高亮反馈。

## ✅ 总结

- 像素风是一套美学约束而非滤镜：有限调色板 + 量化帧 + 复古音效。
- pixelfx 的价值在于 244 个特效代码化 + "起草 → 渲染 → 看 → 精修"迭代法。
