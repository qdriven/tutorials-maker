**故事**：给口播稿配张图轮播，是 PPT 视频；让镜头跟着旁白节奏走，才是口播视频。video-talkcraft 内置 108 张动效配方卡、七层反 PPT 镜头系统与三重验收，核心是"锁在人声上"的帧级音画同步。本课用一段 60 秒口播稿走完"镜头序列 → 渲染"全流程。

**学习目标**：学完能按旁白节奏设计镜头序列、理解字级配音同步，并产出无静态 PPT 感的口播动效视频。

**技能**：口播稿拆解，镜头序列设计，音画同步，反 PPT 镜头，动效配方卡

**摘要**：口播稿 + 配音 → 动效成片；108 张动效配方卡 + 七层反 PPT 镜头系统，核心是帧级音画同步与三重验收。

## 🛠 实战操作

### 60 秒口播的镜头序列

1. **拆稿**：把 60 秒口播稿按句/意群拆成镜头单元，标注每句的起止时间（或字数 → 时长换算）。
2. **配镜头**：为每个单元选一张动效配方卡（108 张之一），镜头切换点对齐旁白换气/断句处。
3. **做同步**：让 Agent 按"字级配音同步"把动效锚点对齐到配音时间轴。
4. **渲染与验**：渲染成片，按三重验收（卡点 / 同步 / 无 PPT 感）逐项过。

### 验收

1. 镜头与旁白卡点：每次镜头切换都落在旁白断句或重音处，没有"话说一半画面先切"。
2. 音画同步：动效起止与配音时间轴对齐，字幕/强调动效随字出现。
3. 无静态 PPT 感：镜头内元素持续运动、镜头有推拉摇移，不是整段静止的图文轮播。

## ✅ 总结

- 口播视频的核心是"锁在人声上"：镜头序列对齐旁白节奏，字级配音同步。
- 七层反 PPT 镜头系统 + 108 张动效配方卡，是把"PPT 视频"升级为"口播视频"的骨架。
