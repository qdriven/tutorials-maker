# 12 · 商业成片工具箱

> 这个仓库是商业/广告成片的"全流程工具箱"：覆盖素材、节奏、输出多个环节，用独立批评者循环保证成片质量——1,330 颗星，是"成片工程化"的范本。

**故事**：商业短片不是"会动就行"：素材规格、镜头节奏、音画同步、输出参数环环相扣。这个 skill 把成片流程拆成多个环节并配质量循环（builder 与 judge 分离），让 Agent 像小型制片组一样工作，而不是一次性生成一个文件。

**学习目标**：学完能用该工具箱跑通一条 30 秒商业短片的完整成片流程，并让输出规格达标。

**技能**：成片流程，素材规格，镜头节奏，音画同步，输出验收

**摘要**：成片 = 流程 + 规格 + 质检。本课用工具箱跑一条 30 秒商业短片，验收流程完整、输出达标、成片可直接使用。

## 🎯 本课重点

- **重点用什么**：成片流程的各环节（素材、节奏、输出）与该工具箱的质量循环机制。
- **完成什么**：一条 30 秒商业短片的成片 + 一份覆盖各环节的输出规格说明。

3. **发第一条 prompt**：用四要素（产出形态、时长/规模、动效类型、验收标准）。

## 🛠 实战操作

### 跑一条 30 秒商业短片流程

1. **定需求**：给 Agent 一条商业诉求（如"30 秒产品功能短片，突出核心卖点"），并在 prompt 里写明输出规格（分辨率 1080p、帧率 30fps、MP4）。
2. **过流程**：让 Agent 按工具箱的环节清单推进——素材准备、镜头节奏、音画同步、输出渲染，每环节产出中间物。
3. **走质检**：让 Agent 扮演"批评者"角色对照质量清单自检，builder 与 judge 分离，不达标环节回修。
4. **导出成片**：确认规格与内容后输出最终 MP4，并附一份"各环节交付物 + 质检结论"的说明。

### 验收

1. 成片流程完整：素材、节奏、输出各环节都有中间物与结论，无跳步。
2. 输出规格符合要求：分辨率、帧率、时长（30 秒 ± 容差）、格式全部达标。
3. 成片可直接使用：音画同步、无黑帧/卡顿，播放一遍即可看到完整叙事。

## ✅ 总结

- 商业成片的核心是"流程 + 规格 + 质检"：工具箱的价值在于把三者固化为可执行清单。
- builder 与 judge 分离的质检循环，比一次性生成更能守住成片质量。
