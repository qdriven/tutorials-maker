### 调研方法

- 通过 GitHub API 按 stars 排序检索 Agent 动画 skill 类仓库。
- 按 stars 取 top 15，覆盖五大类（网页动效、产品宣传片、口播视频、动效原则、像素/2D）+ 3D/WebGL 横切。
