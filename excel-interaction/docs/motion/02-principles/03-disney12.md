# 03 · 迪士尼 12 原则 → UI 动效的适配

> 迪士尼 12 原则诞生于手绘动画，但其中多条可直接映射到 UI 动效。本课讲清哪些原则适用、怎么适配。

**故事**：一个按钮"挤压拉伸"后回弹，比生硬的缩放更生动。这不是 UI 规范，而是迪士尼 12 原则里的"挤压拉伸"——经典原则在数字界面依然有效。

**学习目标**：学完能说出 12 原则中哪几条适用于 UI，并给出适配后的实现方式。

**技能**：挤压拉伸、预备动作、跟随重叠、次级动作、舞台化

**摘要**：12 原则里约 6 条可直接映射 UI：挤压拉伸（回弹）、预备动作（入场前倾）、跟随重叠（延迟跟随）、次级动作（背景微动）、舞台化（焦点引导）、慢入慢出（缓动）。

## 🎯 本课重点

- **重点用什么**：12 原则中适用于 UI 的 6 条及其适配实现。
- **完成什么**：给一个 UI 动效标注它用了哪几条原则，并说明理由。

## 🧱 基础操作

1. **读 12 原则**：挤压拉伸、预备动作、跟随重叠、次级动作、舞台化、慢入慢出、弧线、立体、吸引力、动作延续、重叠动作、夸张。
2. **筛出 UI 可用项**：不是所有原则都适合 UI（如"立体"在 2D 界面意义有限）。重点记 6 条可映射的。

## 🛠 实战操作

### 六条原则 → UI 适配

| 原则 | UI 适配 | 实现示例 |
| --- | --- | --- |
| 挤压拉伸 | 按钮/图标的回弹 | `transform: scaleX(1.15) scaleY(0.9)` → `scale(1)` |
| 预备动作 | 入场前的"蓄力" | 元素入场前先反向位移 8px 再冲入 |
| 跟随重叠 | 多层次的延迟跟随 | 头像组 hover 时主头像先动，邻居 30ms 后跟随 |
| 次级动作 | 背景微动衬托主体 | 卡片 hover 时背景光晕缓慢漂移 |
| 舞台化 | 焦点引导 | 暗化背景、高亮中心，引导视线 |
| 慢入慢出 | 缓动曲线 | `ease-in-out` 或 spring 两端慢中间快 |

### 操作步骤

1. **选原则**：看动效目标——回弹用挤压拉伸，入场用预备动作，层次用跟随重叠。
2. **写实现**：用 CSS/GSAP 实现对应效果，注意 `prefers-reduced-motion` 降级。
3. **验收**：动效是否传达了"重量感""方向感""层次感"。

### 验收

1. 用了哪几条原则，是否服务于叙事。
2. 是否过度使用（原则堆砌反而显得乱）。
3. 降级后是否仍可用。

## ✅ 总结

- 12 原则里约 6 条可直接映射 UI：挤压拉伸、预备动作、跟随重叠、次级动作、舞台化、慢入慢出。
- 原则为叙事服务，不堆砌；降级后仍可用。
