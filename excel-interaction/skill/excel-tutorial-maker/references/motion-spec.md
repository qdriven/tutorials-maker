# 动效规格（motion spec）

动画课的动效规则：**确定性可重放**是硬约束——同一契约生成两次，画面必须逐帧一致
（可截图对比、可回归测试）。

## 硬约束（违反即返工）

1. **禁止随机**：无 `Math.random()`、无随机时长/延迟/顺序。
2. **禁止无限循环**：每个动效有确定的起止；页面静止后不再动。
3. **禁止依赖墙钟**：时序由步骤状态机驱动，不读 `Date.now()` 决定画面。
4. **可重放**：任何步骤可由状态直接渲染（step → DOM 全量同步），不靠"动画倒带"。

## 动效词汇

| 动效 | 用途 | 时长 |
| --- | --- | --- |
| `flash` | 公式写入/结果生成的瞬间高亮 | 300–500ms |
| `typeIn` | 公式逐字写入单元格 | 按公式长度，≤1.2s/步 |
| `focus` | 单元格聚焦/选中框移动 | 200–300ms |
| `panelStep` | 验收框折叠面板切步 | 200ms 淡入 |

- 单步动画总时长 **≤1.2s**；步间静默由 narration.gapMs 控制（默认 800ms）。
- 动效挂点（DOM 选择器约定）见 [templates/README.md](../templates/README.md)。

## 4 步指南状态机

```
idle → step1(选中) → step2(输入) → step3(确认/计算) → step4(复核) → done
```

- 每个状态是**完整画面描述**（当前单元格、公式原文、结果、步骤折叠面板内容），
  切步 = 从状态重渲染 + 一次入场动效。
- 手动练习模式（用户自己动手）与自动播放共用同一状态机，只是推进来源不同
  （用户点击 vs 计时器）。

## 与契约的关系

- 动效参数（时长、gap）可在契约 `narration` 声明节奏，但**词汇表与硬约束不进契约**——
  模板统一实现，保证跨课一致。
