# IFERROR 错误兜底：公式报错不再满屏 #N/A

> seed——契约 `courses/iferror.json` 的来源原文。转写自 excel-animation `docs/excel/03-formulas/if.md`（IFERROR 分支；探针已验证除零兜底真算）。

## 适用场景

除法遇到目标为 0、查找没查到——公式直接甩出 #DIV/0!、#N/A,报表没法看。
IFERROR 把错误换成你指定的兜底值,公式照跑、报表照看。

## 准备数据

在一张工作表(名称「看板」)里录入:

| | A | B | C | D |
| --- | --- | --- | --- | --- |
| 1 | 指标 | 实际 | 目标 | 达成率 |
| 2 | 销售额 | 92000 | 100000 | |
| 3 | 订单量 | 120 | 0 | |
| 4 | 客单价 | 640 | 0 | |

- D 列留空给公式;C3/C4 目标是 0(刻意制造除零场景)。

## 核心公式

```
=IFERROR(B2/C2,0)
```

- `B2/C2` 是**原公式**:正常算就返回它的结果(92000÷100000=0.92)。
- `0` 是**兜底值**:原公式报错(如除零 #DIV/0!)时返回它,错误不再上屏。
- 规则:先老实算,算得出给真值,算不出给兜底——比满屏 # 更可读。

## 操作步骤

1. 选中 D2;
2. 输入 `=IFERROR(B2/C2,0)`;
3. 回车确认,D2 显示 0.92(正常算出,不用兜底);
4. 把 D2 公式下拉到 D3,显示 0(C3 目标为 0,除零被兜住不报错)。

## 记

- 查找类兜底:XLOOKUP 第 4 参数直接写;VLOOKUP 靠 IFERROR 包裹。
- 口径提醒:兜底值 0 和"未匹配"含义不同,报表口径要写清楚,别一律替换成 0。
