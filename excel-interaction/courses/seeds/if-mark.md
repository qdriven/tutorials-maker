# IF 按条件返回标记：给销售额贴"大额"标签

> seed——契约 `courses/if-mark.json` 的来源原文。转写自 excel-animation `docs/excel/03-formulas/if.md`(采用其原始"大额订单"用例,单公式聚焦)。

## 适用场景

想把销售额达到某个线的订单自动标成"大额订单",其余标"常规订单"——
不要肉眼逐行判断,一条 IF 让每个数字直接读出"是还是不是"。

## 准备数据

在一张工作表(名称「订单表」)里录入:

| | A | B | C |
| --- | --- | --- | --- |
| 1 | 订单号 | 销售额 | 等级 |
| 2 | SO-1001 | 960 | |
| 3 | SO-1002 | 400 | |
| 4 | SO-1003 | 1760 | |
| 5 | SO-1004 | 1200 | |

- B 列是要判断的数字;C2 留给标记结果。
- 判断线:销售额 ≥ 1000 记"大额订单",否则"常规订单"。

## 核心公式

```
=IF(B2>=1000,"大额订单","常规订单")
```

- `B2>=1000` 是**判断条件**:布尔表达式,真或假。
- `"大额订单"` 条件为真时的返回值。
- `"常规订单"` 条件为假时的返回值——三段缺一不可。
- 先算比率再判断会除零时,用 `=IFERROR(B2/C2,0)` 兜底;多条件同真用 AND。

## 操作步骤

1. 选中 C2;
2. 输入 `=IF(B2>=1000,"大额订单","常规订单")`;
3. 回车确认,C2 显示 常规订单(960 未到线);
4. 选中 C2 查看编辑栏,回显公式原文。
