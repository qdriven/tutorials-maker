# 套餐建模四步：三档费用公式 → MIN+INDEX 挑最优

> seed——契约 `plans.json` 的来源原文。A 类场景课（4 块 16 步，链式：费用→最优）；素材 docs/excel/05-workspace-lessons/09-plans.md。（aclass-gen 程序化生成，公式已过探针）。

## 适用场景

每月 25GB 用量，三个套餐（固定费+包含量+超额单价）——把规则写成公式，算出 A=89、B=59、C=79，自动返回最优 B。

## 操作链（每块 4 步）

### 第 1 块 · B7（）

1. 选中 B7；
2. 输入 `=B2+MAX(0,$B$6-C2)*D2`；
3. 回车确认，B7 显示 89（29 + max(0,25−5)×3 = 29+60）；
4. 选中 B7 查看编辑栏。

- `B2`：固定费 29（套餐 A 行）。
- `MAX(0,$B$6-C2)`：超额量：25−5=20；没超时 MAX 兜 0，不出现负超额费。
- `$B$6`：用量 25——绝对引用，三档公式共用同一个用量格。

### 第 2 块 · B8（）

1. 选中 B8；
2. 输入 `=B3+MAX(0,$B$6-C3)*D3`；
3. 回车确认，B8 显示 59（49 + max(0,25−20)×2 = 49+10）；
4. 选中 B8 查看编辑栏。

- `B3`：固定费 49（套餐 B 行，相对引用逐行下移）。
- `C3`：包含 20GB——25−20=5GB 超额。

### 第 3 块 · B9（）

1. 选中 B9；
2. 输入 `=B4+MAX(0,$B$6-C4)*D4`；
3. 回车确认，B9 显示 79（没超量，只付固定费 79——MAX 兜底生效）；
4. 选中 B9 查看编辑栏。

- `C4`：包含 50GB——25<50 没超，MAX(0,−25)=0 只付固定费。

### 第 4 块 · B10（）

1. 选中 B10；
2. 输入 `=INDEX(A2:A4,MATCH(MIN(B7:B9),B7:B9,0))`；
3. 回车确认，B10 显示 B（59 最低，INDEX+MATCH 返回套餐名 B）；
4. 选中 B10 查看编辑栏。

- `MIN(B7:B9)`：三档费用里找最小值 59。
- `MATCH(MIN(B7:B9),B7:B9,0)`：定位最小值在第几档（0=精确匹配）。
- `A2:A4`：返回区域：套餐名——INDEX 按位置取名字。

## 记

MAX(0,…) 是建模关键：用量没超时不出现负超额费；$B$6 绝对引用让三档共用同一用量格。
