# 客户 RFM 分层：频次 → 金额 → 最近月 → 合成标签

> seed——契约 `courses/customer-rfm.json` 的来源原文。本课 4 公式 16 步；数据为教学模型（5 行 3 列客户消费记录）。（l2-gen 程序化生成，公式已过探针）。

## 适用场景

运营要按客户价值分层：先算每个人的订单频次、总消费、最近消费月，再合成'高价值'标签——一条链四步。

## 准备数据

在一张工作表（名称「客户表」）里录入：

| 客户 | 消费月 | 金额 | RFM 任务 | 结果 |
| --- | --- | --- | --- | --- |
| 张三 | 4 | 300 | F 频次（张三订单数） |  |
| 张三 | 5 | 500 | M 金额（张三总消费） |  |
| 李四 | 4 | 800 | R 最近（张三最后消费月） |  |
| 李四 | 5 | 200 | 标签（频次≥2 且金额≥500） |  |
| 李四 | 6 | 600 |  |  |

## 操作链（每块 4 步）

### 第 1 块 · E2

1. 选中 E2；
2. 输入 `=COUNTIFS(A2:A6,"张三")`；
3. 回车确认，E2 显示 2（张三有 2 笔订单）；
4. 选中 E2 查看编辑栏。

- `A2:A6`：条件区域：客户列覆盖全部记录。
- `"张三"`：条件：只数张三的行。

### 第 2 块 · E3

1. 选中 E3；
2. 输入 `=SUMIFS(C2:C6,A2:A6,"张三")`；
3. 回车确认，E3 显示 800（300+500）；
4. 选中 E3 查看编辑栏。

- `C2:C6`：求和区域：金额列（放第一参数）。
- `A2:A6`：条件区域：客户列。
- `"张三"`：条件：只加张三的行。

### 第 3 块 · E4

1. 选中 E4；
2. 输入 `=MAXIFS(B2:B6,A2:A6,"张三")`；
3. 回车确认，E4 显示 5（张三最后消费在 5 月）；
4. 选中 E4 查看编辑栏。

- `B2:B6`：求值区域：消费月列，取最大=最近。
- `A2:A6`：条件区域：客户列。
- `"张三"`：条件：只看张三的行。

### 第 4 块 · E5

1. 选中 E5；
2. 输入 `=AND(E2>=2,E3>=500)`；
3. 回车确认，E5 显示 true（2≥2 且 800≥500，可打高价值标签）；
4. 选中 E5 查看编辑栏。

- `E2>=2`：条件1：频次达标（引用第①步产出）。
- `E3>=500`：条件2：金额达标（引用第②步产出）——AND 全真才真。

## 记

第④步 AND 引用第①②步的产出（E2/E3）——维度独立算、标签合成用，RFM 的结构就藏在依赖关系里。
