# TRIM＋CLEAN 清理文本：把" 华东 "洗成可匹配的"华东"

> seed——契约 `courses/trim-clean.json` 的来源原文。转写自 excel-animation `docs/excel/03-formulas/trim-clean.md`(探针已验证:脏数据 COUNTIF=1,清洗后口径恢复)。

## 适用场景

从网页/系统导出的数据常带看不见的空格——" 华东 "和"华东"在 COUNTIFS/SUMIFS
眼里是两个不同的值,不清洗就会少数、漏加。TRIM＋CLEAN 一条公式把文本洗干净。

## 准备数据

在一张工作表(名称「订单表」)里录入(注意 B2/C8 的地区带空格,是刻意保留的脏数据):

| | A | B | C | D |
| --- | --- | --- | --- | --- |
| 1 | 订单号 | 地区 | 渠道 | 销售额 |
| 2 | SO-1001 | ` 华东 `(首尾空格) | 线上 | 960 |
| 3 | SO-1002 | 华北 | 门店 | 400 |
| 4 | SO-1003 | 华东 | 线上 | 800 |
| 5 | SO-1004 | 华南 | 线上 | 840 |
| 6 | SO-1005 | 华北 | 门店 | 1200 |
| 7 | SO-1006 | `华东 `(尾部空格) | 门店 | 240 |
| 8 | SO-1007 | 华南 | 线上 | 750 |
| 9 | 清洗结果 | | | |

- B2 是带首尾空格的脏地区;B9 留给清洗结果。
- 带空格时 `=COUNTIF(B2:B8,"华东")` 只数到 1(SO-1003);清洗后是 3。

## 核心公式

```
=TRIM(CLEAN(B2))
```

- `CLEAN(B2)` 内层:去掉不可打印字符(网页复制常见)。
- `TRIM(...)` 外层:去掉首尾空格,连续多空格压成一个。
- 嵌套顺序固定 CLEAN 在内、TRIM 在外:先去不可见字符,再收拾空格。

## 操作步骤

1. 选中 B9;
2. 输入 `=TRIM(CLEAN(B2))`;
3. 回车确认,B9 显示 华东(与"华东"完全一致,可匹配可汇总);
4. 选中 B9 查看编辑栏,回显公式原文。

## 口径对比(记)

清洗前 `=COUNTIF(B2:B8,"华东")` = 1;清洗后 = 3(SO-1001/1003/1006),
合计 960+800+240=2000——一个空格就能拆掉两组汇总,清洗必须做在汇总前。
