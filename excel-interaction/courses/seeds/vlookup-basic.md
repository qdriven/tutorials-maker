# VLOOKUP 查找匹配：按工号自动查姓名

> 试点 seed（原始教程文本）——契约 `courses/vlookup-basic.json` 的来源原文。
> 体裁照真实教程：主题 → 数据 → 公式 → 步骤。

## 适用场景

手里有一张员工表，另有一个"查询工号"的输入格，希望**输入工号就自动带出姓名**，
不用肉眼翻表。这是 VLOOKUP 最经典的用法：按第一列的值去查，返回同一行其他列的值。

## 准备数据

在一张工作表（名称「员工表」）里录入：

| | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 1 | 工号 | 姓名 | 部门 | 查询工号 | 查询姓名 |
| 2 | 1001 | 张三 | 销售部 | 1003 | |
| 3 | 1002 | 李四 | 技术部 | | |
| 4 | 1003 | 王五 | 市场部 | | |
| 5 | 1004 | 赵六 | 销售部 | | |

- A、B 两列是**查找区**：工号在第一列（VLOOKUP 只在首列找），姓名在第二列。
- D2 是**查询工号**（输入格），E2 留给查询结果。

## 核心公式

```
=VLOOKUP(D2,A2:B5,2,0)
```

四个参数的含义：

1. `D2` —— 要找的值（查询工号 1003）；
2. `A2:B5` —— 查找区域（首列必须是工号）；
3. `2` —— 返回区域里的第 2 列（姓名）；
4. `0` —— 精确匹配（**必须写 0**，不写会近似匹配出错值）。

## 操作步骤

1. **选中 E2**——这是查询结果要出现的位置。
2. **输入公式** `=VLOOKUP(D2,A2:B5,2,0)`，注意括号和逗号都是英文符号。
3. **回车确认**，E2 立即显示 `王五`——因为 D2 是 1003，表里 1003 对应王五。
4. **复核公式**：选中 E2 看编辑栏，确认公式原文是 `=VLOOKUP(D2,A2:B5,2,0)`；
   再把 D2 改成 `1001`，E2 联动变成 `张三`——结果是真算出来的，不是写死的。

## 常见错误

- 忘写第 4 个参数（精确匹配 0），查出错误结果；
- 查找区域首列不是工号，怎么查都查不到；
- 公式里的逗号/括号用了中文符号，回车直接报错。

## 进阶提示

新版 Excel 还有 XLOOKUP 函数（不用数列号、支持反向查），但 VLOOKUP 兼容性最好，
老版本也能用，入门先掌握 VLOOKUP。
