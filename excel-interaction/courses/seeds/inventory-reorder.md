# 库存补货模型三步：补货点 → 建议量 → 状态

> seed——契约 `inventory-reorder.json` 的来源原文。A 类场景课（3 块 12 步，链式）；素材 docs/excel/05-workspace-lessons/16-inventory-reorder.md。（aclass-gen 程序化生成，公式已过探针）。

## 适用场景

三个商品的库存表：按'补货点=日均×(周期+安全天)'算出咖啡豆要补 16 件并标'补货'——整行公式可复制复用。

## 准备数据

**库存**（主表）：

| 商品 | 当前库存 | 日均销量 | 补货周期 | 安全天数 | 补货点 | 建议补货量 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 咖啡豆 | 80 | 12 | 5 | 3 |  |  |  |
| 精品茶 | 200 | 8 | 4 | 2 |  |  |  |
| 手冲壶 | 40 | 6 | 7 | 3 |  |  |  |


## 操作链（每块 4 步）

### 第 1 块 · F2（）

1. 选中 F2；
2. 输入 `=C2*(D2+E2)`；
3. 回车确认，F2 显示 96（补货点 = 12×8，周期内要备的货）；
4. 选中 F2 查看编辑栏。

- `C2`：日均销量 12。
- `(D2+E2)`：补货周期 5 + 安全天数 3 = 8 天覆盖期。

### 第 2 块 · G2（）

1. 选中 G2；
2. 输入 `=MAX(0,F2-B2)`；
3. 回车确认，G2 显示 16（缺 16 件；MAX 保证不为负）；
4. 选中 G2 查看编辑栏。

- `F2-B2`：补货点 96 − 库存 80 = 16（缺口）。
- `MAX(0,`：兜底：库存充足时差为负，强制 ≥0——不出现'补 −112'。

### 第 3 块 · H2（）

1. 选中 H2；
2. 输入 `=IF(G2>0,"补货","观察")`；
3. 回车确认，H2 显示 补货（16>0，咖啡豆需补）；
4. 选中 H2 查看编辑栏。

- `G2>0`：条件：引用第②块建议量——大于 0 才补货。

## 记

MAX(0,…) 防负数：精品茶 48−200=−152 会被兜成 0 → 状态'观察'——建议补货量不能是负的。
