# 脏数据清洗四连：转数 → 洗空格 → 改编号 → 打标签

> seed——契约 `courses/dirty-data.json` 的来源原文。本课 4 公式 16 步，每步产出是下一步的输入——真实清洗流程的最小复刻。（l2-gen 程序化生成，公式已过探针）。

## 适用场景

系统导出的订单表四种脏法齐全：金额是文本、地区带空格、编号前缀不统一、缺业务标签——一条链四步治完。

| --- | --- | --- | --- | --- | --- |
| SO-1001 | 1200 |  华东  | SO-1001 | ① 文本金额转数 |  |
| SO-1002 | 800 | 华北 | SO-1002 | ② 地区清空格 |  |
| SO-1003 | 1760 |  华南  | SO-1003 | ③ 编号改前缀 |  |
| SO-1004 | 960 | 华东 | SO-1004 | ④ 按金额打标签 |  |

## 操作链（每块 4 步）

### 第 1 块 · F2

1. 选中 F2；
2. 输入 `=VALUE(B2)`；
3. 回车确认，F2 显示 1200（文本变真数，SUM 才认）；
4. 选中 F2 查看编辑栏。

- `B2`：文本形式的数字：看着像数，其实是文本（左对齐）。

### 第 2 块 · F3

1. 选中 F3；
2. 输入 `=TRIM(CLEAN(C2))`；
3. 回车确认，F3 显示 华东（空格洗净，可匹配可汇总）；
4. 选中 F3 查看编辑栏。

- `CLEAN(C2)`：内层：去掉不可打印字符。
- `TRIM(`：外层：去掉首尾空格——CLEAN 在内 TRIM 在外。

### 第 3 块 · F4

1. 选中 F4；
2. 输入 `=SUBSTITUTE(D2,"SO-","订单")`；
3. 回车确认，F4 显示 订单1001（前缀批量改写）；
4. 选中 F4 查看编辑栏。

- `D2`：原文本：要改写的原始编号。
- `"SO-"`：旧文本：要被替换掉的部分。
- `"订单"`：新文本：替换成的内容。

### 第 4 块 · F5

1. 选中 F5；
2. 输入 `=IF(F2>=1000,"大额","常规")`；
3. 回车确认，F5 显示 大额（1200≥1000，用的是第①步产出）；
4. 选中 F5 查看编辑栏。

- `F2>=1000`：判断条件：引用第①步的转数结果（链式依赖）。
- `"大额"`：条件为真的返回值。
