# SUBSTITUTE 文本替换：批量改编号前缀

> seed——契约 `courses/substitute.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

系统导出的订单号带英文前缀，报表要统一成中文编号——批量替换一条公式。

## 准备数据

在一张工作表（名称「编号表」）里录入：

| 原始编号 | 规范编号 |
| --- | --- |
| SO-1001 |  |

- B2 留给结果。

## 核心公式

```
=SUBSTITUTE(A2,"SO-","订单")
```

- `A2`：原文本：要改写的原始编号。
- `"SO-"`：旧文本：要被替换掉的部分。
- `"订单"`：新文本：替换成的内容。

## 操作步骤

1. 选中 B2；
2. 输入 `=SUBSTITUTE(A2,"SO-","订单")`；
3. 回车确认，B2 显示 订单1001；
4. 选中 B2 查看编辑栏，回显公式原文。

## 记

SUBSTITUTE 是全量替换（所有出现都换）；只想换第一个用 REPLACE(文本,旧,新,1)。
