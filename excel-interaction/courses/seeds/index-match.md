# INDEX＋MATCH 双剑合璧：向左查不受列序限制

> seed——契约 `courses/index-match.json` 的来源原文。转写自 excel-animation `docs/excel/03-formulas/`（查找专题；探针已验证 INDEX(D,MATCH) 真算）。

## 适用场景

VLOOKUP 只能从查找列向右取值——想"按商品名反查 SKU"就得把查找列放第一列重排表格。
INDEX＋MATCH 分工合作：MATCH 找到在第几行，INDEX 取那一行的值——向左向右都行。

## 准备数据

在一张工作表(名称「商品表」)里录入:

| | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | SKU | 商品 | 类别 | 单价 | 库存 | 查询单价 |
| 2 | P-101 | 冷萃咖啡 | 饮品 | 120 | 36 | |
| 3 | P-102 | 精品茶 | 饮品 | 80 | 58 | |
| 4 | P-103 | 咖啡豆 | 原料 | 200 | 24 | |
| 5 | P-104 | 保温杯 | 周边 | 150 | 42 | |
| 6 | 手冲壶单价 | | | | | |

- F2 留给查询结果;第 6 行 A6 写"手冲壶单价"只是备注行,不参与公式。

## 核心公式

```
=INDEX(D2:D5,MATCH("P-104",A2:A5,0))
```

- `MATCH("P-104",A2:A5,0)` 内层:在 SKU 列里找 P-104 在第几行(0=精确匹配),
  返回**位置序号**(第 4 个元素)。
- `INDEX(D2:D5,...)` 外层:从单价列取回该位置的值——查找列(A)和返回列(D)
  各自独立,想查哪列查哪列。

## 操作步骤

1. 选中 F2;
2. 输入 `=INDEX(D2:D5,MATCH("P-104",A2:A5,0))`;
3. 回车确认,F2 显示 150;
4. 选中 F2 查看编辑栏,回显公式原文。

## 对比 VLOOKUP(记)

- VLOOKUP 写法:`=VLOOKUP("P-104",A2:E5,4,0)`——列序号 4 在列变动时要维护;
  INDEX＋MATCH 不依赖列序号,列插删都不怕。
- 向左查:VLOOKUP 直接不行;INDEX＋MATCH 把 MATCH 指向商品列、INDEX 指向 SKU 列即可。
