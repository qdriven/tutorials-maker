# AVERAGEIF 条件均值：华东订单的平均销售额

> seed——契约 `courses/averageif.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

华东的平均单笔销售额是多少——条件筛选加求平均，一条公式完成。

## 准备数据

在一张工作表（名称「订单表」）里录入：

| 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| --- | --- | --- | --- | --- |
| SO-1001 | 华东 | 线上 | 960 |  |
| SO-1002 | 华北 | 门店 | 400 |  |
| SO-1003 | 华东 | 线上 | 800 |  |
| SO-1004 | 华南 | 线上 | 840 |  |
| SO-1005 | 华北 | 门店 | 1200 |  |

- E2 留给结果。

## 核心公式

```
=AVERAGEIF(B2:B6,"华东",D2:D6)
```

- `B2:B6`：条件区域：按地区筛行（在前！和 SUMIFS 顺序相反）。
- `"华东"`：条件：只看华东的行。
- `D2:D6`：求平均区域：被平均的销售额。

## 操作步骤

1. 选中 E2；
2. 输入 `=AVERAGEIF(B2:B6,"华东",D2:D6)`；
3. 回车确认，E2 显示 880；
4. 选中 E2 查看编辑栏，回显公式原文。

## 记

参数顺序：AVERAGEIF(条件区域, 条件, 求平均区域)——条件区域在前，和 SUMIFS 相反。
