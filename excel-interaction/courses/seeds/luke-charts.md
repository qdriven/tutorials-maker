# 跨表趋势图：月度表求和 → 副表数据画折线

> seed——契约 `courses/luke-charts.json` 的来源原文。转写自 excel-animation
> `docs/excel/05-workspace-lessons/02-luke-charts.md`（L2 跨表+图表复合，阶段 3）。
> 图表数据源用 `表名!区域` 语法（chart-layer 已支持）；中文表名单引号。

## 适用场景

明细（月度表）与汇总（汇总表）分开放：合计用跨表 SUM 算，**图表直接吃月度表数据**——
改一处，合计与图一起变。这是"数据一处、口径唯一"的报表分工。

## 准备数据

两张工作表：

**汇总**（主表，公式写在这）：

| | A | B |
| --- | --- | --- |
| 1 | 任务 | 结果 |
| 2 | 半年合计 | |

**月度**（副表，图表数据源）：

| | A | B |
| --- | --- | --- |
| 1 | 月份 | 销售额 |
| 2 | 1月 | 980 |
| 3 | 2月 | 1120 |
| 4 | 3月 | 1050 |
| 5 | 4月 | 1360 |
| 6 | 5月 | 1640 |
| 7 | 6月 | 2190 |

## 操作链（8 步 = 公式块 4 步 + 图表块 4 步）

### 第 1 块 · 半年合计（汇总!B2）

1. 选中 B2；
2. 输入 `=SUM('月度'!B2:B7)`；
3. 回车确认，B2 显示 8340；
4. 选中 B2 查看编辑栏。

### 第 2 块 · 跨表数据画折线图

5. 看参考表「月度」——6 行数据就是图表数据源；
6. 插入 → 折线图；
7. 点击折线图——画布渲染（横轴 1月→6月，取自月度表）；
8. 读图：6 月达到 2190，连续第三个月上升。

## 记

- 图表数据源语法：`月度!A2:A7`（横轴）、`月度!B2:B7`（系列）——跨表指定。
- 合计与图**同源**（都来自月度表）——口径唯一，改月度表两者同步变。
