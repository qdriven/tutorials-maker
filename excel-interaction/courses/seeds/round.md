# ROUND 四舍五入：小数保留一位

> seed——契约 `courses/round.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

计算结果一长串小数，报表里要统一保留一位——ROUND 收口。

## 准备数据

在一张工作表（名称「数据表」）里录入：

| 原始值 | 保留1位 |
| --- | --- |
| 1234.567 |  |

- B2 留给结果。

## 核心公式

```
=ROUND(A2,1)
```

- `A2`：原始数值：要修约的数。
- `1`：小数位数：保留 1 位。

## 操作步骤

1. 选中 B2；
2. 输入 `=ROUND(A2,1)`；
3. 回车确认，B2 显示 1234.6；
4. 选中 B2 查看编辑栏，回显公式原文。

## 记

ROUND 是四舍五入；ROUNDDOWN/ROUNDUP 分别是截断和进位，口径按业务定。
