# 二维查找三步：双 MATCH 交叉 → XLOOKUP 变体 → 阈值判断

## 适用场景

销售矩阵（商品×月份）要查'咖啡豆 2026-11'的值：两种写法取到 23000，再判断是否高于 2 万。

| 冷萃咖啡 | 12000 | 15000 | 18000 |
| 精品茶 | 9000 | 11000 | 13000 |
| 咖啡豆 | 18000 | 20000 | 23000 |
|  |  |  |  |
| 商品 | 咖啡豆 |  |  |
| 月份 | 2026-11 |  |  |
| INDEX＋MATCH 结果 |  |  |  |

| 是否高于2万 |  |  |  |


## 操作链（每块 4 步）

### 第 1 块 · B8（）

1. 选中 B8；
2. 输入 `=INDEX(B2:D4,MATCH(B6,A2:A4,0),MATCH(B7,B1:D1,0))`；
3. 回车确认，B8 显示 23000（第 3 行 × 第 3 列的交叉值）；
4. 选中 B8 查看编辑栏。

- `MATCH(B6,A2:A4,0)`：第一个 MATCH：商品'咖啡豆'在第 3 行。
- `MATCH(B7,B1:D1,0)`：第二个 MATCH：月份'2026-11'在第 3 列。
- `B2:D4`：数据区：INDEX(区, 行号, 列号) 取交叉格。

### 第 2 块 · B9（）

1. 选中 B9；
2. 输入 `=INDEX(XLOOKUP(B6,A2:A4,B2:D4),1,MATCH(B7,B1:D1,0))`；
3. 回车确认，B9 显示 23000（XLOOKUP 整行 + MATCH 列号，同一结果）；
4. 选中 B9 查看编辑栏。

- `XLOOKUP(B6,A2:A4,B2:D4)`：XLOOKUP 取商品整行（返回数组，第 3 参数 1=取该行）。
- `MATCH(B7,B1:D1,0)`：MATCH 找月份列号——行已由 XLOOKUP 定位。

### 第 3 块 · B10（）

1. 选中 B10；
2. 输入 `=IF(B8>20000,"高于2万元","不高于2万元")`；
3. 回车确认，B10 显示 高于2万元（引用 B8 判断，链条可复核）；
4. 选中 B10 查看编辑栏。

- `B8>20000`：条件：直接引用第①块结果（23000>20000），不重填金额。

## 记

XLOOKUP 变体里 INDEX 第 2 参数写 1（HyperFormula 口径：行数组需显式行号）；两种写法结果必须一致互为复核。
