# MAX 最大值：找出最高的那笔销售

> seed——契约 `courses/max.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

五笔里卖得最好的一笔是多少——不用逐个比，一条公式挑出最大值。

## 准备数据

在一张工作表（名称「订单表」）里录入：

| 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| --- | --- | --- | --- | --- |
| SO-1001 | 华东 | 线上 | 960 |  |
| SO-1002 | 华北 | 门店 | 400 |  |
| SO-1003 | 华东 | 线上 | 800 |  |
| SO-1004 | 华南 | 线上 | 840 |  |
| SO-1005 | 华北 | 门店 | 1200 |  |

- E2 留给结果。

## 核心公式

```
=MAX(D2:D6)
```

- `D2:D6`：取最大值的数值区域。

## 操作步骤

1. 选中 E2；
2. 输入 `=MAX(D2:D6)`；
3. 回车确认，E2 显示 1200；
4. 选中 E2 查看编辑栏，回显公式原文。

## 记

MAX 只认数字；区域里有文本不影响结果，但空区域会返回 0。
