# 文本拆分三件套：LEFT 定名 → MID 取号 → RIGHT 截区

> seed——契约 `text-date.json` 的来源原文。A 类场景课（3 块 12 步；TEXT 环节 blocked 记档）；素材 docs/excel/05-workspace-lessons/13-text-date.md。（aclass-gen 程序化生成，公式已过探针）。

## 适用场景

客户系统导出的姓名/手机/地区挤在一列（| 分隔）：三步拆成独立字段，每步都能回读核对。

## 准备数据

**客户资料**（主表）：

| 原始记录 | 客户姓名 | 手机号 | 地区 |  | 拆分任务 | 结果 |
| --- | --- | --- | --- | --- | --- | --- |
| 张三|13800138000|上海 |  |  |  |  | ① 姓名（第1段） |  |
| 李四|13900139000|北京 |  |  |  |  | ② 手机号（第2段） |  |
|  |  |  |  |  | ③ 地区（末段） |  |


## 操作链（每块 4 步）

### 第 1 块 · G2（）

1. 选中 G2；
2. 输入 `=LEFT(A2,FIND("|",A2)-1)`；
3. 回车确认，G2 显示 张三（第一个 | 之前的部分）；
4. 选中 G2 查看编辑栏。

- `FIND("|",A2)`：定位第一个分隔符位置（3）——拆分的基准。
- `LEFT(`：从左取 3−1=2 个字符 → 张三。

### 第 2 块 · G3（）

1. 选中 G3；
2. 输入 `=MID(A2,FIND("|",A2)+1,11)`；
3. 回车确认，G3 显示 13800138000（中段 11 位手机号）；
4. 选中 G3 查看编辑栏。

- `FIND("|",A2)+1`：从第一个 | 后一位起（4）。
- `MID(`：固定取 11 位——手机号定长 11。

### 第 3 块 · G4（）

1. 选中 G4；
2. 输入 `=RIGHT(A2,LEN(A2)-FIND("|",A2,FIND("|",A2)+1))`；
3. 回车确认，G4 显示 上海（第 2 个 | 之后的末段）；
4. 选中 G4 查看编辑栏。

- `FIND("|",A2,FIND("|",A2)+1)`：带起始位的 FIND：定位第 2 个 |（15）。
- `RIGHT(`：从右取 LEN−15=2 个字符 → 上海（末段不定长，用 LEN 差）。
