# LEFT 文本提取：从原始记录拆出姓名

> seed——契约 `courses/left.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

客户系统导出的记录把姓名、手机号、地区挤在一列——先把姓名拆出来。

## 准备数据

在一张工作表（名称「客户资料」）里录入：

| 原始记录 | 姓名 |
| --- | --- |
| 张三|13800138000|上海 |  |

- B2 留给结果。

## 核心公式

```
=LEFT(A2,2)
```

- `A2`：源文本：要拆的原始记录。
- `2`：取前 2 个字符：中文姓名定长 2。

## 操作步骤

1. 选中 B2；
2. 输入 `=LEFT(A2,2)`；
3. 回车确认，B2 显示 张三；
4. 选中 B2 查看编辑栏，回显公式原文。

## 记

LEFT 按字符数截取；配合 FIND 找分隔符位置，才能拆不规则文本。
