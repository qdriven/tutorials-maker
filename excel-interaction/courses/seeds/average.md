# AVERAGE 平均值：五笔销售的平均水平

> seed——契约 `courses/average.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

五笔销售额摆在面前，想知道平均卖了多少——不用一个个加再除，一条公式直接算。

## 准备数据

在一张工作表（名称「订单表」）里录入：

| 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| --- | --- | --- | --- | --- |
| SO-1001 | 华东 | 线上 | 960 |  |
| SO-1002 | 华北 | 门店 | 400 |  |
| SO-1003 | 华东 | 线上 | 800 |  |
| SO-1004 | 华南 | 线上 | 840 |  |
| SO-1005 | 华北 | 门店 | 1200 |  |

- E2 留给结果。

## 核心公式

```
=AVERAGE(D2:D6)
```

- `D2:D6`：求平均的数值区域：只算数字，文本自动跳过。

## 操作步骤

1. 选中 E2；
2. 输入 `=AVERAGE(D2:D6)`；
3. 回车确认，E2 显示 840；
4. 选中 E2 查看编辑栏，回显公式原文。

## 记

AVERAGE 只统计数值单元格；区域里混进文本会被跳过（分母也跟着变小），口径要说清楚。
