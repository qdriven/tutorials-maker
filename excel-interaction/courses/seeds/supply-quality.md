# 供应链质量四算：加权缺陷率 → 单位成本 → 简单平均 → 口径差

> seed——契约 `supply-quality.json` 的来源原文。A 类场景课（4 块 16 步，链式：加权→对照→口径差）；素材 docs/excel/05-workspace-lessons/17-supply-quality.md。（aclass-gen 程序化生成，公式已过探针）。

## 适用场景

三家供应商的产量/缺陷/运费：算出整体缺陷率 2.56%、每件运费 5.03 元，再和简单平均对照——发现 0.23 个点的口径差。

## 操作链（每块 4 步）

### 第 1 块 · B6（）

1. 选中 B6；
2. 输入 `=ROUND(SUM(C2:C4)/SUM(B2:B4),4)`；
3. 回车确认，B6 显示 0.0256（115÷4500≈2.56%，整体缺陷率）；
4. 选中 B6 查看编辑栏。

- `SUM(C2:C4)`：缺陷总数 115（先加总分子）。
- `SUM(B2:B4)`：生产总量 4500（先加总分母）——加权口径：不能直接平均三个百分比。

### 第 2 块 · B7（）

1. 选中 B7；
2. 输入 `=ROUND(SUM(E2:E4)/SUM(D2:D4),4)`；
3. 回车确认，B7 显示 5.0278（18100÷3600 元/件）；
4. 选中 B7 查看编辑栏。

- `SUM(E2:E4)`：运输总成本 18100。
- `SUM(D2:D4)`：出货总量 3600——总成本÷总量=每件运费。

### 第 3 块 · B8（）

1. 选中 B8；
2. 输入 `=ROUND(AVERAGE(F2:F4),4)`；
3. 回车确认，B8 显示 0.0233（简单平均，供与加权对照）；
4. 选中 B8 查看编辑栏。

- `AVERAGE(F2:F4)`：三家缺陷率的简单平均（0.02/0.04/0.01）——对照口径。

### 第 4 块 · B9（）

1. 选中 B9；
2. 输入 `=ROUND(B6-B8,4)`；
3. 回车确认，B9 显示 0.0023（两种口径差 0.23 个百分点——大供应商权重更高）；
4. 选中 B9 查看编辑栏。

- `B6-B8`：加权 0.0256 − 简单 0.0233（引用第①③块产出）。

## 记

缺陷率列（F）是各行缺陷数÷产量（已算好供对照）——加权与简单的差说明：量大的供应商对整体影响更大。
