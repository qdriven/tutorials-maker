## 操作链（每块 4 步）

### 第 1 块 · H2（）

1. 选中 H2；
2. 输入 `=IF(AND(C2>0,D2>0),1,0)`；
3. 回车确认，H2 显示 1（数量2>0 且单价3>0，首行有效）；
4. 选中 H2 查看编辑栏。

- `C2>0`：条件1：数量为正（-71 的退货行不过）。
- `D2>0`：条件2：单价为正——AND 全真才判有效。

### 第 2 块 · H3（）

1. 选中 H3；
2. 输入 `=UPPER(TRIM(B6))`；
3. 回车确认，H3 显示 90200D（小写编码统一为大写）；
4. 选中 H3 查看编辑栏。

- `TRIM(B6)`：内层：去空格（B6 原文 90200d 小写）。
- `UPPER(`：外层：统一大写——商品编码规范化。

### 第 3 块 · H4（）

1. 选中 H4；
2. 输入 `=SUMIFS(E2:E11,F2:F11,1)`；
3. 回车确认，H4 显示 241（8 个有效行合计，排除 2 个负数量行）；
4. 选中 H4 查看编辑栏。

- `E2:E11`：求和区域：行销售额（负数量行已预置 0）。
- `F2:F11`：条件区域：Valid 标记列（就是按①的逻辑逐行算的）。
- `1`：条件：只加有效行——退货/异常行被排除。

### 第 4 块 · H5（）

1. 选中 H5；
2. 输入 `=COUNTIFS(F2:F11,1)`；

- `F2:F11`：计数区域：Valid 列。
