## 操作链（每块 4 步）

### 第 1 块 · F2（）

1. 选中 F2；
2. 输入 `=UPPER(TRIM(A2))`；
3. 回车确认，F2 显示 CP002（空格与小写一次洗净）；
4. 选中 F2 查看编辑栏。

- `TRIM(A2)`：内层：去首尾空格（A2 原文带空格小写）。
- `UPPER(`：外层：统一大写——商品编码规范化第一步。

### 第 2 块 · F3（）

1. 选中 F3；
2. 输入 `=IF(OR(C2="线上",C2="门店"),1,0)`；
3. 回车确认，F3 显示 1（C2=线上，OR 成立判有效）；
4. 选中 F3 查看编辑栏。

- `C2="线上"`：条件1：线上渠道。
- `C2="门店"`：条件2：门店渠道——OR 任一成立即有效。

### 第 3 块 · F4（）

1. 选中 F4；
2. 输入 `=SUMIFS(D2:D9,B2:B9,"华东")`；
3. 回车确认，F4 显示 3050（华东四笔订单合计）；
4. 选中 F4 查看编辑栏。

- `D2:D9`：求和区域：销售额列。
- `B2:B9`：条件区域：地区列。
- `"华东"`：条件：只加华东——960+800+240+1050。

### 第 4 块 · 跨表趋势图

5. 看参考表「月度」——6 行数据就是图表数据源；
6. 插入 → 折线图；
7. 点击折线图——画布渲染；
8. 读图：6 月达到 2190，连续第三个月上升。
