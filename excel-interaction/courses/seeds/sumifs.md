# SUMIFS 按条件求和：只算华东＋线上

> seed——契约 `courses/sumifs.json` 的来源原文。转写自 excel-animation `docs/excel/03-formulas/sumifs.md`(口径以配套 CSV 为准:8 行明细取前 7 行,销售额列为 D)。

## 适用场景

手里有一张订单明细(地区、渠道、销售额),想知道"华东＋线上卖了多少"——
不要手工筛选后相加,一条公式直接算出;改条件就换口径。

## 准备数据

在一张工作表(名称「订单表」)里录入:

| | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 1 | 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| 2 | SO-1001 | 华东 | 线上 | 960 | |
| 3 | SO-1002 | 华北 | 门店 | 400 | |
| 4 | SO-1003 | 华东 | 线上 | 800 | |
| 5 | SO-1004 | 华南 | 线上 | 840 | |
| 6 | SO-1005 | 华北 | 门店 | 1200 | |
| 7 | SO-1006 | 华东 | 门店 | 240 | |
| 8 | SO-1007 | 华南 | 线上 | 750 | |

- D 列是要按条件加总的数字区(D2:D8);E2 留给结果。
- 条件一对一对写:地区列(B)=华东,渠道列(C)=线上。

## 核心公式

```
=SUMIFS(D2:D8,B2:B8,"华东",C2:C8,"线上")
```

- `D2:D8` 是**求和区域**:被加总的销售额(永远放第一参数)。
- `B2:B8,"华东"` 第一对条件:地区列等于"华东"。
- `C2:C8,"线上"` 第二对条件:渠道列等于"线上"。
- 华东＋线上的行:SO-1001(960)、SO-1003(800)、SO-1006 是门店不计——合计 **960＋800＝1760**。

## 操作步骤

1. 选中 E2;
2. 输入 `=SUMIFS(D2:D8,B2:B8,"华东",C2:C8,"线上")`;
3. 回车确认,E2 显示 1760;
4. 选中 E2 查看编辑栏,回显公式原文。
