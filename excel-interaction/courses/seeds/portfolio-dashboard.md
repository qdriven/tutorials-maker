# 跨表看板三连：直引利润表 → 区域合计 → 链式判定

> seed——契约 `courses/portfolio-dashboard.json` 的来源原文。转写自 excel-animation
> `docs/excel/05-workspace-lessons/10-portfolio-dashboard.md`（L2 跨表旗舰，阶段 3）。
> 中文表名在公式里必须带单引号：`='利润表'!B2`（HyperFormula 实测口径）。

## 适用场景

看板与明细分表管理：**利润表**单独维护（改数只改一处），**看板**只管取数与判定。
本课三步：跨表直引算比率 → 跨表区域一次加总 → 链式 IF 用前一步产出做判断。

## 三步操作链（每步 4 小节，共 12 步）

### 第 1 块 · 净利润率（看板!B2）

1. 选中 B2；
2. 输入 `='利润表'!B4/'利润表'!B2`；
3. 回车确认，B2 显示 0.15；
4. 选中 B2 查看编辑栏。

### 第 2 块 · 三表合计（看板!B3）

1. 选中 B3；
2. 输入 `=SUM('利润表'!B2:B4)`；
3. 回车确认，B3 显示 1770000；
4. 选中 B3 查看编辑栏。

### 第 3 块 · 健康判定（看板!B4）

1. 选中 B4；
2. 输入 `=IF(B2>=0.1,"健康","预警")`；
3. 回车确认，B4 显示 健康（引用第①块的 B2）；
4. 选中 B4 查看编辑栏。

## 记

- 中文表名**必须单引号**：`='利润表'!B2`；英文表名可省（`Sheet2!B2`）。
- 第③块引用第①块产出（B2）——看板内部也有链式依赖，顺序不能乱。
- 改利润表任何一格，看板三格全部自动刷新——分表管理的全部意义。
