# SUM 求和：把一片区域加总

> 第二门课 seed（原始教程文本）——契约 `courses/sum-basic.json` 的来源原文。
> 体裁照真实教程：主题 → 数据 → 公式 → 步骤。

## 适用场景

手里有一列数字（月度销售额），想在旁边**自动算出总数**，不用心算或计算器。
这是 SUM 最经典的用法：给一片区域，把里面的数字全部加起来。

## 准备数据

在一张工作表（名称「月度数据」）里录入：

| | A | B | C |
| --- | --- | --- | --- |
| 1 | 月份 | 销售额 | 合计 |
| 2 | 1月 | 1200 | |
| 3 | 2月 | 1500 | |
| 4 | 3月 | 900 | |

- B 列是**要加总的数字区**；C2 留给合计结果。

## 核心公式

```
=SUM(B2:B4)
```

- `B2:B4` 是**求和区域**：从 B2 到 B4 的所有数字一起加。

## 操作步骤

1. 选中 C2；
2. 在输入框输入 `=SUM(B2:B4)`；
3. 回车确认，C2 显示 3600；
4. 选中 C2 查看编辑栏，回显公式原文。
