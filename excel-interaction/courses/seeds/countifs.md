# COUNTIFS 按条件计数：数出华北大额订单

> seed——契约 `courses/countifs.json` 的来源原文。转写自 excel-animation `docs/excel/03-formulas/countifs.md`(口径以配套 CSV 为准)。

## 适用场景

想知道"华北且销售额不低于 1000 的订单有几笔"——不要手工数,
一条公式数出满足多个条件的记录行数;条件成对追加,一次写完。

## 准备数据

在一张工作表(名称「订单表」)里录入:

| | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 1 | 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| 2 | SO-1001 | 华东 | 线上 | 960 | |
| 3 | SO-1002 | 华北 | 门店 | 400 | |
| 4 | SO-1003 | 华东 | 线上 | 800 | |
| 5 | SO-1004 | 华南 | 线上 | 840 | |
| 6 | SO-1005 | 华北 | 门店 | 1200 | |
| 7 | SO-1006 | 华东 | 门店 | 240 | |
| 8 | SO-1007 | 华南 | 线上 | 750 | |

- 条件区域 B 列(地区)、D 列(销售额);E2 留给计数结果。
- 华北有 2 笔(SO-1002 400、SO-1005 1200),只有 1200 达到 ≥1000。

## 核心公式

```
=COUNTIFS(B2:B8,"华北",D2:D8,">=1000")
```

- `B2:B8,"华北"` 第一对条件:地区列等于"华北"。
- `D2:D8,">=1000"` 第二对条件:销售额不小于 1000(比较条件写成字符串)。
- 只写一个条件时等价于 COUNTIF;COUNTIFS 数的是**行**,重复订单号会被重复计数。

## 操作步骤

1. 选中 E2;
2. 输入 `=COUNTIFS(B2:B8,"华北",D2:D8,">=1000")`;
3. 回车确认,E2 显示 1;
4. 选中 E2 查看编辑栏,回显公式原文。
