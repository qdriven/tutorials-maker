# MIN 最小值：找出最低的那笔销售

> seed——契约 `courses/min.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

最差的一笔是多少——MIN 和 MAX 一配对，销售区间就出来了。

## 准备数据

在一张工作表（名称「订单表」）里录入：

| 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| --- | --- | --- | --- | --- |
| SO-1001 | 华东 | 线上 | 960 |  |
| SO-1002 | 华北 | 门店 | 400 |  |
| SO-1003 | 华东 | 线上 | 800 |  |
| SO-1004 | 华南 | 线上 | 840 |  |
| SO-1005 | 华北 | 门店 | 1200 |  |

- E2 留给结果。

## 核心公式

```
=MIN(D2:D6)
```

- `D2:D6`：取最小值的数值区域。

## 操作步骤

1. 选中 E2；
2. 输入 `=MIN(D2:D6)`；
3. 回车确认，E2 显示 400；
4. 选中 E2 查看编辑栏，回显公式原文。

## 记

MIN/MAX 配对最常见：先看区间，再看平均，数据轮廓就有了。
