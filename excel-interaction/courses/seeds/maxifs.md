# MAXIFS 条件最大：华北最高的订单

> seed——契约 `courses/maxifs.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

华北最高的订单金额是多少——先按地区筛，再取最大值，一条公式两步做完。

## 准备数据

在一张工作表（名称「订单表」）里录入：

| 订单号 | 地区 | 渠道 | 销售额 | 结果 |
| --- | --- | --- | --- | --- |
| SO-1001 | 华东 | 线上 | 960 |  |
| SO-1002 | 华北 | 门店 | 400 |  |
| SO-1003 | 华东 | 线上 | 800 |  |
| SO-1004 | 华南 | 线上 | 840 |  |
| SO-1005 | 华北 | 门店 | 1200 |  |

- E2 留给结果。

## 核心公式

```
=MAXIFS(D2:D6,B2:B6,"华北")
```

- `D2:D6`：求值区域：从中取最大值的数。
- `B2:B6`：条件区域：按地区筛行，与求值区域同高。
- `"华北"`：条件：只看华北的行。

## 操作步骤

1. 选中 E2；
2. 输入 `=MAXIFS(D2:D6,B2:B6,"华北")`；
3. 回车确认，E2 显示 1200；
4. 选中 E2 查看编辑栏，回显公式原文。

## 记

MAXIFS 与 SUMIFS/COUNTIFS 同族：条件区域与求值区域必须同高；单条件场景不用数组公式。
