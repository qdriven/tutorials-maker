# VALUE 文本转数：文本金额变成可算的数

> seed——契约 `courses/value.json` 的来源原文。转写自 excel-animation docs/excel（批量三，程序化生成；公式已过探针）。

## 适用场景

从系统粘过来的金额是文本——SUM 加不上它，VALUE 转一次就恢复可算。

## 准备数据

在一张工作表（名称「金额表」）里录入：

| 文本金额 | 数值金额 |
| --- | --- |
| 1200 |  |

- B2 留给结果。

## 核心公式

```
=VALUE(A2)
```

- `A2`：文本形式的数字：看着像数，其实是文本（左对齐）。

## 操作步骤

1. 选中 B2；
2. 输入 `=VALUE(A2)`；
3. 回车确认，B2 显示 1200；
4. 选中 B2 查看编辑栏，回显公式原文。

## 记

判断类型看对齐：数字默认右对齐、文本左对齐；ISNUMBER() 可以程序化判断。
