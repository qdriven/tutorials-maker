# 合并查询三连：XLOOKUP 跨表带价 → 计算列 → 有效标记

> seed——契约 `power-query.json` 的来源原文。A 类场景课（3 块 12 步，跨表+链式）；素材 docs/excel/05-workspace-lessons/07-power-query.md。（aclass-gen 程序化生成，公式已过探针）。

## 适用场景

订单表只有 SKU 没有单价，商品表才有价——三步把单价跨表带进来、算出销售额、标出有效行。

## 准备数据

**订单**（主表）：

| 订单号 | SKU | 数量 | 单价 | 销售额 | 有效标记 |
| --- | --- | --- | --- | --- | --- |
| SO-1001 | P-101 | 8 |  |  |  |
| SO-1002 | P-103 | 4 |  |  |  |
| SO-1003 | P-102 | 3 |  |  |  |

**商品表**（副表）：

| SKU | 商品 | 类别 | 单价 | 库存 |
| --- | --- | --- | --- | --- |
| P-101 | 冷萃咖啡 | 饮品 | 120 | 36 |
| P-102 | 精品茶 | 饮品 | 80 | 58 |
| P-103 | 咖啡豆 | 原料 | 200 | 24 |
| P-104 | 保温杯 | 周边 | 150 | 42 |
| P-105 | 手冲壶 | 器具 | 260 | 12 |

## 操作链（每块 4 步）

### 第 1 块 · D2（）

1. 选中 D2；
2. 输入 `=XLOOKUP(B2,'商品表'!$A$2:$A$6,'商品表'!$D$2:$D$6,"未匹配")`；
3. 回车确认，D2 显示 120（从商品表带出 P-101 单价）；
4. 选中 D2 查看编辑栏。

- `B2`：查找值：本行 SKU（相对引用，向下填充自动跟着走）。
- `'商品表'!$A$2:$A$6`：查找数组：商品表 SKU 列（$ 锁定，中文表名单引号）。
- `'商品表'!$D$2:$D$6`：返回数组：单价列——与查找数组分离，合并即带价。

### 第 2 块 · E2（）

1. 选中 E2；
2. 输入 `=C2*D2`；
3. 回车确认，E2 显示 960（8×120，计算列随源数据更新）；
4. 选中 E2 查看编辑栏。

- `C2`：数量：本行 8。
- `D2`：单价：第①块 XLOOKUP 带回的 120（链式依赖）。

### 第 3 块 · F2（）

1. 选中 F2；
2. 输入 `=IF(OR(C2<=0,D2<=0),0,1)`；
3. 回车确认，F2 显示 1（数量 8、单价 120 都为正，行有效）；
4. 选中 F2 查看编辑栏。

- `C2<=0`：条件1：数量非正（退货行）。
- `D2<=0`：条件2：单价非正——OR 任一成立即判无效。

## 记

第②块引用第①块的 D2（链式依赖）——合并完才能计算，计算完才能校验，顺序即数据管道。
