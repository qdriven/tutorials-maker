# 疾速靶场 · 60 秒射击挑战

单人射击小游戏：**60 秒内射中目标的总得分**作为成绩，目标速度分 5 个层级，**越快的目标分值越高**。

## 运行

无需构建、无外部依赖，直接用浏览器打开：

```
shooting-game/index.html
```

## 规则

| 层级 | 颜色 | 相对速度 | 半径 | 命中得分 | 出现权重 |
| ---- | ---- | -------- | ---- | -------- | -------- |
| Lv.1 | 蓝 `#38bdf8` | 70 px/s  | 46px | 10 分 | 28% |
| Lv.2 | 绿 `#4ade80` | 125 px/s | 40px | 20 分 | 26% |
| Lv.3 | 黄 `#facc15` | 190 px/s | 34px | 30 分 | 20% |
| Lv.4 | 橙 `#fb923c` | 265 px/s | 28px | 40 分 | 15% |
| Lv.5 | 红 `#f87171` | 350 px/s | 23px | 50 分 | 11% |

- 一局 60 秒，点击 / 触屏射击，命中率与命中数实时显示
- 目标从屏幕四边飞入，越快的目标越小、越稀少，风险与回报对等
- 刷怪间隔随时间从 0.95s 渐进收紧到 0.5s；同屏目标上限 9 个
- 最高分记录在 `localStorage`（键 `shooter-best-score`）
- 快捷键：`空格` / `Enter` 开始或重开

## 实现

单文件 HTML5 Canvas（`index.html`），requestAnimationFrame + 帧间隔驱动：

- 速度按屏宽缩放（`speedScale`，基准 1000px），大小屏难度一致
- WebAudio 现场合成音效（命中/脱靶/开局/结算），无音频资源文件
- 命中判定带 5px 容差，命中反馈为粒子爆裂 + 得分飘字
- 脚本末尾暴露 `window.__game` 调试钩子（`start` / `shoot` / `debugSpawn`），供自动化测试使用
