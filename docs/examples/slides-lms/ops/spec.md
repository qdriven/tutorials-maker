# spec.md —— Slides 教学网站（需求规约，EARS 记法）

> 来源：一句话需求「一个 Slides 教学网站：左侧章节导航，中间为教学幻灯片展示区（上方教学内容、下方详细内容），右侧为提问区，学习者可输入问题并获得解答。后端使用 PostgreSQL 持久化课程、章节、幻灯片与问答数据。」
> 状态：已通过 clarify 门禁（无未决问题）

## 用户故事
- 作为学习者，我要在左侧看到课程下的章节列表，以便切换学习内容
- 作为学习者，我要在中间区域看到当前幻灯片的标题与内容（上方）及详细讲解（下方），以便按页学习
- 作为学习者，我要在右侧提问并得到解答，且问答被保存，以便复习

## 统一语言（Ubiquitous Language）
| 术语 | 定义 |
|---|---|
| Course（课程） | 聚合根，包含若干 Chapter |
| Chapter（章节） | 属于一个 Course，包含若干 Slide，有序 |
| Slide（幻灯片） | 属于一个 Chapter，含标题/教学内容/详细内容，有序 |
| QaEntry（问答） | 学习者问题 + 系统解答，关联 Course |

## 验收标准（EARS）
1. WHEN 页面加载完成 THE SYSTEM SHALL 在左侧展示首门课程的章节列表，并默认选中第一个章节的第一张幻灯片
2. WHEN 学习者点击某章节 THE SYSTEM SHALL 在中间上方展示该章节第一张幻灯片的教学内容，并在下方展示其详细内容
3. WHEN 学习者在中间区域点击"上一页/下一页" THE SYSTEM SHALL 按幻灯片顺序切换并同步上方与下方内容
4. WHEN 学习者在右侧输入问题并提交 THE SYSTEM SHALL 返回一条解答，并将问答持久化到 PostgreSQL
5. WHEN 学习者重新打开页面 THE SYSTEM SHALL 能从数据库读回历史问答列表
6. WHEN 后端 API 不可达 THE SYSTEM SHALL 在前端降级展示内置种子课程数据，且界面不报错

## 非目标（Out of Scope）
- 用户登录/权限、LLM 真实解答（本版用关键词匹配占位，可替换）、幻灯片编辑器、移动端适配
