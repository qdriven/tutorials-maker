# 01 · 页面布局与信息架构

> 目标：让“找资源”这件事像翻一本编得不错的目录，而不是在一个后台管理系统里筛选数据。

## 1. 先定内容模型，再定页面

布局的混乱通常不是栅格问题，而是内容模型没定。建议先把实体拆成下面六类：

| 实体 | 说明 | 关键字段 |
|---|---|---|
| **Module 模块** | 稳定的一级主题，4–6 个即可 | `no`、`name`、`slug`、`intro`、`cover`、`order` |
| **Collection 合集** | 编辑人工策展的一组资源，像“一期专题” | `issue_no`、`title`、`dek`、`curator`、`cover`、`resource_ids`、`updated_at` |
| **Resource 资源** | 外部课程 / 文章 / 视频 / 工具 / 书 / 播客 | `title`、`url`、`source`、`format`、`level`、`duration`、`language`、`price`、`summary`、`why_curated`、`added_at`、`last_checked` |
| **Lesson 课程 / 教程** | 站内原创内容，和外部资源分开 | `title`、`slug`、`module`、`content`、`toc`、`updated_at` |
| **Tag 标签** | 横向主题 / 技能，用于交叉浏览 | `name`、`slug` |
| **Source 来源** | 机构 / 作者 / 站点 | `name`、`url`、`logo` |

关系：

```
Module 1 ── N Collection
Module 1 ── N Lesson
Collection N ── N Resource
Resource  N ── N Tag
Source    1 ── N Resource
```

两个容易踩的坑：

- **不要把“外部课程”和“站内教程”都叫 Course。** 外部课程是 `Resource`，只能摘要 + 外链；站内教程是 `Lesson`，有正文、目录和阅读进度。两者的详情页结构完全不同。
- **不要只靠 Tag 组织内容。** Tag 是横向的，Module 和 Collection 才是主路径。用户先说“我想看 AI 素养”，再决定“课程还是文章”。

## 2. 信息架构与导航

```
首页
├─ 模块 / Modules（4–6 个）
│  └─ 模块页
│     ├─ 子主题
│     ├─ 精选合集
│     ├─ 全部资源（模块内筛选）
│     └─ 站内教程
├─ 合集 / Collections（期刊式）
│  └─ 合集详情（资源清单）
├─ 资料库 / Library（全量索引 + 筛选 + 搜索）
│  └─ 资源详情
├─ 教程 / Lessons（站内原创）
│  └─ 阅读页
├─ 收藏 / Saved（本地优先，登录后同步）
└─ 关于 / About（编辑准则、提交资源、RSS）
```

顶部导航只放 5 个一级项：

`模块 · 合集 · 资料库 · 教程 · 关于`

右侧固定放：搜索（⌘K）、收藏、主题切换。不要在导航里塞“登录/注册”大按钮，这不是 SaaS。

URL 结构：

```
/modules/[slug]
/collections/[slug]
/library?module=ai&format=course&level=beginner&sort=newest
/resources/[slug]
/lessons/[slug]
/saved
/about
/submit
```

`/resources/[slug]` 用稳定 slug，不要用外部 URL 做 slug；外部链接会变，slug 不能跟着变。旧 slug 301 到新 slug。

### 2.1 四种布局模式，先选一个主模式

| 模式 | 代表 | 适合 | 不适合 | 我们的用法 |
|---|---|---|---|---|
| **画廊优先** | Minimal Gallery、Siteinspire、Minimalissimo | 视觉发现、看截图、找灵感 | 元数据多、需要比较的资源 | 作为资料库的“画廊视图”，不做主模式 |
| **目录 / 索引优先** | 图书馆目录、Are.na 频道、Minimal Gallery 的列表 | 扫读、比较、按条件筛选、人工策展 | 纯视觉型内容 | **主模式**：资料库、首页最新收录、模块资源列表 |
| **课程平台** | Maven、Brilliant、Coursera | 有顺序的课程、进度、练习 | 外部资源聚合、跨来源比较 | 只用于站内 `Lesson` 阅读页 |
| **工作台 / Dashboard** | LMS 后台、Notion 数据库 | 管理内容、看统计 | 公开内容浏览 | 不用；编辑后台另做 |

结论：**目录/索引优先 + 画廊作为可选视图 + 课程平台只用于教程阅读页。** 这决定了首页、资料库、合集、详情页都以“文字行 + 元数据 + 细线”为骨架，而不是卡片墙。

## 3. 六个核心页面模板（+ 收藏页简版）

> 下面的线框只表达区块关系和信息优先级，不追求字符级对齐；中英文混排在不同字体下宽度不同。

### 3.1 首页：期刊封面 + 目录

**目标：** 10 秒内让用户知道“这里有什么、谁在选、从哪开始”。

**区块顺序：**

1. 顶部导航（64px，sticky，底部 1px 线）
2. Hero：左侧一句主张 + 搜索 + 三条路径；右侧“本期专题”卡片
3. 模块索引（编号列表，不是卡片）
4. 最新收录（索引列表，可切换画廊）
5. 精选合集（一大两小，非对称）
6. 编辑手记 + 邮件订阅
7. 页脚（模块 / 合集 / 资料库 / 教程 / 关于 / 提交 / RSS）

**线框：**

```text
└─────────────────────────────────────────────────────────────────────┘
```

**规格：**

- Hero 用 12 栏的 `7 / 5` 分栏，最小高度 480px；不要做居中大标题。
- 主标题 `clamp(44px, 6vw, 84px)`，衬线，最多两行；中文每行控制在 8–12 字。
- 搜索框宽 `min(480px, 100%)`，高 52px，1px 边框，2px 圆角。
- 三条路径是文字链接，不是三张图标卡。
- 模块索引用编号行：`01  模块名  资源数 · 一句话  →`，行高 72px，1px 分隔线。比卡片更紧凑，也更像“目录”。
- 最新收录默认 5 行，行高 64px；行内显示编号、标题、格式、难度、时长、日期。
- 合集区用 `6 / 3 / 3` 非对称分栏：第一张是“本期”，后两张是过往；不要三等分，三等分会削弱主次。
- 区块垂直间距：桌面 96px，平板 64px，手机 48px。

**为什么这样排：**

- Hero 的任务是“表明这是一份人工策展的索引”，不是“卖产品”；所以主张 + 搜索优先，按钮其次。
- 本期专题负责建立编辑身份；模块索引负责可扩展；最新收录负责证明“还在更新”。
- 首页不放“用户数 / 课程数 / 好评率”这类假大空数据；如果放，只放真实可核对的数字。

### 3.2 模块页：一个主题的完整入口

**目标：** 让用户在一个主题里完成“了解范围 → 看精选 → 浏览全部”。

**区块顺序：**

1. 模块头部：编号 + 名称 + 一句话介绍 + 统计（资源数 / 合集数 / 更新时间）
2. 子主题 chips
3. 精选合集（2–3 个）
4. 全部资源（带筛选，模块范围锁定）
5. 站内教程（如果有）
6. 相关模块

**线框：**

```text
┌ 模块 01 · AI 素养 ─────────────────────────────────────────────┐
│ 从“会用工具”到“能在课堂里设计 AI 学习体验”。                     │
│ 24 个资源 · 3 个合集 · 更新于 2026-11-02                        │
│ [ 订阅模块 ] [ 复制链接 ]                                        │
├ 子主题 ────────────────────────────────────────────────────────┤
│ 基础概念   提示词   课堂活动   评估   伦理                        │
├ 精选合集 ──────────────────────────────────────────────────────┤
│ [CollectionCard]   [CollectionCard]   [CollectionCard]          │
├ 全部资源 ──────────────────────────────────────────────────────┤
│ [FilterBar]                                                     │
│ [ResourceRow × N]                                               │
│ [分页]                                                          │
├ 站内教程 ──────────────────────────────────────────────────────┤
│ [LessonCard × N]                                                │
├ 相关模块 ──────────────────────────────────────────────────────┤
│ 学习科学 →    课程与教学设计 →                                  │
└────────────────────────────────────────────────────────────────┘
```

**规格：**

- 模块头部和首页 Hero 用同一套排版，但尺寸降一级：H1 `clamp(36px, 4vw, 56px)`。
- 子主题 chips 用 2px 小圆角矩形，不用胶囊；选中态用墨色底 + 纸色字。
- 模块页的筛选条默认收起“模块”这一项，因为已经锁定；保留格式、难度、语言、价格。
- 模块页底部必须有“相关模块”，避免用户走进死胡同。

### 3.3 资料库：全量索引

**目标：** 高密度地浏览、筛选、比较资源，最终点出去。

**布局选择：顶部工具条，不做常驻侧栏。**

侧栏适合后台管理系统，会让内容站显得像 dashboard。资料库用一条 sticky 工具条 + 可展开的“更多筛选”即可；当筛选维度超过 6 个再考虑左侧栏。

**线框：**

```text
┌ 资料库 ─────────────────────────────────────────────────────────┐
│ 128 个资源，全部由编辑人工筛选。                                  │
├─────────────────────────────────────────────────────────────────┤
│ [搜索…]  模块 ▾  格式 ▾  难度 ▾  更多筛选  排序 [最新 ▾]  ◫ ▦    │ 56 sticky
│ 已选：AI 素养 ×   课程 ×   清除全部                              │
├─────────────────────────────────────────────────────────────────┤
│ No.    标题                          格式    难度    时长   日期  │
│ R-041  用 Claude 构建第一堂课         课程    入门    45min  11-02│
│ R-040  ...                                                      │
│ R-039  ...                                                      │
│ ...                                                             │
├─────────────────────────────────────────────────────────────────┤
│                       1  2  3  …  6  下一页                      │
└─────────────────────────────────────────────────────────────────┘
```

**规格：**

- 工具条 sticky 在导航下方（`top: 64px`），高 56px，底部 1px 线。
- 筛选项建议固定为 5 组：**模块、格式、难度、语言、价格**。来源、标签放进“更多筛选”。
- 已选条件用 chips 展示，支持单个移除和“清除全部”。
- 排序：最新收录（默认）、编辑推荐、时长、标题。
- 默认 **24 条/页**，用带页码的分页，不用无限滚动：利于 SEO、可回到原位、底部页脚可达。
- 桌面默认“索引视图”（纯文字行），可选“画廊视图”（3:2 缩略图卡）。
- 筛选项变化即时更新结果，但不要每次输入都请求；搜索输入 debounce 150–250ms。
- 所有筛选状态写进 URL query，保证可分享、可后退。

**空状态：**

```text
没有符合条件的资源。
试试：去掉“入门” / 只看免费 / 回到全部资源
[ 清除筛选 ]
```

不要只写“暂无数据”。

### 3.4 合集页：一期专题

**目标：** 用编辑视角把散落的资源组织成一条可消费的路径。

**线框：**

```text
┌ 面包屑：合集 / ISSUE 03 ────────────────────────────────────────┐
│ ISSUE 03 · 2026.11 · 编辑：XXX                                  │
│ 从零理解 AI Agent                                               │
│ 12 个资源 · 约 6 小时 · 更新于 2026-11-02                        │
│ [ 保存合集 ]  [ 分享 ]                                          │
├─────────────────────────────────────────────────────────────────┤
│ ┌ 编辑的话 ────────────────┐  ┌ 封面 4:5 ────────────────────┐  │
│ │ 2–3 段，说明为什么选这些、│  │                              │  │
│ │ 适合谁、按什么顺序读。    │  │                              │  │
│ │ 衬线 18/1.8，最大 640px。 │  │                              │  │
│ └──────────────────────────┘  └──────────────────────────────┘  │
├ 目录 / CONTENTS ────────────────────────────────────────────────┤
│ 01  基础概念                                                     │
│     R-031  What is an agent?          文章 · 12min              │
│     R-032  ...                                                  │
│ 02  动手实践                                                     │
│     R-033  ...                                                  │
├ 相关合集 ──────────────────────────────────────────────────────┤
└─────────────────────────────────────────────────────────────────┘
```

**规格：**

- 合集头部用 `ISSUE 03 · 2026.11` 的等宽小字建立“期刊感”；标题用衬线 48–56px。
- 编辑的话是核心资产：2–3 段，说明选编逻辑、适合谁、按什么顺序看。不要只写一段营销文案。
- 目录按“章节 → 资源行”分组；章节编号 `01 / 02 / 03`。
- 长合集在桌面端加左侧 sticky 目录（200px），移动端折叠成“目录”按钮。
- 保存合集后显示“已读 3/12”之类的进度；没登录也能保存在本地，不要用登录墙拦住收藏。
- 合集页不需要“相关文章 / 推荐阅读 / 评论区”三件套；一个“相关合集”就够了。

### 3.5 资源详情：编辑推荐卡

**目标：** 在用户点出去之前，用最少的信息回答三个问题：这是什么？为什么值得？要花多久？

**线框：**

```text
┌ 面包屑：资料库 / AI 素养 / R-041 ───────────────────────────────┐
│ ┌ 主栏 7/12 ─────────────────────────┐ ┌ 侧栏 4/12 ──────────┐ │
│ │ R-041 · 课程                      │ │ 元数据              │ │
│ │ 用 Claude 构建第一堂课             │ │ 格式    课程        │ │
│ │ 来源：Anthropic · 2026            │ │ 难度    入门        │ │
│ │                                   │ │ 时长    45 min      │ │
│ │ 一句话摘要……                      │ │ 语言    英文        │ │
│ │                                   │ │ 价格    免费        │ │
│ │ [ 前往原始资源 ↗ ]  anthropic.com │ │ 收录    2026-11-02  │ │
│ │                                   │ │ 校验    2026-11-05  │ │
│ │ ── 为什么收录 ──                  │ │ [ 保存 ] [ 分享 ]   │ │
│ │ 编辑注 2–4 句。                   │ │ 标签：AI / 课程设计 │ │
│ │                                   │ └─────────────────────┘ │
│ │ 你会得到（3–5 条）                │                         │
│ │ · ……                              │                         │
│ │                                   │                         │
│ │ [预览图 / 视频 16:9]              │                         │
│ │                                   │                         │
│ │ 相关资源                          │                         │
│ │ [ResourceRow × 3]                 │                         │
│ │                                   │                         │
│ │ 链接失效？[报告]                  │                         │
│ └───────────────────────────────────┘                         │
└─────────────────────────────────────────────────────────────────┘
```

**规格：**

- 主栏 7 栏、侧栏 4 栏（留 1 栏空隙）；侧栏在桌面 sticky，移动端移到正文上方或折叠。
- 主 CTA 是外链，必须显示目标域名；`target="_blank"` + `rel="noopener noreferrer"`。
- “为什么收录”用左侧 2px 朱砂线 + 纸色背景，和正文区分开；这是本站的差异点，不要省。
- 元数据用定义列表（`dl`），不要用彩色徽章堆砌；难度、价格用文字，不用红黄绿灯。
- 显示“收录日期”和“最后校验日期”；聚合站最大的信任问题是死链和过时信息。
- 相关资源 3 条即可，不要推荐 12 条分散注意力。
- 结构化数据用 `schema.org/LearningResource`（JSON-LD），帮助搜索引擎理解这是学习资源。

**资源详情页的取舍：**

如果资源本身内容很少（比如一个工具），详情页可能只有摘要 + 元数据 + 外链。这是可以的。不要为了“页面丰富”硬塞评论区、评分、作者访谈。**详情页的价值在于编辑判断，不在于字数。**

### 3.6 课程 / 教程阅读页：书页

**目标：** 让站内原创内容读起来舒服，并能在章节间连续移动。

**线框（≥1200px）：**

```text
┌ 进度 ███████░░░░ 45% ───────────────────────────────────────────┐
│ 课程 / AI 素养 / 第 3 章                                        │
├──────────────┬────────────────────────────────┬─────────────────┤
```

**规格：**

- 三栏：目录 240px / 正文 680–720px / 右栏 240px；1024px 以下先去掉右栏，768px 以下目录折叠。
- 正文 17px / 行高 1.8；中文每行 30–40 字；段间距 1em；不要首行缩进、不要两端对齐。
- H2 32px / 1.3，H3 24px / 1.35；标题和正文之间留 1.5–2em。
- 代码块、引用、提示框、图片、视频都用同一套“内容块”组件；视频 16:9，图片带 1px 边框和说明文字。
- 顶部 2px 进度条；章节末尾“标记完成”；上一节 / 下一节做成整块可点击区域。
- 支持打印样式：去掉导航、目录、按钮，保留正文和链接 URL。
- 键盘：`←` / `→` 切换章节（焦点在正文时），`/` 聚焦搜索；不要拦截输入框按键。

### 3.7 收藏页（简版）

- 本地优先：未登录也能收藏，存 `localStorage`；登录后合并。
- 展示“收藏的资源”和“收藏的合集”两个分组。
- 空状态给 3 个推荐合集，不要让用户面对空白。
- 不做复杂的工作区 / 文件夹 / 标签管理；第一版只需要“收藏”和“取消收藏”。

## 4. 栅格与响应式

| 断点 | 栏数 | 间距 | 页边距 | 导航 | 说明 |
|---|---|---|---|---|---|
| ≥1440 | 12 | 32 | 64 | 完整 | 容器最大 1280 |
| 1280–1439 | 12 | 24 | 48 | 完整 | 容器最大 1280 |
| 1024–1279 | 12 | 24 | 32 | 完整 | 课程页去掉右栏 |
| 768–1023 | 8 | 20 | 24 | 紧凑 | 卡片 2 列，列表保留 |
| <768 | 4 | 16 | 16 | 抽屉菜单 | 单列，列表行堆叠 |

规则：

- 容器 `max-width: 1280px`；正文 `max-width: 720px`；窄内容（编辑注、登录框）`max-width: 640px`。
- 字体尺寸用 `clamp()`，不要为每个断点写一套 font-size。
- 卡片网格用 `repeat(auto-fill, minmax(280px, 1fr))`，但资料库索引视图不要用网格。
- 列表在移动端不要横向滚动：把“格式 / 难度 / 时长”折到标题下方一行，日期放右侧。
- 触摸目标最小 44×44px；相邻链接之间至少 8px。
- 图片统一 3:2（资源卡）或 4:5（合集封面），用 `aspect-ratio` 预留空间，避免 CLS。

## 5. 列表还是卡片？

| 场景 | 推荐 | 理由 |
|---|---|---|
| 资料库全量浏览 | **索引列表**（默认） | 一屏能扫 8–10 条，元数据对齐，像目录；和大多数“卡片瀑布”竞品形成差异 |
| 资源较少 / 视觉素材强 | 画廊卡片（可选） | 让封面和截图说话，适合发现型浏览 |
| 合集 / 模块入口 | 卡片 | 需要封面建立编辑感 |
| 最新收录 | 索引列表 | 强调“新”和“可比较”，不是图片 |
| 相关资源 | 索引列表（3 行） | 不抢主内容 |

**资源行 anatomy：**

```
[No. 64px] [标题 flex] [格式 96px] [难度 96px] [时长 80px] [日期 96px] [→ 24px]
```

- 行高 72px；上下 padding 16px；底部 1px 线。
- 编号用等宽字体，颜色 muted；标题 17px / 500；元数据 13px / muted。
- hover：标题出现下划线、行底色变 `paper-2`、箭头右移 2px；不要整行浮起加阴影。
- 移动端：编号 + 标题 + 箭头一行；格式 / 难度 / 时长 / 日期折到第二行，13px。

**资源卡 anatomy：**

```
[3:2 图片，1px 边框]
[模块 · 格式，12px mono]
[标题，18px / 500，最多 2 行]
[来源 · 时长 · 难度，13px muted]
```

- 图片 2px 圆角、1px 边框、无阴影；不要用大圆角 + 投影。
- 卡片整体可点击，但收藏按钮要单独可点，且阻止冒泡。
- 卡片高度由内容决定，同一网格内用 `align-items: stretch` 对齐；不要做瀑布流。

## 6. 交互与状态

**搜索**

- 全局 `⌘K` / `Ctrl K` 打开搜索面板，宽 640px，位于视口上方 15vh。
- 结果按“资源 / 合集 / 教程”分组；每组最多 5 条，底部“查看全部”。
- 键盘：↑↓ 选择、Enter 打开、Esc 关闭；打开时焦点进输入框，关闭后回到触发按钮。
- 空结果：显示“没有找到 X”，并给 3 个推荐模块 / 合集。
- 搜索面板用实色纸背景 + 1px 边框，不要毛玻璃。

**筛选**

- 筛选变化立即更新结果；结果数实时显示。
- 已选条件永远可见，支持单个移除和“清除全部”。
- 移动端筛选放进底部抽屉，顶部按钮显示已选数量。
- 不要用多选下拉 + “应用”按钮这种后台式交互；除非选项特别多。

**分页**

- 用页码分页，不用无限滚动；保留滚动位置。
- 页码显示：`上一页 1 2 3 … 6 下一页`；当前页用墨色底。
- 列表底部显示“第 1–24 条，共 128 条”。

**保存**

- 点击后立即变实心图标 + toast “已收藏”；再次点击取消。
- 未登录也保存到本地；登录后提示“已同步 3 个收藏”。
- 收藏页支持“全部 / 资源 / 合集”筛选。

**外链**

- 主 CTA 显示“前往原始资源 ↗”+ 域名；不要只写“立即学习”。
- 新标签打开；如果外链失效，提供“报告链接失效”。
- 外链跳转可以做一次中间页吗？不建议。用户讨厌中间页；直接跳，靠 `last_checked` 和报告机制维护。

**加载与错误**

- 首屏内容服务端渲染；不要整页 spinner。
- 筛选结果加载时保留旧结果 + 顶部 2px 进度条，避免布局跳动。
- 图片加载失败时显示“排版封面”（编号 + 模块名 + 纸色背景），不要显示灰色破图。
- 错误信息说人话：“加载失败，请重试”+ 重试按钮，不要只给错误码。

## 7. “现代感”到底来自哪里

不是渐变，也不是大圆角。对内容站来说，现代感主要来自这 6 件事：

1. **排版即布局。** 大标题、小标签、等宽编号、细线，组成清晰的视觉节奏；不靠装饰。
2. **留白与密度的对比。** Hero 很空，资料库很密；一松一紧，页面才有呼吸。
3. **编号系统。** `M-02`、`ISSUE 03`、`R-041` 让内容像被认真编过，也方便引用和搜索。
4. **真实素材。** 真截图、真封面、真来源；AI 插画和 3D 球会立刻拉低可信度。
5. **有目的的非对称。** 7/5、6/3/3 的分栏是为了主次，不是为了“看起来活泼”。
6. **克制的动效。** 160–220ms 的反馈动效就够了；不做滚动视差、不做鼠标跟随。

## 8. 布局反模式

| 不要 | 原因 |
|---|---|
| 居中大标题 + 两个按钮 + 产品截图 | 典型 SaaS 模板，和“人工策展”无关 |
| 三列图标功能卡 | 内容站不需要“功能介绍”，需要“内容入口” |
| 每个 section 都包一张卡片 | 视觉噪音大，内容被容器淹没 |
| 等大 bento 网格 | 没有主次；bento 只有在“大小 = 优先级”时才成立 |
| 首屏轮播图 | 用户看不到重点，SEO 也差 |
| 无限滚动 | 回不到位置、页脚不可达、SEO 不友好 |
| masonry 瀑布流 | 资源卡高度不一，扫读困难 |
| 全屏视频背景 | 加载慢、干扰阅读、移动端体验差 |
| 假数据 / 假 logo / 假评价 | 一旦被识破，策展可信度归零 |
| 每个标题前放一个 icon | 图标不承载信息，只是装饰 |

## 9. MVP 落地顺序

按“用户核心链路”排，不按页面重要性排：

1. **设计令牌 + 页头页脚 + 排版基础**（没有这个，后面每页都会跑偏）
2. **资料库索引列表 + 筛选 + 资源详情**（核心链路：找 → 判断 → 点出去）
3. **合集页**（编辑策展的载体，也是差异点）
4. **首页**（有了内容和合集，首页才有东西可放）
5. **课程阅读页**（站内原创内容上线后再做）
6. **搜索面板 / 收藏 / 空状态 / 报告死链**（体验补齐）

先做首页是最常见的错误：首页会变成一堆占位卡片，等真实内容进来又要重做。
