# 教育资源共享站 · UI 调研

- 调研日期：2026-11-05
- 对应 issue：[qdriven/tutorials-maker#6](https://github.com/qdriven/tutorials-maker/issues/6)
- 目录：`docs/research/ui-resarch/`（按 issue 原文拼写）
- 读者：产品、设计、前端，以及用 AI 生成页面的同学

## 先看结论

这个站不应该像“课程商城”，也不应该像“AI 生成的 SaaS 落地页”。

它更像 **一本可以浏览、检索、收藏的公开课索引**：

| 页面 | 隐喻 | 用户在这里要完成的事 |
|---|---|---|
| 首页 | 期刊封面 + 目录 | 知道这里有什么、从哪开始 |
| 资料库 | 图书馆索引 | 按模块 / 格式 / 难度找到资源 |
| 合集 | 一期专题 | 按编辑思路成组消费 |
| 资源详情 | 编辑推荐卡 | 判断“值不值得去” |
| 课程页 | 书页 | 安静地读完 |

## 五个关键决策

1. **人工策展是产品本身，不是运营手段。** 不追求 SKU 数量，追求“为什么收录”。每个资源都要有一句编辑注，这是和普通导航站最大的区别。
2. **内容模型先于页面。** `Module → Collection → Resource` 是三层主结构；站内原创内容单独作为 `Lesson`，不要和外部课程资源混在一起。
3. **首页用编辑式首页，不用 SaaS 英雄区。** 主打“本期专题 + 模块索引 + 最新收录”，不要居中大标题 + 两个按钮 + 产品截图。
4. **资料库默认用索引列表，不默认用卡片瀑布。** 编号、标题、格式、难度、时长、日期一屏可扫；画廊视图作为可选项。
5. **视觉走“编辑式暖极简”。** 暖纸色、墨色、一个朱砂强调色、衬线大标题、1px 细线、2px 小圆角；明确拒绝蓝紫渐变、玻璃拟态、大圆角阴影卡片和等大 bento。

一句话概括视觉方向：

> 纸、墨、细线、编号，一点朱砂；像一本认真编过的刊物，而不是一个急着转化的落地页。

**最短落地路径：**

1. 读 `02`，确认“编辑式暖极简”方向，不再摇摆。
2. 读 `01` 的六个核心页面模板，先定首页、资料库、资源详情三个。
3. 把 `04` 的 `DESIGN.md` 草稿放到仓库根目录，并在 `CLAUDE.md` / `AGENTS.md` 里加一句“改 UI 前先读 DESIGN.md”。
4. 用 `03` 的 playbook 收集 30–50 个参考，按页面类型归档，不要收集 300 个。
5. 先做“资料库列表 → 资源详情”这条核心链路，再做首页和课程阅读页。

## 调研方法

- 逐个访问并拆解 issue 中给出的 6 个站点，记录它们的定位、信息架构、筛选方式、卡片/列表结构、视觉语言。
- 补充参考三类：策展/编辑类站点（Are.na、Dense Discovery、Minimalissimo、Siteinspire）、学习产品（Khan Academy、Brilliant、Maven、MasterClass）、参考工具（Mobbin、Page Flows、Dribbble、Figma Community、Awwwards、Land-book、Refero）。
- 所有站点数据均为 2026-11-05 页面可见的快照，站点会改版，引用前建议再打开确认。
- 参考站点的作用是“拆结构、借方法”，不是“抄皮肤、搬素材”。版权与时效提醒见 `03` 末尾。

## 不在本次范围

- 具体品牌命名、Logo、插画系统；
- 后端 CMS / 数据库选型；
- 像素级高保真设计稿；
- 课程内容本身的教学设计。

这些可以在方向确定后另开文档。
