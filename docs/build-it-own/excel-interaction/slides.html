第一视角制作复盘：为了什么、怎么做的、做出了什么、怎么批量。

为了什么

  • Excel 教程看一遍记不住，敲一遍才学得会
  • 截图长文 / 纯视频都给不了「实机感」
  • 想要：真表格真算真验收 · 每函数一节课 30 秒 · 可批量的流水线

约束：从零新做不搬旧实现，全程文档化——过程本身也是交付物。

核心思路：一份契约，三个产物

courses/<id>.json（唯一事实源） ├─► apps/<id>/ 交互动画课（练习 + 验收） ├─► out/<id>.mp4 30s 无废话讲解视频（TTS 有声） └─► showcase 登记 全站展示层

核心约束：改课程只改 JSON，不动代码。

方法论先行（写功能之前）

  • 任务分解：项目 → phase（9 阶段）→ task（半天粒度）
  • task 三件套：task.md 计划（验证点先于动手）/ verify.md 证据 / output.md 交接
  • index-log append-only：按实践顺序记 52 条，错了补更正不删旧条
  • 数字说话：版本号 · 路径 · 退出码，FAIL 也记

Day 1 · 11-08 打地基 → 试点出课

  • 环境探测 + 修 3 个 Windows 坑（spawn EINVAL / 假阴性 / 假阳性）
  • phase-0…8 连跑：环境 → 骨架 → 技能 → 契约 → 流水线 → 出课 → 出片 → 展示 → 收尾
  • 10 个用户反馈闭环 task：IME 全角转换 / formulaArgs / 防剧透 / 总结框…
  • 全部改契约与共享 lesson.js，不改单课代码

Day 2 · 11-09 扩展引擎 → 收口

  • 三引擎齐：handsontable（默认）/ univer（跨表真算）/ onlyoffice（FILTER·透视·图表）
  • 新引擎 = 只写一个 engine.js（mount / setFormula / readValue / focusCell）
  • 出片三路径同 plan 互为校验：渲染式 · 录屏式 · 抓窗式
  • 遗留 issue 化 #14–#20 · PR #13 合并 main

Day 3 · 11-10 L2 + 批量 + 站点化

  • L2 冲刺：9 门复合/压轴课，P3 走查通过才解锁批量
  • A 类 7 场景程序化转正（aclass-gen）· 抓窗式 10 门真机出片
  • onlyoffice 四 API 实测 8/8 · univer 金底表头带
  • 三页互达 · 卡片墙 · 共享资产去重 · 90s 全站导览视频

批量流水线：怎么从 1 门铺到 44 门

  • 五个生成器（scripts/batch/）：func-batch · chart-batch · l2-gen · capstone-gen · aclass-gen
  • 契约同构是批量前提：同一批字段块填场景差异，check-manifest 逐份校验
  • 节奏模型：holdMs = max(minHold, speech + gap)——口播是下限，30s 口径天然达标
  • QC 闸门：流断言 + 片长漂移 <5% + 抽帧比对，过不了不进 showcase
  • 回归：pnpm verify + 真浏览器 36/36 才算批量完成

批量的节奏教训

  • 试点 1 课端到端 → 核心课 → 全量，单课验收标准立住再铺开
  • 批量前先清「每课都交税」的遗留项，否则返工 ×N
  • 走查闸门（3 次点击内看片 · 练习验收过）通过才解锁批量转写
