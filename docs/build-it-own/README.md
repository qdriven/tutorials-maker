# build-it-own · 自己造轮子系列

> 这个目录收录「从零自己做出来」的项目的制作过程记录——不是 API 文档，不是用法手册，
> 而是**第一视角的建造叙事**：为了什么 → 怎么做的 → 做出了什么 → 怎么尝试 → 批量怎么跑。

## 收录项目

| 项目 | 一句话 | 文档 |
| --- | --- | --- |
| excel-interaction | 契约驱动的 Excel 实机教程工厂：一份 JSON 同时产出交互动画课 + 30 秒讲解视频 | [excel-interaction.md](excel-interaction.md) |

每个项目三件套：

- `<项目名>.md` —— 第一视角制作过程主文档（过程与结果、为了什么、怎么尝试、批量流水线）
- `<项目名>-timeline.html` —— 时间线页面（零依赖，浏览器直接打开）
- `<项目名>-slides.html` —— 演示幻灯片（reveal.js，浏览器直接打开）

## 约定

1. **第一视角**：写「我为什么这么做、当时遇到了什么、最后做成了什么」，不写营销腔。
2. **过程与结果并重**：每个阶段有动作也有产出数字（几门课、几条验证、几支视频）。
3. **可尝试**：读者照着「怎么尝试」一节的命令能自己跑起来。
4. **批量单独成章**：试点跑通之后如何铺量（生成器、出片、质检、回归），是这类项目的核心资产。
5. **原始证据回链**：详细执行流水、task 三件套仍放回项目自己的 `docs/`，这里只做叙事与导航。
