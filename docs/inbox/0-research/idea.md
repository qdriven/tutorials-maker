# README

这个项目期望做成是：
1. 一个不同edu相关的资源整合，use case的网站
2. 初期的use case和资源都是自己去获得主要都是通过自己挑选获得.

因此这个应用就包括了：
1. 不同的内容模块
2. 具体的课程资源的一个内容聚合


现在需要调研的是：
1. 页面布局怎么展示会合理或者现代
2. 使用什么风格的会比较好
3. 有什么可以参考的mockup或者figma，dribble这样的内容上有什么可以借鉴的

请写入到docs/research/ui-resarch 中去.
