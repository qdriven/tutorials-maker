WHAT IT IS

一个让 agent 替你做 slides 的 skill

它不是模板库,而是一套写给 coding agent 的工作流说明书 — agent 读完就知道怎么问需求、怎么给你看风格、怎么把内容编译成一个自包含的 HTML 文件。

INSTALL / 安装

安装

两条命令,或者一次 git clone。两分钟内装好。

安装 / INSTALL 04 / 15
THREE WAYS IN

三种方式,按你的 agent 挑一种

A / CLAUDE CODE

插件市场安装(推荐)

# 两条命令,分两条消息发送
/plugin marketplace add https://github.com/zarazhangrui/frontend-slides

/plugin install frontend-slides@frontend-slides

务必用 HTTPS 完整地址;短式写法可能走 SSH 导致失败。

B / MANUAL

手动安装(任何目录)

git clone https://github.com/zarazhangrui/frontend-slides.git ~/.claude/skills/frontend-slides

等价做法:把 SKILL.md、STYLE_PRESETS.md、viewport-base.css、bold-template-pack/、scripts/ 复制进技能目录。

C / OTHER AGENTS

Codex / Gemini CLI / OpenCode…

不需要安装。把仓库链接发给它:

https://github.com/zarazhangrui/frontend-slides

能读文件系统的 agent 都会从 SKILL.md 开始,按需加载引用文件。

安装 / INSTALL 装完即可在对话里直接唤起

使用 / PHASE 1 08 / 15
PHASE 1 / FOUR QUESTIONS

开工前,它会一次问清四件事

Q1
目的
路演 / 教学 / 大会分享 / 内部汇报
Q2
长度
短 5-10 / 中 10-20 / 长 20+
Q3
内容
全部就绪 / 粗略笔记 / 只有主题
Q4
密度
演讲版 / 阅读版 — 下一页展开

四个问题一次打包发问,不挤牙膏。密度这一问决定整份 deck 的性格。

使用 / PHASE 1 有图片就顺带评估可用性
使用 / DENSITY 09 / 15
DENSITY

两种密度,两种性格

SPEAKER-LED / 低密度

演讲版

一页一个观点,大字号,大量留白,每页至多三条要点。页数更多,节奏更快 — 给现场讲的人用。

READING-FIRST / 高密度

阅读版

每页自成一篇,网格、表格、注释齐全 — 不看讲解也能读懂。给异步传阅、报告评审用。

共同的底线:不滚动、不溢出、不重叠。装不下就拆页,不要把字缩小。

使用 / DENSITY 混合需求时选更近的那一档
使用 / PHASE 2 10 / 15
PHASE 2 / SHOW, DON'T TELL

风格不用嘴说,用眼睛挑

说不清自己喜欢什么风格是常态。所以它直接生成三张真实的首页预览,你只需要反应。

1 / SAFE PRESET
一个安全预设,来自 12 套内置 STYLE_PRESETS — 稳妥的保底。
2 / BOLD TEMPLATE
至少一个 bold 模板,来自 34 套设计系统库 — 比如 deck 正在用的这一套。
3 / WILDCARD
一张现场自定义 — 只为这份 deck 量身设计的大胆选项。

选中之后才去读那一个模板的完整设计文档 — 按需加载,不看多余的。

使用 / PHASE 2 预览即真实首页,不是风格色卡
03
DOCUMENT → SLIDES / 文档到幻灯片

文档到幻灯片

两条入口,同一个出口:一个自包含的 HTML 文件。

文档到幻灯片 / TWO PATHS 12 / 15
TWO DOORS, ONE EXIT

把一份文档喂给它

A / MARKDOWN · NOTES

文档直转

  • 给它一份 .md 或粗略笔记
  • 回答四个问题,看三张风格预览
  • 选一个,整份 deck 直接生成
B / PPTX

PPT 转网页

  • python scripts/extract-pptx.py 抽取内容
  • 确认文字、图片、页序清单
  • 挑风格 — 演讲备注保留为注释

两条路都通向同一个出口:单文件 HTML,在任何设备的浏览器里播放。

文档到幻灯片 / TWO PATHS 图片走相对路径,和 HTML 放一起
文档到幻灯片 / OUTPUT SPEC 13 / 15
OUTPUT SPEC

产出的 HTML,有几条硬规矩

FIXED STAGE
固定舞台
1920×1080 画布整体缩放适配屏幕,永不按设备重排。
ZERO DEPS
零依赖
单文件,CSS / JS 全内联;viewport-base.css 必须全量拷入。
WEB FONTS
只用网络字体
Fontshare 或 Google Fonts,绝不用系统默认字体。
.SLIDE SWITCH
可见性切换
翻页靠 visibility + opacity,不用 display:none。
KEYBOARD
全键盘操控
方向键、空格、翻页键、触屏滑动、滚轮。
EDIT MODE
行内编辑
按 E 或悬停左上角,点任意文字直接改,Ctrl+S 保存。
文档到幻灯片 / OUTPUT SPEC 这些规矩写死在 SKILL.md 里
分享 / SHARE 14 / 15
SHARE

一条命令,变成链接或 PDF

# 部署成一条 URL,手机也能看
bash scripts/deploy.sh ./deck/
# 逐页 1920×1080 截图合成 PDF
bash scripts/export-pdf.sh deck.html
  • 部署走 Vercel 免费层,链接任何设备可开
  • PDF 是静态快照,动画不保留 — 属正常
  • 演讲备注在 PPT 转换时保留为 HTML 注释

你现在看到的这一份,就是用同一个 skill 的 broadside 模板生成的 — 它吃自己的狗粮。

分享 / SHARE 重跑部署脚本即原地更新,URL 不变
