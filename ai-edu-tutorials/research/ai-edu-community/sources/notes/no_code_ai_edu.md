## 一、无代码/低代码AI平台教育应用

### 1.1 百度秒哒（无代码应用构建平台）

- **产品定位**：百度于2024年11月发布的国内首个"对话式"应用开发平台，基于文心大模型，通过多智能体协作实现生成式应用开发。核心理念是"一句话，做应用"。
- **核心数据**：
  - 截至2025年12月，平台累计生成超**50万个商业应用**，日新增应用涨幅超过150%
  - 覆盖教育、商业、内容创作、企业服务等**200余个场景**
  - 平台用户中**81%为非程序员群体**，主要集中在职场人群与高校师生
  - 全量上线首日吸引超**2万用户**使用，创建应用数量突破**3万个**
- **教育场景案例**：
  - 高一学生开发的《化学分子结构分析工具》荣获秒哒非编程黑客松一等奖，并在北京第一实验学校推广使用
  - 8岁小学生（二年级）扑满使用秒哒开发了"全校拼伞系统"小程序，解决下雨天同学搭伞问题
  - 财经作家吴晓波团队中多位无编程能力的编辑使用秒哒生成了游戏、打卡程序、问卷调查等应用
  - 支持教育场景、餐饮订餐场景等轻应用开发，小学生可搓出"小学数学刷题库"
- **技术特点**：内置需求收集、应用生成、内容生成等十多个AI角色，多智能体协作矩阵，3-10分钟生成应用，支持多轮对话修改

> 来源：CSDN深度体验文章（2026-01-10）、新浪财经（2026-05-13）、微信公众号（2025-03-25）、百度开发者中心（2026-06-09）

### 1.2 Coze（扣子/字节跳动）AI Bot教育应用

  - 全球注册开发者超**300万**，日均活跃智能体**80万+**
  - 基础功能完全免费
- **教育场景应用**：
  - **24/7 AI学生助手**：为新生提供学术资源、校园设施、社交活动的个性化指导，减轻行政人员工作量
  - **互动学习聊天机器人**：教师创建互动测验和即时反馈聊天机器人，提供个性化学习路径，收集学生表现数据

## 二、非技术人员如何创建AI教育内容

### 2.1 提示词工程（Prompt Engineering）作为新素养

- **定义**：通过清晰的指令与各种提示技巧，引导AI模型生成符合用户期望的内容。被称为"AI时代的编程语言"。
- **核心框架（4元素）**：
  - **角色（R）**：指定AI身份（如"资深内部讲师"）
  - **背景（C）**：提供脉络（如"公司要导入AI教育课程"）
  - **任务（T）**：明确工作内容（如"撰写3小时课程大纲"）
  - **格式（F）**：指定输出形式（如"以表格呈现章节、主题、时间、目的"）
- **提示素养框架（Prompt Literacy）**：
  - 生成式AI工具的理解与认知
  - 提示词编写技巧
  - 生成内容的评估能力
  - 伦理与道德意识
- **无需编程的进阶技巧**：JSON格式提示词——将指令拆成键值对，让模型毫无歧义执行，"不需要任何编程能力"

> 来源：台湾严国培训（2026-06-24）、华为PanguLM文档、四川社科院图书馆论文（2024）、微信公众号（2025-09-03）

### 2.2 教师用AI辅助备课、生成教案、制作课件的现状

- **效率提升**：AI提示词可帮助教师一键生成教案模板，备课效率提升**300%**
- **生成教案的核心模块**：
  1. **教学目标**：核心知识点（重点/难点/易错点）、三维目标（知识技能/过程方法/情感价值观）
  2. **教学流程设计**：导入环节（情境模拟/问题驱动/多媒体）、新知讲解（类比/可视化/探究式）、互动设计（小组活动/实验/辩论）、总结与迁移（思维导图/自评量表）
  3. **差异化教学支持**：学困生简化方案、资优生拓展任务、特殊教育需求调整
  4. **评估与反馈**：课堂即时检测题、分层作业设计（基础/提升/挑战）、常见误解预警
- **实际应用工具**：
  - 腾讯元宝：结合教学文件生成结构化教学设计
  - 迅捷AiPPT：一键生成含课程导入与随堂练习的PPT
  - 超星AI助手：24小时虚拟助教答疑
  - 学习通AI学情分析：生成薄弱点报告
  - 教师AI备课工具箱：100+即用提示词，涵盖备课、出题、家长沟通
- **教师AI素养调研**：教龄与AI通用素养呈**负相关**（教龄越短，素养越高）；有企业工作经历者在"教学中应用AI"维度素养更高

> 来源：搜狐（2025-05-06）、头条（2025-05-06）、MSN（2025-05-06）、LightUpMaker教师AI备课（2026-05-07）、职业院校教师AI素养论文（2025-12-06）

### 2.3 家长用AI工具辅导孩子的实际案例

- **使用现状**：
  - 宁波大学园区图书馆调查：34%家长对人工智能甚为了解，**65%表示听过但不清楚**；25.86%从未使用过任何AI工具
  - 家长使用AI频率最高的是智能语音助手（46.5%），主要集中在生活和娱乐休闲方面
  - 中国青少年研究中心调查：超六成（61.7%）学生使用过AI，辅助完成作业是首要用途（71.0%）
- **实际案例**：
  - 重庆90后宝妈用腾讯元宝与孩子"聊天"，AI以第三方身份巧妙减少亲子权力对抗，让孩子主动接受规则（如"国家规定未成年人一周只能玩三小时游戏"），孩子最终主动道歉
  - 家长用豆包生成"我为家乡代言"视频拍摄脚本和文案
  - 家长用AI查找解题思路，认为"开拓思维，效率更高"
  - 作业帮学习笔：双头设计，窄头查词、宽头查题，5.8亿+题库，家长远程控制关闭答案

  - 担忧派：担心孩子失去主动思考能力，AI生成内容真假难辨，"离开模板就无从下笔"
  - 65.52%家长选择推荐AI学习资源，43.06%选择建立AI使用校园规范，20.79%选择参加家长AI素养培训

  - 可一键调用小程序，覆盖消息发送、文件处理、智能总结

  - 非技术用户可通过无代码平台（如即速应用、微盟）创建小程序模板，接入DeepSeek API
  - ManyChat：无需代码的公众号/微信群机器人搭建工具

  - 提出AI五大理念（5 Big Ideas in AI）：感知、表征与推理、机器学习、自然交互、社会影响

  - **核心原则**：不是纯技术课程，重点不在于教会学生编程开发AI产品，而在于理解AI产品背后的基本原理，学会和生活中AI产品相处
  - 强调"不插电活动"（Unplugged Activities）帮助理解AI概念

- **美国Digital Promise《AI素养框架》**：
  - 六个教育实践类别、两个核心价值、三种参与模式、三种使用类型
  - 面向非技术背景人群

- **美国SREB《面向AI时代的劳动力技能》**（2025年7月）：
  - 三个技能群：成功技能（沟通、领导力、批判性思维、创造力）、行业基础技能、技术技能
  - 四级进阶：认知→探索→应用→精通，适用于零基础成人学习者

- **OECD与欧盟联合AI素养框架**（2025年6月）：
  - 借鉴DigComp、UNESCO、AI4K12、Digital Promise等框架
  - 三大关键主题：AI和机器学习工作原理、...（2026年发布完整版）
  - 将为PISA 2029媒体与AI素养评估奠定基础

- **中国香港大学AI素养框架**：
  - AI概念、AI应用、AI"情感"与人类情感、AI安全与保密、负责任的AI使用
  - 定义：在日常生活中理解、使用AI技术并做出明智决策的能力

- **中国广东省"2+1"方案**（2025年4月）：
  - 《广东省中小学学生人工智能素养框架（试行）》：人智观念、技术实现、智能思维、伦理责任
  - **核心目标**：提升全体学生的人工智能素养，而非单一培养人工智能专业人才
  - 明确"如果没有明确的素养框架，AI教育易沦为编程课"

- **中国《教师人工智能素养提升与应用指南》**（2025年，216页）：
  - 框架以"知识-能力-规范"为核心逻辑
  - 知识领域：AI基础知识、工具操作（ChatGPT、豆包等）、教育与科研应用
  - 能力构成：技术理解与应用、教学赋能、科研赋能、伦理与数据管理

- **浙江大学《大学生人工智能素养红皮书》**（2024版）：
  - 四个维度：体系化知识、构建能力、创造性价值、人本伦理

- **通识性AI素养框架**（尹开国等）：
  - 五个要素：AI意识、AI认知、AI技能、AI思维、AI伦理
  - 强调"非专家型"社会公众（没有正式接受过AI培训，不是AI工具开发者而是使用者）

> 来源：UNESCO（2018）、OECD与欧盟（2025-06-03）、SREB（2025-08-08）、北京大学AI教育论文（2022）、广东省教育厅（2025-04-11）、AI素养论文（2024/2025）

### 4.2 普通人需要的AI能力（非编程能力）

- **AI素养三维度（非技术人群）**：
  1. **AI机制**：了解AI是什么、如何工作（机器学习、深度学习基本概念）、人类在AI设计中的角色
  2. **AI能力**：识别AI应用、理解AI能做什么和不能做什么、使用AI解决现实问题
  3. **AI伦理**：数据隐私、算法偏见、工作替代、生成式AI的错误信息风险、安全问题

- **AI素养十二项能力**（生成式AI，Annapureddy等）：
  从基础AI素养到提示工程，再到伦理和法律考量，**编程只是其中一项**，非必需

- **AI素养三大核心**（知网培训）：
  - 批判思维（找茬力）——验证AI输出准确性
  - 人机协作（共生力）——保持主体性，AI是"外脑"，人是"内脑"
  - 伦理意识（边界力）——负责任地使用AI

- **具体能力清单**：
  | 能力类型 | 具体内容 | 为什么重要 |
  |----------|----------|------------|
  | 批判性思维 | 验证AI输出的准确性 | AI会产生"幻觉" |
  | 提问能力 | 精准表达需求（提示词） | AI输出质量取决于输入质量 |
  | 信息甄别 | 识别虚假/偏见信息 | 避免被错误信息误导 |
  | 跨学科整合 | 打破学科界限 | 创新发生在交叉领域 |
  | 情感智能 | 理解他人、建立连接 | AI无法替代 |
  | 终身学习 | 持续更新知识 | 技术迭代太快 |

- **核心结论**：
  - AI素养的非技术背景人群**不需要成为程序员或工程师**
  - 应该具备对AI增强产品和服务做出合理判断的知识
  - 了解AI技术的伦理考量，理解AI相关新闻和对话，有效与AI驱动系统互动

> 来源：ERIC论文（EJ1437452）、arXiv（2412.12107）、浙江大学红皮书（2024）、知乎专栏（2025-03-02）

## 五、向普通人扩散的障碍

### 5.1 认知鸿沟：家长仅"听过但不清楚"AI

- **中国家长数据**：
  - 宁波调查：**65%家长表示"听过但不清楚"AI**，仅34%甚为了解
  - 25.86%的家长从未使用过任何AI工具
  - 中国青少年研究中心：近七成（67.9%）家庭**没有制定AI使用规则**
  - 农村家长"不管"的比例（20.3%）高于城市（15.6%）

- **中国网民数据**：
  - 《2025中国网民AI认知调研报告》（7061份有效问卷）："从未听过AI"仅占3.64%，96%以上有所认知
  - 但"比较了解并偶尔使用"和"非常了解并经常使用"的合计仅54.27%
  - 对比：牛津大学2024年对六国调研，各国消费者对ChatGPT知晓率最高仅61%

- **国际数据**：
  - 美国调查：70%家长对AI有所了解，但仅33%听说过"对话式AI"（67%没听过）
  - 英国图灵研究所：55%儿童没听说过"生成式AI"；37%儿童有成年人向他们解释过AI
  - 比利时调查：2019年56%的人表示对AI有所了解，但26%表示不了解，18%不确定

- **儿童数据**：
  - 描述AI的前五个关键词：机器人（>25%）、计算机（~10%）、ChatGPT/聊天机器人（<10%）、虚拟助手、智能代理
  - 第六个最常用词是"假的"（fake）
  - 近半数学生心里有烦恼时选择求助AI而非身边人，超两成学生"只想和AI聊天，不想和真人聊天"

> 来源：现代金报（2025-03-11）、经济观察报（2026-05-19）、澎湃新闻（2026-03-24）、ERIC论文（EJ1438408）、图灵研究所（2025-06）

### 5.2 非技术教育者采用AI的障碍

- **四大障碍**（JSAER 2024研究）：
  1. **缺乏技术培训**：人文社科背景教师缺乏AI概念基础，专业发展机会要么太技术化、要么太肤浅
  2. **抗拒变革**：教师可能认为AI与其学科无关，尤其是人文社科领域
  3. **基础设施不足**：资源匮乏环境难以实现AI方法
  4. **数据隐私担忧**：对个人信息安全和数据保密性的顾虑

- **GAI背景下的新型数字鸿沟**（CAUE框架）：
  - **认知差距**：技术性认知、价值性认知、易用性认知、局限性认知、风险性认知
  - **获取差距**：信息基础设施、跨境访问限制、账号封禁、环境配置
  - **使用差距**：提示词构建和迭代能力极大影响生成内容质量
  - **评估差距**：缺乏信息甄别能力，弱势群体更容易受虚假信息影响

- **社会认知偏差**：
  - 部分教育管理者、教师、家长对AI持怀疑和排斥态度，担心取代教师角色
  - 认知偏差与信息不对称、经验缺乏、传统教育观念惯性有关
  - 缺乏成功案例示范效应和系统性认知引导

- **社会支持体系缺失**：
  - 缺乏专业技术服务团队、教师培训体系不完善、家校协同机制不健全
  - 多维协同（政府政策支持、企业技术支持、学校实施支持、家庭配合支持）尚未形成

> 来源：JSAER论文（2024）、武汉大学信息学报（2025）、西南大学学报（2025-02-20）

### 5.3 如何让非技术用户感受到AI的价值

- **关键洞察**：
  - 罗征（裸辞后用AI搭炒股系统）："真正愿意钻研AI的人，本来就是有极强学习欲的人。AI不会自动唤醒那些不想学的人。短期内，AI会**加剧人与人之间的鸿沟**，而不是实现普惠。"
  - 夏宁（非技术背景用AI做项目）："快餐文化严重，大家都愿意吃喂到嘴边的，不愿意去扎根技术。"
  - 小度学习机洞察：常常是家长兴致勃勃买回去，孩子不喜欢用，很快就吃灰——"学习与孩子的天性有违背的地方，需要用新的AI技术和交互方式激发兴趣"

- **有效策略**：
  1. **降低感知门槛**：让AI像"微信小微"一样，用自然语言一句话就能生成小工具
  2. **嵌入日常场景**：不教AI，而是在微信、钉钉、飞书、学习笔等日常工具中内置AI功能
  3. **提供即时反馈**：AI课程表拍照导入、AI翻译即说即译、作业拍照即时诊断
  4. **社交化传播**：腾讯元器借助微信生态分发，Coze借助抖音/飞书传播
  5. **家庭共学**：AI作为"第三方伙伴"弥合亲子代沟，而非替代家长或老师
  6. **具象化价值**：从"抽象技术"到"解决具体问题"（拼伞系统、拍照搜题、作文批改）
  7. **市场教育**：运营商渠道、OMO模式（线下体验+线上购买）降低决策门槛

- **成功要素**：
  - 非技术用户不需要理解Transformer架构，只需要知道"这句话能让AI帮我做什么"
  - 提示词工程是"新编程语言"，但比Python门槛低100倍
  - 教育硬件是AI向非技术用户普及的最成熟载体（学习机、词典笔、智能手表）

> 来源：虎嗅（2026-03-04）、人民日报（2023-06-15）、艾瑞咨询（2024-08-05）、小宇宙播客（2025-03-01）
