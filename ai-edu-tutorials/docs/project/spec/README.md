# Spec — AI Edu Tutorials

## 目标

Desktop 可播的交互式教程：多角色对话 + 动手场景；内容可由 Agent 从 PDF/网络整理。

## MVP 验收

1. 样例课（STEM 短课，PDF ≤ 30 页）
2. 幻灯片 + 测验 + 至少 1 交互场景
3. 教师 + peer 角色可对话
4. **Tauri** 壳能导入/打开并播放
5. Agent SOP 可从 PDF 生成可校验 Stage

## 非目标（MVP）

- 合并 OpenMAIC / DeepTutor 代码
- fork OpenMAIC-Project
- 完整 TTS/ASR、全量 PBL
- Innate Host 插件化
