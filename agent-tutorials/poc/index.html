什么是智能体？

      
能感知环境、自主决策、调用工具并持续迭代以达成目标的系统。
LLM 是大脑，四要素围绕它组成闭环。

      

        
大脑 · LLM
理解、推理与生成，一切决策的核心

        
感知 · Input
接收用户目标与环境反馈（Observation）

        
规划 · Plan
拆解目标，决定下一步行动（Thought）

        
行动 · Tools
搜索、计算、API —— 走出"只会说话"的边界

      

    


    
    

      
与传统程序的本质区别

      
传统程序：路径固定，逻辑写死在代码里。
智能体：路径未知，在循环中自主探索直到收敛。

      

        

          
传统程序 · DETERMINISTIC

          

            输入→
            固定逻辑→
            输出
          

          
开发者预先写出每一步分支

        

        

          
智能体 · AGENTIC LOOP

          

            
            目标
            ⇄
            环境
          

          
模型在循环中自己决定下一步

        

      

    


    
    

      
核心范式 · ReAct

      
Reason + Act：推理指导行动，行动结果反馈推理 —— 三步循环，直到能给出最终答案。

      

        
 ThoughtREASONING · 推理

        →
        
 ActionTOOL CALL · 行动

        →
        
 ObservationENVIRONMENT · 观察

        ⟲
      

      
Thought → Action → Observation → … × N → ✅ Final Answer

    16 个术语
  

  
没有找到相关术语 —— 试试「记忆」「MCP」，或切换分类。

  

    
智能体 Agent
能感知环境、自主决策、调用工具并持续迭代以达成目标的系统。

    
工具调用 Tool Calling
模型输出结构化指令，由运行时执行外部工具并把结果回填给模型。

    
多智能体系统 Multi-Agent System
多个智能体按角色分工、通过消息协作完成复杂任务的系统形态。

    
ReAct Reason + Act
推理与行动交替进行的经典范式：Thought → Action → Observation 循环。

    
先规划后执行 Plan-and-Execute
先生成完整任务计划，再逐步执行并按需重规划的范式。

    
自我反思 Reflexion
把失败经验转化为语言化反思，写回记忆指导下一轮尝试。

    
记忆体系 Memory
短期（上下文内）与长期（外部存储）记忆共同构成的体系。

    
检索增强生成 RAG
先从知识库检索相关内容、再注入上下文生成的知识注入方法。

    
向量检索 Vector Search
将文本编码为向量，以相似度找出语义最相关内容的检索方式。

    
上下文工程 Context Engineering
对模型可见信息进行系统性选择、压缩与组织，用有限窗口做最多的事。

    
模型上下文协议 MCP
连接模型与外部工具/数据源的开放协议，"AI 应用的 USB-C"。

    
智能体协作协议 A2A
Agent-to-Agent：跨智能体（可跨厂商/框架）的任务委托与状态通信。

    
智能体强化学习 Agentic RL
以真实/模拟环境中的多步任务为训练信号的强化学习方法。

    
轨迹评估 Trajectory Evaluation
不只看最终答案，还评估中间步骤（工具选择、效率、成本）的评估方式。

    
沙箱 Sandbox
隔离执行智能体生成代码的安全环境，方案三的执行底座。

    
流式输出 Streaming / SSE
服务端向浏览器持续推送事件，让思考与工具调用逐帧可见。
