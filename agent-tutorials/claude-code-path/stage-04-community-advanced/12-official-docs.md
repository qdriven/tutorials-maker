# 12 · 完整官方文档（常驻事实源）

> 资源: [code.claude.com/docs/en/overview](https://code.claude.com/docs/en/overview)
> 免费 · 常驻参考 · 难度 ★☆☆（难在"想起来查"）

## 它讲什么

Claude Code 的完整官方文档站。前 11 课带你走完了主干道；这份文档是**全量地图**——包括本路线没展开的部分：安装与各平台配置、IDE 扩展（VS Code/JetBrains）、CLI 完整参考、hooks 全规格、subagents、settings 配置体系、安全与隐私、网络配置、成本管理（`/cost`、模型选择）等。

## 怎么学（它不是"上完"的课，是"住进去"的库）

1. **先建索引心智**：花 30 分钟只浏览目录树，给每个章节一句话摘要，记进你的笔记——以后知道"哪类问题查哪页"。
2. **补三个本路线未深入的盲区**：
   - **Settings 体系**（settings.json 的层级与优先级）
   - **Subagents**（定义专职子代理，与第 09 课的社区实践互证）
   - **成本管理**（模型选择、`/cost`、长会话的上下文策略）
3. **建立查证习惯**：网上任何教程（包括本路线）与官方文档冲突时，以文档为准——这正是 [rea-eng 教程](../../rea-eng/README.md)反复强调的纪律。
4. 关注 release notes / changelog 入口，新功能第一时间知道。

## 学完你能

- 任何"能不能做到 X"的问题，5 分钟内在官方文档找到权威答案
- 补齐 hooks/subagents/settings 三块拼图，配置层完全可控
