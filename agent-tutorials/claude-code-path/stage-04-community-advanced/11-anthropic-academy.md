# 11 · Anthropic 学院（官方课程平台）

> 资源: [anthropic.skilljar.com](https://anthropic.skilljar.com)（13 门官方课程，免费、带证书）
> 免费 · 按需学习 · 难度 ★★☆

## 它讲什么

Anthropic 官方 Skilljar 学习平台，聚合全部官方课程——你在第 02/03 课上的 Claude Code 101 与 in Action 就来自这里。课程覆盖 Claude Code 各专项（MCP、hooks、CI 集成等）、API 开发、提示词工程、Claude Agent SDK 等，**免费且完成可得证书**。原文特别强调"13 门官方课程，免费带证书"。

## 怎么学

1. 注册/登录 [anthropic.skilljar.com](https://anthropic.skilljar.com)，浏览全部课程目录，按**当前工作需要**排优先级（不必全上）。
2. 推荐路径（在 01–03 课基础上）：
   - 与第 07 课互补：MCP 专项课——文档读完上实操课，理解会翻倍
   - 与第 08 课互补：Skills / hooks 专项课
   - 完成任意一门拿证书——顺手把学习闭环做实
3. 每门课保持第 02 课的节奏：**边看边在终端跟练**，课后立即在真实项目里用一次。
4. 关注新课：平台会随 Claude Code 发版上新课，养成每月看一眼的习惯。

## 学完你能

- 官方认证的能力背书（证书）
- 新功能发布后能第一时间获得系统化讲解，而不是等博客二手转述

## 自测检查点

- [ ] 完成至少 1 门课并拿到证书
- [ ] 选课清单与自己的工作场景对得上（不是囤课）
- [ ] 把至少一门课的内容落进了真实项目
