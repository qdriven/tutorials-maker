# 10 · Awesome Claude Code（社区资源合集）

> 资源: [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code)
> 免费 · 预计 1 h（首次浏览）+ 持续回流 · 难度 ★☆☆

## 它讲什么

社区精选的 Claude Code 资源合集（awesome-list 形式），长期维护，分类大致包括：

- **Slash commands**：社区写好的斜杠命令合集
- **CLAUDE.md 文件**：各类项目的真实记忆文件范例
- **Output styles**：自定义输出风格
- **Hooks / workflows / 工具**：自动化与效率工具
- **官方与第三方资源**：文档、课程、文章导航

它不是"学完就完"的课，而是**常驻发现引擎**——每次 Claude Code 出新功能，社区最佳实践会先出现在这里。

## 怎么学

1. 首次浏览（约 1 h）：只做一件事——**收藏清单**。扫一遍分类，把当下用得上的 3–5 个条目标星。
2. 立即试用一个：从 slash commands 分类里装一个与你工作最相关的，用一周。
3. 对照学习：挑 2 份别人的 CLAUDE.md 范例，与你自己第 06 课写的对比，吸收好的段落。
4. **建立回流习惯**：每周或每次 Claude Code 版本更新后，回来扫一眼新增条目（也可以直接 Watch 仓库）。

## 学完你能

- 保持对社区最佳实践的持续接触，而不是闭门造车
- 有一个随工作演进的"工具/命令收藏夹"

## 自测检查点

- [ ] 收藏 ≥ 3 个条目并至少试用 1 个
- [ ] CLAUDE.md 对标过 2 份社区范例并完成一次升级
- [ ] 设定了自己的回流频率（Watch / 日历提醒）
