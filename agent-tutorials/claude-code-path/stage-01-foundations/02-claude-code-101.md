# 02 · Claude Code 101（官方入门课）

> 资源: [anthropic.skilljar.com/claude-code-101](https://anthropic.skilljar.com/claude-code-101)
> 免费 · 预计 2 h · 难度 ★☆☆

## 它讲什么

Anthropic 官方的 Claude Code 入门课程（Skilljar 平台）：从安装登录讲起，覆盖终端会话的基本操作、日常命令、上下文引入（`@` 文件、CLAUDE.md）、常用工作流（改代码、跑测试、提交 Git）、权限确认等。是"从装好到每天用它干活"的最短路径。

## 怎么学

1. **边看边做**：这门课的价值在跟练。开两个窗口，一个放课程，一个是终端里的 `claude`。
2. 跟着完成每个练习，重点练熟：
   - 启动与会话管理（新会话、恢复会话）
   - 把文件/目录引入上下文（`@` 引用、直接粘贴）
   - 让它改代码并跑验证（改完自动跑测试/lint 的习惯）
   - 权限提示的判断：什么时候批准、什么时候切到 plan mode
3. 课程里的每个快捷键/斜杠命令当场用一遍，不要收藏了事。
4. 课后给自己布置一个真实小任务（比如给本项目 README 改一段），全程只用课上学过的操作完成。

## 学完你能

- 把 Claude Code 当成日常终端工作流的一部分，而不是玩具
- 熟练用会话管理处理"上一个任务还没完"的场景
- 建立基本安全直觉：agent 能做什么、哪里需要你把关

## 自测检查点

- [ ] 不查资料完成：启动 → 引入文件 → 修改 → 验证 → 恢复会话
- [ ] 能说出至少 5 个日常斜杠命令及其用途
- [ ] 完成过一个真实小任务（非练习仓库）
