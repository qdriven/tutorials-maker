# 03 · Claude Code in Action（官方实战演示课）

> 资源: [anthropic.skilljar.com/claude-code-in-action](https://anthropic.skilljar.com/claude-code-in-action)
> 免费 · 预计 1.5 h · 难度 ★☆☆

## 它讲什么

Claude Code 101 的续篇，以**现场演示**为主：看真实的端到端工作流——从需求到代码、调试、重构、多文件修改、与 Git 的配合等。101 教你"会用"，这门课让你"看到熟练者怎么用"，重点观察工作流的组织方式而不是单个命令。

## 怎么学

1. **看演示时带着问题**：每个场景先自己想"我会怎么做"，再看演示里 agent 的路径，对比差异。
2. 重点观察三类动作：
   - 任务怎么**拆**：一次说清还是分步引导？
   - 上下文怎么**喂**：哪些信息是提前放在 CLAUDE.md/文件里的，哪些是现场给的？
   - 验证怎么**闭环**：改完怎么确认没改坏？
3. 演示里出现的每个工作流，挑一个在你自己的项目里复刻一遍。
4. 记下演示中让你"原来还能这样"的瞬间——这些通常是后续阶段（提示词、MCP、Skills）的伏笔。

## 学完你能

- 把"聊天式使用"升级成"工作流式使用"
- 知道复杂任务的标准节奏：plan → 执行 → 验证 → 提交
- 对第二阶段产生明确的问题意识：为什么同样的话 agent 做得忽好忽坏？（答案：提示词与上下文）

## 自测检查点

- [ ] 复刻了至少一个演示工作流到自己的项目
- [ ] 能说出 3 个从演示里学到的"喂上下文"技巧
- [ ] 明确列出自己在使用中最痛的 2 个问题（带着它们进第二阶段）
