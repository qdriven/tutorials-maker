# 06 · CLAUDE.md 与记忆

> 资源: [Memory — code.claude.com/docs/en/memory](https://code.claude.com/docs/en/memory)
> 免费 · 预计 1.5 h · 难度 ★★☆

## 它讲什么

前两课解决"单次提示词"，这一课解决"**每次都生效**"：Claude Code 的记忆体系。核心是 CLAUDE.md——会话启动时自动注入的持久上下文，以及它的层级与来源：

- **项目记忆**：仓库根目录（或子目录）的 `CLAUDE.md`，随项目共享（进 Git）
- **用户记忆**：用户级的全局 CLAUDE.md，跨所有项目生效
- **企业记忆**：组织统一下发
- **临时记忆**：会话中用 `#` 快捷把指令追加进 CLAUDE.md
- **导入机制**：CLAUDE.md 里可以 `@path` 引入其他文件；自动记忆、以及与 cursor/copilot 规则文件的兼容等

典型内容：常用命令（build/test/lint）、代码风格约定、项目结构说明、环境怪癖、"永远不要做……"。

## 怎么学

1. 通读官方 Memory 文档，画一张**层级图**：企业 → 用户 → 项目 → 子目录，标注每层适合放什么。
2. 给你**当前最重要的项目**写一份 CLAUDE.md，按这个骨架起步：

   ```markdown
   # 项目名
   ## 常用命令（构建/测试/lint，精确到可直接执行）
   ## 代码风格（命名、缩进、禁止事项）
   ## 架构速览（目录职责，@-引入更细的文件）
   ## 工作流约定（提交信息格式、分支规则）
   ## 绝对不要（如：不要动 xxx 目录、不要自动 push）
   ```

3. 用 `#` 快捷键练习：会话中每次纠正 agent，就顺手 `#` 固化进 CLAUDE.md——一周后回看积累。
4. 验证效果：删掉 CLAUDE.md 开新会话做同一个任务，对比有/无记忆的产出差异。

## 学完你能

- 把"每次都要重复交代的偏好"一次性固化，agent 默认就懂你
- 分清三 个去向：**一次性的**进提示词、**项目级的**进 CLAUDE.md、**可复用能力包**做成 Skill（下一阶段的伏笔）

## 自测检查点

- [ ] 当前主力项目有一份 ≥ 5 节的 CLAUDE.md 并进了版本库
- [ ] 体验过用户级与项目级记忆的分工
- [ ] 做过有/无 CLAUDE.md 的对照实验并记录差异
