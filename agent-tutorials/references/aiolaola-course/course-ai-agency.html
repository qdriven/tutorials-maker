G0

认识你的 AI 团队

5 分钟亲眼看多角色协作,认识这支专家库,再喝一盆诚实的冷水:多智能体不是银弹,什么时候该组队、什么时候单兵更好。装好工作台,跑通第一次。
0/5 节进行中
一个人 vs 一支团队:亲眼看四个 AI 角色合写一篇小说体验267 个专家是什么:不是提示词,是"带人设的岗位"概念先泼冷水:多智能体不是银弹概念安装桌面端:下载、双击、开工实操配上模型,跑你的第一次自动组队实操
G1

单兵:用好一个专家

把专家装进你的 AI 工具,写文章、做分析、做需求、审代码——每节一个真场景,学会按交付物挑人。
0/5 节
点名一位专家:角色组队页全导览实操写文章:让内容专家从选题干到成稿实操做分析:趋势研究员的一份赛道报告实操做需求与审代码:项目经理 + 审查员的双打实操挑专家的方法:按交付物找人,不按头衔找人方法
G2

组队:AO 核心操作

一句话自动组队、图形界面运行、看懂 DAG 并行、对话式返工、产物管理——把多专家协作用顺。
0/5 节
拆开看 AI 组的队:名单、工序和那道"验收关"概念用现成模板,或自己挑人组队实操看懂并行:为什么几位专家会同时干活概念带意见返工:像老板改稿一样,让专家改到满意实操产物管理:每份交付去哪了,怎么真正用起来实操
G3

一人公司

你当老板,AI 当团队:做产品、做内容、做投研三套流水线 + 全员大会,学会用验收标准(acceptance)管住产出质量。
0/5 节
一人公司:你当老板,AI 当整个团队概念做产品:一个想法,变成能开工的方案实操做内容:一个方向,变成首月作战日历实操做投研:四道工序,加一道必须你签的字实操全员大会:一个点子,9 个部门过堂实操
G4

定制:让团队长成你的形状

读懂 YAML 工作流、画布改流程、把好阵容存成团队、自建角色和私有库、沉淀提示词资产,并会写出能真把产出打回来的验收标准。
0/7 节
读懂流水线的"配方":步骤、角色、任务、依赖概念画布:拖拽改造你的第一条流水线实操存为团队:好阵容一键复用,新任务召唤原班人马实操自建角色:花名册里没有的人,你来写实操提示词资产化:好问法别用一次就扔方法验收标准怎么写:能打回的才叫标准动手从零搭一条你自己的流水线:先在纸上,再在画布上动手
G5

模型与部署

11 种模型怎么选(EVAL 实测结论)、免 key 7 种实操、中转怎么接怎么挑(含风险清单)、Claude Code 安全切换急救、Docker/NAS 部署。
0/5 节
模型怎么选:把 g0.3 的评测变成决策表方法免 key 七条路:你已有的 AI,都能当团队的大脑实操接中转平台:一个 key,调多家模型实操中转怎么挑:一张风险与靠谱清单方法Claude 环境急救:切坏了,也能一键救回来实操
G6

生态与进阶

MCP Server 把 AO 变成 Claude Code/Cursor 的工具、接进脚本与自动化、多语言角色库与贡献指南。
0/2 节
程序员加餐:桌面端之外,还有一整个世界(选修)概念多语言角色库,和成为共建者概念

毕业
