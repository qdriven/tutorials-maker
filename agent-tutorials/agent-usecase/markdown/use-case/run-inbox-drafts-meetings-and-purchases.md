# Run inbox, drafts, meetings, and purchases

> Meta Muse reads the inbox, drafts emails, sends meeting pings, and shops via Stripe with approval required before purchases.

**Category:** Life Admin & Home  
**Agent:** Meta Muse  
**Source:** X · Sep 28, 2026

## What they did

User connected Meta Muse to inbox and Stripe. Agent reads messages, drafts email replies, sends meeting pings, and starts purchases but pauses for approval before any Stripe charge. Person provides final approval on buys.

## How it went

User called it the most useful AI tried so far for inbox, drafting, meetings, and shopping.

## Prompt

```text
Go through my inbox and sort out what needs a reply, then draft responses to the [number] most important emails in my voice. Also suggest times for [upcoming meeting] and draft a ping to [attendees]. Show me every draft and message before sending, and get my approval before any purchase.
```
