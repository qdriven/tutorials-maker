# Run lead research, support and content with agents

> A yacht-software CEO runs 20-30 Lindy agents that research leads, personalize outreach, support users and create and schedule marketing content.

**Category:** Sales, Marketing & Support  
**Agent:** Lindy  
**Source:** lindy.ai · Undated

## What they did

Elliot Cousins, CEO of Ankor, built the agents himself on Lindy, with no engineering team. They connect to Gmail, Slack, HubSpot, Notion, Zoom and Google Sheets. Agents research inbound leads and personalize outreach, monitor app performance and answer user support, create and schedule social posts and newsletters, and brief the team on prospects before calls.

## How it went

Ten agents were live in week one, and 20–30 run today. One API question got a researched, personalized reply within minutes. The 5x return is the CEO's own estimate, and the story gives no other figures.

## Worth knowing

This is a Lindy-published customer story, and the 5x ROI is self-reported with no method given.

## Prompt

```text
Set up an agent that researches new leads for my business, [what I sell and to whom]. For each lead in [spreadsheet or CRM name], it should find the company's recent news and key contacts and draft a personalized outreach email. Put the drafts in a sheet for me to review, and pause and show me each email before anything is sent. It's done when every lead has a researched profile and a draft.
```
