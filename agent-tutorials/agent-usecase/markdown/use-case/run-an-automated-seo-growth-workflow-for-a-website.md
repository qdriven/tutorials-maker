# Run an automated SEO growth workflow for a website

> Hermes agents and coding agents read Search Console and GA4 data, find SEO opportunities, edit the site code and track results for a snorkel forecast site. · Oct 12, 2026

**Category:** Sales, Marketing & Support  
**Agent:** Hermes Agent  
**Source:** refreshagent.com · Oct 12, 2026 · Submitted by @innermaps

## What they did

RefreshAgent connects Search Console and GA4 data to the agent. A scheduled Hermes SEO workflow and coding agents then inspect the site's Django repository, make scoped changes, run checks and log the work in Git. Changes go out through the existing deployment pipeline. Each experiment has a baseline, guardrails and 14- and 28-day reviews. Examples include the "maui snorkel report" query and the "best places to snorkel" page.

## How it went

Search Console clicks rose 68.8% over 30 days, from 1,886 to 3,183, and impressions rose 40.1%. The author says this is observed growth, not attributed to the agents. The page-level experiments were still under review.

## Worth knowing

Search Console data lags, so wait for indexing and the 14- and 28-day reviews before claiming any uplift. Seasonality and earlier development work can also affect the numbers.

## Prompt

```text
Each week, check Search Console and GA4 data for [my site URL] and find pages with high impressions but low clicks, or queries I almost rank for. For the top [3] opportunities, propose specific edits to the site code in [repo path] and show me the diffs. Finished means a short report of opportunities, ready-to-apply changes, and a log to compare results next week. Don't push or deploy changes until I approve.
```
