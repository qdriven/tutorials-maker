# Run first-pass topic research, then verify references

> A commenter uses Manus for first-pass research, then has Genspark double-check every reference and flag problems.

**Category:** Research & Knowledge  
**Agent:** Manus  
**Source:** johnquigginblog.substack.com · Undated

## What they did

A commenter runs the first round of research on a topic in Manus. They then paste that output into Genspark and ask it to double-check every reference and flag any other possible problems. The same commenter also keeps several 'identity versions' of themselves and has the AI write as one of them.

## How it went

The commenter says it has worked well so far. No numbers or examples are given. They say they find both tools hallucinate less than other models.

## Worth knowing

This is a short comment with no cost or time details. The claim that these tools hallucinate less is the commenter's own impression, not a measured result.

## Prompt

```text
Do first-pass research on [topic] and write a [length, e.g. 2-page] summary covering [key questions]. List every source with its URL and the specific claim it supports. Finish when each claim has a source, and flag any claim you could not back up so I can verify it.
```
