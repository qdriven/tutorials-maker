# Organize Canvas courses with an in-platform agent

> Instructure says early adopters use its IgniteAI Agent to rename modules consistently, bulk-change due dates, and rebuild course pages; this comes from a vendor video with no named users.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** instructure.com · Undated

## What they did

Instructors type a goal in plain language into the IgniteAI Agent, an assistant built into Canvas. It carries out multi-step tasks through more than 500 Canvas APIs. Early adopters use it to give modules consistent names and formatting, change due dates across several assignments at once, and rebuild course pages with custom HTML. It acts only when prompted and checks in along the way so the instructor approves the work.

## How it went

The page gives no measured results. Its only user comment is a quote from Brandon Mitchell of Hinds Community College, who says they build modules, design pages and clean up accessibility with it.

## Worth knowing

The Agent is only in the Canvas Next tier, not Core or Plus. The source is a vendor page with no figures for time saved.

## Prompt

```text
Using the Canvas API and my token [token] on my sandbox course [course ID], rename all modules to a consistent format like [naming pattern] and list the due-date changes needed to shift everything by [number] days. First show me a table of every proposed change. Pause for my approval before applying anything, and stop when the sandbox course matches the pattern.
```
