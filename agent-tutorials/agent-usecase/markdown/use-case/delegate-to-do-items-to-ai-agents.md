# Delegate to-do items to AI agents

> An agentic to-do list lets agents pick up assigned tasks, mark them in progress, complete them and return them to a review inbox for approval.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 29, 2026

## What they did

The user keeps a shared task list that both people and AI agents can access. A person assigns a task to one of the bots; the agent claims it, updates the status to in progress while working, moves it to done when finished, and returns it to the review inbox. Agents also self-assign tasks pulled from Granola meeting notes.

## How it went

Tasks flow back and forth between the user and agents as described, with no numbers or performance details reported.

## Prompt

```text
Set up a task inbox where I can assign you to-do items like [example tasks]. For each task, mark it in progress, do the work, and return it to a review list with the result and any questions. Don't send messages, spend money, or delete anything until I approve it from the review list.
```
