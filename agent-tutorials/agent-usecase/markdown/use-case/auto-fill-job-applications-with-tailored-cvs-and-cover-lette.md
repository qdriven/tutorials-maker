# Auto-fill job applications with tailored CVs and cover letters

> Commenter says an agent customizing CV and cover letter for job applications, with the user reviewing, eases the process.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** HN · Jul 1, 2026

## What they did

The source is a brief comment, not a walkthrough. The commenter says applying through Workday or similar portals requires customizing a CV and cover letter for each job, which becomes a full-time job. An AI agent would produce those tailored documents, and the applicant would review them and make changes as needed.

## How it went

No results or numbers are given. The commenter only says this arrangement would make applying somewhat easier, and doesn't report actually running it.

## Worth knowing

The source names no tools, costs, or setup; it describes the idea of keeping a human review step on the agent's tailored CV and cover letter.

## Prompt

```text
Take my CV from [file path] and the job posting at [URL], then tailor my CV and write a cover letter that matches the role using only facts from my CV. Fill in the application form with my details. Pause and show me the CV, cover letter, and filled form before I approve submitting.
```
