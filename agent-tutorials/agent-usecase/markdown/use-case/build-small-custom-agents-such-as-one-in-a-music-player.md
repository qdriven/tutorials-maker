# Build small custom agents such as one in a music player

> The author writes lots of little agents, for instance inside their music player, noting they are trivial as code.

**Category:** Content & Creative  
**Agent:** custom-built or unnamed agent  
**Source:** HN · Sep 14, 2026

## What they did

The author says they write lots of small agents instead of another coding agent, one of them inside their music player. They argue a useful agent's core takes very little code, so these are trivial as code artifacts. The comment gives no mechanics beyond that.

## How it went

The source states no results or numbers. It only says these little agents are easy to build, in contrast to competitive coding agents, which it calls tricky.

## Worth knowing

Skip building a general coding agent, since Codex and Claude are big RL targets; small purpose-built agents are the easy part.
