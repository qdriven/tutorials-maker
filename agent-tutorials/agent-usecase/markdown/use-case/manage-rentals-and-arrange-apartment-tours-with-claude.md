# Manage rentals and arrange apartment tours with Claude

> A property manager's team uses Claude in Chrome for routine management work, with a database so the AI can answer questions and check schedules to help arrange apartment tours.

**Category:** Work & Operations  
**Agent:** Claude in Chrome  
**Source:** almanacnews.com · Oct 6, 2026

## What they did

At Wilbur Properties, which oversees about 800 units, property manager Jonathan Miradi pitched his boss on AI in March. By July managers were using Claude in Chrome. Miradi also built a database so the AI can answer questions and check managers' schedules to help arrange tours. If it can't answer, it alerts a property manager.

## How it went

The article gives no figures on results. Miradi wants the system eventually to answer tenants and prospective renters through the company website, with the aim of cutting routine work rather than replacing managers.

## Worth knowing

Build in a fallback: the AI flags a person when it can't answer. California's Department of Real Estate says licensees stay responsible for checking AI-generated information.

## Prompt

```text
Using my property management tool at [site or database link], find the vacant units for [property name] and check the tour schedule for [date range]. Draft a reply to [prospect name] offering three open tour times. Pause and show me the draft and the slots before sending anything or booking a tour.
```
