# Run web research jobs and capture screenshots into a doc

> A reviewer tested Operator on analyzing web-design posts, summarizing AI news, listing website builders with prices and screenshotting sites into a Google Doc, finding login and CAPTCHA handoffs frustrating.

**Category:** Research & Knowledge  
**Agent:** Operator  
**Source:** icons8.com · Undated

## What they did

The reviewer paid $200 for ChatGPT Operator and spent a week giving it plain-language browser tasks. These included analyzing trending web-design tweets, summarizing AI news, listing AI website builders with pricing, summarizing a set of linked articles, and screenshotting sites into a shared Google Doc. Operator browsed on its own. The reviewer re-prompted it, and had to take over at logins and CAPTCHAs.

## How it went

Results were weak. Operator returned duplicate, stale tweets, summarized one Axios article, and copied the first ten items from a single Bing listicle. It looped between tabs on multi-article summaries and could not take screenshots at all.

## Worth knowing

Operator is built to hand control back at logins, payments and CAPTCHAs, so you must be present for those steps. Expect to supervise even simple multi-step jobs.

## Prompt

```text
Research [topic, e.g. website builders] by visiting the main sites, and list each with its starting price, key features and a screenshot of the homepage. Put everything into a new Google Doc called [doc name]. Hand control to me when you hit a login or CAPTCHA, and finish when the doc is complete and you've given me the link.
```
