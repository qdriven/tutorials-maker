# Schedule recurring restocking of household essentials

> Users create Scheduled Actions in Alexa for Shopping to add kids' snacks monthly and restock pet food, paper towels and detergent; vendor material.

**Category:** Shopping & Errands  
**Agent:** Alexa+  
**Source:** aboutamazon.com · Undated

## What they did

In a chat with Alexa for Shopping, the user taps the "+" icon by the message bar and creates a Scheduled Action. Examples are adding healthy kids' snacks to the cart each month and restocking pet food, paper towels and detergent. Conditions can be added, such as adding sunscreen if the price falls to $10 and it hasn't been bought in two months. Alexa does the product research, then either notifies the user or adds items to the cart.

## How it went

The source gives no results or measurements, since it is a launch announcement. The user still reviews the cart and checks out. It can run once or on a recurring schedule.

## Worth knowing

The agent only fills the cart or sends a notification, and checkout stays manual. It is free for U.S. Amazon customers, with no Prime membership or Echo required.

## Prompt

```text
Set up scheduled actions to add [household items, e.g. pet food, paper towels, detergent] to my cart every [frequency, e.g. month] on [day]. When done, list every recurring action you created with its schedule. Pause and show me the cart before placing any order.
```
