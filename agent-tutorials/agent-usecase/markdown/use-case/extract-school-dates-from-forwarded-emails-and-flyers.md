# Extract school dates from forwarded emails and flyers

> A family task manager pulls dates from forwarded school emails, reads flyer photos and syncs school calendars by zip code.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Apr 1, 2026

## What they did

The Reddit post describes Ohai as a household-focused organizer where a parent forwards school emails and the AI extracts dates, or snaps a photo of a flyer and it reads the event details. It also syncs school calendars by ZIP code and uses two-way calendar sync plus SMS reminders, with people still choosing whether to use it alongside another app for work tasks.

## How it went

The post presents it as the strongest family-specific option in the comparison, especially for reducing manual entry from school communications. The stated limitation is that it is household-only and does not handle work task management, so some families may still need a second app.

## Worth knowing

The source says Ohai costs $9.99/month for individual premium, with family members added as free connections.

## Prompt

```text
In my folder [folder path], read the forwarded school emails and flyer photos. Pull out every date, event, deadline and thing to bring, and put them in one list sorted by date with the source file noted. Then create a calendar file (.ics) I can import, and flag any date you were unsure about. Stop when every file has been processed.
```
