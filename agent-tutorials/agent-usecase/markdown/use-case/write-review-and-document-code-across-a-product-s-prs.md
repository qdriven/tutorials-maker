# Write, review and document code across a product's PRs

> Founders report Devin touching all PRs at ChatPRD and being Gumroad's top contributor with over 1,500 merged PRs.

**Category:** Software & DevOps  
**Agent:** Devin  
**Source:** lennysnewsletter.com · Undated

## What they did

The source is a promotional post and gives few mechanics. Devin takes bugs, features, or refactors assigned through Slack, Linear, Jira, or its website. It writes the code and sends a pull request for a person to review. At ChatPRD, Claire Vo says it reviews code, updates documentation, or writes all of the code on every PR.

## How it went

Claire Vo calls Devin the #2 contributor to ChatPRD, behind only her. Sahil Lavingia says it is Gumroad's top code contributor, with over 1,500 merged PRs, about 10 a day. Both are founder claims with no independent measurement.

## Worth knowing

The free year is for new Devin customers who are Insider subscribers. It includes 50 ACUs a month, which the post equates to about a week of full-time engineer work.
