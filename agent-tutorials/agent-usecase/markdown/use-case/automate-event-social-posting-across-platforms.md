# Automate event social posting across platforms

> Claude Code connected social channels to drive event registrations, working well on Twitter and Reddit and somewhat on LinkedIn.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code  
**Source:** Reddit · May 28, 2026

## What they did

The poster used Claude Code to connect their social channels for promoting the AI x Marketing Summit in San Francisco on May 28–29 and drive registrations. From the thread, the setup let Claude handle cross-platform posting, and the person judged the results by platform rather than describing a fully hands-off workflow; comments mostly discuss alternative stacks rather than extra implementation detail.

## How it went

It worked well on Twitter and Reddit, which the poster called super smooth, and only somewhat on LinkedIn. The thread does not give registration numbers or a cleaner replacement stack.

## Worth knowing

The main catch from the source is platform inconsistency: the same Claude Code setup behaved smoothly on Twitter and Reddit but was less reliable on LinkedIn.
