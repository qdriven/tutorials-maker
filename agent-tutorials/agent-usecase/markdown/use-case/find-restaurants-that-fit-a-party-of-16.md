# Find restaurants that fit a party of 16

> A user had ChatGPT find availability for a rehearsal dinner and build an HTML comparison of suitable restaurants with menus, locations and prices; they booked by phone.

**Category:** Travel & Bookings  
**Agent:** ChatGPT  
**Source:** HN · Nov 5, 2026

## What they did

The user needed a table for 16 for a rehearsal dinner and asked ChatGPT to find availability. It produced an HTML document listing only restaurants that could seat the party, with pictures, menu comparisons, locations and approximate prices. The user chose one of the recommendations, then called the kitchen manager directly to finalize and pay.

## How it went

The user said it handled the research very well and saved many hours, replacing Google, Yelp and similar services. The final booking and payment stayed a human phone call by choice, to build rapport for a special occasion.

## Worth knowing

The user kept the last step, booking and paying, as a personal call to the kitchen manager rather than handing it to the AI.

## Prompt

```text
Find restaurants in [city or neighborhood] that can seat a party of [number] on [date] at about [time] for [event type], with a budget of around [price per person]. Build a single HTML comparison page of the best [5 to 8] options showing the menu highlights, address, price range, private-room or large-group policy, and the phone number and booking contact. Mark anything you couldn't confirm, so I can call to book myself.
```
