# Handle incoming emails with automatic triggers

> Grok Bots watch incoming email, summarize, research, draft replies, extract invoice details, flag urgent items and complete next steps with connected tools.

**Category:** Work & Operations  
**Agent:** Grok Bot  
**Source:** X · Aug 2, 2026

## What they did

Grok Automations are set up with email triggers that fire on matches to sender, recipient or subject filters; the email itself supplies context. The agent then summarizes the message, researches the topic, drafts a reply, extracts invoice details, flags urgent items, and calls connected tools or files to finish next steps. A person describes the job once, attaches files and connectors, or tells Grok what to do in chat; each run saves as a reviewable conversation.

## How it went

No specific results or numbers are stated. The source only describes the general capabilities and delivery options via app notification or email.

## Prompt

```text
Watch my inbox at [email address]. For each new email, write a two-line summary, flag it as urgent or not using these rules: [rules], and draft a reply when one is needed. If it's an invoice, extract the vendor, amount, due date and invoice number into [spreadsheet or tool]. Do not send any reply or pay anything until I approve it.
```
