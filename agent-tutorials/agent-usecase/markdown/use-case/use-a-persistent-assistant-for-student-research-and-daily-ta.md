# Use a persistent assistant for student research and daily tasks

> A student used a named dot for ongoing research and daily tasks with persistent context across chats, set up for email.

**Category:** Research & Knowledge  
**Agent:** Dots  
**Source:** X · Oct 5, 2026

## What they did

A student named his OpenAI dot Lisa and used it for a week on nearly all tasks instead of opening new chats. He relied on the dot's ongoing context and personalization across conversations while testing it for research work, speaking hands-free via phone.

## How it went

The persistent context made daily use feel like working with one person; he barely started fresh chats. No specific results or shortfalls beyond his listed frustrations were stated.

## Prompt

```text
Act as my ongoing research assistant for [my field or course]. Keep notes on my topics, sources, and deadlines so each new chat picks up where the last one left off, and start by summarizing what you know about [current project]. Connect to my email only for reading, and before sending any message or deleting anything, show me exactly what you plan to do.
```
