# Research the web visually by browsing pages

> A commenter uses ChatGPT Agent Mode for visual web research, with the agent opening and working through pages.

**Category:** Research & Knowledge  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Jul 10, 2026

## What they did

The commenter says they used ChatGPT Agent Mode as a visual browser rather than a text crawler. It spun up a virtual computer, opened sites in a browser, looked at the rendered pages the way a person would, and clicked through live buttons and interfaces; they used it to search many online stores for a specific item and check whether each would ship to their country.

## How it went

They say this worked much better on dynamic interfaces than text-based crawling and let the agent visit hundreds of stores to find what they considered the best option. The thread gives no hard metrics, exact prompt, or details on where they had to intervene.

## Worth knowing

The main catch is that the source only gives a high-level description, so if you want to copy it you would need to supply the shopping goal and country constraints yourself.

## Prompt

```text
Research [topic or question] by opening and reading pages on the web, including sites that need scrolling or clicking to reveal information. Visit at least [number] sources, and for each one note what you found, plus the page link. Finish with a one-page summary that flags where sources disagree, and don't log in, submit forms, or buy anything without asking me.
```
