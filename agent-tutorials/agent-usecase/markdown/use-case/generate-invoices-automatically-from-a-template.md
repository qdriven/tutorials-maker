# Generate invoices automatically from a template

> A freelancer built a Make.com automation that fills a professional invoice template to create invoices automatically.

**Category:** Work & Operations  
**Agent:** Make  
**Source:** Reddit · Undated

## What they did

The post says the automation was built in Make.com with Google Workspace. It pulls invoice data from a Google Sheet, fills a professional invoice template, converts the result to PDF, emails it to the client automatically, and then updates the invoice status back in the sheet; the poster says they first made it for their own use and also offered to set it up or demo it for others.

## How it went

The stated outcome is time saved on manual invoicing, and the poster says it was a game-changer for sending 5–10 invoices a week. The thread gives no hard performance numbers, implementation details, or limitations beyond that.

## Worth knowing

The main catch is that the thread stays high level: it names the tools and steps, but puts setup, demo, and cost details in DMs rather than in public.

## Prompt

```text
Build a scenario that creates an invoice from my template [Google Docs or Sheets template link] whenever [trigger, such as a new row in a sheet or a completed job]. It should fill in client name, line items, amounts, invoice number and due date, then save a PDF to [folder]. Test it with one sample invoice and show it to me, and don't email it to any client until I approve.
```
