## What they did

Daria Cupareanu built a consulting-business demo site from the Claude desktop app's Code tab, not the terminal, using auto-accept edits mode. After a first prompt, Claude asked her questions and built the site. She then connected Supabase, Stripe, Resend, GitHub and Vercel with keys and accounts, and Claude also handled SEO, analytics and legal pages. The detailed prompts are behind a paywall.

## How it went

The article says the result is a live custom-domain site with a Stripe payment button, a contact form and a lead magnet that delivers itself. It gives no timings or metrics, and the step-by-step detail is paywalled.

## Worth knowing

You need a Claude Pro plan ($20/month) and a domain (about $10-20/year). The author says the other tools' free tiers are enough to start.
