# Build a full ad campaign from a client's website

> An agent scraped a client's site, built a multilingual ad campaign with keywords, copy and tracking plan, and flagged a conversion problem.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jul 4, 2026

## What they did

User pasted a client's website URL. The Claude Opus agent scraped the site itself, learned the product, identified an unmentioned conversion issue, then generated a full multilingual ad plan with Spanish and Catalan keywords plus negatives, verified ad copy, and tracking setup. It saved everything as a shareable document.

## How it went

The agent produced a complete campaign in minutes that addressed the flagged conversion problem. No performance metrics or shortfalls are stated.

## Worth knowing

Free to try with no card required.

## Prompt

```text
Take [client website URL] and build a [language list] ad campaign for [Google Ads or other platform]. Deliver keyword groups, ad copy for each language, a tracking plan, and a note on any problems you spot on the site that could hurt conversions. Put it all in one document and don't publish or spend anything on ads.
```
