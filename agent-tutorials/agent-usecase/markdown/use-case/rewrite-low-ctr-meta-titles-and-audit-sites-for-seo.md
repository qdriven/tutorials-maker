# Rewrite low-CTR meta titles and audit sites for SEO

> An SEO agency tests Claude Code with a CMS API and Search Console to rewrite meta tags for low-CTR pages, push changes, and audit robots.txt, sitemaps and structured data.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code  
**Source:** studiohawk.com.au · Undated

## What they did

StudioHawk tests Claude Code in controlled batches. It connects to a CMS through its API and pulls Google Search Console data. It finds pages with high impressions and low click-through rate, rewrites their titles and descriptions against page content and intent, and pushes the changes back. It also audits robots.txt for AI crawlers, XML sitemaps and structured data. Strategists define the standards and approve each batch before it goes live.

## How it went

The source calls early results promising. It claims meta audits across hundreds of pages drop from 6-8 hours to minutes. It gives no measured CTR or traffic outcomes.

## Worth knowing

Run every script in dry-run mode first, with backups, JSONL audit logs and 1 request per second throttling. The source estimates $5–15 in API credits per session.

## Prompt

```text
Using the Search Console export in [file path], find pages for [my site] with high impressions but low click-through rate. For each, write a new meta title and description under the length limits, and save them in a spreadsheet with the old and new versions side by side. Do not push any changes to my CMS until I've reviewed the list and said go ahead.
```
