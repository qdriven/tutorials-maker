# Audit a feature's issues and hand them to an engineer's agent

> An AI agent listed all issues with a feature and sent them to an engineer, whose own agent then addressed most of them automatically.

**Category:** Software & DevOps  
**Agent:** custom-built or unnamed agent  
**Source:** Bluesky · Oct 4, 2026

## What they did

Dare Obasanjo had an AI agent go through a feature and list every issue it found. He sent that list to an engineer. The engineer's own agent then worked through the list, and an automated reply came back to him. The post gives no tool names or setup details.

## How it went

The automated reply said the engineer's agent had addressed most of the issues on the list. The post doesn't say how many issues there were or which ones were left.

## Prompt

```text
Review the [feature name] feature in this repo and list every issue you find: bugs, missing edge cases, unclear UX, and test gaps. Write each as a separate issue with a title, steps to reproduce, and suggested fix, and sort them by severity. Stop once the list is complete, and show it to me before filing anything in [issue tracker] or messaging [engineer name].
```
