# Prototype a promo video and design work with bots

> An xAI designer used bots to prototype an animated promo, build a playground from the animation spec, and handle Figma and prototype tasks.

**Category:** Content & Creative  
**Agent:** Grok Bot  
**Source:** x.ai · Undated

## What they did

The designer, John Bai, asked a motion bot (Motion God) to build a localhost playground around the real character animation spec file, not a recreation. He tuned timing, springs and easing by hand and gave short comparative feedback, and the bot reran the sequence each time. A Figma bot used the Figma MCP to fill cards and logos from his component and template.

## How it went

He produced a promo animation of the character appearing, noticing the window and bouncing into place, using the production asset. Figma Bro filled 20 starter-bot cards and placed tool logos. The source gives no timing or cost figures.

## Prompt

```text
I need a prototype of an animated promo for [product or launch]. Based on this description of the animation [paste spec or notes], build a small interactive playground I can click through and list any design tasks you'd handle in [Figma]. You're done when I can preview the prototype and see a short list of next steps.
```
