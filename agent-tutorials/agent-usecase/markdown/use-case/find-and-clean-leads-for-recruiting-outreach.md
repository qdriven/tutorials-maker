# Find and clean leads for recruiting outreach

> A recruiting agency owner uses Claude to find leads; a commenter uses it to clean messy data and draft personalized outreach that gets replies.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code  
**Source:** Reddit · Undated

## What they did

The poster wired Claude to MCP connections for Crustdata, FullEnrich, Lemlist, HubSpot, and GitHub, then gave it plain-English criteria like US companies with 100–500 employees, 15+ recent openings, fresh funding, and a recruiting manager to contact. Claude pulled company and hiring signals, found and verified contacts, assembled hiring and news briefs, and drafted outreach angles; in comments, another recruiter said they use Claude to clean rough lists, enrich and organize them into sheets/CRMs, and polish personalized messages before sending.

## How it went

The source says it saved the poster time and commenters said personalized Claude-assisted outreach gets replies, but it gives no hard performance numbers. Commenters also warned the signals can be late or noisy, so the workflow may find companies already in-market rather than those about to hire.

## Worth knowing

One commenter’s main practical tip was to pay for Claude Pro so usage limits do not interrupt the workflow.

## Prompt

```text
I run a recruiting agency placing [type of role] in [industry/region]. Clean up my messy contact list at [path/to/file] by fixing names, removing duplicates, and standardizing company and title fields. Then draft a short, personalized outreach message for each [candidate/client] based on their details, and save the cleaned file and drafts without sending anything.
```
