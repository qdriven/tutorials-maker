# Build a Great Gatsby lesson plan in a spreadsheet

> Ethan Mollick had Claude computer use build a high school Great Gatsby lesson plan with Common Core-aligned assignments in one spreadsheet.

**Category:** Content & Creative  
**Agent:** Claude computer use  
**Source:** aiiq.substack.com · Undated

## What they did

Ethan Mollick gave Claude's computer use beta one instruction: plan a Great Gatsby unit for high schoolers, split into readable chunks, with assignments tied to Common Core standards, all in one spreadsheet. Claude then worked on its own. It downloaded the book, searched the web for lesson plans, and filled out a draft in a spreadsheet app. It then looked up Common Core standards and revised the sheet. Mollick walked away and checked back later.

## How it went

Mollick found the results not bad and saw no obvious errors, though he said some could remain. He got finished drafts to comment on instead of a process to manage. The system was quite slow.

## Worth knowing

Computer use was only a beta available through the API, so it wasn't usable in the regular chat app. Expect slow runs and check the output for errors.

## Prompt

```text
Build a [number]-week lesson plan for [book or unit] for [grade level] students in one spreadsheet. Include a tab for weekly topics, a tab with assignments aligned to [standards, e.g. Common Core], and a tab for rubrics and due dates. You are done when every week has at least one reading, one assignment and one assessment, and show me the finished file before I share it.
```
