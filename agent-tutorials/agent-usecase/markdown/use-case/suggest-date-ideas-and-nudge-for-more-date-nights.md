# Suggest date ideas and nudge for more date nights

> Trained a Claude Code assistant with date spot lists and guidelines to suggest dates, nudge when needed and possibly book reservations.

**Category:** Life Admin & Home  
**Agent:** Claude Code  
**Source:** X · Dec 27, 2025

## What they did

Gave the Claude Code exec assistant a list of date spots (new and favorites) and had it interview for guidelines on frequency and selection. Agent already had calendar access, suggests solo or double dates with friends, nudges after too long without one, and asks for new spots or friends to add.

## How it went

No results reported yet as the setup targets 2026 dates.

## Prompt

```text
Set up a date-night assistant for me and [partner's name]. Here is a file of our favorite date spots and guidelines: [paste list, budget, dietary needs, distance limits, preferred days]. Each week, suggest three date ideas that fit, and if we haven't had a date in [number] weeks, draft a nudge message for me. Stop when you've written the assistant's instructions and one sample set of suggestions; pause and show me before making any reservation or sending any message.
```
