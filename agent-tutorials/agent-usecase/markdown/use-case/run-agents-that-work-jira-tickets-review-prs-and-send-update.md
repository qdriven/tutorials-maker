# Run agents that work Jira tickets, review PRs and send updates

> Luke runs several Hermes agents that read Jira tickets, write code, review PRs, track costs, summarize docs and send updates.

**Category:** Software & DevOps  
**Agent:** Hermes Agent  
**Source:** X · Jun 29, 2026

## What they did

Luke set up multiple Hermes agents as a team that independently read Jira tickets, wrote code, reviewed PRs, tracked costs, summarized docs, ran workflows, sent updates, built games in Unreal Engine, and created cities. He gave them access to these systems and let them operate while he spent time with family, stepping in only to build and oversee the overall setup.

## How it went

The agents handled the listed tasks in parallel, freeing him to do more without working alone. No specific results or shortfalls are stated.

## Prompt

```text
Watch my Jira project [project key] for tickets assigned to [me / label]. For each one, read it, make the code change in [repo], and open a pull request that links the ticket. Pause and show me the PR and any status update you plan to post to [Slack channel] before posting, and stop once each ticket has a PR.
```
