# Build a company structure with Claude Code agents

> The poster used Claude Code agents to set up a company, including a marketing agent that handles brand identity and color palettes.

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** Reddit · Nov 1, 2025

## What they did

The poster set up Claude Code as a team of specialized agents with separate roles: a CPO for product vision, a product manager for PRDs, marketing for brand identity and color palettes, UX and product design, architecture, security, QA, DevOps, and dev agents for frontend, backend, and DBA work. The system used Linear plus MCP connections to tools like Supabase, with agents documenting work in project files and Linear to preserve task-specific context; the poster says a human still shaped vision, managed balance, and oversaw the workflow.

## How it went

They say the setup genuinely worked, was pleasant to use, and was used to deliver at least one paid utility. But they also describe it as weeks of work, still needing balance and oversight, and only covering their monthly Claude, ChatGPT, and Gemini subscription costs rather than producing meaningful revenue.

## Worth knowing

Their clearest cost figure is about $40 per month for Claude and ChatGPT in one comment, though elsewhere they say the project only earned enough to cover Claude, ChatGPT, and Gemini subscription fees.

## Prompt

```text
Help me set up [company or project name], which [what it does and who it's for], as a small team of agents. Create separate agent definitions for [roles, e.g. marketing, operations, research], and have the marketing agent propose a brand identity with a name rationale, tone of voice, and three color palettes with hex codes. Save everything in a folder called [folder name] and summarize each agent's job. Stop when each role has a working definition and the brand brief is written.
```
