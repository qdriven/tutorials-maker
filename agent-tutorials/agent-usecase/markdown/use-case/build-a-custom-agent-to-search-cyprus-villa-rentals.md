# Build a custom agent to search Cyprus villa rentals

> Marc Lou built an agent that combined public real estate data with air quality, water, noise and landslide data into an Airbnb-style interface for villas.

**Category:** Travel & Bookings  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 5, 2026

## What they did

Marc Lou prompted an AI agent to pull public Cyprus real estate datasets and merge them with public AQI, water quality, noise maps, and landslide susceptibility layers. The agent then generated an Airbnb-style interface from the combined data. He refined the output across five prompts in twenty minutes.

## How it went

The site shows villa listings with environmental overlays and refreshes data every twenty-four hours. No further metrics on listings or usage are stated.

## Worth knowing

Total effort was five prompts and twenty minutes.

## Prompt

```text
Build me a small web app that helps me search [rental type, e.g. villas] in [region]. Combine public listing data from [source] with environmental data like air quality, water quality, noise and natural hazard risk, and show results on a map with filters. Stop when it runs locally and I can filter by [criteria].
```
