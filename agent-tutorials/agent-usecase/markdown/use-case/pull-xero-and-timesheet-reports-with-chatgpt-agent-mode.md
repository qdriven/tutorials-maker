# Pull Xero and timesheet reports with ChatGPT agent mode

> A bricklaying firm owner used an agent to pull reports from Xero and a timesheet app; it helped but notifications dropped and others couldn't check it, and supplier orders tripped it up.

**Category:** Work & Operations  
**Agent:** ChatGPT Agent  
**Source:** scalify.au · Undated

## What they did

The owner of a commercial bricklaying firm with about 200 staff ran an agent tool alone to pull reports from Xero and the timesheet app. The source doesn't say which agent tool it was. The agent did the pulling, and the owner was the only person who used it. The firm's bigger pain was a full day each week spent verifying timesheets for about 100 staff.

## How it went

It helped, but notifications kept dropping out and nobody else in the business could use or check it. Within weeks the firm outgrew it and asked about training six team members instead.

## Worth knowing

The source says a fixed, repeating Xero-to-app data move suits a scheduled automation better than an agent, and that supplier-order filling needs a person approving each order.

## Prompt

```text
Log into [accounting tool] and [timesheet app] and pull the [report names, e.g. profit and loss, weekly timesheets] for [date range]. Put the key figures into one summary table showing [fields you care about] and note any numbers that look off or any steps you couldn't complete. Pause and ask me before submitting any form, placing any order, or changing any data.
```
