# Apply for Dutch rentals and schedule viewings

> Uprent's agent submits viewing requests, reads landlord emails, drafts replies and schedules viewings; one complaint is duplicate applications to the same ad.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** au.trustpilot.com · Sep 13, 2025

## What they did

Uprent's agent learns a renter's preferences, scans listings across Dutch rental sites, and spots new ones. It then submits viewing requests right away. Per the company's description, it also reads landlord emails, drafts replies, schedules viewings and auto-fills forms. Reviewers mention an automatic-apply tool called Bob and Google Calendar events created for scheduled viewings.

## How it went

Reviewers say being first to apply won them viewings, and one couple secured a home in Almere. Trustpilot shows 41 reviews. One reviewer says it sometimes sends several applications to the same ad. Others report site lag and a browser extension that stopped working for a few days.

## Worth knowing

These are user reviews plus the company's own description, not a detailed account. Check for duplicate applications to one landlord, since a reviewer reported that.

## Prompt

```text
Search [rental site, e.g. Funda or Pararius] for rentals in [city] under [max rent] with [bedrooms] bedrooms and [must-haves]. Keep a list of every listing you have already contacted so you never apply to the same ad twice. For each new match, show me the viewing request message you plan to send and wait for my approval before sending it. Stop when I have approved or skipped every current match.
```
