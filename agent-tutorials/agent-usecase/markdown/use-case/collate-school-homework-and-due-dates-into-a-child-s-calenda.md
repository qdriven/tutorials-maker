# Collate school homework and due dates into a child's calendar

> A parent had Meta Muse log into the school information system via its credential vault, gather homework and due dates, and add calendar entries with reminders, running daily.

**Category:** Life Admin & Home  
**Agent:** Meta Muse  
**Source:** HN · Sep 22, 2026

## What they did

The parent gave Meta Muse access to its credential vault so it could log into the child's school information system and other school websites. It read through the postings, collated homework and due dates, and added calendar entries with a day-before reminder linking to the calendar. The parent first modeled the workflow formally, as they do for all LLM procedures, then scheduled it daily.

## How it went

The parent called it not bad overall and found the credential vault useful. It had only just been set up, so long-term results weren't yet known.

## Worth knowing

The parent only shares information with Meta that they would be fine disseminating anyway, and judged the privacy trade worth the reduced school-imposed burden.

## Prompt

```text
Each weekday afternoon, log into [school information system] using my saved credentials and collect [child's name]'s new homework and due dates. Add each item to [calendar name] with a reminder the evening before it is due, and skip anything already on the calendar. Finish each run with a short summary of what you added, and ask me before changing or deleting any existing calendar entry.
```
