# Build an AI to-do list web app in 9 hours with Replit Agent

> The poster used Replit Agent V2 to build a fully functional AI to-do list web app in about nine hours.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** Reddit · Jan 1, 2025

## What they did

A non-developer started with a ChatGPT-written requirements brief, then pasted it into Replit Agent V2 to generate a responsive to-do web app. The agent built and iterated on the app, including ChatGPT-powered task generation, while the poster used other models for prompts, bug fixes, copy, and requirements, and later asked Agent to add PostgreSQL, login, sharing, and PayPal subscriptions before inviting friends to test it.

## How it went

In under 9 hours total, they got a live MVP on their own domain and said it already had four subscribers. It still had a major flaw: premium access restrictions were not enforced, and the poster was unsure about the app’s technical and security quality.

## Worth knowing

They spent $10 on Replit Core and said the app initially stored data locally, with Replit data unencrypted by default until they fixed it.

## Prompt

```text
Build a to-do list web app that uses AI to [e.g. break tasks into steps, prioritize, or suggest due dates]. Include user-friendly task creation, editing, completion, and [login if wanted]. Show me the plan first, build in small steps, and finish when the app runs and I can test the AI feature. Tell me before using anything that costs extra.
```
