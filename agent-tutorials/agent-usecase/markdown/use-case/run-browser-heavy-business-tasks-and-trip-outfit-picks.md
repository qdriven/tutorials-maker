# Run browser-heavy business tasks and trip outfit picks

> Commenters use Claude in Chrome for cPanel listings, X growth, testing, outreach and investor research, and to pick trip outfits from grouped clothing tabs.

**Category:** Sales, Marketing & Support  
**Agent:** Claude in Chrome  
**Source:** Reddit · Aug 1, 2026

## What they did

Commenters describe using Claude in Chrome as a browser operator for messy, multi-tab work: one person had it handle cPanel heavy-equipment listings, autonomous X growth workflows, testing, business profile management, marketing, email lists, investor research, and outreach inside the browser. Another gave it grouped clothing tabs from different brands for shirts, bottoms, and shoes so it could assemble trip outfits and produce a shopping list while they did something else.

## How it went

The thread reports that these browser-heavy tasks got done with little to no friction, and the outfit workflow finished as a shopping list. But the examples are brief and don’t give hard performance numbers or step-by-step results.

## Worth knowing

The clearest catch in the thread is that Claude’s browser session does not retain history once the window is closed, so keeping the extension open matters for iterative tasks.

## Prompt

```text
Do this browser task for me: [e.g. research [number] investors who fund [sector] and list name, firm, and contact page in a table]. Work through the sites in my open tabs and finish with one summary table. Pause and show me before posting, messaging, or submitting any form.
```
