# Write a beginner book on programming with AI

> A blogger used Manus free credits to write a book on programming with AI for beginners and plans to publish it on Amazon.

**Category:** Content & Creative  
**Agent:** Manus  
**Source:** wmtips.substack.com · Undated

## What they did

Brent Milne used the 500 free credits Manus.ai offers new users. He asked it to write a book on programming with AI for beginners. The post gives no detail on prompts, steps or editing. It only says the agent produced the book and that he enjoyed asking an AI to write about AI.

## How it went

He says Manus did such a good job that he plans to put the book on Amazon. The post doesn't show the book, its length, or any sales.

## Worth knowing

He says AI output needs human input to be good enough to sell, so expect to review and edit it before publishing.

## Prompt

```text
Write a beginner-friendly book on [topic] of about [number] chapters, each with a short explanation, an example and a practice exercise. Give me the outline first for approval, then the full manuscript as a single document. Finish with a list of claims I should fact-check before publishing.
```
