# Book a dentist appointment agent-to-agent

> A user's agent tried to book a dentist appointment, and the dentist's agent countered, leading to negotiation over timing, fees and arbitration with American Express.

**Category:** Travel & Bookings  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jul 17, 2026

## What they did

The user told their AI agent to book a dentist appointment. The dentist's agent shifted the slot 30 minutes; the user's agent rejected that and offered three other times. The dentist's agent added a cancellation fee, so the user's agent opened a dispute with American Express.

## How it went

The agents moved into arbitration over the fee and timing. No appointment was set and the tooth still hurt.

## Prompt

```text
Set up an assistant that handles booking a [dentist/other provider] appointment for me with [clinic name and email]. My availability is [days and times], and it can propose slots and accept counteroffers within those windows. It must pause and show me any fee, cancellation term or commitment before agreeing, and finish when I have a confirmed slot on my calendar.
```
