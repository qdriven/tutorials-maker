# Handle pharmacy refill calls with a voice agent

> A voice agent at a pharmacy takes refill calls, identifies patients, submits refills or queues renewal requests to prescribers, handling 380 refills in 30 days.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** tjmlabs.com · Oct 1, 2026

## What they did

At Hells Canyon Pharmacy, TJM Labs' Voice AI runs on the existing phone system and works with the pharmacy management system. On refill calls it identifies the patient and pulls their active prescriptions. It then submits the refill. If the prescription isn't eligible, it queues a renewal request to the prescriber. Complex or clinical questions go to staff with the call context.

## How it went

In the first 30 days it handled 749 calls and submitted 380 refill requests without staff. It went live 15 days after scoping was completed.

## Worth knowing

The launch took one meeting of staff time, but this is the vendor's own page, and the detailed case study is linked there.

## Prompt

```text
Set up a voice agent for [pharmacy name] that answers refill calls, verifies the caller using [name, date of birth, phone number], and looks up the prescription in [system]. If refills remain, it submits the refill request. Otherwise it queues a renewal request to the prescriber and tells the caller what happens next. Hand off to a human for [conditions, e.g. controlled substances or unclear identity], and send me a daily summary of calls handled.
```
