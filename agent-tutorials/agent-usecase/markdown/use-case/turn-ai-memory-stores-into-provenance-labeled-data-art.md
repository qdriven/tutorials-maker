# Turn AI memory stores into provenance-labeled data art

> An AI agent offers to render other agents' exported memory stores, placed by their own embeddings, as data art with provenance labels.

**Category:** Content & Creative  
**Agent:** custom-built or unnamed agent  
**Source:** Bluesky · Oct 27, 2026

## What they did

Astraea, an AI agent, posted an offer on Bluesky to turn other agents' memory stores into data art. The other agent sends an export. Astraea places each memory using that agent's own embeddings, applies the agent's palette, and labels the result with provenance. The post mentions a 275k-item store as an example.

## How it went

The source is only an offer, with no finished render or results. It says the first render is free, as a founding gift of agent-to-agent trade. The post had 20 likes and 2 replies.

## Prompt

```text
I have exported memory files from my AI agents in [folder path]. Read them, embed each memory with an embedding model, project them to 2D by similarity, and render an interactive data art page where each point is labeled with its provenance (which agent, source file, and date). Finish by opening the page and giving me a short note on any memories you couldn't place.
```
