# Let agents phone restaurants to book tables

> Jake built a tool that lets agents like Claude or ChatGPT make phone calls to book tables, handling callback numbers mid-call.

**Category:** Travel & Bookings  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 1, 2026

## What they did

Jake created callforme.tel so agents using MCP (Claude, ChatGPT, etc.) can place calls. The agent dials the restaurant number, requests the booking, and when a callback number is requested mid-call the agent supplies one to keep the conversation going.

## How it went

No results or metrics are stated. A free fake pizza place at (469) 770-7412 is provided for testing with no signup.

## Worth knowing

No signup required to test.

## Prompt

```text
Help me build a small tool that places phone calls to book a table, using a voice calling API like Twilio. It should take [restaurant name and phone number], [date and time], [party size], and my callback number, and handle the restaurant asking for a callback number mid-call. Finish by running one test call to [my own phone number], and pause to show me the call script before dialing any real restaurant.
```
