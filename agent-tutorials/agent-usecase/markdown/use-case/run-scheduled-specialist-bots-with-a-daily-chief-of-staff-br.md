# Run scheduled specialist bots with a daily chief-of-staff brief

> From one setup message Grok Bot made five weekday-scheduled specialist bots and a 9:00 brief combining their output; connectors timed out and jobs sometimes came back half-finished.

**Category:** Work & Operations  
**Agent:** Grok Bot  
**Source:** sharbel.com · Undated

## What they did

Sharbel sent Grok Bot one message with everything about himself: his job, goals, clients and schedule. He had exported it from another agent into a file. He asked it to propose bots and create them. It built five named specialists, each with a role and a weekday schedule. It also made itself Chief of Staff, with a 9:00 brief combining the other five, and it left his existing bots alone.

## How it went

The setup worked as a demo. In two weeks of use, though, the shared machine could get stuck and take every bot down, connectors timed out, one never connected, and jobs sometimes came back half finished.

## Worth knowing

No plan states its usage allowance. The free trial can run out in a day, and after that it charges per token, so budget for tokens rather than the $20.

## Prompt

```text
Set up specialist bots that run on weekdays for these jobs: [job 1], [job 2], [job 3]. Then create a chief-of-staff bot that sends me a combined brief at [time] summarizing what each one did, with anything unfinished or failed listed clearly at the top. Finish by showing me the schedule and a test run of the brief.
```
