# Build a budgeting app from a single prompt

> A low-coder used Replit Agent to build a 'Budget Buddy' with category budgets, a spending dashboard and expense log in about 20 minutes, using half their monthly credits.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** justinyjtan.substack.com · Undated

## What they did

As an early test of Replit Agent, the author gave it one long prompt describing a budgeting tool: monthly budgets per category, a dashboard with pie and line charts, an expense log, and local data storage. The first pass was good. They then refined it with 7-8 more prompts over about 20 minutes into 'Budget Buddy'.

## How it went

It reached a working prototype in roughly 20-30 minutes. The credit figure in the source covers a separate three-day newsletter app build, not Budget Buddy.

## Worth knowing

The half-of-monthly-credits cost came from the three-day newsletter app on Replit Core ($25/month, or $15 on an annual plan). The budgeting test's own cost isn't stated.

## Prompt

```text
Build a personal budgeting app called [app name] where I set budgets per category, log expenses, and see a dashboard of spending against each budget. Keep it simple and use sample data to start. You're done when I can add an expense and watch the dashboard update. Tell me roughly how much of my credits you expect to use before starting.
```
