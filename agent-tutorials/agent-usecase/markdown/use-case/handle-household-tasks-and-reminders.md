# Handle household tasks and reminders

> Nori manages household tasks, important calls, reminders, family schedules and logistics for a family.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jan 28, 2026

## What they did

User speaks tasks like booking dentist appointments or school pickups directly to Nori, which captures them and adds to the family calendar automatically. Nori uses Call Alert to phone the user about reminders instead of sending notifications, and shares all updates across family members' calendars without further input. Person only needs to speak the initial item.

## How it went

User reports no more forgotten tasks, double-bookings, or mental clutter, and no longer tracks everything manually. Source states no metrics or shortfalls.

## Prompt

```text
Be the household manager for my family of [number of people]. Keep track of recurring tasks like [chores or bills], remind me of upcoming items and family schedules each morning, and draft a list of calls I need to make this week with the number and a one-line script for each. Check with me before making any call, sending any message, or paying for anything.
```
