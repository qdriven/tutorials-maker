# Submit affiliate applications and triage inboxes

> Users report Grok Bot submitting 158 affiliate applications via browser, triaging Gmail and Slack, and doing daily site review and code updates.

**Category:** Sales, Marketing & Support  
**Agent:** Grok Bot  
**Source:** superapp.dev · Undated

## What they did

Grok Bot gives each named Bot a cloud computer with a browser, where it signs in to the services you allow and runs scheduled routines. Reviewers reported using it for several kinds of work. Ali Fakhri submitted 158 affiliate applications in two days and entered the passwords himself. Claire Vo connected four Gmail accounts and seven Slack workspaces. Flavio Copes ran a daily blog review and an update-old-posts Bot. Approvals stayed on for sensitive steps.

## How it went

Fakhri measured about 25 hours of work across four workflows falling to about 3. Copes got three merged pull requests in two days. Beta outages and failing connectors hit Fakhri, and the source says Superapp did not test it itself.

## Worth knowing

All of an account's Bots share one computer and its logins, so they are not a security boundary. Frequent routines also use up the weekly allowance quickly.

## Prompt

```text
Using the browser, find affiliate programs in [my niche] that fit my site at [website URL] and fill out their application forms with my details: [name, site, audience description]. Keep a running sheet of each program, the date, and its status. Before submitting each batch, pause and show me the programs and the answers you plan to send, and stop when [number] applications are done.
```
