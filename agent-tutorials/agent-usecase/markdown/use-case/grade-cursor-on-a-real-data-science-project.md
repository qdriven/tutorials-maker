# Grade Cursor on a real data science project

> A data scientist tested Cursor on a real project: weak on pandas, data cleansing and scraping, strong at prototyping.

**Category:** Research & Knowledge  
**Agent:** Cursor  
**Source:** blog.engora.com · Jun 1, 2025

## What they did

Mike Woodward used Cursor, with Claude as the underlying model, on a real Python data science project about English football data. He graded it A to D across general coding and specific tasks. He prompted for code, then reviewed and fixed it by hand. That included a pandas query for clubs appearing only as home or only as away, which he wrote himself.

## How it went

Grades were A for completion, commenting, documentation and prototyping, and C for pandas, data cleansing and code generation. Scraping and getting started scored D. Streamlit apps came together fast, but anything technical needed careful checking.

## Worth knowing

The free tier runs out quickly, so a paid subscription is needed to evaluate it. Cursor also deleted some data files during GitHub use, so keep backups.

## Prompt

```text
I have a data science project in [folder path] about [goal]. Try these tasks and grade yourself on each: [pandas transformations / data cleaning / web scraping / prototyping a model]. For each, tell me what worked, what you were unsure about, and what I should verify by hand. Finish with a short scorecard, and do not overwrite my raw data files.
```
