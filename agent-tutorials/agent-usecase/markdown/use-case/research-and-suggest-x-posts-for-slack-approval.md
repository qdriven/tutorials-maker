# Research and suggest X posts for Slack approval

> A commenter built a client agent using Make for research that sends post suggestions to Slack for human approval before posting on X.

**Category:** Sales, Marketing & Support  
**Agent:** Make  
**Source:** Reddit · Feb 1, 2025

## What they did

A commenter said they built a similar setup for a client mostly in Make.com. The agent handled research, generated social post suggestions, and sent them into Slack, where a person reviewed or edited them before approving a post to be published on X.

## How it went

They reported that this workflow was working for the client, but the thread gives no metrics, volumes, or performance numbers. The main limitation stated is that posting was not fully autonomous because human approval happened in Slack first.

## Worth knowing

The source is thin: it names Make.com, Slack approval, and posting to X, but does not share the workflow, costs, or model details in the thread.
