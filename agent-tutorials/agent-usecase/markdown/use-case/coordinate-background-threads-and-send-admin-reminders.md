# Coordinate background threads and send admin reminders

> A dot managed background threads from one conversation and proactively reminded the user to send documents to an accountant and check on a refund.

**Category:** Life Admin & Home  
**Agent:** Dots  
**Source:** X · Sep 29, 2026

## What they did

The user kept one main conversation with the dot. The dot coordinated other threads in the background on its own and sent proactive messages reminding the user to send quarterly documents to the accountant and check on a refund.

## How it went

The user found the single-conversation coordination convenient and the reminders magical, with no metrics or shortfalls stated.

## Prompt

```text
Keep track of my background tasks in this conversation: [list tasks, e.g. gather tax documents, follow up on a refund from vendor X]. Check in on each at a sensible cadence and remind me proactively, for example to send [documents] to [accountant name] by [date] and to check the status of [refund details]. Give me a short status update every [frequency] and mark items done when I confirm. Before emailing or contacting anyone on my behalf, show me the message and wait for approval.
```
