# Find flight info and book an Uber

> Grok Bot found flight information and booked an Uber ride for the user based on their travel details.

**Category:** Travel & Bookings  
**Agent:** Grok Bot  
**Source:** X · Oct 9, 2026

## What they did

The user shared travel details with Grok. While the user showered, the agent located the flight information on its own and booked an Uber ride without further input.

## How it went

The tasks were completed, leaving the user with a booked Uber ride and a personal assistant experience.

## Prompt

```text
Look in my email for my upcoming trip confirmation for [airline or trip] and pull out the flight number, departure time, terminal and arrival time. Then set up an Uber from [pickup address] to the airport so I arrive [number] hours before departure. Show me the pickup time, estimated price and ride type, and wait for my approval before booking.
```
