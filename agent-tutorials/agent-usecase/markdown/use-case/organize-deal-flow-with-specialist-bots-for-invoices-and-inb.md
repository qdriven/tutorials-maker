# Organize deal flow with specialist bots for invoices and inbox

> Connected to WhatsApp and Notion, five specialist bots handle invoices, inbox cleanup, CRM updates and follow-ups; the author expects to save five to six hours a week.

**Category:** Work & Operations  
**Agent:** Grok Bot  
**Source:** X · Undated

## What they did

User messaged Grok Bot to connect to the Notion workspace tracking deals; the bot located the Notion connector, opened Notion, and requested approval to link. Within an hour it created five specialist bots connected to WhatsApp, Notion, Stripe and other tools, each scoped to one function (Chief of Staff for coordination and handoffs, Partnerships for monitoring conversations, etc.) and set to run asynchronously on tasks such as invoices, inbox cleanup, CRM updates and follow-ups.

## How it went

Bots are expected to recover five to six hours per week by handling repetitive work the user dislikes, while the user continues to review outputs before final steps.

## Worth knowing

Runs on Cursor Pro Plus at $60/month; all bots share one cloud computer so access and approvals must be granted deliberately.

## Prompt

```text
Set up a small team of assistants connected to [WhatsApp, Notion and email] to handle my [invoices, inbox cleanup, CRM updates and follow-ups]. Start by drafting everything for my review, and pause and show me before sending any message, paying anything or deleting anything. You're done when each task type has a working flow and you've shown me a test run on [a few sample items].
```
