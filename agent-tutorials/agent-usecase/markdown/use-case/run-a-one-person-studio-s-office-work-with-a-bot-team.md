# Run a one-person studio's office work with a bot team

> Fourteen Grok Bots handle research, briefs, infra checks and Buffer social queuing; one turned an itch.io comment into merged Amiga fixes in under a day.

**Category:** Work & Operations  
**Agent:** Grok Bot  
**Source:** X · Oct 11, 2026

## What they did

The author set up fourteen Grok bots to run the office side of a one-person studio, covering research, briefs, infra checks, and queuing social posts in Buffer. One bot took an itch.io comment and produced Amiga fixes that were merged in under a day; a separate Monday routine feeds into the same queuing flow.

## How it went

The bots completed the described tasks, with the itch.io case reaching merged code within a day and the routine ending in queued Buffer posts.

## Prompt

```text
Act as an operations assistant for my small [business type]. Each morning, check [infrastructure or site URLs] for problems, summarize anything new in [feedback source such as comments or support inbox], and queue [number] social posts in [scheduling tool] based on my recent work. Send me one short report with issues found and posts queued, and ask me before publishing, deleting, or making changes to anything live.
```
