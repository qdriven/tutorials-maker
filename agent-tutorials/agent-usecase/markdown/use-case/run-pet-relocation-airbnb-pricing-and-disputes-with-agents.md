# Run pet relocation, Airbnb pricing, and disputes with agents

> A user has agents handle pet import/export paperwork and forms, Airbnb pricing with weekly reports, and a commercial dispute they say was won, plus filing documents in Chrome.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** HN · Oct 12, 2026

## What they did

The commenter uses LLM agents to organise a complicated life. One handles communications and form filling for a pet's international import/export, another sets pricing on their Airbnbs and sends a weekly performance report, and one gathers documents for the household's move. Another acted as advocate in a commercial dispute. An agent also drove Chrome to file Airbnb paperwork with the UK government.

## How it went

They report a massive revenue boost from the Airbnb pricing and say the agent won the commercial dispute. No figures are given, and the source doesn't detail the pet move's outcome.

## Worth knowing

Tax filing is only an expectation for next year, with the person checking the agent's work before submitting; it hasn't been done yet.

## Prompt

```text
I'm relocating my pet [species/breed] from [origin country] to [destination country] on about [date]. Research the current import requirements, build a checklist with deadlines, and fill out any forms you can from the details I give you, leaving blanks marked for anything you need from me. Stop and show me each completed form and what you plan to submit before sending or filing anything.
```
