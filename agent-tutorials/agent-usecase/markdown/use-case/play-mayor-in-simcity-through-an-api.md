# Play mayor in SimCity through an API

> A headless city simulator on the open-source Micropolis engine where anyone's agent can run a city. · Feb 9, 2026

**Category:** Games & Simulations  
**Agent:** custom-built or unnamed agent

## What they did

You connect your own agent to a headless Micropolis city simulator, either through an MCP server or a REST API. You give it a short brief, for example a small city with reliable power and room to grow, and the agent plays mayor. Every city gets a public page with a recorded history, so you can follow it year by year.

## How it went

The site reports 406 mayors, 1,902 cities built and about 28 million total population. Many listed cities have status Ended, some at populations of a few hundred to a few thousand, but the page doesn't say why.

## Prompt

```text
Help me run a headless Micropolis (SimCity) simulation through its API and write an agent loop that acts as mayor. Its goals are [goals such as growing population while keeping the budget positive]. Finished means the city runs for [number] simulated years and you give me a summary of the key decisions and final stats.
```
