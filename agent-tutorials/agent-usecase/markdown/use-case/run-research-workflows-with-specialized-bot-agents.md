# Run research workflows with specialized bot agents

> A setup of 10 specialized Grok Bot agents includes a Research agent that finds sources and data and a Deep Research agent that compares sources into insights.

**Category:** Research & Knowledge  
**Agent:** Grok Bot  
**Source:** X · Sep 14, 2026

## What they did

The author built a 6-page PDF defining 10 specialized Grok Bot agents. Chief of Staff receives the goal, breaks it into tasks and assigns agents. Research finds and filters sources; Deep Research compares them for insights; Memory stores decisions and outputs; Planning, Writing, Editing, Design, Verification and Publishing agents then run the sequence on their own. The person created the PDF and the workflow rules.

## How it went

It produced a repeatable system for turning ideas into verified outputs instead of single-assistant answers, per the author's setup and the linked article.

## Prompt

```text
Set up a research workflow for [topic or question]. First, find [number] credible sources and key data points, then run a deeper pass that compares the sources and tells me where they agree and disagree. Deliver a one-page brief with citations and a short list of open questions, and stop there.
```
