# Plan a friend's wedding trip with an agent

> The ChatGPT Agent demo has it buy an outfit, book travel and choose a gift for a friend's wedding.

**Category:** Travel & Bookings  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Undated

## What they did

The thread only relays Sam Altman’s launch post, which says ChatGPT Agent was demoed preparing for a friend’s wedding by using its own computer to handle tasks like buying an outfit, booking travel, and choosing a gift. He also says it combines Deep Research and Operator, can alternate between reasoning and taking actions, and should be given only the minimum access needed.

## How it went

The post gives no metrics or step-by-step outcome for the wedding-trip demo itself. In comments, users describe the shown result as only about 50% accurate and joke that it bought the wrong dress or canceled the wedding, but those are reactions, not verified results.

## Worth knowing

The clearest practical catch is Altman’s warning to treat it as experimental and avoid high-stakes or highly sensitive tasks; limit its access to the minimum needed.

## Prompt

```text
My friend's wedding is on [date] in [location], dress code [dress code], and I'm traveling from [city] with a budget of [amount]. Find an outfit, travel options, and a gift from their registry or around [gift budget], and put the best choices in one summary with prices and links. Pause and show me everything before you buy or book anything.
```
