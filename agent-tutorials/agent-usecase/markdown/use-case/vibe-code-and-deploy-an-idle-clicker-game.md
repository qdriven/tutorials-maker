# Vibe-code and deploy an idle clicker game

> Gilbert Pellegrom had his OpenClaw agent build a simple idle game from a conversation, commit it to GitHub and auto-deploy it to Vercel.

**Category:** Software & DevOps  
**Agent:** OpenClaw  
**Source:** vueschool.io · Undated

## What they did

Gilbert Pellegrom connected Opus 4.5 to his OpenClaw agent and talked through the features he wanted for a simple idle/clicker game. The agent built it, committed it to GitHub, and set up automatic deployment to Vercel. By his own account, he never looked at the code.

## How it went

He says the game was built and deployed from conversation alone. The article only quotes his short post, so there are no details on the game's quality, the time taken or the cost.

## Worth knowing

The article calls this plausible but unverified, and says OpenClaw API costs can climb quickly and that running it has security risks. Shipping code you haven't read adds to that risk.
