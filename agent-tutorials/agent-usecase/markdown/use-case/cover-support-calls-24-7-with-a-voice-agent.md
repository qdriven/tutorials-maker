# Cover support calls 24/7 with a voice agent

> Robin Delta built a voice agent that answers support calls around the clock, resolves tier-1 issues or escalates, and books appointments.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jun 25, 2026

## What they did

Opened ElevenAgents, selected the customer support template, uploaded knowledge base plus SOPs and policies, picked a voice and language, then connected Zendesk, Intercom, calendar, and CRM. The agent answered calls on its own, resolved tier-1 issues or escalated with full context, booked appointments, handled FAQs, and used ExpressiveMode to read tone and de-escalate.

## How it went

Delivered 24/7 coverage in 70+ languages that took all basic calls off the team's plate with no other metrics stated.

## Worth knowing

Built and deployed live in minutes after uploading docs.

## Prompt

```text
Set up a voice agent that answers support calls for [my business] at all hours. It should resolve common tier-1 issues using this information: [FAQ or help docs], book appointments on [my calendar], and escalate anything else to me by [email or text] with a summary of the call. Run a few test calls with me first, and don't go live until I approve.
```
