# Run an entire business from the terminal with Claude Code

> Poster built a system that runs their whole business through Claude Code instead of Claude.ai; the specific tasks aren't detailed in the snippet.

**Category:** Work & Operations  
**Agent:** Claude Code  
**Source:** Reddit · Apr 1, 2026

## What they did

The poster says they replaced the Claude web app with Claude Code in the terminal and built a setup where Claude became “infrastructure” for the business rather than a chat tool. In the thread, they add that they still use Claude.ai for creative and design work, while Claude Code handles infrastructure and execution, with the two connected; commenters also discuss reviewing commands, permissions, and error handling as human checkpoints.

## How it went

The source gives no business KPIs or task-by-task breakdown, so the main result stated is the workflow shift: they say they now run the business through Claude Code instead of Claude.ai. The thread’s clearest limitation is safety, with commenters warning against broad system permissions and stressing review and rollback.

## Worth knowing

Useful catch: even the poster says Claude.ai still does the creative/design side, so this was not a full one-tool replacement.
