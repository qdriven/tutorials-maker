# Build interactive HTML presentations for history classes

> A history teacher has Claude create interactive HTML presentations for class and used Gemini for lesson-planning brainstorming, freeing time for students.

**Category:** Content & Creative  
**Agent:** Claude, Gemini  
**Source:** Reddit · Dec 24, 2025

## What they did

In a comment on the thread, a history teacher in Romania said they use Claude to make interactive HTML presentations. To avoid editing code by hand, they had Claude build a GUI HTML editor for swapping placeholder text and images; for lesson planning, they brainstormed methodologies, gamification ideas, and skill targets with Gemini Pro 2.5, then used Claude to produce the presentation.

## How it went

They said the split workflow worked well: Gemini handled planning and Claude handled execution, which gave them more time to work with students. The only limitation they mentioned was that Claude’s phrasing could be rigid and presentations used placeholder images until edited.

## Worth knowing

The most practical catch was needing a separate GUI editor because the generated presentations could contain stiff wording and placeholder images that still had to be replaced.

## Prompt

```text
I teach [grade level] history and my next unit is [topic/period]. Create a single self-contained interactive HTML presentation with [number] slides, including a clickable timeline, [maps/primary source viewers/quiz questions], and discussion prompts for students. Keep the text readable on a classroom projector and give me the finished file so I can open it in a browser, with a short list of facts I should double-check.
```
