# Automate invoicing, legislation tracking, and email triage with Cowork

> Users had Claude Cowork create, send and track invoices, gather and analyze proposed state AI legislation, and send a daily email of the top 3 emails to answer by priority score.

**Category:** Work & Operations  
**Agent:** Claude Cowork  
**Source:** thezvi.substack.com · Undated

## What they did

The source says these were done with Claude Code and other coding agents, not Cowork itself. Nikhil Krishnan, a non-technical user, spent about an hour with Claude Code setting up a daily email. It lists the top 3 emails to answer, using a priority scoring system built with Claude and data from several places. Dean Ball used coding agents to automate invoice creation, sending and tracking, and to gather and analyze proposed state AI legislation.

## How it went

The daily priority email was running after about an hour. Ball gives no figures. He says the legislation research is no substitute for reading a bill before writing about it.

## Worth knowing

Cowork is a Mac-only research preview for Max subscribers. It has no memory between sessions, and the app must stay open during tasks.

## Prompt

```text
Help me run my admin each week. First, create invoices for [clients and amounts] from [template or folder], track which are paid, and draft reminders for overdue ones. Second, each morning email me the top 3 messages in [my inbox] that need a reply, ranked by a priority score and including a one-line reason each. Show me every invoice and email before sending anything, and don't delete anything.
```
