# Run social, SEO and content marketing with an agent

> The author ran OpenClaw for four weeks with cron jobs, Telegram and MCP tools; one agent analyzed engagement and advised moving focus from X to Bluesky.

**Category:** Sales, Marketing & Support  
**Agent:** OpenClaw  
**Source:** buildtolaunch.substack.com · Undated

## What they did

Jenny Ouyang ran OpenClaw for about four weeks with 18 cron jobs, Telegram as the interface, GitHub-managed skills and MCP connections to outside tools. One agent ran on a schedule, analyzed two weeks of engagement data across X and Bluesky, and updated its own strategy file without being asked. She read the recommendation and followed it.

## How it went

The agent told her to stop posting on X and focus on Bluesky, and she did. The full walkthrough, including the SEO workflow and memory handling, is behind a paywall, so details here are limited.

## Prompt

```text
Act as my marketing assistant for [my project or brand]. Every [day/week], pull engagement stats from [X, Bluesky, other accounts], summarize what performed best, and recommend where I should focus my effort. Send me the report on [Telegram/other channel]. Do not publish any posts yourself; show me drafts and wait for my approval. You're done when I've received a first report with three specific recommendations.
```
