# Hand consumer errands to an always-on agent

> A journalist tested Dot on ISP signup, an Ikea account and food ordering; it finished only some with human help, blocked by browser checks and payment steps.

**Category:** Shopping & Errands  
**Agent:** Dots  
**Source:** zetik.com · Undated

## What they did

A reviewer gave OpenAI's Dot agent everyday errands: signing up for an ISP, getting into an Ikea account, and ordering food. Dot kept hitting browser blocks, and the reviewer had to do manual click-and-hold verification. Some tasks only finished with that human help. Dot also had no virtual-card checkout flow for payments.

## How it went

Dot completed only some of the errands, and only with human help. It did much better on work tasks on the reviewer's own computer, such as rebuilding a personal website after a 10-minute voice briefing.

## Worth knowing

Dot is rolling out first to top-tier users, including the $100-a-month Pro plan, which the reviewer said wasn't yet justified for their own workflow.

## Prompt

```text
Help me with this errand: [e.g. sign up for internet service at my address, create an account at a store, or order dinner from a restaurant]. Do as much as you can and tell me which steps you couldn't finish. Stop and show me the details before any payment, account creation or form submission.
```
