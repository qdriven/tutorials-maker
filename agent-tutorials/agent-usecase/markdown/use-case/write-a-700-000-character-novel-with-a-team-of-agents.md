# Write a 700,000-character novel with a team of agents

> An author managed a novel like a software project, with Claude Code updating timeline, character and foreshadowing files and several agents acting as writer, editor, setting checker and more. · Oct 29, 2026

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** cloud.tencent.com · Oct 29, 2026 · Submitted by from search gap: 小说

## What they did

Before drafting, the author had Claude Code research Fanqie novel rankings, study same-genre books, and read TV Tropes. He then planned the outline through Socratic Q&A. Each chapter ran in six steps: plan, plan check, draft of 2500-3500 characters, review by editor, setting and reader agents, targeted rewrite, then wiki and foreshadowing updates. The project lived in markdown files.

## How it went

He finished a 700,000-character apocalypse novel over one holiday and says the file system and review loop kept it from falling apart. The source gives no reader or quality results.

## Worth knowing

A separate de-AI-flavor pass was needed, because first drafts did not read as human; vague prompts like "make it more exciting" did nothing.

## Prompt

```text
I'm writing a [genre] novel of about [length] characters. In this folder, create and maintain a timeline file, a character file, and a foreshadowing tracker, then act in turn as writer, editor, and setting checker for each chapter I outline. Start by drafting [chapter 1 outline] and updating all three files; stop when the chapter is written and the files reflect it, and show me the changes before overwriting any existing file.
```
