# Let Cursor maintain an Obsidian notes vault

> Cursor reviews vault structure, suggests connections, answers questions about notes and writes a daily done note documenting other agent sessions.

**Category:** Research & Knowledge  
**Agent:** Cursor  
**Source:** beatriz.page · Jan 23, 2026

## What they did

Beatriz opens her whole Obsidian vault in Cursor, so the agent can read every note. She asks it to check consistency, such as template and frontmatter structure. She also asks it to review structure and suggest missing links or tags. It answers questions from note properties and tags without creating notes. After work done in other Cursor agent sessions, it writes a daily done note listing highlights and files created.

## How it went

She says it saves hours each week and keeps the vault better organized. The source gives no measured results. She reviews every suggestion and keeps final say on changes.

## Worth knowing

Cursor only creates notes when asked, apart from the daily done note, so queries leave the vault uncluttered. Review its suggestions before accepting them.

## Prompt

```text
Open my Obsidian vault at [path] and review its structure. Suggest [5] useful connections between notes and folders I could reorganize, and answer this question using my notes: [question]. Then write a daily note in [folder] summarizing what was done today. Propose any file moves or deletions first and wait for my approval.
```
