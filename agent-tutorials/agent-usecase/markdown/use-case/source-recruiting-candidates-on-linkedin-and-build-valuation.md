# Source recruiting candidates on LinkedIn and build valuation models

> ChatGPT Agent logged into LinkedIn, filtered YouTube manager candidates in Bangalore into a spreadsheet, and in another demo built an Excel valuation model from company financials in 17 minutes.

**Category:** Work & Operations  
**Agent:** ChatGPT Agent  
**Source:** leadwithai.co · Undated

## What they did

In one demo, Ishan Sharma gave ChatGPT Agent a job description for a YouTube manager. Using his logged-in LinkedIn account, it browsed Bangalore profiles, filtered for relevant experience, and compiled a spreadsheet of LinkedIn URLs and portfolios. In another, Rob the AI Guy had it build a DCF model for an energy company. It researched the web, pulled revenue, debt and cash flow figures, reasoned through assumptions, and produced an Excel file.

## How it went

The valuation model, with valuation outputs, took 17 minutes. The article gives no quality assessment of the candidate list, and it only reports these as demos that others ran.

## Worth knowing

Plus and Team plans allow 40 Agent prompts a month. Reviewers describe the agent as slow, and it refuses financial matters, so check that your model request goes through.

## Prompt

```text
Build an Excel valuation model for [company] using its latest public financials: a [DCF or comparables] with clearly labeled assumptions I can change. Save it as a downloadable spreadsheet and summarize the result in a few lines. If you need me to log in to any site, pause and tell me first, and do not send any messages or submit any forms without showing me what you're about to do.
```
