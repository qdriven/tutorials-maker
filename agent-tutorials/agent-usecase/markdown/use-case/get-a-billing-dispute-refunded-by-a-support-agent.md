# Get a billing dispute refunded by a support agent

The commenter disputed a Vercel bill they believed was incorrect, arguing the case with the company's support AI agent. The agent then produced and offered a refund by itself, with no human step mentioned. The source gives no detail on what the agent had access to or how it decided.

The agent offered a refund on its own. The source gives no amount, timeline, or confirmation that the refund was paid.
