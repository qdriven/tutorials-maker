# Generate custom interactive HTML lessons for students

> A teacher gives Claude Code a passage, level, vocab list and goals, and gets back a full lesson file with flip cards and comprehension questions, replacing hours of weekly worksheet work.

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** baseclasses.com · Undated

## What they did

The teacher is a Reddit user whom Luke Shepard quotes in his essay. They give Claude Code a reading passage, the student level, a vocab list and the skills students should practice. It returns one interactive HTML file with flip-style vocab cards, comprehension questions, multiple choice, text entry boxes, a teacher mode and progress indicators. The teacher opens it on a laptop or smartboard and teaches from it.

## How it went

The teacher says this replaced hours of weekly work on worksheets, slides and reading activities. The source gives no measured numbers or examples of the output, and the account is a short secondhand quote.

## Prompt

```text
Build me a single self-contained interactive HTML lesson file from this passage: [paste passage]. The students are at [level], and the vocabulary to cover is [word list]. The learning goals are [goals]. Include flip cards for the vocab, comprehension questions with instant feedback, and a short wrap-up. The job is finished when I can open the file in a browser and everything works. Save it as [filename].html and don't touch other files.
```
