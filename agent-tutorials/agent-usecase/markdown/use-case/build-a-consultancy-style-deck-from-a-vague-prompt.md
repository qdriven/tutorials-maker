# Build a consultancy-style deck from a vague prompt

> The author had Manus Slides research sources and build a 16-slide outline on 2025 generative AI trends in UK English.

**Category:** Content & Creative  
**Agent:** Manus  
**Source:** buildingcreativemachines.substack.com · Undated

## What they did

The author gave Manus Slides one deliberately vague prompt: a deck on 2025 generative AI trends, accurate and source-based, consultancy-style, in UK English. Manus made a task list and project directory, researched sources such as Microsoft and Morgan Stanley, logged its steps, then built a 16-slide outline and designed each slide. The author then reviewed the result.

## How it went

The deck came out polished and was rated 4.5 stars, with a research-backed structure. Final slides had no source citations, page sizes were inconsistent, and some icons overlapped chart labels.

## Worth knowing

Ask for citations or a bibliography slide in the prompt, and check the output for overlapping elements before presenting. The author calls the result a 90% done deck.

## Prompt

```text
Research [topic, e.g. generative AI trends in 2025] and build a [number, e.g. 16]-slide consultancy-style deck in [UK or US] English. Start with an outline for me to see, use credible cited sources, and put the sources on the final slide. Finish with an exported deck and a note on any claims you are less sure about.
```
