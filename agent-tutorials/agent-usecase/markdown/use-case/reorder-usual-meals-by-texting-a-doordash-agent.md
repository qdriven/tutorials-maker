# Reorder usual meals by texting a DoorDash agent

> DoorDash's agent in Apple Messages pulls order history, builds the cart and checks out for customers who confirm in the thread, including group orders with mixed dietary needs.

**Category:** Shopping & Errands  
**Agent:** custom-built or unnamed agent  
**Source:** pymnts.com · Undated

## What they did

DoorDash's agent runs inside Apple's Messages. It matches the texter's phone number to their DoorDash profile and uses their order history and preferences. Given a request like "order my usual," it searches nearby restaurants, reads menus, suggests a cart and texts food photos. It can sort mixed dietary needs for group orders. The customer confirms in the thread, then it pays with the stored payment method.

## How it went

It is in a U.S. beta, open by waitlist. Bloomberg's test of an early version found prices that differed from the app's. DoorDash says waitlist users will get a newer version.

## Worth knowing

Check the prices the agent quotes against the app, because Bloomberg's early test found mismatches, and you have to join the waitlist to try it.

## Prompt

```text
Open DoorDash in my logged-in account and look at my order history at [restaurant name]. Rebuild my usual order of [items], adjusting for these dietary needs: [needs]. Stop with the cart on screen and show me items, delivery address and total, and only place the order after I confirm.
```
