# Pull wallet data from dashboards into a spreadsheet

> Claude computer use operated the desktop, handled logins and modals, and entered wallet numbers into a spreadsheet over 19 minutes.

**Category:** Work & Operations  
**Agent:** Claude computer use  
**Source:** X · Jun 21, 2026

## What they did

Claude computer use was enabled with no custom setup. One prompt asked it to pull wallet data from dashboards, check them, and clean a summary in a spreadsheet. The agent accessed the full desktop, paused on login pages to figure out the flow, navigated modals and loading screens, tabbed between tools, extracted numbers, entered them into the open spreadsheet, and formatted results.

## How it went

Task finished in 19 minutes with visible screenshots and actions for oversight; cost stayed tiny even while exploring.

## Worth knowing

No new protocols or stacks required beyond enabling the feature.

## Prompt

```text
Open each of these dashboards in turn: [dashboard names or URLs]. Find [the specific numbers, e.g. wallet balances] and enter them into my spreadsheet [spreadsheet name] in columns [column layout]. Stop when every row is filled in, and tell me about any dashboard where you couldn't find the data. Pause and ask me to log in if a login needs credentials.
```
