# Turn a blog post into an animated infographic

> A content creator fed a blog post into Gemini Canvas, which produced a coded animated infographic using brand colors and audience details from the chat thread.

**Category:** Content & Creative  
**Agent:** Gemini  
**Source:** kimdoyal.substack.com · Undated

## What they did

In a long-running Gemini chat that already held her brand hex codes, fonts and audience, she pasted in a blog post about the state of AI for entrepreneurs. She switched to Canvas and chose Create > Infographic. She then dictated follow-up fixes by voice, and Gemini regenerated the page.

## How it went

Within a couple of minutes it produced an on-brand infographic with fade-in data points and chart hover effects. The first draft had cut-off text and a wonky legend, and one round of corrections fixed them.

## Worth knowing

The first draft needed fixes, so plan on at least one revision round. The output is HTML that can be pasted into a website HTML block via Share.

## Prompt

```text
Using Canvas, turn this blog post into an animated infographic coded in HTML: [paste post or link]. Use my brand colors [hex codes] and write for [audience]. Highlight the [5] key points with simple animations. Finish when I can preview it in Canvas, and tell me how to export or embed it.
```
