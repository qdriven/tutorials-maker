# Turn voice notes into Linear tickets and review analytics

> The author built Codex skills that convert voice notes into formatted Linear tickets, review YouTube analytics weekly, and run nightly self-improvement automations.

**Category:** Work & Operations  
**Agent:** Codex  
**Source:** rumjahn.substack.com · Undated

## What they did

Keith Rumjahn saved repeated prompts as Codex Skills. A Linear skill turns his voice notes about features into properly formatted tickets. A YouTube analytics skill downloads his channel data and suggests optimizations. Two automations, borrowed from OpenAI's video, run on a schedule: Upskill nightly, from failure logs, and Update Agents.md every 12 hours, from his conversations.

## How it went

He says the analytics skill saves 90 minutes every Sunday. Channel views are up 114% and watch time up 111%, partly because he now acts on the suggestions. The post gives no figures for the Linear skill.

## Worth knowing

Codex requires ChatGPT Plus at $20/month, and the full Upskill and Update Agents.md prompts are shared only in his community.

## Prompt

```text
Create a reusable skill that takes a voice note transcript I paste in and turns it into a formatted ticket for [Linear/Jira] with title, description, acceptance criteria, and priority using this template: [template]. Show me the drafted tickets for approval before creating anything in [project name]. Once that works, add a weekly routine that reviews [analytics source, e.g. YouTube analytics] and sends me a summary of what changed.
```
