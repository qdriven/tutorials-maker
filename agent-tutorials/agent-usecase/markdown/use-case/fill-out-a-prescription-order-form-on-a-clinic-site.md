# Fill out a prescription order form on a clinic site

> ChatGPT Agent filled in medication, dosage and number of days on a clinic's website, while the user entered sensitive data manually.

**Category:** Life Admin & Home  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Jul 24, 2025

## What they did

One commenter tested agent mode on a clinic’s prescription refill form. They put the medication information into the prompt, and the agent filled in the medication name, dosage, and number of days on the website; the person handled the sensitive fields manually instead of having the agent enter them.

## How it went

In that test, it completed the non-sensitive prescription details correctly. The only stated limitation was that sensitive information still had to be entered by the user.

## Prompt

```text
Go to [clinic website URL] and fill in the prescription order form with this medication: [name], dosage: [dose], for [number] days. Leave all personal and medical identity fields blank for me to complete myself. Stop before submitting and show me what is filled in so I can review it and submit it myself.
```
