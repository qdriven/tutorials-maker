# Generate ads from a website URL

> Arcads agents take a website URL, learn the brand, and produce ad ideas, static ads and AI UGC videos.

**Category:** Content & Creative  
**Agent:** custom-built or unnamed agent  
**Source:** X · Aug 4, 2026

## What they did

User gave the Arcads agent one website URL plus one sentence. The agent read the site to learn the brand, pulled existing assets, generated ad ideas on its own, then produced static ads and AI UGC videos without further input.

## How it went

Output quality was surprisingly good.

## Prompt

```text
Go to [my website URL] and learn my brand, product and audience. Then produce 5 ad concepts, written copy and a visual brief for each of 3 static ads, and 2 short UGC-style video scripts. Stop when you have a single document with all of it. Do not publish or submit anything to ad platforms.
```
