# Produce a short-form video from research to captions

> Hermes Agent researched a JWST topic, wrote the script, generated assets, built Remotion motion graphics, added voiceover, music and captions for a vertical video.

**Category:** Content & Creative  
**Agent:** Hermes Agent  
**Source:** dev.to · Undated

## What they did

The author prompted Hermes Agent step by step. It searched the web and compared sources, then wrote a research document and recommended a topic. The author picked JWST finding methane on an interstellar comet. From that, the agent wrote a script and a scene-by-scene plan, generated artwork, and built Remotion components using installed Remotion skills. It checked rendered frames against the plan and revised scenes. It then added voiceover, music and effects, and Whisper-timed word-highlight captions.

## How it went

The result is a rendered vertical video for Shorts, Reels or TikTok. The article gives no timings, costs or failure details, and shows the result mainly through a linked video walkthrough.

## Worth knowing

Voiceover and image generation can use local or cloud providers, so choose these before you start. The article doesn't state costs or run time.

## Prompt

```text
Make a vertical short-form video about [topic]. Research it using reliable sources, write a 45-second script, generate visuals, build motion graphics, add a voiceover, background music, and captions. Show me the script for approval before you generate assets, and finish by saving the video to [folder].
```
