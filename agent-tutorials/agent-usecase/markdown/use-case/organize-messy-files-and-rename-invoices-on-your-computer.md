# Organize messy files and rename invoices on your computer

> The author used Manus My Computer to sort a folder of thousands of files in minutes, and describes using it for photo sorting and invoice renaming.

**Category:** Life Admin & Home  
**Agent:** Manus  
**Source:** barbarosozturk.com · Undated

## What they did

The author installed the Manus My Computer desktop app (macOS and Windows) and pointed it at a messy folder of thousands of files. You authorize which folders it can reach, and it runs real terminal commands. You approve each action or whitelist trusted routines. For photos it scans images and sorts them into folders by type or date. The author also describes asking it to rename hundreds of invoices.

## How it went

The author says the folder of thousands of files was organized in minutes. The photo sorting and invoice renaming are described as use cases, with no figures or results given for them.

## Worth knowing

The agent has file system and terminal access, so one wrong command could delete or overwrite files. Approve actions manually at first and limit which folders it can touch.

## Prompt

```text
Help me organize the folder [folder path] on my computer. First scan it and show me the plan: the folder structure you propose, plus how you would rename files like [e.g. invoices as YYYY-MM-DD_Vendor_Amount]. Wait for my approval before moving or renaming anything, and never delete files. When done, give me a summary of what changed.
```
