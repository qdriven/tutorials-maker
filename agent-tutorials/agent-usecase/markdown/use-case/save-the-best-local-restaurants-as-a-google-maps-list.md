# Save the best local restaurants as a Google Maps list

> Before a vacation, ChatGPT agent picked 10 restaurants, paused for his Google login, then saved a Maps list with signature-dish notes in about 23 minutes.

**Category:** Travel & Bookings  
**Agent:** ChatGPT Agent  
**Source:** artificialcorner.com · Undated

## What they did

Frank Andrade asked ChatGPT agent to find the best restaurants in the city he was visiting and build a new saved Google Maps list with signature-dish notes. The agent searched, chose 10 restaurants and gathered their signature dishes. It then paused so he could take over and enter his Google login. After that it created and saved the list with notes for each place.

## How it went

The task finished in about 23 minutes and the list was saved. The author doesn't say how good the picks were. He calls the agent slow and not fully hands-off.

## Worth knowing

Each interruption, including a login handoff, uses one agent credit. Plus users get 40 messages a month and Pro users get 400.

## Prompt

```text
I'm visiting [city or neighborhood] from [dates]. Find 10 well-reviewed local restaurants that fit [cuisine, budget, dietary needs], then create a Google Maps list called [list name] and save each one with a note on its signature dish. Pause and let me log in to Google when needed, and finish by showing me the list link and why you chose each place.
```
