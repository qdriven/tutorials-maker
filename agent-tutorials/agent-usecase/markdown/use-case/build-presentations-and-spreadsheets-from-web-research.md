# Build presentations and spreadsheets from web research

> A user had Agent Mode build a presentation, draft an eBook and turn web research into spreadsheets; the author said the design was not award-winning but saved hours.

**Category:** Work & Operations  
**Agent:** ChatGPT Agent  
**Source:** aiblewmymind.substack.com · Undated

## What they did

Daria Cupareanu used ChatGPT Agent Mode for three tasks. It built an AI-in-education deck from one near-bare prompt, then added her logo and brand colors. It drafted an eBook from her uploaded Substack posts in Google Drive plus approved outside sources. It crawled the Y Combinator directory into a Google Sheet and searched for each company's contact info.

## How it went

The deck was functional but not award-winning. The eBook came out at 11 pages against the 20 requested and wasn't publish-ready. The sheet was raw but usable, though the agent stopped at the first page of 20 entries.

## Worth knowing

Specify entry counts, output format and structure up front. Runs counted against her Plus plan's 40 monthly agent messages, and tasks took 10–30 minutes.

## Prompt

```text
Research [topic] on the web using reputable sources, then build a [number]-slide presentation for [audience] and a spreadsheet with [the data points I need, e.g. competitors, prices, dates] with source links. Keep the design clean and simple. Finish by giving me both files to download plus a list of anything you could not verify.
```
