# Edit keynote videos with motion graphics using a video agent

> A marketer built a Claude Code video agent that cuts a keynote take without clipping words, adds motion graphics, captions, branding and music, and renders 16:9 and 9:16 versions. · Oct 22, 2026

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** futureofmarketing.de · Oct 22, 2026 · Submitted by from search gap: 视频

## What they did

Andreas Fuchs set up a folder-based Claude Code agent and gave it one keynote take plus brand assets and music. The agent transcribed with word timestamps, cut with ffmpeg, built each sentence's visual as a web page, and rendered with HyperFrames. It had to show proof after each step, such as a transcript or still frame.

## How it went

From a single take, the agent produced a finished video with a motion graphic for every sentence, captions, branding and music, plus a vertical Reel. The later steps and prompts are behind a free signup.

## Worth knowing

Setup takes about an hour and needs only a Claude plan (Pro from $17/month annual), plus a music licence if needed. Heavy daily use may hit Pro limits.

## Prompt

```text
Edit my raw video at [path to video file] into a polished clip. Transcribe it, cut out mistakes and dead air without clipping any words, then add captions, simple motion graphics for key points, my branding from [logo or color details], and background music from [music folder]. Render a 16:9 version and a 9:16 version into [output folder], and stop once both play cleanly. Show me the cut list before you render the final files.
```
