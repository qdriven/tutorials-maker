# Fill a supermarket cart with agent mode for pickup

> Agent mode added groceries to the cart at a local supermarket while the poster worked, for pickup the next morning.

**Category:** Shopping & Errands  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Jul 8, 2025

## What they did

The poster had agent mode shop a local supermarket for next-morning pickup while they worked. They gave it only a few constraints: avoid red meat, prioritize health, and stay under $150; the agent built the cart on its own, asked once about pantry staples, and the poster told it not to add them.

## How it went

It completed the grocery order without issues, and the poster said the resulting list was workable for them. They also said it did only an okay job and would likely do better with more specific meal-based instructions.

## Worth knowing

The run took 55 minutes, so the main catch is trading a long agent session for less manual cart-building.

## Prompt

```text
Go to [local supermarket website], sign in with my saved account, and add these items to my cart: [grocery list]. Choose pickup for [day and time window] at [store location]. Stop before placing the order and show me the cart, substitutions, and total so I can approve it.
```
