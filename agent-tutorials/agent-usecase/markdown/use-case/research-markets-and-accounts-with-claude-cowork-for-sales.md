# Research markets and accounts with Claude Cowork for sales

> A salesperson has Claude Cowork do market and account research and prospecting via a ZoomInfo API while they take calls, manually reviewing what it pulls.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Cowork, Claude  
**Source:** Reddit · Sep 2, 2026

## What they did

One salesperson said they use Claude’s ZoomInfo API connection for prospecting. In practice, Claude pulls prospecting information from ZoomInfo, and the human still manually reviews what it returns rather than trusting it end to end.

## How it went

The source only calls it pretty useful for prospecting and does not give results, conversion numbers, or time saved. It also does not describe the exact prompt flow or any automation beyond Claude pulling the information.

## Worth knowing

The main catch is that you still have to manually review the info Claude pulls.

## Prompt

```text
While I'm on calls, research [target market or list of accounts] for me. For each company, pull key details like size, industry, recent news, and the best contacts to reach in [target roles], using [ZoomInfo or another data source] if connected. Put everything in a spreadsheet in [folder] with a column noting your confidence and source, and stop once you've covered [number] accounts so I can review them by hand.
```
