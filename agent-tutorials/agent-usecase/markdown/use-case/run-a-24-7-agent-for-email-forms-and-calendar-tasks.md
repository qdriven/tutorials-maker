# Run a 24/7 agent for email, forms and calendar tasks

> Users run Hermes on a mini PC for email, browsing, form filling and cron jobs, and one has it manage Obsidian tasks against Apple Calendar with Telegram/Signal reminders.

**Category:** Life Admin & Home  
**Agent:** Hermes Agent  
**Source:** hermes-agent.nousresearch.com · Undated

## What they did

One Discord user (@monty_13277) keeps Claude for day-to-day chat and runs Hermes around the clock on a mini PC for email, web browsing, form filling, calendar updates and cron jobs. Another user (@kouff) told Hermes to manage tasks in Obsidian and cross-check them against Apple Calendar. Hermes later confirmed a workflow of Apple Calendar, Obsidian and cron/Signal reminders.

## How it went

The source gives no numbers or measured results. It only describes the setups and says Hermes confirmed the task and calendar workflow. It doesn't say how well either setup worked.

## Prompt

```text
Act as my always-on assistant. Each morning at [time], check my email for [kinds of messages], compare my tasks in [Obsidian folder or task list] with my calendar at [calendar], and message me on [Telegram or Signal] with a short plan and reminders for the day. Draft replies and fill out forms for me, but pause and show me before sending or submitting anything.
```
