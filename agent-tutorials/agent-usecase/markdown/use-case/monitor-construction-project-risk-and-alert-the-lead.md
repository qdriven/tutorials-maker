# Monitor construction project risk and alert the lead

> A builder made an n8n and Gemini watchdog that checks schedules, budgets, procurement, labor, weather and site reports, finds the main bottleneck, and alerts the project lead.

**Category:** Work & Operations  
**Agent:** n8n, Gemini  
**Source:** X · Oct 4, 2026

## What they did

The builder set up an n8n workflow with Gemini that pulls data on schedules, budgets, procurement, labor, weather, and site reports. The agent calculates overall project risk on its own, identifies the largest bottleneck, and sends an alert to the project lead.

## How it went
