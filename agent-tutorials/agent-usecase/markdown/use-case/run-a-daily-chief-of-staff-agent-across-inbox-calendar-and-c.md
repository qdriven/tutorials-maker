# Run a daily chief-of-staff agent across inbox, calendar and CRM

> A surgeon runs about twenty scheduled Cowork tasks that triage email, prep meetings, flag stale deals and leave drafts ready in a dashboard.

**Category:** Work & Operations  
**Agent:** Claude Cowork  
**Source:** substack.com · Undated

## What they did

The author set up Claude Cowork scheduled tasks on daily, weekly and monthly cadences. MCP connectors give Claude access to Gmail, Calendar, Slack, Granola transcripts, HubSpot and Brex. At 5 AM it triages email, preps meetings, flags stale deals and scans CMS and the Federal Register. He then acts from a dashboard with drafts waiting. A prompt interviews you to pick tasks.

## How it went

He runs about twenty tasks across clinical, company, policy, academic and personal areas. By morning he has a dashboard with drafts, action items and source links. The source gives no measured results.

## Worth knowing

Start with the free interview prompt, which has Claude recommend only tasks matching your tools and ask you to confirm before it creates anything.

## Prompt

```text
Set up scheduled daily tasks that act as my chief of staff. Each morning, triage my inbox into [categories you use], prep me for today's meetings from [calendar and notes], flag [CRM] deals with no activity in [number] days, and leave reply drafts ready. Put everything in one summary file I can read in five minutes. Never send an email or change a calendar event without my approval.
```
