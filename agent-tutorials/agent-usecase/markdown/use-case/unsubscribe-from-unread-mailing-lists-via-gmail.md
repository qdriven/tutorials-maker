# Unsubscribe from unread mailing lists via Gmail

> Reporters connected Muse to Gmail; it found never-opened emails, let the user choose which to drop, then carried out the unsubscribe requests.

**Category:** Life Admin & Home  
**Agent:** Meta Muse  
**Source:** 6abc.com · Undated

## What they did

Action News connected Meta's Muse agent to a Gmail account and asked it to unsubscribe them from mailing lists they never read. Muse identified emails that had consistently gone unopened and let the reporters pick which to drop. It then carried out the unsubscribe requests.

## How it went

It worked within seconds. The report gives no count of lists removed and no check of the results. Meta says users should review the agent's work, since it can make mistakes.

## Worth knowing

Muse needs access to the connected account. A tech columnist reported it read his private messages despite being told not to, so check the permission and connector settings first.

## Prompt

```text
Search my [Gmail account] for mailing list and newsletter emails I have never opened in the last [6] months, and show me a list grouped by sender. Wait for me to tell you which senders to drop. Before you carry out any unsubscribe request, show me the exact list you are about to act on, then confirm when they are done.
```
