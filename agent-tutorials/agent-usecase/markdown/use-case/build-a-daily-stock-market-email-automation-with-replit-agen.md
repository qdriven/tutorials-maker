# Build a daily stock-market email automation with Replit Agent

> A reviewer had Replit Agent 3 plan and build a workflow with a 7 AM trigger, market data retrieval, email formatting and delivery, finding it easier than Zapier.

**Category:** Work & Operations  
**Agent:** Replit Agent  
**Source:** nocode.mba · Undated

## What they did

The reviewer gave Replit Agent 3 one plain-English prompt asking for a daily 7 AM stock market update email. The agent drafted a plan covering the trigger, data retrieval, email formatting and Replit mail delivery, then generated the files and integrations. It asked for the reviewer's email address for testing and stored it in the secrets manager. It tested each component before finishing.

## How it went

The build took about 20 minutes. The email arrived as formatted HTML with current, well-organized market data. The reviewer thought the visual design could use polish.

## Worth knowing

Free accounts can build and test the automation, but publishing it so it runs on schedule needs a paid plan.

## Prompt

```text
Build an automation that runs every day at [time, e.g. 7 AM, my timezone], pulls [data, e.g. major index levels and top movers] from [data source or any free market API], formats it into a clean email, and sends it to [my email address]. Ask me for any API keys you need. Send one test email to me first, and stop when the test arrives looking right and the daily schedule is active.
```
