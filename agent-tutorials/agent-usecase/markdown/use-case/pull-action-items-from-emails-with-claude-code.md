# Pull action items from emails with Claude Code

> After seeing Claude Code extract and organise action items from emails in plain English, Becky tried it and built four apps in three weeks.

**Category:** Work & Operations  
**Agent:** Claude Code  
**Source:** smallcreatorbigworld.substack.com · Undated

## What they did

Becky watched Alex Dobrenko share his screen while he asked Claude Code, in plain English, to pull action items from his emails and organise them. She then started describing what she wanted in ordinary sentences. Her first prompt was to scrape her Substack notes into a database. Over three weeks she built four tools without writing code.

## How it went

She built a YouTube quote carousel generator, a podcast packager, a channel analyser and a thumbnail analytics tool. The analytics tool covered 776 videos across 57 channels in an afternoon, against three days of manual work. She did not run the email task herself.

## Worth knowing

The post only shows the email demo being watched, not built, so there are no email setup details. Her own work was other tools, hosted on free or low-cost platforms.

## Prompt

```text
Read the emails in [folder or export file path] and extract every action item, with who asked, what is needed and any deadline. Organize them into one list sorted by due date and save it as [format, e.g. HTML page or spreadsheet]. You're done when each email is accounted for; don't reply to or delete any emails.
```
