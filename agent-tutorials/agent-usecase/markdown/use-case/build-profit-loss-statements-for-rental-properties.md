# Build profit/loss statements for rental properties

> Meta Muse logged into property software and built profit/loss statements for every rental property.

**Category:** Work & Operations  
**Agent:** Meta Muse  
**Source:** X · Oct 3, 2026

## What they did

Meta Muse received login access to the user's property management software. The agent logged in on its own and generated a profit/loss statement for each rental property.

## How it went

It completed the statements for every rental. No further results or shortfalls are stated.

Don't change or delete anything in the software.
