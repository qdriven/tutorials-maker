# Run a meeting assistant that handles meetings and summaries

> A commenter built a meeting assistant with Lindy that had been running for a week, handling meetings and producing summaries.

**Category:** Work & Operations  
**Agent:** Lindy  
**Source:** Reddit · Aug 27, 2025

## What they did

In the Reddit thread, a commenter said they used Lindy to build an AI assistant for meetings and related tasks after seeing recommendations there. The source only states that it had been running for a week and was handling meetings and producing summaries; it does not describe the workflow, integrations, or any human review steps.

## How it went

The reported result was that it was running in real use for a week and doing meeting handling and summaries. The same commenter said they were already seeing the limits of its usefulness and had become more cautious.

## Worth knowing

The main catch from the source is how thinly proven it was: the commenter had only been running it for a week.

## Prompt

```text
Set up a Lindy assistant that joins my [Zoom, Google Meet, or Teams] meetings, takes notes, and after each one writes a summary with decisions and action items with owners. Send the summary to me for review first, and only email it to [attendees] after I approve. The job is done when one real meeting produces a summary I can send as is.
```
