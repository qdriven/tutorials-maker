# Email car brands without web apps and build them one

> @JerryJenasom had Manus find car brands lacking a web app and email them; brands replied and he then built a web app for them.

**Category:** Sales, Marketing & Support  
**Agent:** Manus  
**Source:** X · Sep 22, 2026

## What they did

The user prompted Manus AI to locate car brands lacking web apps, draft emails to them, and send the messages. Manus handled the search and emailing on its own. The user received the replies and built the web app himself.

## How it went

The brands replied, and the user built a web app for one.

## Prompt

```text
Find [number] [type of company, e.g. car brands] that don't have a [type of product, e.g. web app or online configurator], using [sources or search terms]. For each, find a contact email and draft a short personalized pitch offering [your service] with a link to [your portfolio]. Put the list and drafts in a spreadsheet. Don't send any emails until I've reviewed and approved the drafts.
```
