# Negotiate a lower GoDaddy support price via chat agent

> The poster told an AI agent to negotiate a cheaper price in GoDaddy support chat, checking for replies every 60 seconds, and says it got a better deal.

**Category:** Money, Bills & Benefits  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Undated

## What they did

The poster had an AI agent handle a GoDaddy support chat, with instructions to negotiate a lower price and check the chat every 60 seconds for new replies. In the comments, they said they used FillApp, a Chrome extension, and the agent carried the exchange until it reached a lower offer; the human appears to have mainly set it up and let it run.

## How it went

They said the final price was negotiated down to $278, which they described as a $70 savings. The thread does not include the actual chat transcript or explain the negotiation tactics, so the process details are thin.

## Worth knowing

The poster said the run used about $0.10 in LLM credits, but without the transcript you cannot tell how reliably it would work elsewhere.

## Prompt

```text
Open the support chat for [company, e.g. GoDaddy] and ask for a lower price on [product or renewal] currently costing [$X]. Negotiate politely, mention [competitor offers or loyalty], and check for replies about every 60 seconds until you have an offer or they refuse. Pause and show me any offer before accepting it or entering payment details, then summarize what was offered.
```
