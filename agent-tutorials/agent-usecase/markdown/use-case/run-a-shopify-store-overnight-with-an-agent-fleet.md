# Run a Shopify store overnight with an agent fleet

> NightShift detects store issues overnight, auto-fixes safe ones, and audits every action, shown in a YouTube demo.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** X · Aug 31, 2026

## What they did

NightShift is an autonomous AI agent fleet of 5 specialists given access to a Shopify store. The agents ran overnight to detect issues, auto-fixed safe ones on their own, and asked for approval before any risky action. Every step was audited.

## How it went

A YouTube demo shows the fleet running the store overnight.

## Prompt

```text
Build a workflow that runs every night on my Shopify store [store name]. It should detect issues like [out-of-stock best sellers, broken links, failed orders, price errors], auto-fix only low-risk ones such as [safe fixes], and log every action to [Google Sheet or Slack]. Anything risky should be sent to me for approval before it runs, and I should get a morning summary.
```
