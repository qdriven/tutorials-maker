# Build prospect lists and cold emails from the web

> Claude Code driving the author's logged-in Chrome read seed pages and LinkedIn profiles to find 25-30 sourced prospects; about 20 emails sent drew 7 replies.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code, Claude in Chrome  
**Source:** 4thecurious.com · Undated

## What they did

The author kept a campaign folder with a CLAUDE.md file holding his numbers, rules and contact log. Claude Code, running in his logged-in Chrome, started from 2-3 seed pages and followed links through LinkedIn and team pages. It built a sourced target list, then opened pre-filled drafts in his mail app. He read and sent each one, and Claude logged replies from Gmail.

## How it went

Claude found 25-30 people, each with a source URL. He emailed about 20 and got 7 replies, several with intros. Work that took 3 hours now takes about 1.

## Worth knowing

Write and send the first email by hand so it becomes the template. Source URLs on each row keep Claude from inventing personalized lines.

## Prompt

```text
I sell [product or service] to [type of customer]. Using these seed pages [URLs] and LinkedIn, find 25 prospects who fit, and record name, role, company, a source link, and one personal detail for each in a table. Then draft a short cold email for each, but do not send anything; show me the table and drafts so I can review them first.
```
