# Build and grow a mobile game with bots

> A guide describes six bots building, shipping and improving a mobile game, including uploading ad creatives learned from a recorded click-path.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** x.ai · Undated

## What they did

Ryan Perry gave six Grok Bot agents job descriptions for his game Rank'em: orchestrator, analytics, creatives, engineer, deploy and bug fixing. Each bot had its own cloud computer, connected accounts, nightly routines and handoffs to the others. Meta's API wasn't available because of verification issues, so he recorded one manual creative upload in the web UI. The bot replayed that click-path, uploading about one new creative per day.

## How it went

He credits the bots with two wins. Cost per install fell from $15 to $1 after the ad was swapped for a partner-focused cut. A hint feature raised D7 retention about 4x. The game passed 1000 downloads in a week.

## Worth knowing

The Meta API was blocked by verification, so the recorded UI click-path was the workaround. The bot was told to check with the owner before anything that spends money.
