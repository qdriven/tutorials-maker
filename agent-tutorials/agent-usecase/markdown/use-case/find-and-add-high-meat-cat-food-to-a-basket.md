# Find and add high-meat cat food to a basket

> A reviewer had Comet's assistant find the cat food with the most meat and add it to the basket, plus some product comparison and form filling, though imperfectly.

**Category:** Shopping & Errands  
**Agent:** Perplexity Comet  
**Source:** cybernews.com · Undated

## What they did

In Perplexity's Comet browser, the reviewer asked the built-in Assistant to find the cat food with the most meat in an online shop. The Assistant browsed the shop pages while the reviewer watched, with blue frames marking the pages it was reading. It listed meat and fish options, and the reviewer then added one to the basket through Perplexity's interface.

## How it went

It found suitable options and added one to the basket. It didn't seem to check every item in the shop, and it gave no list of the pages it reviewed. Asked later to re-add the last basket item, it found no memory of it until the shop was named.

## Worth knowing

Name the shop explicitly in follow-up requests, because Comet's memory of earlier basket activity failed without it. You can't verify which products it checked.

## Prompt

```text
On [store website], find the [product type, e.g. cat food] with the highest [criterion, e.g. meat content] under [budget], comparing at least [number] options in a short table with the evidence for each. Add the winner to my basket and stop there. Don't check out, and show me the basket before any further step.
```
