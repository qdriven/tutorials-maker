# Update a code base with Copilot chat and agent mode

> A commenter used Copilot's chat and agent mode to update their code base and likes the CLI's autopilot mode and todo tool.

**Category:** Software & DevOps  
**Agent:** GitHub Copilot  
**Source:** Reddit · Undated

## What they did

In the comments, one user said they update their code base with GitHub Copilot’s VS Code chat and agent mode, then asked how Copilot CLI compares on premium requests and output quality. The poster replied that CLI uses the same premium-request multiplier logic as the IDE and said they mostly run it in autopilot mode, preferring its output; elsewhere in the thread they describe that style of agent as reading the codebase, planning, writing code, running tests, and opening PRs.

## How it went

The reported result was qualitative, not measured: the poster said CLI quality is superior for them and that they use autopilot most of the time. No numbers on code changes, time saved, or success rate were given.

## Worth knowing

Premium-request multipliers were said to be the same in the IDE and CLI.

## Prompt

```text
Use the Copilot CLI in autopilot mode with a todo list to update my code base: [describe the change, e.g. migrate from library X to library Y]. First write out the todo list and show it to me, then work through it item by item, checking things off as you go. Stop when every item is done and [tests/build] pass, and summarize what changed.
```
