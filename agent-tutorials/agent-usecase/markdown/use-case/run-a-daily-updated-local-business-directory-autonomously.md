# Run a daily-updated local business directory autonomously

> Claude on a scheduled task built and deployed a directory of local contractors, then each morning finds and vets new examples, makes an SEO fix, and pushes to GitHub. · Oct 14, 2026

**Category:** Sales, Marketing & Support  
**Agent:** Claude  
**Source:** localaiwins.com · Oct 14, 2026 · Submitted by JC Preston

## What they did

The site is the finished product: a directory of HVAC, plumbing and roofing companies' AI results. Each entry links to its source. The page says an AI agent finds and writes up the wins, and a person reviews what goes out. It doesn't describe the scheduling, the SEO fixes or the GitHub deployment.

## How it went

The directory has 13 sourced entries, added Oct 14 and 15, 2026. They are sorted by outcome and trade. The page gives no figures on the agent's own effort or accuracy.

## Worth knowing

The source says a person reviews the agent's output before it goes out, so plan for a human check. It doesn't cover cost or setup.

## Prompt

```text
Set up a scheduled daily task that finds [2-3] new [type of local business, e.g. roofing contractors] in [city or region] for my directory in [repo or site]. Vet each one by checking for a real website, reviews and a valid license, then add the passing entries and make one small SEO improvement. Finished means a short log of what was added, what was rejected and why, and a prepared commit. Show me the changes before pushing to GitHub or publishing.
```
