# Build a website with Manus

> A user had Manus build a website but could not access it outside the Manus sandbox, so they could not log in directly to change the backend.

**Category:** Software & DevOps  
**Agent:** Manus  
**Source:** Reddit · Undated

## What they did

The poster says they used Manus to build a website, but the result was stuck inside the Manus environment: they could not access the site outside the sandbox, get zip exports, or log in directly to edit the backend. They also say that even after multiple rebuilds in the same project, Manus sometimes could not find files already in the project folder, and support had not resolved it.

## How it went

It did produce a website, but the source only describes failures after that: limited backend controls, no direct external access, and no usable export. No success metrics or completed workaround are given.

## Worth knowing

One commenter says they use Manus for web development multiple times a week but offload everything to GitHub as a safeguard.
