# Let an agent build and run its own online business

> Nat Eliason gave his OpenClaw agent Felix $1,000, and it launched a website, an info product and an X account, reportedly earning $14,718 in three weeks.

**Category:** Sales, Marketing & Support  
**Agent:** OpenClaw  
**Source:** creatoreconomy.so · Undated

## What they did

Nat Eliason gave his OpenClaw bot, Felix, $1,000 to build a business. Felix launched a website, an info product and an X account. Nat set up a 3-layer memory system first: a knowledge graph, daily notes consolidated nightly, and a file of facts about him. He also ran multiple chats in parallel, and Felix ignored prompt injections on X.

## How it went

Over three weeks Felix reportedly made $14,718, including $3,500 in week one according to the Stripe dashboard. The full setup prompt and details are behind a paywall.

## Worth knowing

Nat advises setting up the memory structure before anything else, so the conversations from day one are useful. The 6,500+ character prompt is paywalled.

## Prompt

```text
I'm giving you a budget of [amount] to launch a small online business around [topic]. Research the idea, propose a plan with a website, one digital product, and a social account, and wait for my approval. Pause and show me before spending money, publishing anything, or posting from my accounts, and send me a weekly report of costs and revenue.
```
