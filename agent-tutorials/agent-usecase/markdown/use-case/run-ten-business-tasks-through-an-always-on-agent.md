# Run ten business tasks through an always-on agent

> A reviewer tested Dots on product research, publishing a webpage, content planning and scheduled jobs; inbox triage and follow-ups needed supervision and a spreadsheet had broken formulas.

**Category:** Work & Operations  
**Agent:** Dots, ChatGPT Agent  
**Source:** aiagentslibrary.com · Oct 2, 2026

## What they did

Diana set up a dot named Sparky on ChatGPT Pro. She connected Gmail, Calendar, Drive, Sheets, GitHub, Slack and ChatGPT Sites, and left the default rules unchanged. Over two days she gave it ten real business tasks, one attempt each. They covered meeting prep, inbox triage, a platform comparison, publishing a webpage, a content plan, a spreadsheet and a scheduled monitor. She scored each task on five criteria.

## How it went

Measured task average was 8.8/10. The platform comparison, the webpage, the content plan and the scheduled job scored 9.8. Post-meeting follow-up scored 7, inbox triage and the spreadsheet 7.5. The spreadsheet's formulas broke in Google Sheets despite a self-reported pass on 27 checks.

## Worth knowing

Only one scheduled run completed in a two-day test, so reliability over weeks is untested. Open generated spreadsheets in the tool you actually use before trusting them.

## Prompt

```text
Handle this business task for me: [e.g. research competitors for product X, draft a content plan for next month, or publish a simple webpage]. Give me the finished output in [format] and note anything you're unsure about. Check with me before publishing, sending or deleting anything.
```
