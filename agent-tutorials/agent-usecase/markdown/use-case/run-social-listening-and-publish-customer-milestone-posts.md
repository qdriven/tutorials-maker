# Run social listening and publish customer-milestone posts

> An enterprise client uses Lindy agents to scrape customers, monitor social and G2, draft milestone posts, build content calendars and publish.

**Category:** Sales, Marketing & Support  
**Agent:** Lindy  
**Source:** understoryagency.com · Undated

## What they did

An enterprise Lindy client has agents scrape its current customers, then run social listening across their Twitter, LinkedIn and G2 reviews. The agents draft posts about milestones such as product launches or funding rounds. They take feedback, save memories to improve, build Airtable content calendars and publish the posts.

## How it went

The source says this replaces coordinating separate social listening, content and publishing specialists. It gives no metrics, volumes or quality results, and it describes the setup only briefly, as a podcast guest's account.

## Worth knowing

The source is a podcast summary with no build details, so expect to work out the prompts, feedback loop and approval steps yourself. Lindy also offers white-glove implementation help.

## Prompt

```text
Monitor [social platforms and review sites like G2] for mentions of [my company or product] and summarize the sentiment each week. Draft [three] posts celebrating customer milestones, using details from [customer list or sheet]. Put them in a content calendar for the next [two weeks]. Show me each post for approval before anything is published, and finish when the calendar is filled in.
```
