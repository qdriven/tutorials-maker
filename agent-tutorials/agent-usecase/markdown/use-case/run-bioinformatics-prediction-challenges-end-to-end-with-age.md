# Run bioinformatics prediction challenges end to end with agents

> Claude agents ran 13 bioinformatics prediction challenges at a hackathon, covering literature, design, code, benchmarks and a report; 2 still ongoing and results not yet human-verified.

**Category:** Security, Science & Hardware  
**Agent:** Claude  
**Source:** Bluesky · Oct 28, 2026

## What they did

At an AI hackathon, Pedro Beltrao's group let Claude agents work through 13 bioinformatics prediction challenges. For each one, the agents ran the whole pipeline: reading the literature, designing an approach, writing code, running benchmarks and producing a report. The post is an overview of what came out.

## How it went

Eleven of the 13 challenges had produced outputs, and 2 were still running. The post says this was before much human verification, so the quality of the results is unchecked.

## Prompt

```text
I'm working on a prediction challenge in [bioinformatics area, e.g. protein stability or variant effect]: [paste challenge description and data link]. Review the relevant literature, propose a modeling approach, write the code, benchmark it against a simple baseline, and give me a short report with the results and caveats. Flag clearly anything you could not verify so I can check it myself before I rely on it.
```
