# Run AI agent swarms in Minecraft and Mindustry

> Agent swarms were run in the games Minecraft and Mindustry; the post is only a headline, so no further detail is stated. · Oct 29, 2026

**Category:** Games & Simulations  
**Agent:** custom-built or unnamed agent

## What they did

The team built an open-source harness using Pi for the agent loop and Mineflayer tools for acting in the game. They put 50 GPT-6.1 Sol agents in a survival world for 3 hours with one goal, building a thriving civilization. The agents had an agent directory, a shared sandbox, and DMs. They organized themselves, with a leader, a ration ledger, and fishing shifts.

## How it went

The agents sent about 5,900 messages and suffered 34 deaths, 22 of them on the first night, and then turned cautious and food-focused. Some deliveries went astray. The Mindustry results were not read.

## Worth knowing

Death only dropped gear, yet the first-night deaths still made the agents risk-averse. Feeding 50 agents became the main problem, so check food supply early.
