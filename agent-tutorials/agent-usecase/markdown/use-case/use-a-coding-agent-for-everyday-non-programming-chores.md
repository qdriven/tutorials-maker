# Use a coding agent for everyday non-programming chores

> A user's Claude Code handled non-coding tasks: photo edits, PDF analysis for exam prep, killing a hung process, finding materials, checking warranties, and renaming an agent across files.

**Category:** Life Admin & Home  
**Agent:** Claude Code  
**Source:** X · Oct 7, 2026

## What they did

The user asked their Claude Code assistant to list recent tasks solved together. It rotated a photo from a shared folder and copied it to the clipboard, read a PDF exam to identify question types, located and killed a hung process, searched for cheap weatherproof steel, checked remaining warranties, combined and scaled two photos, explained a share dialog sentence, and renamed an agent name across six files.

## How it went

All tasks completed without being programming work; code was generated only when the user explicitly requested it.

## Prompt

```text
I'm going to give you some everyday chores in this folder: [list of tasks, e.g. resize photos in /photos, summarize the PDFs in /study for an exam on [topic], find files about [subject], rename [old name] to [new name] across my files]. Do them one at a time and tell me what you changed. Pause and show me the list of files before you rename, overwrite or delete anything. Finish with a short recap of each task.
```
