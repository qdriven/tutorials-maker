# Apply to jobs automatically and schedule calls

> Muse applied to 60+ jobs with updated resumes and cover letters, scheduled calls, and created prep files, reaching interview rounds.

**Category:** Life Admin & Home  
**Agent:** Meta Muse  
**Source:** X · Oct 9, 2026

## What they did

Muse was given instructions to handle job applications end to end. It updated resumes and cover letters then submitted automatic applications to over 60 positions on its own. With further direction it notified the user of an HR call request, scheduled calls, and generated an MD file with role prep.

## How it went

Three companies responded and one advanced to interview rounds. The user passed the first interview and moved to the next round.

## Prompt

```text
Find [number] open [job title] roles in [location or remote] that match my résumé, which is at [file or link]. For each one, tailor the résumé and write a short cover letter, and show me the first three before you submit any application. Once I approve, apply to the rest, schedule any calls on my calendar from [available times], and create a prep file for each interview with company notes and likely questions.
```
