# Use Grok as the narrative engine of a game

> The poster built a game where Grok generates the story narration, and says it outperformed Gemini and GPT for narrative output.

**Category:** Games & Simulations  
**Agent:** Grok Bot, Gemini  
**Source:** Reddit · May 11, 2026

## What they did

The poster says they built a text-based game where players make choices, roll dice, and face consequences, while Grok acts as the main narrator behind the scenes. According to the post, Grok keeps the game state on track and writes the story the player reads; the human built the game and framed it as a structured demo on their profile.

## How it went

They report Grok worked much better than Gemini and GPT for narrative output, crediting both its writing quality and fewer refusals around player actions. The thread gives no hard metrics, implementation details, or measured comparison results.

## Worth knowing

The useful catch is that the post is only a high-level claim and demo pointer, so you would need the profile-linked project for actual build details.

## Prompt

```text
Act as the narrator of a [genre] text adventure set in [setting]. Describe each scene vividly in 2 to 3 paragraphs, keep track of my inventory, choices, and the story so far, and end each turn by asking what I do next. Begin with the opening scene and wait for my first action.
```
