# Learn personal scripts from a tools folder

> Claude Cowork read a folder of personal scripts for email, CRM, research and drafting, added them to memory, and carried the capabilities to a new interface.

**Category:** Work & Operations  
**Agent:** Claude Cowork  
**Source:** X · Jan 13, 2026

## What they did

Tomasz Tunguz pointed Claude Cowork at a local folder holding dozens of personal scripts he had built over a year for email, CRM updates, startup research, and drafting replies. Cowork read the folder, parsed each script, and added the logic to its memory across eleven steps so the workflows ran in the Cowork interface instead of the terminal.

## How it went

The same capabilities now worked in the new interface with no loss of function. The early Cowork version was slow and crashed twice on startup.

## Worth knowing

Cowork changed the authorization settings on the original Claude Code install.

## Prompt

```text
Read the scripts in my folder [folder path] and write a plain-language summary of what each one does, such as email, CRM, research, or drafting. Save that to memory so you can use these tools in future tasks. Stop when you've given me a list of capabilities and how to invoke each one, and don't run any script without asking me.
```
