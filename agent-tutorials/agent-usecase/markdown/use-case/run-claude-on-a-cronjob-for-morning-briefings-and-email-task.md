# Run Claude on a cronjob for morning briefings and email tasks

> User built a Claude-in-a-loop with cron that produces morning briefings and podcasts and handles tasks emailed or texted to it.

**Category:** Life Admin & Home  
**Agent:** Claude  
**Source:** HN · Apr 10, 2026

## What they did

SyneRyder wrote a small Claude-in-a-loop without using OpenClaw. A cronjob runs claude -p in the early morning while they sleep, with access to context about them and long-term memory it can explore. It produces morning briefings and personalized podcasts. Emails, voice texts or Telegram messages, including forwarded emails, also start sessions and get replies.

## How it went

The source gives no numbers. The author says the agent sometimes surfaces useful, even surprising suggestions overnight without being prompted, once it has enough context about them.

## Worth knowing

The value depends on giving the agent plenty of personal context and long-term memory it can explore; a bare scheduled prompt won't produce the same results.

## Prompt

```text
Help me set up a cron job that runs Claude every morning at [time] to write a briefing from my [calendar, email, and news topics] and save it as [text file or audio]. Also have it check [email address or inbox folder] for tasks I send it and handle them. Finished means one briefing was generated by a test run. Show me any email it wants to send before it sends it.
```
