# Build and test a simple endpoint project with Devin

> A reviewer had Devin set up a project, write code, install dependencies, test endpoints and add error handling in about 4 minutes on a simple task.

**Category:** Software & DevOps  
**Agent:** Devin  
**Source:** aimadetools.com · Undated

## What they did

On day one of a week-long review, the reviewer gave Devin a plain-English prompt for a Node.js Express API with GET, POST and DELETE user endpoints and in-memory storage. Devin ran in its own sandbox with a browser, terminal and editor. It set up the project, wrote the code, installed dependencies, tested the endpoints with curl and added basic error handling.

## How it went

It finished in about 4 minutes, against the reviewer's estimate of 5 minutes by hand. The reviewer says Devin's advantage is small on tasks this simple, and that it was slower than doing the work yourself on other tasks.

## Worth knowing

Devin was priced at $500/month on the Teams plan, which the reviewer found hard to justify for solo work, and its output still needs review.

## Prompt

```text
Set up a new project called [name] in [language/framework] with an endpoint that [does X], installing the needed dependencies. Write the code, test the endpoint with sample requests, and add error handling for [invalid input or missing data]. Finish by showing me how to run it and the test results.
```
