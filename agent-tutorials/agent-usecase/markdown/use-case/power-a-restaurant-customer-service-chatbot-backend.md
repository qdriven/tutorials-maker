# Power a restaurant customer service chatbot backend

> A Make.com workflow serves as the backend for a restaurant chatbot that replies to customers via text and voice notes.

**Category:** Sales, Marketing & Support  
**Agent:** Make  
**Source:** X · Oct 13, 2026

## What they did

User built an automated Make.com workflow as backend for all chatbot responses. Vibe-coded the restaurant customer service chatbot with Lovable to reply to customers in texts and voice notes.

## How it went

The setup enables text and voice note replies via the Make.com backend.

## Prompt

```text
Build a workflow that acts as the backend for a customer chatbot for [restaurant name]. It should receive customer text messages and voice notes from [channel, e.g. WhatsApp], transcribe voice notes, and answer questions about [menu, hours, location, reservations] using the info in [source document]. Hand anything about orders, refunds or complaints to me instead of answering. Done when test messages in both text and voice get correct replies.
```
