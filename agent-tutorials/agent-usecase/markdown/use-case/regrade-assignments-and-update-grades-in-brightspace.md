# Regrade assignments and update grades in Brightspace

> A professor had an agent regrade TA-graded assignments, verify answers with Claude, and revise grades and feedback in Brightspace, catching missed issues.

**Category:** Work & Operations  
**Agent:** Claude Code  
**Source:** X · Oct 3, 2026

## What they did

The professor gave the already TA-graded assignment submissions to OpenAI's agent. The agent regraded every submission to find issues the TA missed, verified AI-generated answers by querying Claude, and directly revised all grades and feedback inside Brightspace. The professor only initiated the request.

## How it went

The process produced expanded feedback and adjusted grades that caught additional problems the TA had overlooked. The professor reached a new level of confidence in the AI output.

## Prompt

```text
Take the submitted assignments in [folder or export] for [course name] along with the answer key and rubric in [file]. Regrade each one, verify the correct answers independently, and produce a table of any grade changes with the reason and proposed feedback text. Do not update the grades in [Brightspace or my LMS] until I have reviewed the table and approved it.
```
