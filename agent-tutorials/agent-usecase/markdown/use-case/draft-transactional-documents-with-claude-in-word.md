# Draft transactional documents with Claude in Word

> The poster used Claude inside Word and coworking tools to handle the drafting grunt work of transactional documents.

**Category:** Work & Operations  
**Agent:** Claude  
**Source:** Reddit · May 14, 2026

## What they did

The poster says they use Claude inside Word and Claude coworking tools for transactional drafting tasks like fixing defined terms, removing precedent leftovers, checking cross-references, and building first drafts from prior documents once enough context is provided. In the thread, they stress that output still has to be reviewed and prompted carefully because Claude can overchange documents and still lacks some structuring judgment and deal instinct.

## How it went

The stated result was a real productivity gain, with the poster estimating it saves hours each week and makes drafting feel semi-automated. The main shortcoming they note is weaker judgment on structure and creativity, so it is not hands-off.

## Worth knowing

The clearest catch is that reliability depends on giving lots of context and manually reviewing where Claude tends to break.

## Prompt

```text
I'm drafting a [type of transactional document, e.g. purchase agreement] in Word. Using the term sheet and notes I've pasted below, draft the [section names], follow the defined terms and style in [precedent document], and flag any open points or assumptions in brackets. Finish with a clean draft I can review, plus a short list of questions you need answered. [paste terms and precedent]
```
