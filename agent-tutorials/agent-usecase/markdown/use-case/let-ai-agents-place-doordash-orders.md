# Let AI agents place DoorDash orders

> DoorDash's dd-cli beta lets agents order food, with a demo of Claude completing a full order end to end.

**Category:** Shopping & Errands  
**Agent:** Claude  
**Source:** ca.finance.yahoo.com · Undated

## What they did

DoorDash CTO Andy Fang unveiled dd-cli, a command-line tool that lets an AI agent search stores, compare deals and check out on DoorDash with real payments. In a public demo, Anthropic's Claude placed a full order without a human stepping in. The tool connects to DoorDash's ordering infrastructure directly, not through the consumer app.

## How it went

The demo showed Claude completing an order end to end. The source gives no figures on how many developers are in the beta, and no public release date has been announced.

## Worth knowing

Access is invite-only. Early access is for US and Canadian macOS developers via a waitlist, and applicants must submit a social link and a description of their intended use.
