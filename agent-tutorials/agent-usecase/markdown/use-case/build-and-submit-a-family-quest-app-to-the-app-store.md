# Build and submit a family quest app to the App Store

> A user built Kogoto Quest, which turns family reminders into quests, with Replit Agent and submitted it for App Store review.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** X · Sep 21, 2026

## What they did

The user, a mother of three with no prior coding experience, partnered with Replit Agent to develop Kogoto Quest from initial idea through full implementation, RevenueCat integration for premium AI features, and App Store submission prep. The agent performed the coding and setup steps while the user provided direction and oversight throughout.

## How it went

The app was submitted for App Store review. Free quests run on-device; premium unlocks AI via RevenueCat.

## Prompt

```text
Build a mobile app called [app name] that turns [type of reminders, e.g. family chores and appointments] into playful quests for [who will use it]. Include [3 key features, e.g. quest creation, points, shared family view]. When the app runs end to end, give me a checklist of what Apple requires for App Store submission (icons, privacy policy, screenshots) and pause before submitting anything.
```
