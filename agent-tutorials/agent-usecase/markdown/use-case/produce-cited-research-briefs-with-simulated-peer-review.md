# Produce cited research briefs with simulated peer review

> Feynman multi-agent system searches papers and the web, synthesizes findings, runs simulated peer review, verifies citations, and outputs a cited brief.

**Category:** Research & Knowledge  
**Agent:** custom-built or unnamed agent  
**Source:** X · Apr 6, 2026

## What they did

User runs one curl-bash install from terminal then types a topic. Researcher agent pulls evidence from papers, repos, docs, and web; Reviewer runs simulated peer review with severity-graded feedback; Writer drafts paper-style output from notes; Verifier checks every citation and drops dead links. Additional agents can replicate experiments on local/cloud GPUs or audit papers against codebases.

## How it went

Produces a fully cited research brief with all claims source-grounded. No usage metrics or shortfalls reported in the post.

## Worth knowing

Single curl install command; repo at github.com/Companion-Inc/feynman; thread notes the installer script is not itself open.

## Prompt

```text
Research [topic] and write a cited brief of about [length]. Search academic papers and the web, synthesize the main findings, then critique your own draft as a skeptical peer reviewer and fix the weak points. Verify every citation actually exists and supports its claim; you're done when I have the brief with a reference list and a note on any claims you couldn't verify.
```
