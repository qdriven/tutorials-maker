# Rename and sort 100+ images into folders

> The poster gave ChatGPT Agent a zip of over 100 images to rename by content and sort into subfolders, and said it did a pretty solid job.

**Category:** Work & Operations  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Jul 1, 2025

## What they did

A commenter said they uploaded a zip file containing more than 100 images, asked ChatGPT Agent to rename each file from what it saw in the image, then create subfolders and move the images into categories. In a follow-up test, they gave it the same image set and asked it to find a beach photo of a girl; they said it found the right one. They clarified they handed over a zip and got a zip back, with each query running in a separate VPC.

## How it went

They said it did a pretty solid job organizing the images and nailed the follow-up search request. The thread gives no accuracy rate, examples of mistakes, or timing.

## Worth knowing

The practical catch is that the workflow described was zip in, zip out rather than direct edits on the poster’s hard drive.

## Prompt

```text
I'm uploading a zip of [number] images. Look at each one, rename it with a short descriptive filename like [naming pattern], and sort them into subfolders by [theme/subject/date]. Give me back a zip of the organized files and a table of old names, new names, and folders. Flag any images you were unsure about instead of guessing.
```
