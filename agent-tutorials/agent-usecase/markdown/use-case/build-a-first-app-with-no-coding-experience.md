# Build a first app with no coding experience

**Category:** Software & DevOps

**Source:** Reddit · Undated

## What they did

A commenter said they built Rhettit.app with Claude and Replit’s agent, using prompts shaped around Aristotle’s rhetoric appeals—ethos, pathos, and logos—for persuasive writing. They describe the app as AI-built and say they had never coded anything functional before; the thread does not add more detail about manual steps or handoff points.

## How it went

They said it took about five minutes and cost about $5 total for Claude Sonnet API use plus Replit agent usage. The source gives no performance metrics, launch details, or specific shortcomings for this app.

## Worth knowing

The main practical detail is the reported build time and spend: about five minutes and roughly $5.

## Prompt

