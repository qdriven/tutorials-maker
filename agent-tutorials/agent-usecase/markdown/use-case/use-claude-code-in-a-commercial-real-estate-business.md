# Use Claude Code in a commercial real estate business

> A commercial real estate developer and syndicator says Claude Code changed the game for their business workflow, with few specifics given.

**Category:** Work & Operations  
**Agent:** Claude Code  
**Source:** Reddit · Jun 14, 2026

## What they did

A solo commercial real estate developer said they moved from relying on third-party Argus analysts to building their own Excel underwriting models with Claude Code. They started with a single-tenant industrial DCF, expanded to multi-tenant industrial, and were adapting it for retail, using Claude Code to build logic for rent rolls, reimbursements, downtime, renewals, leasing assumptions, tenant improvements, commissions, debt, exits, and sensitivities.

## How it went

They said the models were approaching Argus-level flexibility and reliability for their deal types, and let them customize underwriting around their own process. The stated gain was speed: minutes instead of hours or days, though they said Argus may still matter for institutional, very large, or highly standardized work.

## Worth knowing

The catch is that this account gives no implementation detail beyond Excel plus Claude Code, so you would need strong underwriting judgment to validate the model yourself.
