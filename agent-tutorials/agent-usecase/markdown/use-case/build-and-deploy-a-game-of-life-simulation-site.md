# Build and deploy a Game of Life simulation site

> In a vendor launch demo, Devin built an interactive Game of Life website, added requested features step by step, and deployed it to Netlify.

**Category:** Software & DevOps  
**Agent:** Devin  
**Source:** cognition.com · Mar 12, 2024

## What they did

The blog post describes a video demo. Devin works in a sandbox with a shell, code editor and browser. It built an interactive Game of Life website, then added features the user requested one at a time. Finally it deployed the site to Netlify. Devin reports progress as it goes and takes feedback from the user.

## How it went

The demo shows the site built and deployed end to end. The post gives no timings, costs or failure details, and it is a vendor showcase, not an independent test.

## Prompt

```text
Build an interactive website for [a simulation, e.g. Conway's Game of Life] and add these features one at a time: [feature 1, feature 2, feature 3]. Check each one works before moving on. Finish by deploying it to [Netlify or another host] and giving me the live link. Pause before the deploy step so I can approve it.
```
