# Give a coding agent a world-facing client for a game

> The author uses a coding agent to build the game Overlands and is giving it access to the world through a dedicated agent client, where it chose a name and designed its own avatar.

**Category:** Games & Simulations  
**Agent:** custom-built or unnamed agent  
**Source:** Bluesky · Sep 24, 2026

## What they did

The author already uses a coding agent to build the game Overlands. They then gave it access to the game world through a new dedicated agent client. Once it was in the world, the agent picked the name Hypha and designed its own in-world avatar. The post includes a video of this.

## How it went

The agent chose a name and an avatar, which the author describes as some kind of flying mushroom. The post gives no further results or technical detail.

## Worth knowing

The post is a short announcement. It says nothing about how the agent client works, what it costs, or how much the agent is allowed to do in the world.
