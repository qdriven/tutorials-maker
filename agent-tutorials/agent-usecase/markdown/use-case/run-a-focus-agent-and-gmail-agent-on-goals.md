# Run a focus agent and Gmail agent on goals

> The author built a background focus agent linking calendar to goals, plus a Gmail agent that handles the inbox and filters noise.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Undated

## What they did

The author says they built a minimalist background focus agent after spending hours manually maintaining Google Calendar for classes, a thesis, internships, and hackathons. The system is meant to bridge calendar blocks and actual goals while staying out of the way, and they say they are now adding a Gmail agent to handle the inbox and filter noise based on feedback from early adopters.

## How it went

The post reports qualitative feedback only: several early adopters asked for more automation, leading to a Gmail agent, site blocker tied to focus blocks, and a Chrome extension. It does not give usage numbers or measured results yet.

## Prompt

```text
Every morning, read my [Google] calendar and compare it to my goals: [list 3 goals]. Tell me which events support those goals and which don't, and suggest one block of focus time for the top goal. Also scan my Gmail, sort out newsletters and promotions, and give me a short list of messages that need a reply. Don't send or delete anything without showing me first.
```
