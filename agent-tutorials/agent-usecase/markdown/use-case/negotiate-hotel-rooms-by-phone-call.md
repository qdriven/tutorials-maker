# Negotiate hotel rooms by phone call

> An AI assistant called a hotel in Japan and negotiated the same two rooms for all five nights; the user listened to the recording afterward.

**Category:** Travel & Bookings  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 29, 2026

## What they did

The AI agent @hey__fo was instructed to handle hotel booking for two rooms over five nights in Japan. It placed the call independently and conducted the negotiation on the phone. The user provided no real-time input and only listened to the full call recording afterward.

## How it went

The agent secured the exact same two rooms for all five nights.

## Prompt

```text
Call [hotel name and phone number] and ask whether they can offer [number] rooms for the same room type for all [number] nights, [dates], at a rate close to [target price]. Be polite, ask for options, and don't agree to anything or give payment details without checking with me first. Send me a summary and the call recording or transcript afterward.
```
