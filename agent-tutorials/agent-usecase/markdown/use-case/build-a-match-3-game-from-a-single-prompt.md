# Build a match-3 game from a single prompt

> An author prompted Gemini 3 Pro once to produce a working Candy Crush-style game with a shareable link, and says a non-technical friend did too.

**Category:** Games & Simulations  
**Agent:** Gemini  
**Source:** dev.to · Undated

## What they did

In the Gemini web app with Gemini 3 Pro selected, the author pasted one detailed prompt. It asked for a single-file HTML canvas match-3 game with no external libraries. The prompt listed swapping, match detection, gravity, refill, scoring, a move or timer limit, rising difficulty, sound and particle effects, and auto-running in the chat. The game appeared in an interactive pane, and a share icon produced a link.

## How it went

The author says the game was playable in about 30 seconds and a non-technical friend got it working too. The author admits the code isn't perfect. No test results are given beyond playing it.

## Worth knowing

The author says it was free at the time of writing and took 30 seconds to 5 minutes. The post is vague on follow-up tweaks, and its intro says Gemini 2.0 while the title says Gemini 3.

## Prompt

```text
Build a working [game type, e.g. match-3 puzzle] web game with [features, e.g. score, levels, animations, a restart button] and give me a shareable link. Keep it to one page and make it playable on mobile. You're done when the game runs without errors and I can open it from the link.
```
