# Run communications, PR merges and family tasks with nine bots

> The author moved from OpenClaw to Grok Bot, building bots for email in his voice, a daily check of GitHub PRs ready to merge, and household family tasks.

**Category:** Work & Operations  
**Agent:** Grok Bot, OpenClaw  
**Source:** chatprd.ai · Undated

## What they did

Claire Vo built bots on Grok Bot, each with plugins for Gmail, Slack and GitHub, plus a cloud computer and scheduled routines. Chief sweeps six inboxes hourly and drafts replies after studying her sent mail for voice. LGTM goes through her assigned GitHub PRs daily, finds ones ready to merge, close or rebase, and starts Cursor cloud agent jobs under her rules. TradBot prints a family newspaper and messages parents about pickups.

## How it went

LGTM helped clear about 50 stalled PRs in one Friday, and the PR queue is healthier. Chief's writing is still not trusted for high-stakes emails, and routines need explicit setup.

## Worth knowing

Routines must be set up more explicitly than OpenClaw's heartbeat, and bots are single-player: you can't add one to a group chat yet.

## Prompt

```text
Set up three recurring helpers for me: one that drafts email replies in my voice from [examples of my writing], one that checks each morning for [GitHub repo] pull requests that are ready to merge and lists them, and one that tracks [household or family tasks]. Show me every drafted email before it is sent, and don't merge anything without my say-so. Finish by sending me a summary of what each helper will do and when.
```
