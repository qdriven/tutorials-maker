# Rebuild a math curriculum into a one-year plan with materials

> Claude restructured an accelerated math curriculum into one year, writing tests, games, worksheets, a schedule, and a hosted site integrated with a teacher planner.

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** X · Oct 2, 2026

## What they did

User gave Claude the full curriculum stack for an accelerated two-year math class and asked it to rebuild into a one-year program, write tests, create optional online games, make worksheets, and schedule the year, with Claude consulting Grok, Gemini, ChatGPT, and KIMI via MCP. Claude generated the materials on its own and produced a hosted site with games, scoring, and leaderboard plus printouts, tests, and calendar. All output integrated into an existing online teacher planner; no code was written.

## How it went

An hour later the complete materials and hosted site were ready. No shortfalls noted.

## Worth knowing

All built in one hour without any coding experience, integrated with a pre-existing planner.

## Prompt

```text
Here is my current [grade level] math curriculum: [paste or attach files]. Restructure it into a one-year plan of [number] weeks, and create for each unit a worksheet, a short test, and a game or activity, plus a week-by-week schedule. Put everything in [folder] and build a simple website to browse it. You're done when every unit has its materials and the schedule covers the full year.
```
