# Prepare and file overdue German VAT statements

> Cowork with Claude's Chrome extension prepared accounts from invoice PDFs, then logged into Elster and submitted the overdue Q3 2025 VAT forms.

**Category:** Money, Bills & Benefits  
**Agent:** Claude Cowork, Claude in Chrome  
**Source:** X · Feb 9, 2026

## What they did

Gave Claude Cowork a project folder holding invoice and receipt PDFs and asked it to prepare accounts for each quarter. Logged into Elster, then used the Claude Chrome extension to locate the forms, fill them with the prepared data, and submit the Q3 2025 VAT statements. Recorded the browser session and later asked Claude to redact personal details and speed the video up 3x.

## How it went

The overdue Q3 2025 statements were filed. No other results or shortfalls reported.

## Worth knowing

Used only Anthropic's off-the-shelf Cowork and Chrome extension with no programming.

## Prompt

```text
Use the invoice PDFs in [folder path] to prepare my accounts and a VAT summary for [period]. Then open [tax portal, e.g. Elster] in my browser, and fill in the VAT return form with the figures. Stop before submitting and show me every number you entered so I can approve the filing.
```
