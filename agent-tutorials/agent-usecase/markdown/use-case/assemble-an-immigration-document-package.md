# Assemble an immigration document package

> A user had ChatGPT browser use gather seven years of taxes, bank statements and immigration documents into a package in minutes.

**Category:** Life Admin & Home  
**Agent:** ChatGPT Agent  
**Source:** X · Aug 17, 2026

## What they did

ChatGPT browser use was given access to the user's accounts and scraped seven years of taxes, bank statements, and immigration documents. It assembled them into a complete package with no further steps described.

## How it went

The package was prepared in minutes. No other results or shortfalls are stated.

## Prompt

```text
Help me assemble a document package for my [type of immigration application]. Go through my [email, cloud drive, or bank and tax portals] and collect [number] years of tax returns, bank statements, and identity and immigration documents, then organize them into one folder with an index listing each file and any missing items. Pause and ask me before logging into any account or downloading anything sensitive, and don't submit or send the package anywhere.
```
