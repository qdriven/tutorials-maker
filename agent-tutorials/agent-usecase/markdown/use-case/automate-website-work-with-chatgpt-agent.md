# Automate website work with ChatGPT Agent

> A user used ChatGPT Agent heavily in one chat to automate work on a website, until the tool disappeared as they were nearly done.

**Category:** Work & Operations  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Undated

## What they did

The thread says a user had access to ChatGPT Agent briefly, used it heavily in a single chat, and had it automate work on a website through the computer/operator tool. Partway through, the feature disappeared: they could still open new Agent chats, but it would no longer use the website automation tool, so the work stopped before they could finish.

## How it went

The reported outcome was mostly frustration: it worked for about two hours and got close to done, then access was removed. Multiple commenters said Agent or Operator also vanished for them, sometimes after 30 minutes or later the same day.

## Worth knowing

Big catch: access looked unstable in this rollout, with users reporting the tool could disappear mid-task even while chat history remained.
