# File insurance claims for overcharges

> Tarun told an agent to file all the claims after finding overcharges and has received $200 back so far.

**Category:** Money, Bills & Benefits  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 2, 2026

## What they did

Tarun gave the agent access to his insurance account information. After spotting nearly $1,700 in overcharges on items that should have been zero copay, he instructed the agent to file all the claims.

## How it went

The agent filed the claims and $200 has been recovered so far.

## Prompt

```text
I found overcharges on [accounts/bills] totaling about [amount]. For each one, open the provider's claim or refund page at [site] and prepare the claim with the supporting details: [dates, amounts, reference numbers]. Pause and show me each claim before submitting, and finish with a list of what was filed and what I'm owed.
```
