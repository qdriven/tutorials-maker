# Build a first real project with Replit Agent

> A student completed a real build with Replit Agent, spending about $65 in agent usage and finding the cost unexpected.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** Reddit · Jul 1, 2026

## What they did

The poster used Replit Agent for a first real MVP: a basic UI tied to Supabase with a few iteration rounds. They let the agent handle open-ended build and debugging work, then learned after the fact that charges kept accruing through retries and “drift”; support advised resetting sessions when it started looping, and later gave a one-time courtesy refund.

## How it went

After about two days, the project had cost $20 for Replit Core plus about $65 in Agent usage, while the app was still under 50% finished. The poster said the main shortfall was unexpected spend from looping and rework rather than visible progress.

## Worth knowing

Their most practical takeaway was to set a hard spending limit before the first prompt, use Economy Mode at roughly one-third the credits per task, and restart chats as soon as the agent goes in circles.

## Prompt

```text
Help me build a first project: [describe the project] using the simplest approach. Before building, give me a rough estimate of how much agent usage it may cost and break the work into small steps. Pause after each step for my okay so I can stay under a budget of [$ amount], and stop when the core feature works.
```
