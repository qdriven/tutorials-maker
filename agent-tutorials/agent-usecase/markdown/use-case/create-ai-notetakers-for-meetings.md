# Create AI notetakers for meetings

> A user who moved from n8n to Lindy uses it with Outlook and Slack to create and manage AI notetakers so they no longer take meeting notes by hand.

**Category:** Work & Operations  
**Agent:** Lindy, n8n  
**Source:** g2.com · Undated

## What they did

The reviewer (Tony L.) moved from n8n to Lindy and describes the setup as easy. They create AI agents by prompting Lindy, then use it with Outlook and Slack to create and manage notetakers for their meetings. The review doesn't go into step-by-step mechanics.

## How it went

They no longer take notes by hand and get consistent feedback from each meeting. The one drawback: when Lindy makes mistakes while building agents, those errors use up a lot of credits.

## Worth knowing

Errors made while building agents consume many credits, so expect some cost while you get the agent right.

## Prompt

```text
Set up a Lindy notetaker that joins my [Outlook/Teams/Zoom] meetings, records the key decisions and action items with owners, and posts a summary to [Slack channel] after each one. Only join meetings that match [rule, e.g. have external guests]. Test it on my next meeting and show me the summary before posting to the channel.
```
