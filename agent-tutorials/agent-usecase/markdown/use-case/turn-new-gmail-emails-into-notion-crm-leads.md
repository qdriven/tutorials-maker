# Turn new Gmail emails into Notion CRM leads

> A Zapier Agent triggers on each new Gmail email and creates a lead record in a Notion database with mapped properties filled in.

**Category:** Sales, Marketing & Support  
**Agent:** Zapier Agents  
**Source:** simonesmerilli.com · Undated

## What they did

Simone Smerilli created a Zapier Agent with a Behavior triggered by Gmail's New Email event. His written instructions told it to judge whether each email is a lead, research the sender online (company, website, LinkedIn, fun facts), and if so add a Notion database item with the thread URL in Notes. He mapped the Notion properties, tested, and refined the prompt.

## How it went

Once switched on, it runs automatically on each new email like a normal Zap. The source gives no accuracy or time-saved figures, and Smerilli says the use case may or may not suit your business.

## Worth knowing

Each run uses about 4 Zapier Agents activities, which is how usage is billed. A regular Zap gives more predictable results, whereas an agent needs careful prompt tuning.

## Prompt

```text
Create a Zapier Agent that triggers on each new email in [Gmail label or inbox]. If the email looks like a real lead, create a new record in my [Notion CRM database] with these properties filled in: [name, company, email, source, summary of request, date]. Skip spam and newsletters, and tell me which emails you skipped. You're done when a test email produces a correctly filled lead record.
```
