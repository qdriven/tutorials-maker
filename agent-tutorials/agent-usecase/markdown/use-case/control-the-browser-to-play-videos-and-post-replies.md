# Control the browser to play videos and post replies

> Comet takes over the browser to find a YouTube playlist, start the first video and pause it, and to reply to tweets and post on Reddit.

**Category:** Life Admin & Home  
**Agent:** Perplexity Comet  
**Source:** Reddit · Aug 1, 2025

## What they did

One commenter said they use Comet for simple browser-control tasks: they ask it to find a specific YouTube playlist, open the first video, reset it to the start, and pause it. The same person also said they use it to reply to tweets and post multiple things on Reddit, implying the agent takes over the browser to carry out those posting steps.

## How it went

The reported result was that the YouTube routine worked as asked. The source gives no numbers, examples of the tweet or Reddit posts, or details on failures for this specific use case.

## Worth knowing

This came from a casual comment describing “stupid stuff mostly,” so the thread gives almost no setup detail beyond that Comet can directly control the browser.
