# Triage inbox, draft replies and manage calendar from a desktop agent

> A reviewer used Scout to summarize a Microsoft 365 inbox, draft replies, manage calendar events, browse and work with local files; it needs the app open and can be costly.

**Category:** Work & Operations  
**Agent:** Microsoft Scout  
**Source:** intelligink.com · Undated

## What they did

Ben Stegink reviewed Microsoft Scout, a desktop app on macOS and Windows. An admin had to enable it and push a policy through Intune or Group Policy. He picked a model from those his organization allows through GitHub Copilot. Through Work IQ, Scout summarized the Microsoft 365 inbox, drafted replies, managed calendar events, browsed the web and worked with local files. It also supports scheduled heartbeats and automations.

## How it went

Scout does things Microsoft 365 Copilot alone can't, namely local file access and MCP. The review calls it a strong 1.0 with rough edges. Its automations only run while the app is open and the machine is awake.

## Worth knowing

It needs two Copilot licenses, about $50 a month, plus token and Work IQ charges. One light query runs around sixteen cents, and scheduled heartbeats add up.

## Prompt

```text
Summarize my unread Microsoft 365 email from [time period] grouped by what needs action, and draft replies for the important ones without sending any. Review my calendar for [week] and suggest changes or new events for [commitments], asking before you create, move, or cancel anything. Finish with a short list of drafts and proposed calendar changes.
```
