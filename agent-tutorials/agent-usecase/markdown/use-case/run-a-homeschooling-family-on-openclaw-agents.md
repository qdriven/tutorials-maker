# Run a homeschooling family on OpenClaw agents

> A mom runs five OpenClaw agents that plan lessons from curriculum photos, manage the family schedule, and built a kids' TV app deployed to a TV.

**Category:** Life Admin & Home  
**Agent:** OpenClaw  
**Source:** shippingskool.com · Undated

## What they did

Jesse Genet runs five OpenClaw agents, each on its own Mac Mini with limited permissions. She photographed curriculum books and sent them to Sylvie, the homeschool agent. Sylvie turned them into lesson plans, Gemini watercolor illustrations and an Obsidian inventory of toys. She directed coding agent Cole from her phone to build the Mira kids' TV app. When Cole said a TV install wasn't possible, she pushed back and it found a way.

## How it went

Cole built Mira in four days and it was deployed to a Google TV Streamer. Sylvie's plans, inventory and print-from-photo worked. The article gives no measured results beyond that.

## Worth knowing

Setup cost about $3,000 in hardware and under $50 a month in API costs. The article says the first week will feel clunky, and one machine can run several agents but loses the security separation.

## Prompt

```text
Help me plan [number] weeks of homeschool lessons for [child's name and grade] from the curriculum photos I'll share. Produce a day-by-day schedule with subjects, materials needed and time estimates, and put it in a format I can print or add to my calendar. Show me the full plan for review before you add anything to my calendar or send it to anyone.
```
