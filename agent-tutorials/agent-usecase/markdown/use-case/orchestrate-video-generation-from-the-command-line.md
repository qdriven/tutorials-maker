# Orchestrate video generation from the command line

> Grok was connected to an agent via CLI to generate Imagine clips, assemble the video and add music and effects.

**Category:** Content & Creative  
**Agent:** Grok Bot  
**Source:** X · Oct 7, 2026

## What they did

The user ran their custom agent dimul from the command line. It connected to Grok via CLI under a SuperGrok subscription and used it to orchestrate Imagine clip generation from prompts. Grok 4.7 then handled assembly of the video plus music and effects.

## How it went

A 215-second video resulted. The agent will be released publicly in a couple of days.

## Worth knowing

Agent release planned in a couple of days.

## Prompt

```text
Using command-line tools, generate [number] short Grok Imagine clips for [video concept], then assemble them in order into one video with background music and simple effects. Keep the clips and the final file in [folder]. Stop when the final video plays start to finish, and tell me the command to rerun it with different clips.
```
