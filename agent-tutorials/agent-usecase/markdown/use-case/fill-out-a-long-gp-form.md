# Fill out a long GP form

> An agent filled out a long GP form, which led to a doctor call and tests being booked automatically.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 2, 2026

## What they did

The user instructed their agent to complete a long GP form they had been avoiding. The agent handled the full submission on its own with no further user input during the process. The user only became involved after receiving the follow-up doctor call.

## How it went

The doctor called and booked the tests automatically. This completed tasks the user had repeatedly postponed.

## Prompt

```text
Fill out this long [GP/medical registration] form at [form link or attached file] using the details I give you: [name, date of birth, address, medical history, medications]. Ask me about anything missing rather than guessing. Before submitting or booking anything, pause and show me the completed form for review, and stop once it is submitted and I have the confirmation.
```
