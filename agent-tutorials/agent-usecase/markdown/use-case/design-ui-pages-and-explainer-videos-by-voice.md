# Design UI pages and explainer videos by voice

> A user directed Grok Bot by voice to create UI/UX pages for a financial desk, images, animated designs and explainer videos.

**Category:** Content & Creative  
**Agent:** Grok Bot  
**Source:** X · Oct 10, 2026

## What they did

User spoke instructions and supplied design references to Grok Bot to build UI/UX pages for an agentic financial desk. The bot generated the pages, created images, animated the designs on its own, and produced explainer videos. User directed the overall request and chose references.

## How it went

All requested pages, animations, and videos were completed.

## Prompt

```text
Design a set of UI pages for [type of product, such as a dashboard for my team] based on what I describe: [features and style preferences]. Create the page mockups and a short animated explainer video showing how it works. Finish with the images and video in one folder and a list of design choices you made so I can give feedback.
```
