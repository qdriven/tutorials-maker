# Run shopping, trip planning and project tracking with a dot

> A reviewer's dot flagged a failed payment unprompted but only read and reported it; a shopping site blocked it and follow-through was unfinished.

**Category:** Work & Operations  
**Agent:** Dots, ChatGPT Agent  
**Source:** ai.joaoqueiros.com · Undated

## What they did

Pat Simmons gave OpenAI's Dots agent shopping, travel, project-tracking and inbox work, connecting Slack, Gmail and a project queue. Amazon blocked the dot's cloud browser, so he separately granted local-browser access. The dot researched trips, built a rough training dashboard, scheduled weekday status summaries, and flagged a failed $22 Vercel payment without being asked to watch billing.

## How it went

The shopping reached a cart but no purchase. No trip was booked. The dashboard was rough, and the payment alert was only reported, not fixed or independently verified.

## Worth knowing

Dots is rolling out gradually to eligible Pro users outside the EEA, Switzerland and the UK. Pat kept issue closures as proposals for his approval.

## Prompt

```text
Act as my always-on assistant for [shopping, trip planning, and tracking my project: name]. Each day, check [email or payment account] for problems like failed payments and tell me right away what you find. Don't pay, send or change anything without showing me the action first.
```
