# Generate structured company research reports

> Dharmesh's Company Research agent pulls firmographics, executives, traffic, search marketing data and G2 reviews into a structured report on any company.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** X · Nov 11, 2025

## What they did

Dharmesh built the agent at companyresearch.ai and gave it access to multiple paid and proprietary data sources. The agent aggregates firmographics, top executives, web traffic, search marketing data, and G2 reviews into one structured report when a user enters any company name. Users then customize sections, add custom questions, save reports, or push to HubSpot.

## How it went

Reports cover revenue multiples and revenue per employee for public companies. The agent launched for personal and team use in sales, partnerships, and customer success with a Smart Note feature still in development.

## Prompt

```text
Build a structured research report on [company name or website]. Include firmographics, key executives, estimated web traffic, search and marketing activity, and customer review themes from G2 or similar sites. Finish with a one-page summary of strengths, weaknesses and sales angles for [my purpose, e.g. outreach], and list the sources you used.
```
