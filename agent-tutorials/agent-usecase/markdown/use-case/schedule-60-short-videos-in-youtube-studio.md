# Schedule 60 short videos in YouTube Studio

> Claude via the Chrome extension scheduled 60 generated short videos in YouTube Studio after suggesting the task itself.

**Category:** Content & Creative  
**Agent:** Claude in Chrome, Claude  
**Source:** X · Oct 7, 2026

## What they did

Opus 5.5 generated 60 short videos for the Kepler IPTV app and suggested scheduling them in YouTube Studio. The user prompted it to handle the task itself. The agent installed the Claude Chrome extension and used it to schedule all the shorts.

## How it went

All 60 shorts were scheduled.

## Prompt

```text
Open YouTube Studio in my logged-in browser and schedule these [number] short videos from [folder or list] to publish one at a time starting [date] at [time], with [number] per day. Use the titles and descriptions from [file or list], and set the audience and visibility as [settings]. Before you confirm the first schedule, show me the plan, and report any video that failed to upload or schedule.
```
