# Build and test a Mars simulator game

> Grok Build wrote the systems for a Mars simulator game, tested it, studied gameplay, fixed bugs and iterated.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** X · Aug 26, 2026

## What they did

The user gave Grok Build simple prompts to create a Mars simulator game for his nephew. The agent wrote the systems, built and tested the game, studied the gameplay, found and fixed bugs, then kept iterating on its own.

## How it went

It produced a working Mars simulator game.

## Prompt

```text
Build a simple [Mars colony / other theme] simulator game that runs in the browser. Write the core systems ([resource management, survival, events]), then play-test it yourself, note where it is buggy or dull, fix those problems and repeat for [3] rounds. Stop when it is playable start to finish and give me a short list of what you changed.
```
