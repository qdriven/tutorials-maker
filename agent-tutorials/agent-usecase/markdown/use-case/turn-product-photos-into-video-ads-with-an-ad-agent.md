# Turn product photos into video ads with an ad agent

> A commenter feeds product photos and audience details to an agent that drafts the script, generates b-roll, and adds voiceover; another mentions a bot organizing calendar and payments.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Apr 9, 2026

## What they did

One commenter said they give a dedicated ad agent raw product photos plus an audience demographic, and it handles a first pass end to end: drafting the script, generating b-roll, and adding voiceover. They do not leave it fully unattended; the useful part is that the agent outputs the exact prompt for each scene, so the person can fix only the bad scene and re-run that clip instead of reworking the whole ad.

## How it went

They said this makes the workflow usable and saves them from spending 20 minutes wrestling with a general LLM on every fix. The limitation they stressed is that unguided output is still generic, so it is not a hands-off system.

## Worth knowing

A separate commenter said a friend's driving-school bot only handled repetitive admin, funneling messages and appointments while organizing calendar and payment data into a database.

## Prompt

```text
Using these product photos [files or links] and this audience description [who they are, what they care about], write a [15-30] second video ad script, generate matching b-roll, and add a voiceover in a [tone] voice. Deliver the finished video plus the script as separate files. Do not publish or upload it anywhere; show me the result first.
```
