# Automate payroll tax and garnishment cheque processing

> A payroll team built an agent to process tax and garnishment cheques, building missing tools when it hit a system limitation.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 2, 2026

## What they did

The payroll team built an AI agent to automate tax and garnishment cheque processing. When the agent hit a system limitation, the team built the missing tools and connected the workflow.

## How it went

The agent removed repetitive work for the payroll team.

## Prompt

```text
Help me process [tax payment and garnishment cheques] for payroll from [folder or system with the source files]. For each item, check the amount and payee against [payroll register or report], prepare the cheque details or payment record, and flag anything that does not match or that you lack a way to do. A finished job is a reconciled list ready for me to review. Pause and show me everything before you submit, send or file anything.
```
