# Open a Search Console report in Chrome

> A business owner's Claude-based AI employee opened a Search Console report in a tab but stopped at sign-in, which the owner had to complete first.

**Category:** Sales, Marketing & Support  
**Agent:** Claude in Chrome, Claude  
**Source:** kevinwelter.com · Undated

## What they did

Kevin Welter's AI employee Sebastian (SEO and GEO) had to open the AI report in Google Search Console, which is only in the portal and not the API. Using the Claude in Chrome extension, he opened a tab in Kevin's running Chrome, took screenshots and read the page. When Google asked for a login, he stopped and reported it, because the workforce rule is that AI handles no credentials.

## How it went

No report came out of it. The task ended at the login, and Kevin signed in himself so Claude could read the page. He treats that boundary as the useful result.

## Worth knowing

The extension needs Google Chrome on desktop and a paid Claude plan (Pro or higher). Each website needs approval, and Claude does not type passwords.

## Prompt

```text
Open [Search Console or analytics site URL] in a new tab. If it shows a sign-in page, stop and tell me so I can log in myself, and wait until I say I'm done. Once I'm in, open the [report name] report for [date range], and summarize the top [number] [queries or pages] and any notable changes versus [comparison period] in a short list. You're finished when I have the summary; don't change any settings.
```
