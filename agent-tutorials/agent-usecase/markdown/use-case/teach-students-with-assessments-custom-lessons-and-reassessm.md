# Teach students with assessments, custom lessons and reassessment

> Hugh Shbalz trained an agent to give standardized assessments, write lessons to fill gaps, then reassess mastery of core concepts.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 29, 2026

## What they did

At his last job Hugh trained an AI agent to administer standardized assessments, generate custom lessons that targeted identified knowledge gaps, and then run reassessments to check mastery of core concepts.

## How it went

The agent performed the full cycle of a top-level teacher's work.

## Worth knowing

Minimal risk of inappropriate behavior toward students.

## Prompt

```text
Act as a tutor for [student grade and subject]. First give a short assessment on [topic] and score it to find the gaps. Then write custom lessons with practice problems for just those gaps, and finish with a reassessment on the same core concepts. Report the before and after results so I can see whether the student has mastered it.
```
