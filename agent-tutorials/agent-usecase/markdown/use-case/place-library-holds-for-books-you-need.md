# Place library holds for books you need

> An always-on agent picks titles for a request like chess books for a 6-year-old and books them via the county library site; the library emails when ready. · Oct 12, 2026

**Category:** Life Admin & Home  
**Agent:** Meta Muse  
**Source:** eleanorkonik.com · Oct 12, 2026 · Submitted by Eleanor Konik

## What they did

Eleanor Konik uses Muse, a hosted always-on agent, and has given it her library card login, which it stores in a locker it can't see and can only use on the right site. She sends one instruction, such as finding chess books for a bright 6-year-old. Muse picks the titles and requests them on the county website.

## How it went

A few days later the county emailed that the books were ready, and she went to pick them up. The source gives no count of titles or any failures for this task.

## Worth knowing

Muse runs a model about six months behind the frontier, and Grok Bot won't store library or Costco logins. Hosted agents also cost compute on every scheduled wakeup, so audit your jobs.

## Prompt

```text
I want to borrow [number] books about [topic] for [reader, e.g. a 6-year-old] from [my library system's website]. Pick good titles that are available, and add them to my holds using my library account. Before you place any hold, show me the list and wait for my approval; you're done when I've confirmed and the holds are placed.
```
