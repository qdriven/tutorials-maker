# Play Doom with computer-use agents as an informal benchmark

> The OpenClaw team used computer-use agents to play Doom on remote machines, treating game performance as an informal way to improve the computer-use workflow.

**Category:** Games & Simulations  
**Agent:** OpenClaw  
**Source:** theneuron.ai · Undated

## What they did

The source only mentions this in one line of a livestream recap with Vincent Koc. The OpenClaw team has computer-use agents play Doom inside remote machines. Those machines come from their Crabbox remote-execution setup, where a person can open the VNC desktop or SSH in. They treat how well the agents play as an informal benchmark for improving computer-use.

## How it went

No scores or results are given for the Doom runs. Koc says computer use is now about 10% of his workload, mostly clicking through infrastructure interfaces or verification screens.

## Worth knowing

The source gives no cost or setup detail for the Doom runs. Crabbox has no built-in cost limits yet, so cap spending on any remote machines you provision yourself.
