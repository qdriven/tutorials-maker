# Move OpenClaw skills to Grok Bot

> The poster transferred their OpenClaw skills to Grok Bot, which they say took over their responsibilities using a mix of cloud and local-machine work.

**Category:** Work & Operations  
**Agent:** Grok Bot, OpenClaw  
**Source:** Reddit · Sep 1, 2026

## What they did

The commenter said they replaced OpenClaw and other automations with Grok Bot for admin and personal-assistant work, not mainly development. They described a hybrid setup where Grok Bot worked with scripts, read their iMessages, used files and folders already on the OpenClaw machine, and kept credentials on that local box while also doing work in the cloud; they said it needs scratch space and scripts rather than just the mobile app.

## How it went

They said it effectively took over much of their admin workload and acted as a force multiplier, especially for someone in IT. The main limitation they mentioned was usage limits, plus that it only becomes effective when you provide the right tools and local setup.

## Worth knowing

The clearest catch is that this was not plug-and-play: they said it needs scratch space, scripts, and an existing machine holding files and credentials to work well.

## Prompt

```text
I'm moving from OpenClaw to you. Here are my existing skills and instructions: [paste skills or describe them]. Recreate each one as a task you can run, using your cloud computer where possible and telling me which ones need my local machine. Run each once with a test input and show me the result. Ask me before sending messages, spending money, or deleting anything, and stop when every skill has been tested or flagged as unsupported.
```
