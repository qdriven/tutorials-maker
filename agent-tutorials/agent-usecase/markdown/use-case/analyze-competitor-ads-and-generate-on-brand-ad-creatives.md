# Analyze competitor ads and generate on-brand ad creatives

> An autonomous Ad Agent built on the Claude Agent SDK finds competitors, analyzes their ads, generates on-brand creatives and packages a shareable report.

**Category:** Sales, Marketing & Support  
**Agent:** Claude  
**Source:** X · Jan 6, 2026

## What they did

The Ad Agent was built on the Claude Agent SDK and given a prompt to find competitors, learn from their ads, generate on-brand creatives, and package a shareable report. It ran the full sequence autonomously with no node-based workflows or extra setup. A person could supply the initial prompt or let it proceed independently.

## How it went

The agent completed the described workflow of competitor analysis, creative generation, and report packaging. The post provides no performance numbers or noted shortfalls.

## Prompt

```text
Find the top [number] competitors of [my brand and what it sells], look at their current ads on [Meta Ad Library, Google, or TikTok], and summarize their messaging, offers, and visual styles. Then create [number] new ad concepts in my brand style ([colors, tone, logo notes]) and put everything into a shareable report. You're done when the report has the competitor analysis and the ad creatives with short reasoning for each.
```
