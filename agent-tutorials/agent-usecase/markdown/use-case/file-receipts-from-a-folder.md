# File receipts from a folder

> Grok Bot filed 14 receipts from a folder, held 2 that needed a card number, and saved a new payment method it found.

**Category:** Money, Bills & Benefits  
**Agent:** Grok Bot  
**Source:** X · Aug 19, 2026

## What they did

User ran Grok Bot against a receipts folder. The agent filed 14 receipts on its own, held 2 because they needed a card number, and saved a payment method it found without the user writing it.

## How it went

Returned 14 filed receipts, 2 held for card details, and one saved payment method.

## Prompt

```text
Go through the receipts in [folder path], file each one into [expense tool or spreadsheet] with date, vendor, amount, and category. If any receipt needs information you don't have, like a card number, hold it and list it for me. Show me the full list of what was filed and what's held, and don't delete any originals.
```
