# Run a shared team agent for calls, approvals and tasks

> Nikki set up a shared Hermes Agent for a startup team that pulls call context, handles approvals and creates tasks using shared Obsidian knowledge.

**Category:** Work & Operations  
**Agent:** Hermes Agent  
**Source:** X · Oct 1, 2026

## What they did

Nikki created a shared Hermes Agent named Robert for the buzzdotxyz startup team. It receives access to the team's full Obsidian knowledge base plus Hermes memory, enabling any member to ask questions or assign work. On its own it pulls call context, processes approvals, and creates tasks in Multica.

## How it went

Robert supplies context beyond any single chat, helping the non-technical co-founder and others complete more work. Nikki is now planning to add the SaaS design team.

## Prompt

```text
Act as a shared assistant for our team of [number] people. After each call in [call tool], pull the context, draft action items as tasks in [task tool], and use our shared notes in [Obsidian folder] for background. Ask for my approval, showing the exact task or message, before creating tasks or notifying anyone, and finish when every call from [timeframe] has a task list.
```
