# Help people with ADHD edit text by talking to an agent

> A toolkit that lets people with ADHD use agents, now with a Prose module for editing text in the browser by talking to the agent. · Nov 3, 2026

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent

## What they did

xo is a starter kit you start by pasting a message into Claude Code or Codex, so the agent can work with files on your computer. It saves memory as plain local files and only adds connections you choose. The Prose module, by David Crespo, lets you review a Markdown draft in the browser and send passage questions or edits to the agent through a checked connection.

## How it went

The page gives no results or numbers. The kit's own Prose variant is not released yet, so for now you write in chat. The kit is described as new and not fully tested.

## Worth knowing

Usage limits can run out during setup, possibly a five-hour window, so you would have to continue later. Cloud apps send everything you share to the provider.

## Prompt

```text
I have ADHD and find editing long text overwhelming. I'll paste a draft of [type of text, e.g. email or essay] and tell you out loud or in short messages what I want changed, like 'make it shorter' or 'sound friendlier'. Make one change at a time, show me the updated version, and ask what to fix next until I say it's done.
```
