# Build a report-writing program for real estate appraisals

> A real estate appraiser used Claude to build a report-writing program that removes tedious work from the appraisal process.

**Category:** Work & Operations  
**Agent:** Claude  
**Source:** Reddit · Jun 14, 2026

## What they did

A real estate appraiser in South Korea said they used Claude Code to build a report-writing program for appraisal work, despite having no coding or software background. Over about two months, they iterated heavily, spending a lot of tokens and moving past repeated frustrations, after an earlier attempt to build a similar system with professional developers had failed because the workflow was hard to communicate.

## How it went

They said the tool removed much of the repetitive reporting work, coworkers found it impressive, and the firm was likely to adopt it officially. The CEO noticed it and offered an incentive similar to royalties, but the post does not give performance metrics.

## Worth knowing

The main catch was cost and effort: they said it took two months and required paying for Claude’s expensive plan.
