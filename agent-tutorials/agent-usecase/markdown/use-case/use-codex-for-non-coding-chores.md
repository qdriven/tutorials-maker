# Use Codex for non-coding chores

> Commenters use Codex for Pi-hole upgrades, market research, wiki building, file search, PowerPoint edits, light Excel work, scraping, and data entry.

**Category:** Life Admin & Home  
**Agent:** Codex  
**Source:** Reddit · Undated

## What they did

People in the thread describe using Codex directly for ad hoc computer work rather than building full automations first. They had it handle research and scraping, search through files and emails, fill forms, align and edit PowerPoints, do light Excel work, build markdown or wiki knowledge bases, and walk them through chores like Pi-hole upgrades; one commenter says the key is giving detailed instructions, using planning first, and reviewing artifacts step by step.

## How it went

They report large time savings on tedious tasks and say Codex replaced hours of research, planning, and execution for some jobs. The main limits were heavy iteration for unreliable workflows and product or token limits that made experimentation harder.

## Worth knowing

One commenter says enterprise access made token-heavy uses like scraping, formatting, and data entry practical; another says usage limits forced them to pick targets carefully.

## Prompt

```text
I have a chore I'd like you to handle: [chore, e.g. upgrade Pi-hole, edit slides in [file], clean up spreadsheet [file], search my files for [topic]]. Work through it step by step and tell me what you changed. Before deleting, overwriting, or running anything that alters a system, pause and show me the plan.
```
