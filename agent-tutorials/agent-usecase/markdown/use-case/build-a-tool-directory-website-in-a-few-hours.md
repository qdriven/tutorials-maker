# Build a tool directory website in a few hours

> The poster launched a tool directory, toolbrew.co, in a few hours using Replit Agent 3.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** Reddit · Undated

## What they did

The poster used Replit Agent 3 to build toolbrew.co, a simple tools directory with no backend or user system, in a few hours. They fed it colors and branding from screenshots and included most of the tools they wanted in the first prompt; the agent handled most tasks on its own, including testing the tools, while the poster had to work more closely on the YouTube downloader.

## How it went

The site launched quickly and the poster says Agent 3 handled a complex initial prompt much better than the previous version. It fell short on UI and design unless given very specific direction, and the YouTube downloader needed extra back-and-forth.

## Worth knowing

The main catch from the thread is cost: the poster says you still pay for mistakes and lag, and commenters repeatedly call Agent 3 expensive to debug.

## Prompt

```text
Build a directory website for [type of tools, e.g. AI writing tools] with a homepage, category pages, search, and a submission form for new listings. Seed it with [10] example entries that include name, description, link and category. Finish when the site runs with working search and filtering, and show me the preview before you publish anything.
```
