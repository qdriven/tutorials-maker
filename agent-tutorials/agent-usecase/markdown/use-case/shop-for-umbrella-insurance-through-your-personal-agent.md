# Shop for umbrella insurance through your personal agent

> Personal AI agents use Coverage Cat's Agent API/MCP to size umbrella coverage and compare carrier options with price ranges, backed by a licensed broker. · Sep 22, 2026

**Category:** Money, Bills & Benefits  
**Agent:** custom-built or unnamed agent

## What they did

Coverage Cat is a licensed brokerage that publishes an Agent API and MCP endpoint for AI agents. The agent starts from the MCP manifest and calls the umbrella_consumer_prefill tool. AI-guided intake sizes the coverage and returns price ranges and real carrier options. The brokerage team sits behind the flow, and the shopper-facing flow is handed off to Coverage Cat.

## How it went

The page gives no outcome numbers for agent-driven umbrella shopping. It only describes the flow. The service is live in California, Florida, New York, Texas and Washington.

## Worth knowing

An API key is needed (the site has a get-API-key guide), and coverage is limited to five states for now.

## Prompt

```text
Help me figure out how much umbrella insurance I need given [my home value, savings, income, and number of drivers]. Visit [insurance provider or comparison site], get quote ranges for that coverage level from a few carriers, and put them in a comparison table. Stop before submitting any application or entering sensitive personal details, and show me what you plan to enter first.
```
