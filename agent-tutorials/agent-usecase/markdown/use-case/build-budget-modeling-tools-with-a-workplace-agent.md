# Build budget modeling tools with a workplace agent

> C&S Paper uses Tencent's WorkBuddy across marketing, finance and HR to build budget modeling tools, turning a week-long job into real-time feedback. · Oct 23, 2026

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** finance.biggo.com · Oct 23, 2026 · Submitted by from search gap: workbuddy

## What they did

C&S Paper rolled out WorkBuddy in June, and President Gao Bo had it build budget modeling tools. Instead of waiting on Excel models, he can add 2 million yuan to a category and see the simulated result straight away, then keep adjusting. The agent works in an isolated data environment with tiered permissions, not the core databases. Finance staff build Skills that business staff reuse.

## How it went

A budget cycle that managed five or six scenarios in over two months, and a week's wait per change, became real-time feedback. Accounts grew from 500 to nearly 1,300, and several hundred staff can now run basic analysis.

## Worth knowing

Hallucinations remain, so the CDO runs one task to analyze and a separate one to check it, and managers still own the final decision.

## Prompt

```text
Build me a budget modeling spreadsheet for [department or project] using the data in [file or folder]. Include input cells for [key assumptions, e.g. headcount, spend by category], formulas that update totals live, and a summary tab showing variance against [target or last year]. Finish when the file is saved and you've explained each assumption so I can check it. Don't overwrite my original files.
```
