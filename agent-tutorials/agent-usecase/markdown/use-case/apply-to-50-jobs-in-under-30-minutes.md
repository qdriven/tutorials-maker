# Apply to 50 jobs in under 30 minutes

> Claude computer use submitted 50 job applications in under 30 minutes, shown in a video demo.

**Category:** Life Admin & Home  
**Agent:** Claude computer use  
**Source:** X · Mar 24, 2026

## What they did

User enabled Claude computer use on their machine. The agent then handled job search and submission steps across sites to apply to positions.

## How it went

It submitted 50 applications in under 30 minutes.

## Prompt

```text
Help me apply to [number, e.g. 10] [job title] jobs in [location or remote] using my resume at [file path] and the job board [site name]. For each posting, fill in the application using my resume and these details: [phone, work authorization, salary expectations]. Keep a list of each company, role, and link as you go, and stop when you've completed [number] applications. Before you submit any application, pause and show me what you're about to send so I can approve it.
```
