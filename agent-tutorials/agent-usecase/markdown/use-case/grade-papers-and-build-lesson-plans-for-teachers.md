# Grade papers and build lesson plans for teachers

> Author built a proof-of-concept app using ChatGPT prompt templates to grade papers, generate lesson plans, and give feedback.

**Category:** Work & Operations  
**Agent:** ChatGPT  
**Source:** Reddit · Undated

## What they did

The author built a proof-of-concept app called Archimedes, described as a React and Flask app that used ChatGPT across school levels from elementary through doctorate. Its core mechanism was a prompt-engineering command harness that let ChatGPT read files into the prompt, then run templates for grading papers, generating lesson plans, and producing feedback; the human built the app and tested it on several papers.

## How it went

The author says the grading on several of their papers felt accurate and often more informative and critical than feedback they had received from professors. It was still only a proof of concept and was not deployed for others to try.

## Worth knowing

They say development had already cost about $20 in OpenAI API fees, which is why they had not stood the app up for public testing.

## Prompt

```text
Build a simple app that takes a student paper and my rubric [rubric or criteria], then returns a suggested grade and written feedback by criterion. Add a second feature that generates a lesson plan from a [topic] and [grade level]. Use prompt templates I can edit, test with [2-3] sample papers, and show me the results before anything is final.
```
