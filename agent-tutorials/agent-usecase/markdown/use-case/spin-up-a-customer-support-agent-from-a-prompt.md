# Spin up a customer-support agent from a prompt

> The reviewer prompted Lindy to build a support agent, connected Google and Slack, and had it ready to run; only setup was described, no long-run results.

**Category:** Sales, Marketing & Support  
**Agent:** Lindy  
**Source:** unite.ai · Undated

## What they did

On a 7-day free trial, the reviewer picked Lindy's suggested customer support email prompt and sent it unchanged. The prompt told the agent to monitor a support inbox, answer from a knowledge base, and escalate unknown questions by Slack DM. Lindy built the agent in about a minute, showing its steps. The reviewer then connected Google and Slack accounts and could edit each step's prompt or model.

## How it went

The agent was built in about a minute and was ready to test, share and publish. The article reports no actual testing, so there are no results on answer quality or escalations.

## Worth knowing

The review says Lindy is fairly expensive, struggles with complex tasks, and may need human oversight. The setup was only checked on the free trial.

## Prompt

```text
Build me a customer-support agent in Lindy that reads incoming messages at [support email or Slack channel], answers common questions about [product/service] using [help docs or FAQ link], and escalates anything about [refunds, billing, angry customers] to [person]. Have it draft replies for my approval instead of sending them. It is done when it handles three sample questions correctly.
```
