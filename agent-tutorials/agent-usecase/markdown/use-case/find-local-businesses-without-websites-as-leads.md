# Find local businesses without websites as leads

> Hermes spawned sub-agents per area to scrape Northwest London plumbers lacking websites, filtered them, and returned three qualified leads with pitch angles.

**Category:** Sales, Marketing & Support  
**Agent:** Hermes Agent  
**Source:** mindstudio.ai · Undated

## What they did

In a live demo, the prompt asked Hermes to scrape the web for Northwest London plumbers with no website and return three qualified leads for an AI-built website pitch. Hermes spawned a sub-agent for each area to scrape. It then ran a disqualification pass, keeping leads with real addresses, a clear profile and a natural pitch angle.

## How it went

It returned three leads, each with a tailored pitch angle. One example was Oliver Plumbers Limited. It also added legal caveats and a pre-outreach checklist that nobody had asked for.

## Worth knowing

No website found in search doesn't mean none exists, since a business might only have a WhatsApp profile. Verify each lead before outreach. The demo ran on a $0.24/hour CPU instance.

## Prompt

```text
Find [type of local business, e.g. plumbers] in [area] that have no website. Split the area into sub-areas and search each one, then filter out duplicates and businesses that look closed. Return [number] qualified leads with name, phone, source link, and a suggested pitch angle for [my service]. Don't contact anyone; show me the list before any outreach.
```
