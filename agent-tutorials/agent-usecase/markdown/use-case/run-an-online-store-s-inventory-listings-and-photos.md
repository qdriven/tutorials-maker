# Run an online store's inventory, listings and photos

> An agent takes a weekly inventory spreadsheet, updates prices and stock, writes original listings, redraws photos as studio shots, and holds uncertain items for approval.

**Category:** Shopping & Errands  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 7, 2026

## What they did

The agent receives the weekly inventory spreadsheet emailed to a dedicated address. It updates every price and stock count on the store, removes any product absent from the sheet, researches each new item's maker page to generate an original listing with description, search title, photo text and crossed-out original price, redraws messy photos as clean studio shots, and holds uncertain changes for human approval.

## How it went

The owner now sends only one email per week; the agent runs the rest of the online store.

## Prompt

```text
Each week when I add a new inventory spreadsheet at [Google Sheet or file location], update prices and stock for my store on [Shopify, Etsy, or other platform]. Write original listing descriptions in [tone] for new items and flag any item where the data is unclear. Hold the flagged items and send me a summary at [email] for approval before publishing anything. Finish when all clear items are updated and the flagged list is delivered.
```
