# Build a dramatic digital envelope app for asking friends for money

> Used Replit Agent and Design Mode to build an app with decoy messages, drum rolls and live status tracking for a buildathon.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** X · Aug 8, 2026

## What they did

User prompted Replit Agent in Design Mode to create an interactive digital envelope app. The agent generated the app with decoy messages, drum rolls, and live status tracking for requesting money or items dramatically. The person submitted the result to the ReplitBuildathon.

## How it went

App was completed and submitted. Source states no further results or metrics.

## Prompt

```text
Build me a playful web app for asking [friends/group] to chip in [amount] for [occasion], styled as a dramatic digital envelope with decoy messages, a drum roll before the reveal, and a live status tracker showing who has opened or responded. Use a [theme/style] look and make it work well on phones. Finish with a running preview and a shareable link, and tell me what to test first.
```
