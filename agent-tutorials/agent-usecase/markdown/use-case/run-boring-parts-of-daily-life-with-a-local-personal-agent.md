## What they did

The author runs a personal agent called Hermes on their own machine. It uses a mix of local models and whichever hosted model is cheap enough, usually DeepSeek. They have used it for a couple of months. The comment names no specific tasks or steps, only that it takes over routine parts of daily life.

The author says they are converted and has more time for family, and that it grows more useful as you learn what to hand it. No numbers or concrete results are given.

## Worth knowing
