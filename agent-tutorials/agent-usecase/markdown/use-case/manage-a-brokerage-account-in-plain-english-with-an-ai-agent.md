# Manage a brokerage account in plain English with an AI agent

> Coinbase's SEC-registered AI agent uses full portfolio context and account history to take account actions from plain English and suggest investment ideas.

**Category:** Money, Bills & Benefits  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jun 16, 2026

## What they did

The SEC-registered AI agent receives complete user portfolio and account history context. Users issue plain-English commands for it to take actions on the account, and the agent generates investment suggestions the user had not considered. It is rolling out to Coinbase One members.

## How it went

Enables real-time portfolio analysis and automated tax loss harvesting via chat. No usage numbers or results are stated.

## Prompt

```text
Using the portfolio details I give you here: [holdings, account types, goals, risk tolerance], review my allocation and recent activity and explain it in plain English. Suggest three investment ideas that fit my goals, each with the reasoning and the main risks. Stop when you've given me the summary and ideas, and do not place any orders or log into any account.
```
