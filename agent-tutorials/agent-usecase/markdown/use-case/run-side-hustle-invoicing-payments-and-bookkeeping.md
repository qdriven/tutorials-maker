# Run side hustle invoicing, payments and bookkeeping

> A side hustler connected their bank to Claude via MCP and QuickBooks so an agent handles invoicing, contractor payments, expense tracking and bookkeeping.

**Category:** Work & Operations  
**Agent:** Claude  
**Source:** Reddit · Undated

## What they did

They connected a Meow bank account and QuickBooks to Claude through MCP for a side-business SaaS doing about $10k MRR. The agent drafts invoices, queues contractor payments, tracks expenses, and runs reconciliation and bookkeeping in QuickBooks; the owner set client details, rates, and categorization rules in the prompt and approves anything before money moves.

## How it went

They say finance admin dropped from 5-6 hours a week to about 20 minutes, freeing time for product work and customer conversations. The main limit is that it is not fully autonomous: payments and outgoing invoices still rely on their approval and prompt setup.

## Worth knowing

Their stated extra cost was just an existing Claude subscription, and they said this replaced separate invoicing and bookkeeping tools so it cost less than their old setup.

## Prompt

```text
Help me run the books for my side business [business name]. Using my [QuickBooks/bank export] data, review this month's transactions, categorize expenses, list unpaid invoices, and draft invoices for [clients]. When you have a clean monthly summary, stop. Pause and show me anything before sending an invoice or making a payment.
```
