# Make music videos, portfolio sites and sorting scripts

> A creator used Grok Bot for a full music video, a prompt engine, portfolio site code, scripts to sort 158 AI images and videos, and a career page.

**Category:** Content & Creative  
**Agent:** Grok Bot  
**Source:** X · Oct 8, 2026

## What they did

Over one week the creator gave Grok Bot successive tasks: generate a complete music video from song through final edited clip; research Grok Imagine limits then output a reusable cinematic prompt engine; write full portfolio site code in HTML/CSS/JS with filters, mobile layout and live preview; write scripts that pulled 158 AI images/videos from X posts and auto-sorted them; plus code to cut/trim/stitch video clips and convert a theatre résumé into a career page. The user directed the work and maintained separate agents for film, prompts and chief-of-staff roles.

## How it went

All requested outputs were delivered and replaced the studio, developer and assistant previously needed. No shortfalls are stated.

## Prompt

```text
I have [number] AI-generated images and videos in [folder or location]. Write and run a script that sorts them into folders by [criteria such as theme, date, or style] and renames them consistently. Show me a preview of the planned moves before changing any files, and finish with a report of what ended up in each folder.
```
