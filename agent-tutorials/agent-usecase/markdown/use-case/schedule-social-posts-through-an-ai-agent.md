## What they did

In the Reddit thread, one commenter says their setup uses Obsei to ingest social content and getlate.dev to post it across social networks, excluding Reddit. They add that Socialclaw can connect that posting stack to Claude or another AI agent so the agent can schedule posts, but the thread does not spell out the workflow beyond those tool links.
