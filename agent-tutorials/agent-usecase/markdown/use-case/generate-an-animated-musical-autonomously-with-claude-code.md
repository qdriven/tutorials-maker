# Generate an animated musical autonomously with Claude Code

> The author runs Claude Code with permissions skipped to autonomously generate and keep improving a fully programmatic animated musical, 500,000+ lines of code, rendering around the clock.

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** HN · Oct 21, 2026

## What they did

The author runs Claude Code with the dangerously-skip-permissions flag, a day-one habit, so it has full access to their computer. A fully programmatic animated musical, over 500,000 lines of code, is rendered and improved on their machine around the clock, run almost completely autonomously. The source gives no further detail on prompts or workflow.

## How it went

The author reports no security issues so far and calls the convenience insane, but expects to be compromised eventually. The source gives no quality, cost, or completion details for the musical.

## Worth knowing

Skipping permissions hands the agent full desktop access, and the author admits a compromised tool would expose the whole computer.

## Prompt

```text
In a new folder, build a fully programmatic animated short musical about [premise], with the music, characters, and animation all generated by code and rendered to a video file. Start with a working first version of [one song and one scene], then keep improving it in rounds, such as better visuals, more songs, and cleaner code, committing to git after each round. Stop after [number] rounds or when I say so, and give me a summary of what changed and how to render the latest cut.
```
