# Build and promote games from GitHub and X

> A user gave Grok Bot a GitHub account with 20+ repos and X accounts to create and update games and promote the sites with posts.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** Reddit · Oct 24, 2026

## What they did

The commenter said they gave Grok Bot access to a dedicated GitHub account with 20-plus repositories and several X/Twitter accounts, then relied on its standing instructions. With that access, it handled creating new games, updating existing ones, and posting frequent X promotions for the related sites; the person’s role was mainly setting the instructions and letting it run.

## How it went

They said it was doing pretty well for small pet projects and that they no longer had to do those tasks themselves. The only concrete limitation mentioned was scope: they framed the success as being for small side projects.

## Worth knowing

A practical catch they mentioned is credential persistence: Grok Bot remembered the logins, and they said they had not needed to reauthorize it for a while.

## Prompt

```text
I've given you access to my GitHub account [username] and my X account [handle]. Build a small browser game of [type, e.g. puzzle or arcade] in a new repo called [repo name], deploy it to [hosting, e.g. GitHub Pages], and write three promotional posts for X. Done means the game works at a live URL and the posts are drafted. Before you publish any post or make changes to any existing repo, pause and show me what you're about to do.
```
