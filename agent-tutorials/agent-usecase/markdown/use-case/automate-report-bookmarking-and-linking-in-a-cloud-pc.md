# Automate report bookmarking and linking in a cloud PC

> A commenter gave an agent control of their Microsoft 365 cloud PC to do bookmarking and linking in a report while they took a break.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Feb 1, 2025

## What they did

A commenter said they used agent mode for the tedious Word work of adding bookmarks and linking parts of a report together, rather than doing that formatting by hand. The person’s role was just to hand the task over; they describe taking a break while the AI worked on making the report nicer.

## How it went

The reported outcome was simply that it handled the boring report cleanup for them. The source gives no numbers, no prompt, and no detail on errors or review steps.

## Worth knowing

The main catch is how little detail the commenter shared: no timing beyond it being "break time," and no setup instructions for reproducing it.

## Prompt

```text
In my [Microsoft 365 cloud PC or remote desktop], open the report [document name] and do the following: add bookmarks at each [e.g. section heading], then add links in [location, e.g. the summary table] pointing to the matching bookmarks. Work through the whole document and tell me when finished, listing every bookmark and link you created. Pause and ask me if anything looks ambiguous rather than guessing.
```
