# Automate teacher report marking, assessment dashboards and curriculum planning

> A primary teacher used Claude to build an app that marks reports, a dashboard for assessment data, and a skill that aligns planning ideas to the curriculum.

**Category:** Work & Operations  
**Agent:** Claude  
**Source:** Reddit · Sep 24, 2026

## What they did

A primary teacher said they used Claude to write a Google Apps Script app for marking reports, built a dashboard to track assessment data, and made a skill that maps planning ideas to the curriculum and the school’s instructional model. The thread gives no step-by-step build details beyond that brief edit, and the comments mainly advise refining custom skills yourself and checking outputs carefully.

## How it went

The stated result was three working teacher tools: report marking, assessment-data dashboards, and curriculum-aligned planning support. No time saved, accuracy figures, or limitations of those specific tools were given in the post.

## Worth knowing

The clearest catch from the thread is to avoid giving Claude identifiable student information and to double- or triple-check anything you use.

## Prompt

```text
I teach [year group/subject] and want a simple tool to help with end-of-year reports. Build me a small app where I paste in [assessment notes or marks] for each student and it drafts a report in my school's tone using this template: [paste template or example report]. Also add a dashboard view that summarizes [assessment data, e.g. reading levels] by student and class. Finish with a working app and brief instructions, and flag any place where I should check the wording before sending anything to parents.
```
