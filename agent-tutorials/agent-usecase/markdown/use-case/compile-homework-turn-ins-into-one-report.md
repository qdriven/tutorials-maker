# Compile homework turn-ins into one report

> A teacher built a no-code AI agent that checks Google Classroom, email, and paper submissions for homework turn-ins and produces a unified report.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Sep 10, 2024

## What they did

A poster described a teacher who used no-code automations to stop manually checking Google Classroom, email, and paper submissions for homework. Using Office 365 tools plus platforms named as Power Automate, BhindiAI, Zapier, and Make, the setup scanned those sources and produced one unified turn-in report; the human role described was choosing and wiring the no-code workflow.

## How it went

The stated result was that a task that used to take 45 minutes was reduced to seconds. The post gives no build steps, accuracy data, or details on how paper submissions were digitized, and a commenter raised FERPA compliance concerns.

## Worth knowing

The source’s clearest catch is compliance: a commenter warned that if this was in the USA, FERPA could be a serious issue.

## Prompt

```text
Build me an assistant that, every [day and time], checks [Google Classroom class name], my email folder [folder or label], and a spreadsheet where I log paper turn-ins, for homework named [assignment name]. It should produce one report listing each student in [class roster] as turned in, late, or missing, and email it to me. Do not send anything to students or parents; show me the report first and ask before any message goes out.
```
