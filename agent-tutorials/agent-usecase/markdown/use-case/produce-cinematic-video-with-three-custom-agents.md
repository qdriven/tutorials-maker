# Produce cinematic video with three custom agents

> The poster built a cinematic studio in Grok Imagine using three custom agents for prompt direction, audio scripting and character-consistent video.

**Category:** Content & Creative  
**Agent:** Grok Bot  
**Source:** Reddit · May 11, 2026

## What they did

The poster set up three Grok Imagine custom agents: an Imagine Prompt Master for final prompt writing, a Studio Director that owned the main spec, and a Mega Production Architect that combined character/world design, storyboarding, and timed audio scripting. The workflow was to define reusable character variables, generate a reference image first, turn it into video, then extend it clip by clip while the Studio Director refreshed a single “Production Bible” from chat history.

## How it went

The claimed result was a “professional-grade cinematic studio” with character consistency, storyboarded video, and synced audio inside Grok. In comments, the poster said character consistency stayed about 95%+ and that Grok’s practical video maximum was 30 seconds via 5x6s or 3x10s clips.

## Worth knowing

Setup was described as taking about 5 minutes, but the poster says the key is the master studio prompt and the current reliable workflow tops out around 24–30 seconds.

## Prompt

```text
Act as a three-part production team for a cinematic short about [story idea]. First, write the visual prompts shot by shot. Second, write the audio script with narration, sound design, and music cues. Third, write a character sheet with fixed details for [character names], so they look the same in every shot. Give me all three as a numbered shot list for [number] shots.
```
