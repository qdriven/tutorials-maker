# Turn Gmail action items into an AI to-do list

> A Chrome extension scans a messy Gmail inbox, calendar invites and follow-ups and turns the action items into a to-do list.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Undated

## What they did

The poster built a Chrome extension that reads Gmail and uses AI to turn emails into a clean, prioritized to-do list, aimed at buried action items in threads, invites, and follow-ups. The setup is deliberately low-friction: install it and it works, with no signup, no manual copying, and no way for the maker to contact users because there are no logins.

## How it went

After 18 days, the extension had 47 organic users and later the maker mentioned a first sale of $2. The main shortfall they call out is not knowing whether it is truly solving the problem or what users want next.

## Worth knowing

The biggest catch is the no-login design: it reduced friction, but also left the maker without user contact or feedback channels.

## Prompt

```text
Open my Gmail inbox and scan the last [7] days of emails, calendar invites, and follow-ups. Make a to-do list of action items, each with the sender, the deadline if there is one, and a priority of high, medium or low. Finish when every unread or flagged thread is covered, and don't reply to, archive or delete anything.
```
