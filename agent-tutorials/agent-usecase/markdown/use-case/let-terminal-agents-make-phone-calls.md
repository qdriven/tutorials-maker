# Let terminal agents make phone calls

> A CLI tool built on Twilio gives terminal agents a voice to make calls, with a dashboard for questions they can't answer.

**Category:** Software & DevOps  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 30, 2026

## What they did

The author built a CLI tool using Twilio and GPT-live that gives terminal agents a voice for outbound calls. The agent operates independently on the line until it receives a question it cannot answer, at which point the included dashboard HUD prompts the person for an answer and redirects it back into the call without disconnecting.

## How it went

The result is a functional calling experience shown in a live QA and coding walkthrough video, with the agent handling calls and escalating unknowns to the person.

## Prompt

```text
In my project at [folder path], build a small command-line tool using Twilio that lets a terminal agent place a phone call, say a scripted purpose like [reason for call], and record the conversation outcome. Add a simple local dashboard where I can see and answer questions the agent couldn't handle. Include a dry-run mode that prints the call instead of placing it, and test with that before any real call.
```
