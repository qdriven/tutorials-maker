# Build a tenant management portal for landlords

> A commenter built a landlord tenant-management portal with Replit in five days and had 31 trial users, with revenue still unknown.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** Reddit · Undated

## What they did

A commenter said they built TenantPulse, a tenant management portal for landlords, in Replit in five days. In a follow-up, they described using a detailed initial prompt, often refined in ChatGPT, to set up most of the framework, then repeatedly deploying and running pre-production and production health-check prompt protocols while they manually verified forms, steps, and database connections.

## How it went

At the time of the thread, the app was live with 31 users on a one-month free trial. Revenue was still unknown because they said they would find out at the end of the month.

## Worth knowing

Their main catch was process: deploy frequently and run a final-check/health-check prompt protocol before pushing live changes.

## Prompt

```text
Build a tenant management portal for a landlord with [number] properties. It should let tenants submit maintenance requests and see their rent status, and let me view all requests and mark them resolved. Finish when I can log in as both a landlord and a tenant and complete a request from start to finish using sample data. Ask me before sending any real emails or connecting payments.
```
