# Watch a ticket site and report available times

> Mika Reyes set a Grok Bot routine to keep checking a Dancing with the Stars ticket website and come back with times.

**Category:** Travel & Bookings  
**Agent:** Grok Bot  
**Source:** mikareyes.com · Undated

## What they did

Mika Reyes used Grok Bot, whose agents each get a cloud computer with a browser, and pointed one at a Dancing with the Stars ticket website. The bot can keep opening the site and report back with times. She suggests making this kind of repeating check, on a site you already refresh, your first routine. Routines can be written by hand or set by asking the agent.

## How it went

The source gives no results or ticket times from the check. It presents the ticket watch as an example of a job suited to the bot, not as a measured outcome.

## Worth knowing

Grok Bot is in early beta. Access is a card-required one-week trial with limited usage, Cursor Ultra at $200 a month, or SuperGrok Heavy, and a long agent run can use up the trial in one sitting.

## Prompt

```text
Check [ticket website URL] every [interval] for [show or event] tickets, and tell me as soon as new dates or times appear, with the times, prices and a link. Don't buy anything or submit any forms. Keep watching until [end date] or until I tell you to stop.
```
