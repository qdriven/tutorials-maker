# Rank CRM prospects and draft outreach with Codex

> A demo has Codex pull CRM data, rank top accounts, and build a 13-slide deck with per-account strategy and draft outreach emails.

**Category:** Sales, Marketing & Support  
**Agent:** Codex  
**Source:** startuphub.ai · Undated

## What they did

Using Codex's Sales plugin, the demo connected to a demo Salesforce instance, pulled data, and ranked the top 10 prospect accounts with plain-English reasons and color-coded priority. Codex then built a 13-slide PowerPoint with per-account strategy and draft emails, and saved drafts in Gmail. A daily 8:03 AM automation adds the next cadence draft and refreshes the plan if Salesforce changes.

## How it went

The demo produced a ranked list, a 13-slide plan paired with draft emails, and a morning automation. The source gives no measured results and describes only a demo instance.

## Worth knowing

The automation keeps emails as drafts only and never sends them, so a person still reviews and sends each one.

## Prompt

```text
Pull accounts from [CRM export or connected CRM] and rank the top [10] by [criteria like deal size, recent activity, and fit]. Build a slide deck with one slide per account covering a suggested strategy, plus a draft outreach email for each. Save drafts only and do not send any emails; show me the deck when finished.
```
