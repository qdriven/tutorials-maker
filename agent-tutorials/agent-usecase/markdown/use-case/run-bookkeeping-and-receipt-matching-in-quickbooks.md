# Run bookkeeping and receipt matching in QuickBooks

> A user wired AI into QuickBooks, SharePoint and email to attach receipts, forward invoices for checks, add vendors and request W-9s, replacing paid bookkeeping.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 2, 2026

## What they did

The user connected an AI agent to QuickBooks, SharePoint, and email. It attaches receipts sent by email to the matching line item in QB, forwards invoices into the checks-to-print queue, adds new vendors, and sends W-9 requests. It also pulls and formats invoices and receipts for audit responses on demand.

## How it went

Bookkeeping and ongoing accountant work were replaced; the user states the bot performed better than the prior accountant at these tasks. Payroll and yearly taxes still require a human accountant.

## Worth knowing

No specific setup time or cost details given.

## Prompt

```text
Build a workflow connecting [QuickBooks], [SharePoint/Drive folder] and my email so that when a receipt or invoice arrives it is matched to the right transaction and attached. For new vendors it should add them and draft a W-9 request. Pause for my approval before forwarding invoices, sending any email or changing any QuickBooks records, and finish with a test run on [number] sample documents.
```
