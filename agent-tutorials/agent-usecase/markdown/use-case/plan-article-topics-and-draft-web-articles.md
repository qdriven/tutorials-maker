# Plan article topics and draft web articles

> A web writer uses Cowork for keyword selection, building a topic table that checks overlap with past articles, and drafting articles that learn from corrections.

**Category:** Content & Creative  
**Agent:** Claude Cowork  
**Source:** note.com · Undated

## What they did

On a Windows PC, the writer points Cowork at a folder of past articles. It reads them and saves a topic table that flags overlap with earlier pieces and suggests how to differentiate. Rakko Keywords is linked in for search volume and difficulty. Cowork drafts in the writer's stated style rules and reuses past corrections. The writer picks the keywords and rewrites the drafts.

## How it went

The writer now produces 40 to 50 pieces a month, commissioned articles and notes combined, and no longer copy-pastes between chat and files. Drafts still need manual fact-checking and rewriting of the experiential parts.

## Worth knowing

Share only the folders the task needs, and check client contracts before letting the AI read client materials. Claude Pro costs about 3,480 yen a month.

## Prompt

```text
I write web articles about [topic area]. Using my past articles in [folder or list of URLs], build a table of [15] new topic ideas with a target keyword, search intent, and a note on any overlap with what I've already published. Once I pick a topic, draft the article in my style, and keep a notes file of corrections I make so future drafts improve. Stop after the topic table and wait for my pick.
```
