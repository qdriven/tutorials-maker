# Automate legal drafting and workflows with Claude Code

> A commenter used Claude Code to build integrations and run agents on legal workflows, with Claude for Word for drafting plus playbooks and precedent libraries.

**Category:** Work & Operations  
**Agent:** Claude Code, Claude  
**Source:** Reddit · May 14, 2026

## What they did

A transactional lawyer said they skipped legaltech wrappers and used Claude directly: Claude Code built the integrations, ran agents on the lawyer’s own workflows, and Claude for Word beta handled drafting inside documents. The lawyer then added playbooks, precedent libraries, and drafting standards tuned to their own practice rather than a vendor’s setup.

## How it went

The commenter said this delivered a setup tailored to how they practice transactional law for a fraction of a per-seat license. The post gives no performance metrics or implementation details beyond that claim.

## Worth knowing

The main catch is that the source offers no build steps or governance details, only that it was done with an enterprise Claude or Codex subscription.
