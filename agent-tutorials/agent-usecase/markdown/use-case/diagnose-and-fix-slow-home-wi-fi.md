# Diagnose and fix slow home Wi-Fi

> A user had Claude Code run speed tests, read signal data and guide router changes, finding three issues and raising speed from about 90 to 292 Mbps. · Oct 24, 2026

**Category:** Life Admin & Home  
**Agent:** Claude Code  
**Source:** tech.yahoo.com · Oct 24, 2026 · Submitted by from search gap: wifi

## What they did

A LinkedIn user gave Claude Code a single prompt asking it to help increase his Wi-Fi speed. According to his post, Claude ran speed tests, read signal data from his Mac and walked him through the router's settings. He typed in the router password himself.

## How it went

Claude found three problems: a crowded channel shared with a stronger neighboring network, WMM disabled, and the laptop on a slower band. Speed rose from about 90 to 292 Mbps on a 300 Mbps plan.

## Worth knowing

This is one person's self-reported result, not a general guarantee. Router hardware, interference, device capability, distance and the ISP connection all affect real speeds.

## Prompt

```text
My home Wi-Fi feels slow. My router is a [router model] and my internet plan is [advertised speed] Mbps. Run a speed test from this computer, check what you can about signal strength, channel congestion and which band I'm connected to, and give me a ranked list of likely problems. Walk me through each fix one step at a time, retest after each, and finish with a before-and-after speed comparison. Before telling me to change any router setting that could disconnect devices, pause and explain what it will do.
```
