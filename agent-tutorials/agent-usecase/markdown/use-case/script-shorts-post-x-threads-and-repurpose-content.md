# Script Shorts, post X threads and repurpose content

> An agent scripts YouTube Shorts, posts X threads and repurposes content so the creator avoids touching a content calendar.

**Category:** Content & Creative  
**Agent:** custom-built or unnamed agent  
**Source:** X · Aug 14, 2026

## What they did

Built one agent on CreaoAI via a prompt that takes one long-form idea and generates YouTube Shorts scripts, X threads, and LinkedIn posts automatically. The agent scripts the Shorts, posts the threads, and handles all repurposing. The creator supplies the initial idea but no longer maintains a calendar.

## How it went

Creator reports no need to touch a content calendar for three weeks.

## Prompt

```text
I create content about [topic] for [audience]. Take this source material [link or pasted text] and turn it into a 45-second YouTube Shorts script, a thread of [number] posts for X, and [number] other repurposed pieces. Put everything in one document with a suggested posting order for the next [number] days. Show me everything before posting anything.
```
