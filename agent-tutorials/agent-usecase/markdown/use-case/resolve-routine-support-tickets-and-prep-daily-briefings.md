# Resolve routine support tickets and prep daily briefings

> Lindy agents handle routine support tickets and, for one founder, prepare daily briefings and manage calendar conflicts, per a vendor-published case study.

**Category:** Work & Operations  
**Agent:** Lindy  
**Source:** anthropic.com · Undated

## What they did

A bootstrapped productivity tool uses a Lindy agent, running on Claude as its default model, to give 24/7 first-line support. The agent resolves routine tickets, and the human team keeps product feedback, customer success and sensitive cases. Separately, one executive founder uses a Lindy agent to prepare daily briefings and manage calendar conflicts.

## How it went

The support agent resolves over 70% of routine tickets. The founder says it feels like delegating to a real team member. The source gives no figures for the briefing and calendar work.

## Prompt

```text
Create a Lindy agent that reads new tickets in [helpdesk or inbox], resolves routine ones like [password resets, order status] using [help docs], and flags the rest for me. Also have it send me a daily briefing at [time] with my meetings, open issues and any calendar conflicts. Have it show me replies and calendar changes for approval before sending or moving anything.
```
