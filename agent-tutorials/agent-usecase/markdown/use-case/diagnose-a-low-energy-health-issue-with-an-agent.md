# Diagnose a low-energy health issue with an agent

> Noah built an agent that suggested which blood work to get and which doctors to see, and says it found the solution four doctors missed.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 2, 2026

## What they did

Noah gave his agent a description of his low-energy symptoms. The agent listed specific blood-work panels to order and named doctors to consult. Noah then scheduled the tests and appointments on his own; the agent continued to flag the first four doctors as lazy when they dismissed the results.

## How it went

The fifth doctor confirmed the exact diagnosis and treatment the agent had identified first. Four prior doctors had said nothing was wrong.

## Prompt

```text
I've had [symptoms, e.g. low energy, fatigue] for [duration]. Here are my history, current medications and past test results: [paste details]. Research likely causes, then give me a ranked list of blood tests to ask for, which kinds of specialists to see, and questions to bring to each appointment, with sources for each suggestion. Finish with a one-page summary I can bring to my doctor. This is for discussion with a clinician, not a diagnosis, and don't book any appointments without showing me first.
```
