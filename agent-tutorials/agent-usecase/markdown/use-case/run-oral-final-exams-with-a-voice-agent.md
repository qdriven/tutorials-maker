# Run oral final exams with a voice agent

> A professor used a voice agent to examine 36 students over 9 days, with an LLM council grading transcripts and surfacing class-wide gaps.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jan 2, 2026

## What they did

Professor ran oral exams on student projects via voice agent, with LLM council grading transcripts after deliberation. It examined 36 students over 9 days at ~25 min each, producing full transcripts and audit trails.

## How it went

Total cost $15 (~$0.42/student). Exposed class-wide A/B testing gap; 13% of students preferred the AI oral format.

## Prompt

```text
Help me set up oral exams for [course name] with [number] students. Write a voice-interview script that asks [number] questions on [topics], follows up on vague answers, and records a transcript for each student. Then grade each transcript against this rubric: [rubric] and summarize which concepts the whole class struggled with. Show me the grading for review before anything is shared with students.
```
