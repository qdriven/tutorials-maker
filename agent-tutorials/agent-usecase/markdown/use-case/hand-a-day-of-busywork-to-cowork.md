# Hand a day of busywork to Cowork

> The author gave Cowork a day of busywork, including pulling numbers from three sources into a report that needed light editing and a scheduled weekly metrics report; screen-driving was slower and needed nudges.

**Category:** Work & Operations  
**Agent:** Claude Cowork  
**Source:** dev.to · Undated

## What they did

The author, an architect, described outcomes to Cowork in the Claude desktop app and approved its plan before it ran. Tasks were sorting a 200-plus-file folder (he changed one rule to keep originals), filling a weekly report template from source files, and turning messy notes and links into a structured draft.

## How it went

The folder came back tidy with a duplicates note. The report draft needed only light editing, and the notes became a structured draft with the synthesis done. Driving apps by screen was slower and sometimes needed nudges.

## Worth knowing

Cowork uses up usage limits much faster than Chat, so a few heavy tasks on Pro means rationing. The author suggests Max for serious use.

## Prompt

```text
Pull the latest numbers from [source 1], [source 2], and [source 3] into one report in [format, e.g. a spreadsheet or doc] saved at [location]. Then set up a recurring task that rebuilds it every [day, e.g. Monday morning]. Show me the first draft and ask before sending it to anyone or scheduling anything.
```
