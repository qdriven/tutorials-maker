# Index a newsletter archive and repurpose writing

> Per the guide, Casey Newton used Claude Code to index 818 newsletter editions in under 30 minutes, and writers audit note vaults and turn essays into newsletter and thread files.

**Category:** Content & Creative  
**Agent:** Claude Code  
**Source:** ccforeveryone.com · Undated

## What they did

The guide says Casey Newton of Platformer indexed 818 newsletter editions into a searchable archive. Darren Rowse audited about 1,000 notes in an Obsidian vault, which Claude Code reads as plain markdown folders. For repurposing, one instruction produces newsletter, thread and summary files that follow voice rules in CLAUDE.md. The writer reviews each edit as a diff.

## How it went

Newton's index took under 30 minutes. Rowse says his vault became part of how he creates. Dheeraj Sharma went from 4–5 to 8 articles a month, though the guide calls that one writer's case study.

## Worth knowing

Start vault cleanup bounded: ask for an inventory and proposed structure first, then approve moves folder by folder. Broad cleanup requests reportedly produced invented tags and chaos.

## Prompt

```text
Index all the writing in [folder path of newsletter archive or notes vault] so you can answer questions about it. Then give me a short audit of recurring themes and any gaps, and turn [essay filename] into a newsletter draft file and a thread draft file in [output folder]. Don't edit or delete any of my original files; stop when the two drafts and the audit are saved.
```
