# Keep affiliate links and captions ready for influencers

> A consultant built a Grok Bot Affiliate Bot that stores affiliate links, captions, hashtags and disclaimers for influencers to request when posting.

**Category:** Sales, Marketing & Support  
**Agent:** Grok Bot  
**Source:** brandauthentic.substack.com · Undated

## What they did

Liza Dora built Affiliate Bot in Grok Bot for influencer clients. The influencer enters their affiliate links, captions, hashtags and disclaimer text once, or screenshots them. When posting a story, they ask the bot for a product, such as a pair of shoes from Amazon. They then copy the link and text from the chat into the story. A Claude version needs a skill created, and the prompt is included.

## How it went

The source reports no metrics. It presents the bot as cutting the clicks and scrolling needed to find links in Notes, Amazon or LTK, so stories with affiliate links post faster.

## Worth knowing

The Claude version isn't ready-made. You have to create the skill yourself from the included prompt, and the full bot is sold through Gumroad.

## Prompt

```text
Act as an Affiliate Bot for my influencers. Store these affiliate links, captions, hashtags, and required disclaimers: [paste details per product]. When an influencer asks for [product], reply with the right link, a caption, hashtags, and the disclaimer. You're done when each product has a ready-to-use post kit; ask me before sending anything to an influencer for the first time.
```
