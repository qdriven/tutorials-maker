# Build interactive web games from prompts

> Per an influencer's tests, Manus built a role-play web game as Google's CEO in about an hour and a match-three puzzle game with tech logos.

**Category:** Games & Simulations  
**Agent:** Manus  
**Source:** recodechinaai.substack.com · Undated

## What they did

The author had no invitation code, so he relied on tests by the Chinese tech influencer Lanxi. Manus runs each agent in a virtual machine, where it plans steps, writes and runs code, and browses the web. It built a role-play web game as Google's CEO, and a match-three puzzle game using tech company logos.

## How it went

The Google CEO game took about an hour. The puzzle game first hit download restrictions on third-party sites. Once the requirements were changed, Manus finished it on its own. Manus still struggles with complex tasks, and server outages sometimes interrupted work.

## Worth knowing

Tasks often take over 30 minutes and sometimes hours. Screen adaptability issues mean you need clear instructions. The source estimates about $2 per task, and access was invite-only at the time.

## Prompt

```text
Build me a playable web game in one HTML page: [game idea, e.g. a role-play where I play as the CEO of a company making big decisions, or a match-three puzzle using [theme] icons]. Include a start screen, scoring or win and lose conditions, and simple visuals. Finish by giving me a live link I can open and play, and tell me how to change the theme.
```
