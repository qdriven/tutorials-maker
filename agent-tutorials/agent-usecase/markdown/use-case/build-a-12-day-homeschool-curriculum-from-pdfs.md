# Build a 12-day homeschool curriculum from PDFs

> Cowork read 12 PDFs of worksheets and reading material, organized them by subject and built a 12-day curriculum to the requested schedule.

**Category:** Life Admin & Home  
**Agent:** Claude Cowork  
**Source:** michaelcrist.substack.com · Undated

## What they did

Michael Crist took the 12 PDFs his wife normally sorts by hand each month (supplementary materials, worksheets and reading content, some about 100 pages) and uploaded them to Claude Cowork. He described the daily schedule: which subjects go on which days, how long each block runs, and what order the material flows in. Cowork read the PDFs, sorted them by subject and built the plan.

## How it went

The 12-day curriculum came out color-coded and ordered, with checkboxes, discussion prompts and popcorn reading. He says it took about 40 minutes, against roughly 20 hours of weekend work for his wife.

## Worth knowing

The source gives no prompt for this one and doesn't say whether the plan needed corrections. For complex jobs, the author suggests adding a request to show the plan before it starts.

## Prompt

```text
Read the PDFs of worksheets and readings in [folder path] and organize them by subject. Build a [number]-day curriculum for a [grade level] student with [hours] hours of study per day. Save it as a document with a daily schedule listing which file to use each day. Stop when every file is assigned and flag any that don't fit.
```
