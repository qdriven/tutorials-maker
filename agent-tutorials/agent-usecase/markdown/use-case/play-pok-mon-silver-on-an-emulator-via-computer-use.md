# Play Pokémon Silver on an emulator via Computer Use

> A user had ChatGPT with Computer Use control a Pokémon Silver emulator, picking a starter and starting a playthrough, though usage limits were consumed by setup and repetitive dialogue.

**Category:** Games & Simulations  
**Agent:** ChatGPT Agent  
**Source:** community.openai.com · Undated

## What they did

The user ran Pokémon Silver in an emulator and let ChatGPT, which they call Lyric, control it through Computer Use. They played alongside it instead of having it only give advice. The agent chose Totodile as its starter and named it Riptide. They then began setting up a playthrough the user could stream through OBS.

## How it went

It worked well enough to start the game and pick a starter. Setup, navigation, repetitive dialogue and simple movement used up a lot of the Computer Use allowance before real play began.

## Worth knowing

Plus-plan Computer Use limits drain quickly on repetitive game inputs, and the post says it doesn't show how much allowance is left or when it resets.

## Prompt

```text
Open the emulator on my desktop with [game name and ROM already loaded], pick [starter or character choice], and play for about [number] minutes, advancing dialogue and exploring. Keep a short log of progress and stop at [milestone] or when you reach the time limit. Don't download anything or change system settings without asking me first.
```
