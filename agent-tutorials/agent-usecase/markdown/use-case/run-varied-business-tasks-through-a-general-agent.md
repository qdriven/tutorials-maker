# Run varied business tasks through a general agent

> Reviewers gave Manus 15 tasks including competitor analysis, itinerary, content calendar and PDF summary; most succeeded, some partial, one API integration failed.

**Category:** Work & Operations  
**Agent:** Manus  
**Source:** justpickai.com · Undated

## What they did

The reviewers gave Manus, a cloud-based agent that browses the web, writes and runs code, and manages files, 15 real tasks. They included a competitor spreadsheet, a travel itinerary with booking links, CSV analysis with charts, a landing page, a content calendar and a 50-page PDF summary. They timed each run and scored the quality.

## How it went

The article's table lists 10 tasks, and its stated split is 70% full success, 20% partial, 10% failure. The API integration failed after 25 minutes (3/10). Price comparison and Python debugging were partial.

## Worth knowing

Tasks took 4 to 25 minutes each, and the reviewers advise keeping sensitive or proprietary data out because Manus processes it on servers primarily in China.

## Prompt

```text
I'm going to give you a batch of tasks: [list tasks, e.g. competitor analysis for X, a 3-day itinerary for Y, a 4-week content calendar for Z, a summary of the attached PDF]. Complete each one separately and deliver a finished output for each. At the end, give me a short status list marking each task as done, partial, or failed, with a reason for anything not fully completed.
```
