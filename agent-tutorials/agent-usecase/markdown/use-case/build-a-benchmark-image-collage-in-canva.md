# Build a benchmark image collage in Canva

> The author had ChatGPT Agent log into Canva and build a collage of benchmark results; after over 75 minutes the result was poor as it fumbled the interface and drew shapes in Python.

**Category:** Content & Creative  
**Agent:** ChatGPT Agent  
**Source:** datacamp.com · Undated

## What they did

The author asked ChatGPT Agent to pull the benchmark images from OpenAI's announcement post and arrange them in Canva, with red rectangles around the Agent's columns. The first attempt ignored Canva. The second prompt was stricter. The author solved a CAPTCHA and logged into Canva by hand, then redirected the agent when it tried to draw the charts itself.

## How it went

It took over 75 minutes and the collage was rough. The agent struggled to drag and align images, and it drew the rectangles in Python rather than Canva, so they couldn't be edited. A title element cropped the layout, and the author fixed that manually.

## Worth knowing

The author found a simpler Canva task, a cover image, worked much better, and the agent stayed logged in to Canva across separate chat threads.

## Prompt

```text
Create a one-page collage in [Canva or other design tool] showing [the results, charts, or images I'm attaching]. Use a clean [style] layout with a title and short labels. Give it a time limit of [20 minutes]. If the design tool is not cooperating, stop and tell me what you tried, and don't sign in to anything new or publish or share the design without showing it to me first.
```
