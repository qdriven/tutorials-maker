# Track sleep, notes, code and earthquakes with a personal agent

> An OpenClaw agent with access to Garmin, Obsidian, GitHub, a VPS and chat apps logs sleep, warns about late nights, deploys code, updates notes and monitors Tokyo earthquakes.

**Category:** Life Admin & Home  
**Agent:** OpenClaw  
**Source:** openclaw.ai · Undated

## What they did

The user, bangkokbuild, gave their OpenClaw agent access to a Garmin watch, an Obsidian vault, GitHub repos, a VPS, Telegram, WhatsApp and X. The agent logs sleep, health and exercise data and says when they stay up too late. It writes and deploys code, updates daily notes, tracks visitors to MenuCapture, watches Tokyo earthquakes, and checks in on Telegram if they go quiet.

Connect to my [sleep tracker, e.g. Garmin], my notes in [Obsidian or notes app], and [chat app]. Each morning log last night's sleep into my notes, and if I'm still active after [bedtime, e.g. 11pm] send me a nudge. Also check [data source, e.g. an earthquake feed for my city] hourly and alert me only for events above [magnitude]. Ask me before deploying code or editing anything outside my notes, and stop once you have confirmed each connection works with a test message.
