# Order pizza for a group with computer use

> Anthropic engineers had Claude computer use navigate DoorDash and choose pizzas for a group.

**Category:** Shopping & Errands  
**Agent:** Claude computer use  
**Source:** aol.com · Undated

## What they did

Anthropic engineers asked Claude's computer use feature, in public beta on Claude 3.5 Sonnet, to order enough food for a group. Claude navigated DoorDash on its own and picked the food. The source gives no detail on prompts, setup or human checks beyond the request.

## How it went

About a minute later, Claude had decided to order pizzas, according to Alex Albert's X post. The article gives no cost, order details or accuracy figures. Anthropic calls the tool experimental and error-prone.

## Worth knowing

Anthropic recommends a dedicated virtual machine, limited access to sensitive data, restricted internet domains, and a human in the loop for sensitive tasks, to guard against prompt injection.

## Prompt

```text
Open DoorDash on my desktop and find pizza places near [address] that deliver. Choose [number] pizzas that suit a group of [number] people with these preferences: [toppings, dietary needs], and add them to the cart. Stop at the checkout screen and show me the cart and total; do not pay.
```
