# Handle Shopify support tickets, orders and refunds

> An AI agent built on Claude and GPT cancels orders, tracks shipments, creates return labels and processes refunds for Shopify merchants' support tickets (vendor listing).

**Category:** Sales, Marketing & Support  
**Agent:** Claude  
**Source:** apps.shopify.com · Undated

## What they did

Merchants install the Supportify app, which syncs with Shopify, and connect their FAQ, shipping and return portal, and channels (chat, email, Instagram, Facebook). The agent, powered by Claude and GPT, then handles tickets itself. It can cancel or edit orders, track shipments, create return labels and process refunds. When a human is needed, it escalates the ticket with full context.

## How it went

The listing gives no resolution rates or savings. It shows a 5.0 rating from 17 reviews, and merchants call setup quick and the chatbot time-saving.

## Worth knowing

Pricing is $0.60 per AI session after 50 free sessions. The app asks for broad edit access to orders, customers, discounts and gift cards.

## Prompt

```text
Build an agent that watches my support inbox [helpdesk or email] for tickets from my Shopify store [store name]. For each ticket, look up the order, check tracking status, and draft a reply and a proposed action such as cancel, return label, or refund up to [amount limit]. Pause and show me the draft and the action for approval before sending any message or issuing any refund or cancellation.
```
