# Create assessments and grade papers for classes

> A teacher's co-teacher uses ChatGPT to create assignments and tests, with commenters also using it to grade papers and create texts.

**Category:** Work & Operations  
**Agent:** ChatGPT  
**Source:** Reddit · Undated

## What they did

The Reddit post says a co-teacher was using ChatGPT to make tests, handouts, and other assignments, and a student noticed because the format matched a ChatGPT-made study guide they had generated for themself. In the comments, teachers describe using AI tools like ChatGPT, Claude, or district-paid Copilot to draft lesson materials, then heavily rewriting prompts, content, and formatting by hand to fit curriculum and students.

## How it went

The thread’s main result is that teachers found AI could help generate a starting point, but many said it did not save much time because they had to rework almost everything. Commenters also said the outputs often looked bad, were inaccurate, or needed extensive modification before use.

## Worth knowing

One commenter said timing both methods showed making the resource from scratch was consistently quicker and more accurate than using AI first.

## Prompt

```text
Create a [quiz/test/assignment] for my [grade] [subject] class on [topic], with [number] questions, an answer key, and a mix of [question types]. Then, using my rubric [rubric], grade the sample student responses in [folder] and give brief feedback on each. Save everything in [folder] and flag any answers you were unsure how to grade.
```
