# Create a presentation on AI career and salary trends

> A tester had ChatGPT Agent build a generative AI careers deck; the result was basic with hard-to-read tables, and the Canva connector was read-only so it couldn't improve it.

**Category:** Content & Creative  
**Agent:** ChatGPT Agent  
**Source:** analyticsvidhya.com · Undated

## What they did

In agent mode, the tester gave ChatGPT Agent a detailed prompt for a 10-15 slide PowerPoint on career and salary growth in generative AI. The prompt listed an 11-slide outline, with charts, icons and minimal text. The tester then tried linking Canva to improve the deck, but the connector could only search and retrieve existing designs.

## How it went

The deck came out very basic in content and design, and its tables were hard to read. Canva could not create presentations or upload files, so the deck was not improved. The tester says Manus, Genspark or Gamma would likely do better.

## Worth knowing

Slide creation is in beta, can't use existing decks as templates, and the slide viewer may differ from the exported PowerPoint. Plus plans get only 40 agent messages a month.

## Prompt

```text
Research current trends in [field, e.g. AI careers and salaries] and build a [number]-slide presentation with sourced figures. Keep tables short and readable, using charts or simple visuals instead of dense grids. Finish when the .pptx is ready, and flag any slides whose layout you think still needs manual cleanup.
```
