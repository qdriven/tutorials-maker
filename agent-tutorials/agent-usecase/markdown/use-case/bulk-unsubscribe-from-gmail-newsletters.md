# Bulk-unsubscribe from Gmail newsletters

> A PCWorld writer had Claude Cowork pick newsletters safe to cut, then unsubscribe in bulk via the Chrome extension with a JavaScript function it wrote to click Unsubscribe.

**Category:** Life Admin & Home  
**Agent:** Claude Cowork, Claude in Chrome  
**Source:** pcworld.com · Undated

## What they did

In a Cowork project with the Gmail connector enabled, Ben Patterson asked Claude Sonnet to review his "archivable" label and list newsletters safe to unsubscribe from, without acting yet. Claude then quizzed him on each one in multiple-choice form with its own recommendation. After that it used the Chrome extension and a JavaScript function it wrote to click Unsubscribe in Gmail.

## How it went

Claude unsubscribed from 21 newsletters in about five minutes, one for each he chose to cut. It also suggested a follow-up routine to mark any that reappear as spam.

## Worth knowing

Cowork needs a paid Claude plan; the author used Claude Pro at $20 a month. His prompt told Claude to list candidates first and not act yet.

## Prompt

```text
Go through my Gmail inbox at [your email address] and list the newsletters and promotional senders from the last [time period], grouped by how often I open them. Propose which ones are safe to unsubscribe from and show me the list. After I approve it, unsubscribe from only those senders, and finish with a summary of what you removed.
```
