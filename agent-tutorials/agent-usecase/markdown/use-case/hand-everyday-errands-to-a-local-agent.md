# Hand everyday errands to a local agent

> A commenter lists tasks given to a trusted local agent: planning flights and hotels, converting music, finding DRM-free ebooks, designing 3D-printed holders, and tracking email appointments.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** HN · Oct 6, 2026

## What they did

The commenter runs a local agent they trust not to share conversations, and uses it like a search engine in place of a browser. They hand it errands: plan flights, a hotel and sights for a conference talk, convert downloaded FLAC music to OGG for a player, find DRM-free epubs for owned books, and make a tweakable OpenSCAD holder from a photo beside a tape measure.
