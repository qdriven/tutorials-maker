# Build and publish a BaZi chart reading agent

> Built solo with coding agents, an agent computes BaZi charts, interprets them, detects language and takes on-chain payments for readings.

**Category:** Software & DevOps  
**Agent:** Codex  
**Source:** X · Jul 14, 2026

## What they did

The developer used AI coding agents to build the full stack solo. The agent received a deterministic BaZi calendar engine to compute exact charts from birth data using solar terms, stem-branch calendar and 10-year luck cycles, then interpreted results while auto-detecting language for output plus chart image. On-chain USDT payments via x402 settled four service tiers without further human input after deployment.

## How it went

It went live on the OKX AI Marketplace as Agent #4939 and settled over 20 real transactions. The stack runs 24/7.

## Worth knowing

Spec to live marketplace listing took under a week.
