# Set up Google Ads campaigns through the UI

> A non-engineer PM had Claude in Chrome operate Google Ads to create four US English campaigns with headlines and copy; a short test showed a strong conversion rate.

**Category:** Sales, Marketing & Support  
**Agent:** Claude in Chrome  
**Source:** rimo.app · Undated

## What they did

Rinako, a PM, gave Claude in Chrome a Semrush keyword list and asked it to design a campaign structure and budget. Claude then configured the campaigns in her logged-in Google Ads account, using competitor copy and keywords as reference. It wrote the headlines and ad copy itself. She left it running, then made manual adjustments before launch.

## How it went

Claude set up the four campaigns it had proposed. After about two hours the setup was roughly 60–70% done, and she reused 70–80% of the copy. A few-hour test of one campaign showed a strong conversion rate, possibly early luck.

## Worth knowing

A bare 'set up a campaign' gave too few headlines and weak asset strength. Following up to tell it to use the Semrush data and increase asset coverage fixed that.

## Prompt

```text
Open Google Ads in my logged-in browser and set up [number] search campaigns for [product or service] targeting [country] in [language], with a daily budget of [amount]. Write headlines and descriptions based on [my website URL] and save everything as drafts. Stop before publishing and show me each campaign's settings, budget and copy so I can approve them. Do not enable any campaign or spend money without my go-ahead.
```
