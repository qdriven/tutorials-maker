# Run marketing tasks like getting past gated lead forms

> An SE Ranking marketer tested ChatGPT Agent on marketing tasks including a gated HubSpot report; it fully succeeded in only two of five runs.

**Category:** Sales, Marketing & Support  
**Agent:** ChatGPT Agent  
**Source:** seranking.com · Undated

## What they did

Victor Schmitt-Bush gave ChatGPT Agent a prompt to get HubSpot's 2025 State of Marketing report. On its own it found the page, clicked the button, filled in the gated form, downloaded the file and summarized it. He also tried restaurant bookings and an SE Ranking demo booking. A colleague stepped in to type login credentials for a keyword task.

## How it went

Across five tests, Agent fully succeeded only twice. The HubSpot download worked, but Google blocked it from Gmail, so it couldn't email the summary. The VICE reservation took over eight minutes, and Figmor couldn't be booked online.

## Worth knowing

Agent couldn't enter credentials itself and asked the user to take over. Google also rejected its browser for Gmail, so plan for manual handoffs.

## Prompt

```text
Go to [URL of gated report or landing page] and get the content by filling in the lead form with these details: [name, work email, company]. Pause and show me the form before you submit it. Once through, summarize the key findings in [number] bullets and tell me if anything blocked you.
```
