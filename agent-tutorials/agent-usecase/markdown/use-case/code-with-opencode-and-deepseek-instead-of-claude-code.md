# Code with OpenCode and DeepSeek instead of Claude Code

> A developer switched their coding agent from Claude Code to OpenCode with DeepSeek, reporting comparable quality at far lower cost for coding sessions.

**Category:** Software & DevOps  
**Agent:** Claude Code  
**Source:** Bluesky · Oct 14, 2026

## What they did

The poster switched their coding agent from Claude Code to OpenCode, running DeepSeek as the model. The post is a short Bluesky note and gives no setup detail. It doesn't describe configuration, tasks or review steps. It says they made the switch the day before and then coded with it.

## How it went

They report quality comparable to Claude Code at a much lower price, about 25 centavos of real for 2 hours of straight coding work. No benchmarks or task details are given.

## Worth knowing

This is one user's impression after about a day of use, so check quality on your own projects before relying on the cost comparison.
