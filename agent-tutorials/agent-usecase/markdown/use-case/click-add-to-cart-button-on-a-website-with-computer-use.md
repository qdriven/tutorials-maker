# Click add-to-cart button on a website with computer use

> Víctor Paytuvi had Claude computer use find and click a site's add-to-cart button on the first try after Gemini failed.

**Category:** Shopping & Errands  
**Agent:** Claude computer use, Gemini  
**Source:** X · Oct 8, 2025

## What they did

Víctor asked AI computer-use models to check a website as requested by others. He ran Gemini's model first, which searched extensively before locating the add-to-cart button. Claude computer use was then given the same task and located plus clicked the button without extra guidance.

## How it went

Claude succeeded on the first try and felt more intelligent and agentic than Gemini, which never clicked.

## Prompt

```text
Open [website URL] in the browser, find the [product name or description], choose [size/color/options], and click the add-to-cart button. Stop once the item is in the cart and tell me the item, price, and quantity shown. Do not proceed to checkout or enter any payment details.
```
