# Write, schedule and track social posts daily

> An agent writes a business's social posts, schedules them daily and tracks performance without manual input.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** X · Jun 20, 2026

## What they did

The user built the agent on CreaoAI. It writes the business social posts, schedules them daily, and tracks performance metrics automatically, running every day with no further input after setup.

## How it went

The agent handles the full daily workflow in 12 minutes, reclaiming 4 hours per day or 1,460 hours a year compared to manual work.

## Prompt

```text
Create an agent for [my business] that writes one social post per day for [platforms] about [topics and audience] in a voice like [describe voice]. It should queue them in [scheduling tool] for [time] and each week send me a report on likes, clicks and the best performers. Start by drafting a week of posts and showing me before anything is scheduled.
```
