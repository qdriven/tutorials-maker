# Build a Rust game engine with spawned agents

> OnXStephen had Grok Bot spawn agents that built a Rust game engine with .NET scripting, multi-threading, weather, lighting, and hot reloading.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** X · Oct 10, 2026

## What they did

User spawned 4 Grok bots with one as coordinator and prompted them to build a game engine offering Unity's ease of use without its render pipeline issues. The agents generated a functional Rust editor including .NET 10 scripting, native multi-threaded runtime, culling, built-in weather, dynamic lighting and water simulations, plus hot reloading.

## How it went

A working editor appeared within minutes with all requested features implemented.

## Worth knowing

Took only minutes from prompt to running editor with hot reload.

## Prompt

```text
Spawn separate agents to build a game engine in [Rust] with [scripting language] scripting, multi-threading and [weather, lighting, hot reloading]. Give each agent one subsystem, have them integrate their work, and make sure the whole thing compiles and runs a demo scene. Stop when the demo scene runs and report which features work and which are incomplete.
```
