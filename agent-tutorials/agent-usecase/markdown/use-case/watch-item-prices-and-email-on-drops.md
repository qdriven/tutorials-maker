# Watch item prices and email on drops

> A commenter set up a ChatGPT price watch on items they want and gets an email only when the price drops.

**Category:** Shopping & Errands  
**Agent:** ChatGPT Agent  
**Source:** Reddit · Undated

## What they did

The commenter set up a recurring ChatGPT task using the schedule tool rather than separate watches for each item. They ask it to check all US/web stores for an item, notify only when it falls to a target price, and optionally connect a mail app so the alert is emailed; another commenter says they bundle multiple home-decor items into one watch.

## How it went

They describe it as one of the boring setups that actually sticks because it only messages on a real drop. The thread gives no purchase savings or success-rate numbers, and notes plan limits on how many scheduled checks you can have.

## Worth knowing

One practical catch: free and Plus plans were said to top out at hourly checks, with a cap on the number of scheduled watches, so grouping items into one task helps.

## Prompt

```text
Set up a recurring price watch on these items: [product links or names] at [retailers]. Check [daily/weekly] and email me at [email] only when the price drops below [target price] or falls by more than [percent]. Don't buy anything; just tell me what you set up and confirm the first price you found for each item.
```
