# Summarize transcripts and build documents with Codex

> A guide shows Codex summarizing transcripts into a Word doc, building an Excel revenue model and making carousel images from a document.

**Category:** Work & Operations  
**Agent:** Codex  
**Source:** mindstudio.ai · Undated

## What they did

The guide switches Codex from coding mode to everyday work mode and points it at a local project folder. In the demos, it read two transcripts and wrote a Word summary. It built an Excel revenue model from a one-line prompt. It turned an existing document into four carousel images, first as HTML slides, then as image files after the user asked for image generation.

## How it went

The Word summary took about five minutes. The Excel model took 3 minutes 46 seconds, and a follow-up prompt fixed an initial import formatting problem. The carousel images took about five minutes.

## Worth knowing

Codex burns credits faster than normal chat, so check the Usage tab. The guide suggests medium reasoning for document work and saving high reasoning for code generation.

## Prompt

```text
Read the transcript at [file path] and produce a Word document with a summary, key decisions, and action items by owner. Then build an Excel model from [assumptions or data file] with [revenue drivers] and a short assumptions tab. Stop when both files are saved in [output folder], and tell me anything you had to guess.
```
