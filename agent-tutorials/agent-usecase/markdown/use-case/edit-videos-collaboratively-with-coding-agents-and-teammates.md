# Edit videos collaboratively with coding agents and teammates

> Kino lets agents like Codex and Claude Code edit a shared code-based video timeline alongside teammates; the launch video was made with 5+ agents editing concurrently.

**Category:** Content & Creative  
**Agent:** Codex, Claude Code, Claude  
**Source:** HN · Nov 4, 2026

## What they did

Luke used Kino, a code-first editor built on Remotion where timeline edits, motion graphics, comments and 3D scenes are all code. For the launch video he told Claude to reskin everything to match a macOS Leopard install disk. He ran 5+ agents on the timeline at once, one color grading via LUTs, while his friend Donald's agents did rotoscoping.

## How it went

The launch video was made entirely in Kino with several agents and two people editing the same timeline in real time. The source gives no time or quality measurements. Kino runs only as an Electron app for now.

## Worth knowing

The full editor is free with MCP access, but Pro at $25 per editor per month is needed for unlimited MCP tool calls, share links, and editing alongside your team.

## Prompt

```text
Help me make a short video about [topic or product] by editing a code-based timeline in this project. Break it into scenes with [length] total, write the code for each scene and the transitions, and render a preview I can watch. Stop when the preview plays end to end, and list anything you want me to review before I share it.
```
