# Run personal life admin with Claude Code skills

> Claude Code skills look up trash schedules, book a cheaper car inspection, add calendar events, and send morning briefs from email and texts.

**Category:** Life Admin & Home  
**Agent:** Claude Code  
**Source:** X · Dec 17, 2025

## What they did

User dictates via phone-based Claude Code UI to an assistant that writes skills. Skills received access to email, calendar, texts and a 2004 city web portal; one created a cron job for 48-hour briefs, another looked up trash schedules, found and booked a cheaper inspection, updated a memory file on user preference for the dealership, located a bakery and added the stop plus day-of reminder to the calendar.

## How it went

All listed tasks ran as described with the inspection booking corrected by the user and the pie stop added to the calendar.

## Prompt

```text
Help me set up reusable skills for my life admin: look up [local info, e.g. my trash pickup schedule for my address], add the results to my calendar as events, and send me a morning brief at [time] summarizing my [email and texts] and today's schedule. Start with the trash schedule and calendar events and show me the plan first. Before sending any message, booking anything, or changing a calendar entry, pause and show me exactly what you're about to do.
```
