# Handle restaurant reservations over WhatsApp

> The author built a WhatsApp agent for a local restaurant that checks availability, answers questions and confirms bookings; one paying customer so far.

**Category:** Travel & Bookings  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Jul 1, 2026

## What they did

The author built a WhatsApp agent for a local restaurant that handles the full reservation chat with customers: it checks availability, answers restaurant questions, confirms bookings, and also sends reminder and thank-you messages. Alongside it, they provide a web app for staff to manage reservations, view table layouts, and see which bookings are assigned to each table; the first customer came from cold outreach and a meeting.

## How it went

They say they have one paying restaurant customer so far. The main shortfall is distribution: after sending more than 1,000 cold emails, most restaurants either did not reply or rejected the idea.

## Worth knowing

The clearest catch is go-to-market, not build: 1,000+ cold emails produced only one paying customer.

## Prompt

```text
Build a WhatsApp workflow for [restaurant name] that answers questions about hours, menu and location, checks table availability in [booking system or Google Sheet], and confirms bookings for [party size limits]. Before it sends any booking confirmation, have it show me the draft message and reservation details for approval. Done means I can test it with a sample booking from start to finish.
```
