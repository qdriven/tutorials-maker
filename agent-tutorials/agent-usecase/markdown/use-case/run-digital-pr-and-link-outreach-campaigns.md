# Run digital PR and link outreach campaigns

> The author has a Dot named Jamie run a defined outreach campaign, keep the tracker accurate and flag replies or placements needing attention.

**Category:** Sales, Marketing & Support  
**Agent:** Dots  
**Source:** promptslove.com · Undated

## What they did

The author gave a Dot named Jamie a Promptslove outreach campaign. Jamie researched prospects, checked a study's claims before pitching, and noticed the connected mailbox wasn't the sender requested. It sent pitches and submissions, asked sites to turn plain-text mentions into links, and logged each status. It ran an hourly link-building task, and the author checked results.

## How it went

A checkpoint showed 13 reported outreach actions and zero live links. Later, Jamie reported a first live link, a nofollow directory listing the author verified. Editorial approval was unconfirmed, and rankings and traffic were unmeasured.

## Worth knowing

Track submitted and live separately: an uncertain Geekout send was left unretried to avoid duplicates, and a deadline written in the prompt did not end the recurring task, which still said End repeat: Never.

## Prompt

```text
Run a link outreach campaign for [my site or client] targeting [type of publications]. Keep a tracker with each contact, status and date of last message, and flag replies or new placements that need my attention. Show me each outreach email before it's sent.
```
