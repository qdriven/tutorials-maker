# Vibecode a video tool and generate its hype video

> The author vibecoded a project entirely with Claude and asked it for a hype video to accompany the code; the author called the result garbage.

**Category:** Content & Creative  
**Agent:** Claude  
**Source:** Bluesky · Nov 1, 2026

## What they did

The author vibecoded a project called fungoid entirely with Claude. It was built more for making videos than for realtime use. To go with the code release, they asked Claude for a hype video and posted that video on Bluesky with a link to the GitHub repo. The post gives no detail on prompts or tooling.

## How it went

The author called the hype video garbage but posted it anyway. They warned that the tool's realtime performance is bad. The post gives no other results.

## Worth knowing

The author says realtime performance is bad because the tool was made for rendering videos, so don't expect live use.

## Prompt

```text
I just finished building [project name], a tool that [what it does]. Write a 30 to 45 second hype video script with scene-by-scene visuals, on-screen text and voiceover lines, in a [tone, e.g. punchy and funny] style. Then build the video as an HTML or React animation I can screen-record, and stop once I have a script and a working animation to preview.
```
