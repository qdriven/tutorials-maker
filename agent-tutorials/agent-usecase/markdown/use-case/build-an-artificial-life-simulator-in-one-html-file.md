# Build an artificial life simulator in one HTML file

> Four Grok agents were asked to build an artificial life simulator with glowing particles, force sliders, and emergent behaviors.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** X · Feb 17, 2026

## What they did

Four Grok 4.20 (Beta) agents received the prompt to create one self-contained HTML file simulating hundreds of glowing neon particles across six cyberpunk colors, with a 6x6 matrix of attraction/repulsion sliders, click-to-spawn controls, randomize button, pause/speed/particle-count toggles, and optional trails plus dark UI effects. The agents generated the full file independently. The user opened it and recorded the running simulation.

## How it went

The file produced swarms, orbiting rings, chasing packs and exploding clusters that the poster called mind-blowing; a short video of the live demo was shared.

## Prompt

```text
Build an artificial life simulator in a single HTML file with glowing particles of [number] types, sliders for the forces between them, and emergent behaviors like clustering and orbiting. Test it in a browser and fix any performance problems. Stop when the sliders produce visibly different behaviors and the file opens with no setup.
```
