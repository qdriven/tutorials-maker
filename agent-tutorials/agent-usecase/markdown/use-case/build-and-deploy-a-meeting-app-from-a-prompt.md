# Build and deploy a meeting app from a prompt

> A user had Replit Agent create a meeting app with dashboard, logic and analytics, and deploy it live without manual code changes.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** X · Nov 7, 2025

## What they did

User entered one prompt into Replit describing a meeting management app that tracks agendas, participants, and action items plus analytics for effectiveness, participation, and follow-up. The agent generated the clean dashboard, task tracking, recurring templates, and analytics views, then deployed the app live with no user code edits or config.

## How it went

Delivered a fully responsive production app with all listed features that went live on the web within minutes.

## Worth knowing

Agent handled building, testing, and deployment automatically in the background.

## Prompt

```text
Build a meeting app for [my team or use case] with a dashboard of upcoming meetings, [key logic, e.g. scheduling or reminders], and analytics on [metric]. Deploy it live and give me the URL. You are done when I can log in and use each feature, and ask me before connecting any payment or email service.
```
