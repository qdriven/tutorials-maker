# Fix wrong-day flight reservations between bots

> Ron's speaking-gig bot noticed flights on the wrong days and, with his permission, had his travel bot fix them and reschedule everything.

**Category:** Travel & Bookings  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 3, 2026

## What they did

The speaking-gig agent noticed that flight reservations for upcoming speeches were on the wrong days. It contacted the user to report the issue and asked permission to involve the separate travel bot. After the user approved, the two agents communicated directly with each other to correct and reschedule the bookings.

## How it went

All reservations were updated without further input from the user.

## Worth knowing

The speaking-gig agent uses profanity.

## Prompt

```text
Review the flights on my calendar and in my email for [event or trip] and check that they match the event dates of [dates]. If any are on the wrong day, propose the corrected flights and rescheduled plans, and wait for my approval before changing or canceling anything. When done, give me an updated itinerary.
```
