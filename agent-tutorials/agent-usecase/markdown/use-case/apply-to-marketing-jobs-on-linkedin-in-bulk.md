# Apply to marketing jobs on LinkedIn in bulk

> A Comet user had the agent submit about 100 LinkedIn applications in 40 minutes, with no interviews resulting.

**Category:** Life Admin & Home  
**Agent:** Perplexity Comet  
**Source:** aiforbeginners.substack.com · Sep 17, 2025

## What they did

A Comet browser user told the agent in plain English to apply to marketing jobs on LinkedIn. The agent searched for postings, clicked Easy Apply, filled the forms from the user's profile, answered basic experience and education questions, and submitted. The user left it running and came back afterward. The source is a second-hand summary of a Reddit post.

## How it went

About 100 applications went out in 40 minutes, but none led to interviews. The agent also marked the user's French as Professional when they could barely speak it.

## Worth knowing

The agent filled in answers on its own and overstated a qualification, so check the answers it gives before it submits.

## Prompt

```text
Search LinkedIn for [job title] roles in [location or remote] that match my background in [short description or resume summary]. List the first [number] matches with company and link, then wait for my approval. For each one I approve, fill in the application using my details and show me the filled form and any cover note before you click submit. Stop after the approved applications are submitted.
```
