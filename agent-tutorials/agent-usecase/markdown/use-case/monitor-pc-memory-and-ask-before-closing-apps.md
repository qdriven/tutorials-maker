# Monitor PC memory and ask before closing apps

> Grok Bot noticed high RAM use from 22 Python processes, texted a breakdown, and asked permission before closing applications.

**Category:** Life Admin & Home  
**Agent:** Grok Bot  
**Source:** X · Oct 6, 2026

## What they did

The Grok bot monitored the PC and sent a text alert when RAM hit nearly 28GB with 22 Python processes and iCloud using 10GB. It listed processes eating memory, suggested what to close, asked permission before any action, and remembered the prior instruction to leave ChatGPT open. The user replied via text naming what to shut down and warning that the Python processes might belong to Claude.

## How it went

The user got the text during lunch at a construction site and handled the response remotely without the computer running out of memory.

## Prompt

```text
Keep an eye on memory use on my [PC] and tell me by text when RAM goes above [85]%. Include a breakdown of which processes are using the most. Ask for my permission before closing any application or process.
```
