# Build purchase orders and track payables nightly

> A Make.com automation builds purchase orders and watches payables nightly, updating estimating formulas with the latest material costs in real time.

**Category:** Work & Operations  
**Agent:** Make  
**Source:** X · Oct 7, 2026

## What they did

Make.com automation was set up to build purchase orders and perform other tasks. It watches payables nightly on its own and updates estimating formulas in real time by pulling the most recent paid costs for materials such as deck boards or nails.

## How it went

Formulas stayed current through Covid amid weekly and monthly material price increases.

## Prompt

```text
Build a scenario that runs every night for [business name]. It should read supplier price updates from [source, e.g. spreadsheet or email], update the material costs in my estimating sheet [sheet name], and list unpaid items from [accounting tool] due within [number] days. Create purchase orders as drafts only and send me a summary, and don't send any order to a supplier until I've approved it.
```
