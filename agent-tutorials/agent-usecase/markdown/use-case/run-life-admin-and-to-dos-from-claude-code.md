# Run life admin and to-dos from Claude Code

> A new mom and entrepreneur uses Claude Code to capture to-dos, break overwhelming tasks into 10-minute first steps, and learn her preferences into a file.

**Category:** Life Admin & Home  
**Agent:** Claude Code  
**Source:** lennysnewsletter.com · Undated

## What they did

Hilary Gridley uses Claude Code as a simple life-admin system she calls an anti-system system. An iPhone back-tap shortcut captures to-dos without switching apps. Claude organizes the reminders and picks up her preferences by observing her, so she doesn't configure them upfront. For overwhelming tasks, it proposes a 10-minute first step. She also talks through what she's doing, so she doesn't need integrations.

## How it went

The source is a podcast page with a topic list and no measured results. It does show demos, including a returns-tracking skill built from scratch and a recording-mode skill that anonymizes demos.

## Worth knowing

The page is only a summary, so the setup details, such as the shortcut and the preference file, are in the episode itself.

## Prompt

```text
Act as my life admin assistant. I'm going to dump my to-dos for [this week or area of life]; save them in a file called todos.md, and for any task that feels overwhelming, break it into a first step that takes 10 minutes or less. Also keep a file called preferences.md where you note what you learn about how I like to work, and stop once todos.md is organized and the first steps are written.
```
