# Run a 10-agent SEO content pipeline

> The poster built a 10-agent SEO pipeline, including a research agent that scrapes top SERP results plus Reddit and Quora, and is now offering a hosted version.

**Category:** Sales, Marketing & Support  
**Agent:** ChatGPT  
**Source:** Reddit · Feb 1, 2026

## What they did

The poster built a sequential 10-agent SEO workflow after finding single ChatGPT prompts produced generic drafts and invented facts. In the hosted version, a user pastes a keyword, then specialized agents research the top 20 SERP results plus Reddit and Quora, build the outline, draft in brand voice, fact-check, add E-E-A-T signals, humanize, polish SEO elements, optimize for citations/snippets, and plan clusters; the human role described is giving the keyword and reviewing the output.

## How it went

They say the hosted tool returns a publish-ready article in about 4 minutes, and that the fact-checking step catches 20-25% of made-up claims. The post frames it as early-stage and asks for feedback rather than sharing traffic or revenue results.

## Worth knowing

The main catch is build effort and hosting: they spent about 12 hours a day for a week turning the free local Gumroad pipeline into a hosted UI because users did not want to run it locally.

## Prompt

```text
Help me design an n8n workflow that works as an SEO content pipeline for [website or niche]. It should take a target keyword from [Google Sheet or list], scrape the top search results plus relevant Reddit and Quora threads, summarize the common questions and gaps, then draft an outline and article in [tone]. Save each draft to [Google Doc or Notion] and notify me for review; do not publish anything automatically. You are done when I can run it on one test keyword and get a reviewable draft.
```
