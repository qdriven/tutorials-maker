# Book the best-priced flight and later refund it

> A Claude Code agent booked a flight three months ahead at the best price, then got it refunded after talking to the airline for 24 hours.

**Category:** Travel & Bookings  
**Agent:** Claude Code  
**Source:** X · Oct 13, 2026

## What they did

The user asked Claude Code to find the best price, and it booked the flight autonomously three months ahead. Separately, @bot obtained the refund by talking to the airline for 24 hours.

## How it went

The ticket was successfully refunded.

## Prompt

```text
Help me find and book the cheapest flight from [origin] to [destination] around [date range], with a maximum of [price] and preferences of [e.g. nonstop, carry-on only]. Compare options across [airlines or sites], then show me your top picks and wait for my approval before paying or submitting any booking. After booking, keep the confirmation details in a file and, if I later ask for a refund, draft the request and show it to me before sending it to the airline.
```
