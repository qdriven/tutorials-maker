# Ship more pull requests with Devin across tools

> Ryan Carson uses Devin from iPhone, Slack, browser, GitHub and Linear for real work and reports higher PR shipping velocity.

**Category:** Software & DevOps  
**Agent:** Devin  
**Source:** X · Mar 22, 2026

## What they did

Ryan paid $500 for Devin and gave it access to his GitHub, Linear, Slack, browser, and iPhone. It handled coding tasks end-to-end across those surfaces, replacing his prior hand-built setup of Open Inspect plus Codex plus Linear. He directed the work from any of the tools while tracking the resulting PRs.

## How it went

PR shipping velocity rose higher than before.

## Worth knowing

$500 cost plus one-week full-use trial.

