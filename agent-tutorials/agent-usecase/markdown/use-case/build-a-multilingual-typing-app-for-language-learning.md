# Build a multilingual typing app for language learning

> A buildathon participant used Replit Agent for the first time to create LingoType, a typing app for mastering new languages.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** X · May 3, 2026

## What they did

A Japan-based buildathon participant used Replit Agent for the first time to create LingoType, a multilingual typing app for mastering new languages. The agent handled the build from the user's prompt.

## How it went

The creator reported happiness at bringing the long-time idea to life with the completed app.

## Prompt

```text
Build me a typing practice app for learning [language] where I type words and phrases and get instant feedback on accuracy and speed. Include lessons that progress from [beginner topics] to [harder topics], show translations, and track my progress across sessions. Finish with a working preview I can try and a short list of what you'd add next.
```
