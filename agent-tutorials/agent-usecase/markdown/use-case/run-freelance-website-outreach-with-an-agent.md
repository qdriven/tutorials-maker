# Run freelance website outreach with an agent

> Chris Wozniczek has Devin find businesses and gigs, build pre-made websites, and send tailored cold emails to sell website services.

**Category:** Sales, Marketing & Support  
**Agent:** Devin  
**Source:** X · Oct 8, 2026

## What they did

Chris gave Devin a GitHub repo as its brain with all processes and decisions, plus access to Linear, Slack, and other tools. Devin searches for businesses and freelancer gigs on its own, builds pre-made websites, and sends tailored cold outreach emails to sell website services. Chris wired the tools and works mostly through Slack and Linear but started the setup just before the weekend.

## How it went

No results yet. The run is too new to show outcomes.

## Worth knowing

Should have warmed up mailboxes earlier.

## Prompt

```text
Find [number] local [type of business, e.g. restaurants] in [city] that have no website or a poor one. For each, build a simple sample website and draft a tailored cold email that links to it and offers my services at [price or offer]. Put all the drafts in a spreadsheet and don't send any emails; show them to me for approval first.
```
