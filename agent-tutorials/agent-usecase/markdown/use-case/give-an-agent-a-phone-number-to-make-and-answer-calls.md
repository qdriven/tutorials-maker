# Give an agent a phone number to make and answer calls

> David Ondrej gave his Hermes Agent a phone number so it makes and answers calls and runs tasks while he sleeps.

**Category:** Work & Operations  
**Agent:** Hermes Agent  
**Source:** X · Jun 28, 2026

## What they did

David Ondrej gave his Hermes Agent a phone number. The agent then made calls, answered calls, and ran tasks on its own while he slept. Videos in the thread show the agent handling these calls.

## How it went

The agent performed the calls and tasks without further input from him.

## Prompt

```text
Help me set up a phone number for you through [voice provider such as Twilio] so you can place and answer calls on my behalf. Walk me through the setup, then handle incoming calls by [what it should do, e.g. take messages, answer FAQs about my business] and send me a summary of each call at [email or chat]. Before placing any outbound call or taking any action that costs money, pause and show me who you plan to call and what you will say.
```
