# Fill out job applications in a browser

> Claude Cowork opens tabs, reads job listings, fills out applications and decides based on user rules, working autonomously until done.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Cowork  
**Source:** X · Mar 23, 2026

## What they did

Claude Cowork desktop app gives Claude its own Chrome browser plus three user docs (resume, cover letter, Q&A on common questions). User pastes one prompt listing job boards, salary/location rules, skip conditions, and Sheets logging. Agent then opens tabs, searches boards, reads each listing, skips mismatches, fills fields from the docs, answers screenings, and logs every application.

## How it went

It applies to 50 jobs in under 30 minutes while the user does other work; source shows no further results or failure rates.

## Prompt

```text
Open the job listings I've saved at [links or a spreadsheet] and read each one. Skip any that break my rules ([salary minimum, location, role requirements]), and for the rest fill out the application using my resume at [file path]. Before pressing submit on any form, stop and show me the filled-in answers for approval, and finish with a list of what you applied to and what you skipped and why.
```
