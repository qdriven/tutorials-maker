# Qualify real estate leads and book viewings

> An AI assistant qualifies leads on Telegram, matches listings, books viewings from calendars, and logs to the CRM.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** X · Mar 9, 2026

## What they did

The Telegram bot for a luxury real estate firm was given access to a property knowledge base, live calendars, email sending, and the CRM. On each incoming message it first collected name, email and number, then asked for budget, location, type and bedrooms, semantically retrieved matching listings with images, checked availability to book the slot and emailed confirmation with agent contacts, while transcribing voice notes for the same flow and logging every lead.

## How it went

No results, metrics or shortfalls are stated.

## Prompt

```text
Set up an assistant that chats with new real estate leads on [Telegram or WhatsApp], asks about budget, area, timeline and must-haves, and matches them to listings from [my listings sheet]. When a lead qualifies, propose viewing times from my [calendar] and log the lead in [my CRM]. Ask me to approve before it sends any booking confirmation, and stop once the workflow runs on a test lead.
```
