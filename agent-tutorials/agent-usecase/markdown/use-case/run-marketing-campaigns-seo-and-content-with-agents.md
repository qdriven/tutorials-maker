# Run marketing campaigns, SEO and content with agents

> The author built 18 open-source marketing agents for Claude Code covering campaigns, SEO, content and social posting.

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code  
**Source:** Reddit · Mar 1, 2026

## What they did

The author packaged marketing work into AgentKits Marketing, a free open-source set of 18 specialized agents, 93 slash commands, and 28 skills that run inside Claude Code. Instead of leaving the IDE for prompts, they invoke role-specific agents for tasks like lead gen, landing pages, SEO content, email sequences, CRO, technical SEO, and content optimization; the post frames it as a tool the user runs directly in their coding environment.

## How it went

The stated result was smoother marketing work without context-switching between coding and separate chat tools. The post lists capabilities and components, but it does not give performance metrics, campaign results, or examples of where the agents failed.

## Worth knowing

The main catch is setup scope: this is a sizable kit built around Claude Code itself, with 18 agents, 93 slash commands, and 28 skills.

## Prompt

```text
Set up a small team of marketing helpers for my [type of business] in this folder: one for SEO keyword research, one for drafting blog posts, and one for writing [social platform] posts. Start by reading [website URL or brand notes file] to learn my voice, then produce a one-week content plan and a first draft of each piece. Save everything as files here and do not publish anything; stop when I have the plan and drafts to review.
```
