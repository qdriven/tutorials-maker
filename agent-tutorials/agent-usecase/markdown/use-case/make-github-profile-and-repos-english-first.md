# Make GitHub profile and repos English-first

> Codex inventoried the account, backed up content, and updated the profile, descriptions and README navigation across 87 public repos, then verified the changes against GitHub. · Oct 28, 2026

**Category:** Software & DevOps  
**Agent:** Codex  
**Source:** github.com · Oct 28, 2026 · Submitted by SvenKunkka

## What they did

The source is the finished GitHub profile, not a log of the agent's work. It shows a profile README with an English section ahead of the Chinese one, a bilingual project table, and English-first descriptions on pinned repos. The account has 87 repositories.

## How it went

The profile now leads with English, keeps Chinese alongside it, and states each project's maturity. The page doesn't show the inventory, backup or verification steps, or how many repos were changed.

## Worth knowing

The profile says forks and learning-resource repos keep their original authorship, so check upstream attribution before rewriting descriptions on forks.

## Prompt

```text
Go through my GitHub account [username] and list every public repo with its current description and README. Back up the originals to [folder], then rewrite the profile, descriptions, and README navigation to be English-first. Show me the proposed changes for a few repos before applying anything, and check the final result against GitHub when done.
```
