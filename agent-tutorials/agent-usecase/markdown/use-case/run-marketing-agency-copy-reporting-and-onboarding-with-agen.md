# Run marketing agency copy, reporting and onboarding with agents

> An agency co-founder used Claude Code to build systems for ad copywriting, reporting and onboarding, including a bulk Facebook Ads publisher and a client reporting portal. · Oct 17, 2026

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code  
**Source:** sucana.ai · Oct 17, 2026 · Submitted by from search gap: marketing

## What they did

Victor Chazarra built a Git repository for his agency, Fan Convert, using plain-language prompts in Claude Code. It has a CLAUDE.md router, a client template, and skills for copywriting, reporting and onboarding. Claude also wrote a Python Facebook Ads publisher that reads a Google Sheet and a Next.js client portal on Vercel. He tested each piece on real client data and checked the output files himself.

## How it went

The build took three days. A dry run, then a live run, produced 48 paused ads in about two minutes. Onboarding filled a full client workspace, and Claude answered client questions correctly from the files.

## Worth knowing

He estimates $20 to $60 in Claude usage for the three-day build. He says to build the routing and onboarding first, and to set up git sync on day one.

## Prompt

```text
I run a marketing agency and want to automate [one task: ad copywriting, client reporting, or onboarding]. Build a simple tool that takes [inputs, e.g. client brief or ad account data] and produces [output, e.g. 5 ad copy variants or a weekly report page]. Test it on sample data for [client name] and show me the result. Don't publish ads or send anything to clients without my approval.
```
