# Negotiate Facebook Marketplace purchases with sellers

> A user set up an agent to lowball sellers on Facebook Marketplace, and it reportedly negotiated a Jeep Wrangler for $1500 plus a PS5 and three TVs.

**Category:** Shopping & Errands  
**Agent:** OpenClaw  
**Source:** X · Feb 27, 2026

## What they did

User set up an OpenClaw agent to lowball sellers on Facebook Marketplace. The agent contacted listings and negotiated on its own. It secured the listed items including a 2008 Jeep Wrangler.

## How it went

Secured a PS5 for $80, 2008 Jeep Wrangler for $1500, John Deere mower free, three TVs free, first-edition Pokemon booster for $100, and 20 pre-2010 Lego Star Wars sets for $50.

## Prompt

```text
Search Facebook Marketplace near [location] for [item] under [max price]. For listings that look worthwhile, draft a polite lowball offer starting at [percent or amount] with a walk-away price of [max price]. Show me each message and the seller's reply before sending anything, and do not commit to buying or arrange a meetup without my approval.
```
