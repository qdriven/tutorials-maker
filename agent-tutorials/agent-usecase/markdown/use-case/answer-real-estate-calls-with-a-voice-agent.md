# Answer real estate calls with a voice agent

> A builder made an ElevenLabs and n8n voice agent for a real estate firm that answers calls, collects budget and location, and feeds an automated workflow.

**Category:** Sales, Marketing & Support  
**Agent:** n8n  
**Source:** X · Oct 4, 2026

## What they did

The builder connected ElevenLabs voice to n8n workflows for Agape Real Estate. The agent answers incoming calls, understands the enquiry, collects the caller's budget and location, then passes both into the n8n automation. The person set up the integration and connections but the agent runs the call handling end to end.

## How it went

The workflow now turns missed calls into usable leads the team can follow up. The posted video demonstrates the flow but omits the agent's voice output due to Loom limits.

## Worth knowing

Loom did not capture the agent's spoken responses in the demo video.

## Prompt

```text
Help me build an n8n workflow for a voice agent that answers inbound calls for [type of business, e.g. a real estate firm]. It should ask callers for [budget, location, and other details], then save the answers to [CRM or spreadsheet] and trigger a follow-up email to the caller. Run a test call with sample data, and pause for my approval before the workflow sends any real message.
```
