# Build and launch a code-snippet sharing app

> The poster built the Snippra app with Replit Agent, which handled UI copy, feature planning, debugging and naming while they guided it.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** Reddit · May 20, 2025

## What they did

The poster says they built the Snippra app itself with Replit Agent while keeping the main website on WordPress. They describe feeding the agent a UI reference image from Behance via Figma, asking it to clone the design, then using it for UI copy, dummy snippets, feature planning, debugging, naming, and idea refinement while they steered prompts and tweaked the result.

## How it went

They launched Snippra live with 40+ languages, custom categories, shareable links, and a Pro snippet-to-social image feature. In comments, they noted users currently have to add their own snippets, though they were considering dummy snippets or templates.

## Worth knowing

The clearest concrete catch is cost: when asked, the poster said the build cost $72.

## Prompt

```text
Build me a web app called [app name] that lets users [core purpose, e.g. save and share code snippets with a public link]. Plan the main features first and show me the list, then write the interface copy, build the app, and fix any bugs you find while testing it. You're finished when I can use it end to end in the preview. Ask me before you deploy it publicly.
```
