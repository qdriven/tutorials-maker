# Run a client's Facebook ad account

> An AI agent handles setup, optimization and performance for a client's Facebook ad account, which the poster says beats his manual work.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 5, 2026

## What they did

The agent runs daily at 7am with read access to the client's FB ad account and CRM. It pulls all campaigns and ads, diffs them against the approved roster, matches platform leads to real CRM entries, computes CPL only from verified leads, reads the sales pipeline, and sends one brief plus one recommended move. The user approves or rejects every action; the agent makes no live edits itself.

## How it went

CPL fell 23-41% versus the manual baseline. It spotted junk leads from a buried old retargeting geo setting and caught a $157K estimate that went cold after the weekend.

## Prompt

```text
Review the Facebook ad account for [client or business name] and tell me what's working and what isn't based on [metrics like cost per lead or ROAS] over [time period]. Suggest specific changes to audiences, budgets and creative, and set up draft ad changes for my review. Finish with a short performance report, and pause to show me each change before applying it or spending any money.
```
