# Build a minigame collection in a day

> A data professional drafted a prompt with ChatGPT and used Cursor agent mode to build a Python tkinter game with four minigames.

**Category:** Games & Simulations  
**Agent:** Cursor, ChatGPT Agent  
**Source:** medium.com · Undated

## What they did

Alvin Leung, a data scientist, spent a few minutes with ChatGPT refining a game concept into a short prompt: four minigames, Python with tkinter, time-based scoring. In Cursor he first had a simple scene-based architecture set up. He then described each minigame in plain language to agent mode, which generated the logic, UI, input handling and scoring, and he asked for follow-up tweaks. He tuned difficulty himself.

## How it went

He had a playable game in a couple of hours. It had four minigames, JSON-saved high scores and a leaderboard, and BCG-green theming. Feedback came from three colleagues, so the evidence is thin.

## Worth knowing

He did the game design himself and tuned balance, such as enemy and block counts, by hand without the AI.

## Prompt

```text
Help me build a simple desktop game collection in Python using tkinter, with [number] minigames like [examples: snake, pong, memory match]. Build, run, and debug each minigame until it works end to end, then show me the finished app.
```
