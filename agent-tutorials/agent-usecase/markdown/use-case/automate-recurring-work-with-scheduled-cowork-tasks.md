# Automate recurring work with scheduled Cowork tasks

> The author tested six scheduled tasks: email briefings, file cleanup, Stripe reporting, invoice reconciliation, notes tidying and flight price tracking.

**Category:** Work & Operations  
**Agent:** Claude Cowork  
**Source:** aiblewmymind.substack.com · Undated

## What they did

The author wrote a prompt once in Claude Cowork, either through the /schedule command or the sidebar form, and chose a cadence of hourly, daily, weekly or weekdays. She then ran six tasks: email and calendar briefing, file sorting, Stripe reporting, invoice reconciliation, Apple Notes tidying and flight price tracking. After the first run, Claude rewrites the prompt based on what it learned.

## How it went

The free part of the post only covers setup. The six tested use cases, their prompts and any results sit behind a paywall, so outcomes aren't visible.

## Worth knowing

A task tied to a local folder only runs while your computer is on and awake. Leaving the folder empty runs it in the cloud, and the Desktop app needs to be fully updated first.

## Prompt

```text
Set up a scheduled task that runs [daily or weekly] at [time]: [describe job, such as summarize my unread email, clean up my Downloads folder, or track prices for flights from [origin] to [destination]]. Each run should produce a short report saved to [folder]. Before deleting or moving any files, list what you plan to do and wait for my approval.
```
