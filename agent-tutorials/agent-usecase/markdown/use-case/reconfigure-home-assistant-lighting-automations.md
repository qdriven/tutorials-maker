# Reconfigure Home Assistant lighting automations

> Levelsio used AI to rework Home Assistant so bright LEDs turn off and diffuse lights come on, with all lights off at 10pm and red for sleep.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** X · Apr 22, 2026

## What they did

The user prompted an AI to edit Home Assistant automations so any signal turning on the house's bright white LED spots would instead kill those and activate the diffuse indirect light strips instead. The AI also added rules turning all lights off at 10pm, with color ones switching to red only.

## How it went

The house now uses the softer glow lights by default and shifts to full red at night.

## Prompt

```text
Help me reconfigure my Home Assistant automations. Read my config at [path or URL] and propose changes so that [bright lights] turn off and [soft lights] come on in the evening, everything turns off at [time], and lights go [color] for sleep. Show me a diff of the YAML changes before applying anything, and finish when the new automations pass a config check.
```
