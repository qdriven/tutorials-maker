# Build a 2D platformer game without coding

> A content creator with no coding experience used Claude Code to build a black-and-white wave-combat platformer in HTML canvas and played it live.

**Category:** Games & Simulations  
**Agent:** Claude Code  
**Source:** daily.dev · Undated

## What they did

A content creator with no coding experience used Claude Code (Opus 4) to generate a game called 'Seek' in HTML/JavaScript canvas. It has a silhouette hero with an oversized sword, wave-based combat, four enemy types (grunts, archers, brutes, flyers), and an ending tied to player choices. The creator then played the result live.

## How it went

The game closely matched the creator's original vision. They reached wave 10, where they met a boss that seemed unbeatable. They endorsed Claude Code and teased a future comparison with Codex.

## Worth knowing

The daily.dev page only summarizes a 12-minute YouTube video, so the exact prompts and any fixes aren't described. Watch the original for those.

```text
I have no coding experience. Build me a 2D platformer in a single HTML file with a [art style, e.g. black-and-white] look and [core mechanic, e.g. waves of enemies to fight]. Use simple controls like [keys], explain how to open it in my browser, and keep improving it based on my feedback. You're finished when I can play a full level from start to finish.
```
