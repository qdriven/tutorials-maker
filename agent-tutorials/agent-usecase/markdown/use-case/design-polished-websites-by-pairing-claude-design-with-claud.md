# Design polished websites by pairing Claude Design with Claude Code

> An author had Claude Code build sites for six industries, found them generic, then used Claude Design to set the visual direction and Claude Code to implement it. · Nov 1, 2026

**Category:** Content & Creative  
**Agent:** Claude Code, Claude  
**Source:** vocus.cc · Nov 1, 2026 · Submitted by from search gap: 设计

## What they did

The author had AI build sites for six industries with free styling. Every one used the same badges, gradient text and card trios. For his own site, aiqkangber.com, he fed Claude Design his existing code or GitHub repo. It asked him questions, offered three button directions, and he steered spacing and color, sometimes with Dribbble screenshots. He then sent the result to Claude Code as a bundle of specs and design tokens.

## How it went

His homepage, services page and newsletter page lost the generic look. The homepage got a particle-globe hero. Claude Design can't produce photos or complex illustrations, so those still have to come from you.

## Worth knowing

Since late May 2026, Claude Design draws from the same usage pool as chat and Claude Code. It needs a paid plan, and using both together drains the quota faster.

## Prompt

```text
Build a [type of site, e.g. restaurant, law firm] website for [business name] in this folder. Before writing code, propose three distinct visual directions (palette, typography, layout, mood) so it doesn't look generic, and wait for me to pick one. Then implement the chosen direction as a responsive site I can preview locally, and stop when every page matches the direction.
```
