# Run Xiaohongshu account operations via an MCP

> A developer built an open-source Xiaohongshu MCP so Claude Code researches content itself and publishes posts to the platform. · Nov 1, 2026

**Category:** Sales, Marketing & Support  
**Agent:** Claude Code  
**Source:** v2ex.com · Nov 1, 2026 · Submitted by from search gap: 运营

## What they did

The developer built an open-source MCP server with two functions at first: logging in and publishing image-and-text posts. Claude Code gathered or researched content on its own, then called the MCP to publish. Images can be local files or URLs. He ran a brand-new account this way for about a week, with over 90% automated. Search and feed browsing were added later.

## How it went

In about a week the account got over 6,000 likes and favorites, close to 1,000 a day early on. Week two slowed down, and he paused the fully automated run.

## Worth knowing

Posts may be flagged as suspected AI-generated and lose traffic. Titles are limited to about 20 characters, and Xiaohongshu caps daily posts. A May 2026 commenter said issues mention account bans.

## Prompt

```text
Help me set up an MCP server so you can research and publish posts on my Xiaohongshu account about [my topic or niche]. First research [number] trending posts in this niche and summarize what works, then draft [number] posts in my voice: [describe voice]. Pause and show me each draft, with images and tags, before publishing anything, and stop once the approved posts are live.
```
