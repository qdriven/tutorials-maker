# Build a Pong game and website from scratch

> A tester asked Devin to create a basic Pong-style game and a website, and it finished both in under 20 minutes.

**Category:** Software & DevOps  
**Agent:** Devin  
**Source:** siliconangle.com · Mar 12, 2024

## What they did

Bloomberg's Ashlee Vance, one of a few journalists with private-preview access, asked Devin for a basic Pong-style game and a website built from scratch. Devin works from a chat prompt inside a sandbox with a code editor, browser and shell. It makes a step-by-step plan, writes and tests code, fixes its own bugs, and reports progress. The user can add prompts to correct it.

## How it went

Per Vance, Devin finished both the Pong-style game and the website in under 20 minutes. The article gives no detail on the quality of the results. It says more complex tasks take longer.

## Worth knowing

Devin was only in private preview at the time, so access was limited to selected users.

## Prompt

```text
Create a basic [type of game, e.g. Pong-style] game and a simple website to host it. Make the game playable in the browser with [controls, e.g. keyboard], and the site should include [sections, e.g. title, instructions, play area]. You're done when both run locally and you've given me the steps to open them. Ask me before deploying anything publicly.
```
