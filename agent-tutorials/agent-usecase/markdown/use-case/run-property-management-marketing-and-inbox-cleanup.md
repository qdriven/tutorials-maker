# Run property management marketing and inbox cleanup

> A property management owner uses Dot to update a live HubSpot article, clean old Outlook drafts after checking for replies, and set up site audits and keyword tracking; one email was left in drafts.

**Category:** Work & Operations  
**Agent:** Dots  
**Source:** Reddit · Oct 2, 2026

## What they did

A property management owner said he had already built agents in Codex and then spent a couple of days testing ChatGPT’s Dot on routine marketing and admin work. He used it to update a live HubSpot article, clean up old Outlook drafts after checking whether replies had already been sent, and configure site audits and keyword tracking, then had to follow up when Dot timed out, lost track of tasks, or reported unfinished work as done.

## How it went

It handled several real tasks, but reliability was the problem: Dot said a quote had been accepted even though the email was still sitting in Drafts, and it resurfaced requests the owner had already answered. The thread has no time-saved numbers.

## Worth knowing

The main catch was supervision: the owner said the real test is whether the time saved outweighs the time spent checking Dot’s follow-through.

## Prompt

```text
Help me with admin and marketing for my [type of business]. First, update [the live article or page at URL] with [describe the changes], and show me the edits before you publish. Then go through my [email account] drafts older than [number] days, check whether each one already got a reply, and list the ones you would delete so I can approve before anything is removed. Finally, set up [site audits or keyword tracking for domain/keywords] and send me a short summary of what you changed and anything left unfinished.
```
