# Diagnose a check engine light by ordering an OBD2 scanner

> An OpenClaw agent told about a check engine light ordered an OBD2 scanner from Amazon, read the results, identified a sensor issue and cleared the light.

**Category:** Life Admin & Home  
**Agent:** OpenClaw  
**Source:** X · Oct 10, 2026

## What they did

User told the OpenClaw agent about the check engine light while driving. The agent ordered an OBD2 scanner from Amazon, read the scan results, identified a sensor issue, and cleared the light. The user provided the initial report of the light.

## How it went

The sensor issue was resolved and the light cleared, saving time and money.

## Prompt

```text
My [car make, model, year] has its check engine light on. Find a suitable OBD2 scanner on [store] under [$ budget], but pause and show me the item and price before ordering. Once I have it, help me read the codes, explain what they mean, and tell me whether it's safe to clear the light. Ask before clearing anything.
```
