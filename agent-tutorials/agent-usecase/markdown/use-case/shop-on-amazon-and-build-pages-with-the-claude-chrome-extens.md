# Shop on Amazon and build pages with the Claude Chrome extension

> A reviewer used the Claude Chrome extension for Amazon shopping, building an interactive model timeline from one prompt, and translating and summarizing pages; one screenshot bug appeared.

**Category:** Shopping & Errands  
**Agent:** Claude in Chrome  
**Source:** daily.dev · Undated

## What they did

The reviewer used the Claude Beta Chrome extension on three tasks. Claude searched and interacted with Amazon pages for shopping. It generated an interactive timeline of Claude models in a new browser tab. It also translated and summarized web pages across English, Spanish, and Italian.

## How it went

The reviewer was impressed enough to keep the extension installed. One bug turned up in the screenshot feature. The available text gives no timings or other measurements.

## Worth knowing

The extension is labeled Beta, and the screenshot feature had a bug. The daily.dev page only summarizes the review, so read the original XDA article for details.

## Prompt

```text
On Amazon, find [product] under [price] with at least [rating] stars, compare the top [number] options on price, reviews and delivery date, and give me a short ranked list with links. Add my pick to the cart if I choose one, but stop before checkout and show me the cart and total. Do not place any order without my confirmation.
```
