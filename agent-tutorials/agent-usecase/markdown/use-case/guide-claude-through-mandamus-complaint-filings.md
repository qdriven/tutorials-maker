# Guide Claude through mandamus complaint filings

> The poster prepared a Claude markdown file with guidance on filing a mandamus complaint, serving the summons and complaint, and filing proof-of-service forms in district court.

**Category:** Life Admin & Home  
**Agent:** Claude  
**Source:** Reddit · Sep 1, 2026

## What they did

The poster made a markdown file to upload into Claude, so Claude could generate and guide a USCIS mandamus complaint and demand letter. The file was updated to tell Claude how to walk someone through filing in district court, mailing the complaint and summons to each defendant by USPS, choosing when to file proof of service, and producing three checklists; the human still had to upload the file, keep using the same chat, and file or mail everything.

## How it went

The post reports process improvements, not case results: it says filing proof of service after mailing rather than waiting for USPS delivery can save about 3 to 10 days, while waiting too long risks dismissal for missing the court’s service deadline. It also says a $20 Claude plan was enough for a couple of hours at a time before hitting usage limits.

## Worth knowing

Main catch: Claude loses context in a new conversation, so you have to resume the same thread, and usage on the $20 plan may pause for several hours when credits reset.

## Prompt

```text
Help me prepare a mandamus complaint in [federal district court name] about [agency and delayed action]. Read the notes and documents in [folder path], then write a guidance file listing the filing steps, how to serve the summons and complaint on [required parties], and which proof-of-service forms to complete. Draft the documents with placeholders for facts I must confirm, do not file or send anything, and stop when I have a checklist and complete drafts to review. Note that I should have a lawyer check them.
```
