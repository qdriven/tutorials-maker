# Run a private personal-admin agent in Cursor

> The author uses Cursor for personal admin like drafting a dentist appointment email, using private notes and rules that keep personal details out of public drafts.

**Category:** Life Admin & Home  
**Agent:** Cursor  
**Source:** petralian.com · Undated

## What they did

The author runs brainstorming and personal admin in the same Cursor interface but switches constraints on purpose. For personal work he uses a private notes area and rules that stop personal details from being copied into public or commercial drafts. He captures follow-ups on his phone in a few lines. At the desk he asks the agent to continue from the note's Open questions.

## How it went

The source gives no measured results. It presents this as a working setup. The dentist email is mentioned only as an example of personal admin. The author says the mode split depends on habit.

## Worth knowing

Mode locks are habits that Cursor won't enforce. Keep one handoff note per lane, with Context, Captures today and Open questions headings, and update it in about three minutes after each chat.

## Prompt

```text
Using my private notes in [folder path] and the rules in [rules file], draft an email to [dentist / doctor / other provider] asking to book an appointment for [reason] around [dates]. Keep personal details like [what to keep out, e.g. insurance ID, full address] out of the draft. Give me the finished draft and do not send anything.
```
