# Run business WhatsApp customer messages with an agent

> An n8n agent handles customer WhatsApp messages, searches info, checks the calendar, logs to Sheets or Notion, and replies by WhatsApp and email.

**Category:** Sales, Marketing & Support

## What they did

The n8n agent receives incoming customer WhatsApp messages, performs searches, checks the calendar, and logs entries to Sheets or Notion before sending replies on WhatsApp and email. It operates automatically with no further human steps described.
