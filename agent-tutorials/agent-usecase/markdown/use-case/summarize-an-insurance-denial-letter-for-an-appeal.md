# Summarize an insurance denial letter for an appeal

> The poster used an AI assistant to summarize a denial PDF to draft an appeal, but it invented an appeal deadline.

**Category:** Money, Bills & Benefits  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Oct 6, 2026

## What they did

The poster fed a long insurance denial PDF to an AI assistant and asked for a summary to help draft an appeal. The assistant produced a polished summary but falsely stated there was a 14-day appeal deadline; the poster caught the error by reopening the original PDF, which actually gave a 60-day window and a specific mailing address.

## How it went

It was useful enough to speed up drafting, but it hallucinated a key deadline under stress. The poster’s takeaway was to verify every date and dollar amount in the source document before sending anything.

## Worth knowing

Their practical rule was to keep the PDF open beside the draft and treat every number as something to verify, not trust automatically.

## Prompt

```text
I'm attaching my insurance denial letter. Summarize the reason for denial, the policy or code sections cited, and any deadlines, quoting the exact lines in the letter that state them. If the letter doesn't state a deadline, say so rather than guessing. Then draft an appeal letter for [my situation] that I can review, and list the facts I should double-check with my insurer.
```
