# Search for cheap round-trip flights from JFK

> ChatGPT agent returned a table of dates and prices per destination that matched on checking, but gave no booking links so the reporter had to search manually.

**Category:** Travel & Bookings  
**Agent:** ChatGPT Agent  
**Source:** tomsguide.com · Undated

## What they did

The reporter turned on ChatGPT agent from the + menu in the chatbox. He asked it to search for the best round-trip deals from JFK in January 2026. The agent browsed the web and returned a table of specific dates and prices for each destination. He then checked the results himself.

## How it went

The flight times and prices matched what ChatGPT listed when he checked them. The agent gave no direct booking links, so he had to search for each connection manually in a separate tab.

## Worth knowing

Plan to look up each itinerary yourself. In the same article, Claude with the Kiwi connector did return direct booking links.

## Prompt

```text
Search for cheap round-trip flights from [home airport] to [destination or list of destinations] for travel between [date range] lasting [number] days. Build a table of the cheapest date and price for each destination, with a direct booking link for each. Do not book anything; I will review the table first.
```
