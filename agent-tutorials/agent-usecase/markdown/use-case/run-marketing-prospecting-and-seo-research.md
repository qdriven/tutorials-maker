# Run marketing prospecting and SEO research

> Comet found growth-signal e-commerce companies, built contact lists with Gmail drafts, mined Reddit for SEO questions, and audited a checkout flow.

**Category:** Sales, Marketing & Support  
**Agent:** Perplexity Comet  
**Source:** medium.com · Undated

## What they did

The author used Perplexity's Comet browser agent and gave it plain-language prompts for each task. For prospecting, it found e-commerce companies showing growth signals, built a contact list, and saved outreach drafts to Gmail. For SEO research, it searched Reddit for high-intent questions from the last 7 days and emailed a summary of pain points. It also audited a checkout flow by following a process doc.

## How it went

The source gives no measured results, only example prompts and general praise after a few weeks of use. It doesn't show output quality, error rates, or how much human review the drafts needed.

## Worth knowing

The source is a prompt list, not a worked case, so expect to test and refine each prompt and review the Gmail drafts before sending.

## Prompt

```text
Find [number] [type, e.g. e-commerce] companies showing growth signals such as [hiring, funding, new launches], and build a contact list with company, role to target and source link. Create a Gmail draft for each one using this pitch: [short pitch]. Leave the drafts unsent and show me the list when done.
```
