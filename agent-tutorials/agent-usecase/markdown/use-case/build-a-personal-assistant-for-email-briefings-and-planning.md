# Build a personal assistant for email, briefings and planning

> Marc Bara added 50+ capabilities to Hermes Agent over 15 days, including email triage, briefings, calendar planning and an MCP link to his invoice system.

**Category:** Work & Operations  
**Agent:** Hermes Agent  
**Source:** X · Sep 13, 2026

## What they did

Marc installed Hermes Agent from Nous Research as a chat interface. He added more than 50 capabilities himself, such as email triage, daily briefings, calendar and task planning, meeting notes, and research radars. He built a custom MCP server that gave the agent direct interaction with his task, project, client, and invoice system rather than treating it as disconnected data.

## How it went

The agent became an operating layer across Marc's work, research, personal organisation and family life within 15 days. He documented the day-by-day changes in a public timeline.

## Worth knowing

The full day-by-day timeline link is included in the original post.

## Prompt

```text
Set yourself up as my personal assistant. First, triage my inbox each morning into [urgent / needs reply / FYI], then write a short daily briefing with today's calendar and a suggested plan for my time. Finish when I have a working morning briefing for [my email and calendar], and show me any reply or calendar change before you send it.
```
