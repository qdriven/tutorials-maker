# Create a subtitled video from one prompt

> Agent Mode in Grok Imagine made a 36-second video with matching scenes from different angles, a storyline and subtitles.

**Category:** Content & Creative  
**Agent:** Grok Bot  
**Source:** X · Jul 19, 2026

## What they did

User entered a simple prompt into Agent Mode in Grok Imagine. The agent took the prompt and a single image, then generated matching scenes from different angles, built a full visual storyline, and added subtitles to produce the complete video on its own.

## How it went

It produced a 36-second video in five minutes. No shortcomings are stated.

## Worth knowing

The full process took just five minutes.

## Prompt

```text
Make a [length]-second video about [story or topic] in Grok Imagine's Agent Mode. Plan a short storyline, generate matching scenes of the same subject from different angles, and add subtitles that follow the story. Finish with one exported video and the subtitle text so I can edit it.
```
