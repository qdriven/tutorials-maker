# Automate copy-paste and backend wiring work with Codex

> A commenter says they use Codex for work that used to involve lots of copy-pasting and backend wiring.

**Category:** Work & Operations  
**Agent:** Codex  
**Source:** Reddit · May 20, 2026

## What they did

The commenter uses Codex app and CLI, after setting it up through MCP and signing into ChatGPT, to automate mobile-game asset creation and the backend hookup work that used to require lots of copying and pasting. They give Codex instructions like generating and downloading sprite sheets from a theme file and saving them into a hierarchical assets folder, then leave it to run and check back later.

## How it went

They say an hour later the folder is filled with the sprites they need and that this removes a tedious part of the job so they can focus on more important work. They do not give output counts or describe failures in their own workflow.

## Worth knowing

Their practical catch is setup: they mention installing it via MCP and signing into ChatGPT before they could use those Codex CLI workflows.
