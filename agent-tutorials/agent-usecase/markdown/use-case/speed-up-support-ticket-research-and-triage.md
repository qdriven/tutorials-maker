# Speed up support ticket research and triage

> A ClickUp support engineer built a system cutting per-ticket research from 15 to 4 minutes across 5,000+ monthly tickets; Mercari handles first replies for 97% of tickets.

**Category:** Sales, Marketing & Support  
**Agent:** Zapier Agents  
**Source:** zapier.com · Undated

## What they did

The source is a listing page with only short blurbs, so it has little on mechanics. Corey Smith, a Senior Technical Support Engineer at ClickUp, built a system for the research that comes before a rep replies to each ticket. Mercari built an AI support orchestration system on Zapier that handles first replies.

## How it went

ClickUp's research time per ticket fell from 15 minutes to 4, about 917+ hours a month across 5,000+ tickets. Mercari handles first replies for 97% of tickets and resolves roughly 47,000 a month through automation alone.

## Worth knowing

This page gives no build details, tools or costs. Read the full ClickUp and Mercari stories on Zapier's site before copying either approach.
