# Run an outbound sales pipeline with specialized agents

> A set of agents on Grok Bot finds prospects, researches them, writes personalized messages, launches campaigns, qualifies replies and manages the pipeline.

**Category:** Sales, Marketing & Support  
**Agent:** Grok Bot  
**Source:** X · Sep 1, 2026

## What they did

Agents on Grok Bot each receive a defined role and access to the GojiberryAI MCP. Signal Hunter locates prospects with buying signals and passes them to ICP Analyst for fit checks, then to Account Researcher, Lead Enricher, Intent Scorer, LinkedIn Copywriter, and Outreach Operator for contact. Reply Agent, Follow-up Agent, Meeting Qualifier, and Pipeline Analyst continue the handoffs while Sales Manager coordinates. User installs the open-sourced Sales OS in Grok Bot.

## How it went

The system runs end-to-end prospecting, outreach, and qualification autonomously once installed. Source gives no results or conversion numbers.

## Worth knowing

Comment BOT on the post for the install link; 7-day free trial available at gojiberry.ai.

## Prompt

```text
Set up an outbound sales pipeline for [my business and what I sell]. Find 25 prospects matching [ideal customer profile], research each one, and draft a personalized first message for each, then give me the list with drafts in a spreadsheet. Do not send any messages or launch any campaign until you show me the drafts and I approve them.
```
