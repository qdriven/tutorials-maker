# Clear Gmail spam folder with a browser agent

> A reviewer had Comet clear their Gmail spam folder, which worked; adding recipe ingredients to an Instacart cart struggled.

**Category:** Life Admin & Home  
**Agent:** Perplexity Comet  
**Source:** tech.yahoo.com · Undated

## What they did

A PCMag writer used Perplexity's Comet browser exclusively for a week in place of Chrome. Comet has an assistant that can pilot the browser. They opened Gmail and told it to clear out the spam folder. They also asked it to find an oyakodon recipe and add the ingredients to Instacart. The source gives few step-by-step details.

## How it went

Comet cleared the spam folder. It struggled to add items to the Instacart cart. The writer says it often gets stuck or fails, and is usually slower than doing the task by hand.

## Worth knowing

Comet access currently requires an invitation or a Perplexity Max subscription at $200 per month, and the AI features pushed memory use past 4GB.

## Prompt

```text
Open my Gmail and go to the Spam folder. Scan the messages, tell me how many there are and whether any look like real mail from [people or companies I know], then wait for my okay. After I confirm, permanently delete the remaining spam and report how many were removed. Do not touch any other folder.
```
