# Run systematic literature reviews with a research agent

> Poster recommends a research-focused tool that does systematic review (slow but strong), adds notes to papers, and builds a research project over time.

**Category:** Research & Knowledge  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Aug 1, 2025

## What they did

In the Reddit thread, the concrete recommendation for this use case is Elicit’s paid systematic review mode. One commenter says it is “one of the best” but slow; another later suggests pmchat.app because its assistants search PubMed, add finding notes to papers, save papers to a library, and organize them in folders so a research project persists instead of resetting with each chat.

## How it went

The thread gives no benchmark numbers or study results. The main tradeoff stated is that Elicit’s free report is only so-so, while the paid systematic review workflow is stronger but slow.

## Worth knowing

The clearest catch is speed: the commenter says the paid systematic review mode is among the best, but slow.

## Prompt

```text
I need a systematic literature review on [research question]. Search academic sources, define inclusion and exclusion criteria with me first, then screen papers and build a table of each study's authors, year, method, sample and findings. Finish with a short synthesis and a list of full citations with links, and flag any paper you could not verify.
```
