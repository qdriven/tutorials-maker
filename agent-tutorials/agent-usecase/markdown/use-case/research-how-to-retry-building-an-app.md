# Research how to retry building an app

> The poster had Cowork read their own Reddit post and then search the web for how to try making an app again.

**Category:** Research & Knowledge  
**Agent:** Claude Cowork  
**Source:** Reddit · Nov 1, 2025

## What they did

The poster told Claude Cowork to read their earlier Reddit post about struggling to build a Wispr Flow app, search the internet for what was going wrong, and figure out how to try again. After Cowork reported it had identified the problem, the poster had it use terminal access through Claude’s desktop commander extension to direct Claude Code and handle the technical back-and-forth instead of doing that themselves.

## How it went

The poster says this got them a working version of their app after four months of failed attempts, and elsewhere says Cowork did in one to two hours what they could not do in three to six months with Claude Code alone. They do not give technical details of the fix itself.

## Worth knowing

The main catch is risk: the setup involved giving the agent access to the computer and terminal, which the poster says they accepted because they kept sensitive files elsewhere.
