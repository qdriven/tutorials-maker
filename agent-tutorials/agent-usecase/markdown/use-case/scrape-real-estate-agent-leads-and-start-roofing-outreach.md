# Scrape real estate agent leads and start roofing outreach

> An OpenClaw agent scraped Zillow, Redfin and Realtor.com for agents listing older homes, saved contacts and listings to a CSV, then began outreach for a roofing company.

**Category:** Sales, Marketing & Support  
**Agent:** OpenClaw  
**Source:** X · Mar 15, 2026

## What they did

The user prompted his OpenClaw agent Cody via Discord on his phone from a plane. Cody scraped Zillow, Redfin, and Realtor.com for agents listing homes built 1965-2000 in the service area, pulling brokerage, phone, email, active listings, addresses, and year built into a CSV saved to Google Drive. Cody then began outreach.

## How it went

A CSV arrived in Google Drive. Outreach started with no reported lead counts or results.

## Worth knowing

All executed remotely with no employees or VA.

## Prompt

```text
Search Zillow, Redfin, and Realtor.com for real estate agents in [city or region] who have listings of homes built before [year]. Save each agent's name, brokerage, email or phone, and the listing addresses to a CSV file called [filename]. Then draft a short outreach email from [my roofing company] to each agent, but pause and show me the drafts before sending anything. You're done when the CSV is saved and the drafts are ready for my review.
```
