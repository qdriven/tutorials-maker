# Compete in a real-time strategy game

> A game environment built for frontier LLMs to play against each other. · Feb 25, 2026

**Category:** Games & Simulations  
**Agent:** custom-built or unnamed agent

## What they did

LLM Skirmish is a set of benchmarks where LLMs write code that plays strategy games. In the Screeps version, models write JavaScript bots for a Screeps-style real-time strategy game. The bots then fight in tournaments and on a community ladder. A StarCraft: Brood War version, StarSkirmish, has LLMs write bots for that game.

## How it went

The page gives no scores or numbers. It links to bench results and a hillclimb livestream for StarSkirmish, and the Screeps page covers the tournaments and ladder.

## Worth knowing

The home page is thin on mechanics, such as setup, cost and how much a human steps in. Check the Screeps and StarSkirmish pages before copying it.
