# Handle personal admin chores via Telegram agent

> Hermes checked the user into a flight, chased a Student Finance refund, disputed a parking warning, found delivery evidence, unsubscribed from spam and filed a prescription in Paperless.

**Category:** Life Admin & Home  
**Agent:** Hermes Agent  
**Source:** Reddit · Sep 1, 2026

## What they did

The user ran a Hermes AI agent mainly through Telegram and used it for two weeks as a personal assistant for life admin. From the post, the agent read emails, acted on websites, generated files like a cleaner boarding pass, set up flight updates, and handled chores such as chasing a roughly £2,000 Student Finance refund, disputing a Lime parking warning, finding delivery evidence, unsubscribing from spam, and saving an eye prescription into Paperless.

## How it went

It completed a wide range of personal admin and travel tasks, including an ANA check-in and extra bag booking, and the user says this is the kind of boring work they would otherwise procrastinate on. It also failed at times, including using a bad weather source, suggesting a bad cycle route, forgetting a vegan meal, and sometimes misunderstanding instructions.

## Worth knowing

The user says they had been using Hermes for about five months, and a commenter estimated API use at about $0.30 per minute or roughly $5 per task.

## Prompt

```text
Help me clear these personal admin tasks through our chat: [list tasks such as check in for flight, chase a refund from X, dispute a parking charge, unsubscribe from spam, file a document]. Work through them one by one and report what you did. Before sending any message, submitting any form, or deleting anything, show me exactly what you're about to do and wait for my OK. Finish with a checklist of done and pending items.
```
