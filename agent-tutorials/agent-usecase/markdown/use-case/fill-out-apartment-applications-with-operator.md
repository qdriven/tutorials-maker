# Fill out apartment applications with Operator

> A user had Operator apply to apartments by filling out web forms on their behalf and says it worked quite well.

**Category:** Life Admin & Home  
**Agent:** Operator  
**Source:** Reddit · Undated

## What they did

The poster says they used Operator over two days to apply to apartments by submitting rental listing forms for them. According to the thread, it contacted about 20 to 30 listings on its own, and the user also says they used a VPN and had no trouble using other languages or non-US websites.

## How it went

They report it worked quite well and led to their first apartment viewing by the second day. The main issue was that one website blocked Operator, and they worried that might become more common.

## Worth knowing

The clearest constraint from the post is site blocking: at least one application page would not let Operator proceed.

## Prompt

```text
Fill out rental applications for these apartment listings: [listing URLs]. Use my details: [name, email, phone, income, move-in date, number of occupants, pets]. Before submitting each application, pause and show me the filled-out form for review, and don't enter SSN or payment details, I'll do those. Done when every application is ready for me to submit or has a note on why it couldn't be completed.
```
