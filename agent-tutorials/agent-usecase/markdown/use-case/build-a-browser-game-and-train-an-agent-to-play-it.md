# Build a browser game and train an agent to play it

> Grok built the browser game Roofline, then trained a PPO agent that plays the live page, reaching a best score of 39,359.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** X · Sep 1, 2026

## What they did

The user prompted Grok to create the Roofline browser game. Grok then trained a PPO agent to interact directly with the live page at roof.grok.me. A person supplied the prompts and recorded the runs.

## How it went

The best recorded run reached 39,359 score, 4,924 meters, and combo 117.

## Prompt

```text
Build a simple browser game based on [game idea] and host it so it's playable at a live link. Then train a reinforcement learning agent, such as PPO, to play it, and report its best score and a few examples of how it plays. Finish with the game link, the training code, and a short summary of results.
```
