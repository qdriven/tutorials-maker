# Control a PC and launch World of Warcraft from your phone

> A writer had Claude Code run desktop tasks like Calculator to Notepad and, via Dispatch from his phone, launch Battle.net and log into a World of Warcraft character.

**Category:** Life Admin & Home  
**Agent:** Claude Code, Claude Cowork  
**Source:** xda-developers.com · Undated

## What they did

Simon Batt installed Git and enabled computer-use permissions for Claude Code on his Windows PC. A plain-English prompt had it open Calculator, multiply two numbers, and save the result to Notepad on the Desktop. With Dispatch linking his phone to the PC, he sent one message and Claude opened Battle.net, started World of Warcraft, waited through login, and picked a character.

## How it went

Both tasks worked. For the WoW request, Claude reported back when finished and the character was logged in. The article offers only these simple demos, and commenters questioned how useful they are.

## Worth knowing

Setup needed Git and manual permission to control the computer. The article gives no cost, though a commenter says Claude Code is on the $20/month Pro plan.

## Prompt

```text
On my desktop computer, open [Calculator], work out [a simple calculation], and paste the result into [Notepad or notes app] saved as [filename]. Then open [game launcher, e.g. Battle.net] and get it to the login screen for [game or character]. Pause and show me what you are about to do before entering any password or launching the game, and stop once the launcher is ready.
```
