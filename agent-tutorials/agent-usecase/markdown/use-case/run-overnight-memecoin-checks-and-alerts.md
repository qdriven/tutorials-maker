# Run overnight memecoin checks and alerts

> Grok Bot ran a taught 4-minute memecoin check 3,140 times overnight across several sites, wrote reports, and generated 160 alerts; the user claims $9,320 profit.

**Category:** Money, Bills & Benefits  
**Agent:** Grok Bot  
**Source:** X · Oct 10, 2026

## What they did

User recorded their 4-minute memecoin routine once (dexscreener, gmgn top traders tab, rugcheck, bubblemap, X pre-call buyers) and had the Grok Bot replicate it on its cloud computer. The bot created a team of agents: scout watching launches and KOLs every 5 minutes, checker repeating the routine, reporter writing one-line verdicts with screenshots, and handing to human jev for final buy decisions. It ran overnight with the laptop closed.

## How it went

Over 30 days the system checked 3140 coins, skipped 2980, generated 160 alerts, and supported 52 trades for +$9320 profit.

## Worth knowing

Bot never received wallet keys; all trades executed manually by jev from a limited-size wallet.

## Prompt

```text
I'll teach you my routine for checking [type of token or asset] across [sites]. Once it's right, run it every [4 minutes] overnight, write a short report on each pass, and send me an alert only when [my criteria] is met. Don't buy, sell, or move any funds. Alerts and reports only, and I'll decide what to do.
```
