# Run portfolio, attribution and real estate analyses with Agent Mode

> A reviewer ran ChatGPT Agent Mode through five business tests, including equity portfolio analysis, marketing attribution and real estate scenarios, noting where it needed babysitting.

**Category:** Work & Operations  
**Agent:** ChatGPT Agent  
**Source:** natesnewsletter.substack.com · Undated

## What they did

The reviewer gave Agent Mode five business tasks: analysing a portfolio of about three dozen equities, multi-country marketing attribution across hundreds of channels, and real estate acquisition scenarios across US ZIP codes. The other two were a startup growth plan and cross-border incorporation planning. The agent could reach Google Drive, edit spreadsheets, browse the web and build presentations. The reviewer documented each run and kept the outputs.

## How it went

The reviewer's overall grade for the 2025 thesis that LLMs with tools do useful work is about a C. Agent Mode works in spots but still needs babysitting. The detailed per-test results are behind a paywall.

## Worth knowing

Only the intro is free. The per-test findings and the assets Agent Mode produced require a paid subscription, so the specific failures weren't visible.

## Prompt

```text
Analyze [portfolio holdings, marketing data or property scenario] using the data in [file or link]. Produce a spreadsheet with your calculations and a one-page summary of the main findings, assumptions and risks. Stop and ask me if you hit missing data rather than guessing, and finish when I have both files.
```
