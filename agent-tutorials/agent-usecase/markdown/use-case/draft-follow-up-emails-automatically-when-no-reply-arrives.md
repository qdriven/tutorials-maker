# Draft follow-up emails automatically when no reply arrives

> A user set up a Lindy flow that watches sent emails, waits for a reply, and drafts a follow-up if none comes.

**Category:** Work & Operations  
**Agent:** Lindy  
**Source:** Reddit · Feb 1, 2024

## What they did

One commenter said they set up a Lindy flow tied to their sent email so that after each outgoing message, the AI waits a set amount of time and checks for a reply. If no response arrives, it drafts a follow-up and sends that draft to the user's inbox, where the person decides whether to send it.

## How it went

The user said they had started using it the day before and that it was working well so far. The thread gives no metrics, volumes, or longer-term results for this follow-up flow.

## Worth knowing

The practical catch from the source is that the follow-up was drafted for human review in the inbox, not sent automatically.

## Prompt

```text
Build a flow that watches my sent emails in [Gmail or Outlook] for messages to [type of recipient, e.g. clients or prospects]. If there's no reply after [number] business days, draft a short, polite follow-up in my voice that references the original message, and save it as a draft in my inbox. Never send anything automatically; show me the first draft and the flow setup before you turn it on.
```
