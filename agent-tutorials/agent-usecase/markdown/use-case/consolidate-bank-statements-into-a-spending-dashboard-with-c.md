# Consolidate bank statements into a spending dashboard with Claude

> Miles Deutscher reportedly uses Claude to merge monthly bank statements into a dashboard, visualize spending, compute metrics and analyze portfolio allocation.

**Category:** Money, Bills & Benefits  
**Agent:** Claude  
**Source:** X · Oct 3, 2026

## What they did

Miles Deutscher drags monthly bank statements into Claude. The model consolidates the statements, builds a dashboard for spending visualization and calculations, and analyzes portfolio allocation. The user double-checks outputs because the model can hallucinate.

## How it went

This let him handle his basic passive portfolio without full-time high-cost advisers, though he still seeks occasional consulting advice.

## Worth knowing

Always verify AI outputs manually as hallucinations remain possible.

## Prompt

```text
I've put my monthly bank statements from [months] in [folder]. Merge them into one spreadsheet, categorize each transaction, and build a dashboard showing spending by category, monthly totals, and [metrics, e.g. savings rate]. If I add [portfolio holdings file], also show my allocation by asset type. Finish by telling me the three biggest things you notice, and do not change or delete my original files.
```
