# Pre-qualify inbound leads automatically

> Futurepedia uses a Zapier Agent to research each inbound lead's company, write a fit-brief, and route the best ones to sales, with no SDR involved.

**Category:** Sales, Marketing & Support  
**Agent:** Zapier Agents  
**Source:** X · Mar 6, 2026

## What they did

Futurepedia set up a Zapier Agent triggered by inbound leads. The agent researches each company, writes a fit-brief, and routes the best ones to sales. It ran through 5 fully automated steps with no SDR involved.

## How it went

Leads reached sales pre-qualified with no manual inbox review required.

## Prompt

```text
Build an agent that triggers whenever a new lead arrives from [form or CRM name]. For each lead, research their company using [their website and LinkedIn], write a short brief covering what they do, size, and how well they fit our ideal customer, which is [describe your ICP]. If the fit is strong, post the brief to [Slack channel or sales owner's email] and add it to [CRM]; otherwise log it without notifying anyone. Show me a test run on [sample lead] before turning it on.
```
