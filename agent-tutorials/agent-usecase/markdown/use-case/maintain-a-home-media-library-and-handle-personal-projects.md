# Maintain a home media library and handle personal projects

> Commenters say Grok Bot manages a Plex library with backups, deduplication, thumbnails, and collections, and helped build a Tesla HUD display after finding old purchase emails.

**Category:** Life Admin & Home  
**Agent:** Grok Bot  
**Source:** Reddit · Oct 11, 2026

## What they did

One commenter said they use Grok Bot to run a home media library around Plex by doing the jobs they used to do manually. They said they asked it to standardize folders and filenames, sync and schedule backups, deduplicate, find missing posters, delete empty folders, and create custom thumbnails, descriptions, categories, and collections for films, TV, combat sports, documentaries, and creator videos; another said Grok Bot checked old email purchases to identify spare AliExpress parts and helped make a Tesla HUD that mirrors an S3XY Knob display onto a Tita HUD using an ESP32.

## How it went

The thread reports both setups working, but gives no hard metrics on time saved or reliability. The clearest limitation is that the media-library commenter shared no deeper setup details beyond prompting Grok to take over those tasks.

## Worth knowing

The practical catch from the thread is that the Plex setup was described as simple prompting rather than a documented integration, so anyone copying it would need to work out the actual wiring themselves.

## Prompt

```text
Go through my home media library in [folder or server location]. Find duplicate files, list missing thumbnails or poor metadata, and propose collections grouped by [theme, like franchise or genre]. Make a backup first, then show me a list of what you plan to delete or rename and wait for my approval before changing anything.
```
