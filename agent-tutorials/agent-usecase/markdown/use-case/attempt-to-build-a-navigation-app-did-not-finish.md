# Attempt to build a navigation app (did not finish)

> A poster tried to build a navigation app with Manus but spent a month of credits and over 8 hours without a working app.

**Category:** Software & DevOps  
**Agent:** Manus  
**Source:** Reddit · Undated

## What they did

A commenter described using Manus on their first day to build a navigation app with live maps, lane guidance, and voice directions. The agent iterated through repeated debugging and five APK builds: fixing Expo Go crashes, guiding the user through EAS CLI builds, changing how the API key was embedded, removing the live map for a static one, then trying a WebView-based live map; the user did the testing and rebuild steps.

## How it went

After more than 8 hours and 8,100 credits, they still did not have a working navigation app. Search eventually worked, but navigation kept crashing, and one temporary version only showed a static map with text directions.

## Worth knowing

The clearest catch was cost and time: one failed first-day attempt used an entire monthly 8,100-credit allocation and ran past 2:41 AM.

## Prompt

```text
I want to build a simple navigation app for [platform] that does [core feature, e.g. route from A to B with turn-by-turn directions] using [map service]. Begin with the smallest working version, test it, and show me what runs before adding anything more. Stop and check with me after each milestone, and tell me before spending a large amount of credits.
```
