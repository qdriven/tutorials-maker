# Shop for a shirt and place the order

> An AI agent compared six brands on sizing, return policies, and shipping minimums, found the nearest store, picked a size, and ordered a white dress shirt.

**Category:** Shopping & Errands  
**Agent:** custom-built or unnamed agent  
**Source:** X · Oct 2, 2026

## What they did

User prompted the agent to shop for a white dress shirt. It compared six brands on sizing, return policies, and free shipping minimums, found the nearest store, picked the size, and placed the order on its own. The user provided no further input after the initial request and did not visit any brand sites.

## How it went

The order was completed. The source states no specific brand, price, delivery details, or shortfalls.

## Prompt

```text
Find me a [item, e.g. white dress shirt] in size [size]. Compare [number] brands on sizing, return policy, shipping minimums, and price, and find the nearest store to [location] that has it. You are done when you've recommended one option and added it to the cart. Show me the cart and total and wait for my approval before placing the order.
```
