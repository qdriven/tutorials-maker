# Use the Codex app for ongoing non-coding research

> The poster uses the Codex app as a stateful way to build knowledge and data over time, processing their department and applying that context to cross-discipline tools.

**Category:** Research & Knowledge  
**Agent:** Codex  
**Source:** Reddit · Undated

## What they did

The poster says they use the Codex app as a stateful research workspace rather than just for coding, because it can accumulate context and knowledge over time across chats. They also rely on an AGENTS.md file for persistent style and instruction control, and describe switching between coding or desktop operations and detailed question-answering inside the same app.

## How it went

The reported result is qualitative: they preferred Codex’s answers to ChatGPT’s Research mode and found it useful for lightweight web searches and ongoing research. The main downside mentioned in the thread is that the app still felt bare-bones.

## Worth knowing

One practical catch from the comments is that Codex usage shares the same overall chat-model quotas across ChatGPT, web, Codex app, and Codex CLI, except for Codex Spark.

## Prompt

```text
I want to use you as an ongoing research partner for [my department or topic]. Read the documents in [folder path], build a structured knowledge base in [format] covering key people, processes, data, and open questions, and write down how you organized it so you can pick up where you left off next session. You're done when I can ask you a question about [topic] and you answer from the saved notes with sources, and you should tell me before changing or deleting any of my original files.
```
