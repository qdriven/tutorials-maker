# Draft support answers from docs and hand off to reps

> A commenter's agents on a cloud computer read docs, draft answers, and hand customers to a rep with the full conversation, with outbound messages awaiting approval.

**Category:** Sales, Marketing & Support  
**Agent:** custom-built or unnamed agent  
**Source:** Reddit · Sep 21, 2026

## What they did

One commenter said their Skydive agents run on a cloud computer and work through Slack and email rather than on live phone calls. They read company docs, draft customer answers, and when a case needs a person they hand it to a rep with the full conversation attached; any outbound customer message waits for human approval, and the commenter stressed checking that every answer cites a source and declines when the docs do not cover it.

## How it went

The thread gives no team metrics or rollout numbers; the commenter said everything is still early. They also said it is not a replacement for live call assist tools and does not integrate with Salesforce.

## Worth knowing

They offered a small pilot detail: a REDDITAMA code for $25 in credit, and said the main thing to test is how the system fails when docs are stale or missing.

## Prompt

```text
Create an assistant that reads our docs at [link or folder] and drafts answers to incoming customer questions from [channel]. When a question needs a person, hand it to [rep name] with the full conversation attached. Never send a message to a customer until I approve the draft.
```
