# Build a local landmarks map app from one prompt

> The author prompted Replit Agent to make a map of local landmarks and got a working Flask web app with an interactive map and Wikipedia integration in about 10 minutes.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** medium.com · Undated

## What they did

Using a Replit account with AI access, the author chose Create with Replit Agent and typed one sentence asking for a map of local landmarks. The Agent first proposed a plan: a Flask app, Wikipedia's API for landmark data, and a map frontend. It then wrote the backend, frontend, and map markers, and showed a running preview. The author could approve or change the plan and ask for follow-up changes.

## How it went

The article says it took about 10 minutes to get a working Flask app with an interactive map and Wikipedia integration. It reports no problems or failures. The code shown leaves the marker coordinates undefined.

## Worth knowing

The AI features were part of Replit's Core plan at the time, though free trials were often available. The author advises reviewing the generated code and building up in small steps.

## Prompt

```text
Build me a web app with an interactive map of landmarks in [my town or region]. Each marker should show the landmark's name, a short summary and a photo pulled from Wikipedia, with a link to the full article. Stop when the app runs in the preview with at least [10] landmarks on the map and the marker pop-ups load correctly.
```
