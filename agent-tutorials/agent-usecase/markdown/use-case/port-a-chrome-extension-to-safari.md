# Port a Chrome extension to Safari

> The author had ChatGPT take the Session Buddy extension source from Chrome, port it to Safari and install it, taking about 20 minutes.

**Category:** Software & DevOps  
**Agent:** ChatGPT  
**Source:** HN · Oct 13, 2026

## What they did

The author already had Session Buddy installed in Chrome, so they told ChatGPT it could pull the source code from there. They then asked it to port the extension to Safari and install it. The comment describes no further steps or manual intervention.

## How it went

After about 20 minutes, Session Buddy was running in Safari. The author estimates a few dollars in tokens, though it actually used about 6% of their $20/month plan.

## Prompt

```text
I want to port the Chrome extension [extension name] to [Safari or another browser]. Here is the source code or repo link: [paste or link]. Convert it, list any APIs that don't work in the new browser and how you handled them, and give me step-by-step instructions to build and install it locally. You're done when I can load it and the main features work; tell me before changing anything that affects my data.
```
