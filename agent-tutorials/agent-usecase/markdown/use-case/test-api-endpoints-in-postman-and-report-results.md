# Test API endpoints in Postman and report results

> @ai_for_success used Comet to generate test payloads from context, run API endpoint tests in Postman and produce a final report.

**Category:** Software & DevOps  
**Agent:** Perplexity Comet  
**Source:** X · Nov 30, 2025

## What they did

User supplied Comet with context on the API payloads and details, then let it handle testing in Postman. Comet generated multiple test payloads, executed the endpoint tests itself, and produced a final report after the run.

## How it went

Comet completed the tests and delivered the report with no further input required.

## Prompt

```text
Open [Postman workspace or collection URL] and, for each endpoint in [collection name], generate realistic test payloads based on the API docs at [docs URL]. Run the requests and record the status code, response time, and any errors. Finish with a short report listing which endpoints passed and failed and why. Don't modify or delete any existing requests, and use only the [staging or test] environment.
```
