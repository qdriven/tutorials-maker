# Organize a Friday night with friends

> The Instinct agent coordinated with friends' agents, picked food, drinks and a movie, synced timing, placed the order and added it to the calendar.

**Category:** Life Admin & Home  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 15, 2026

## What they did

User told the Instinct agent to organize a Friday night with friends. The agent coordinated directly with each friend’s Instinct agent, selected food and drinks plus a movie, aligned everyone’s availability, placed the order, and added the event to the calendar.

## How it went

The plan was finalized without any group chat, availability questions, or follow-ups; the user only gave the initial command and received confirmation that it was locked in.

## Prompt

```text
Help me plan a Friday night in with [friends' names]. Suggest three options for food, drinks, and a movie based on these preferences: [dietary needs and tastes], and propose a start time that fits everyone's availability. Once I pick, show me the full order and calendar event before you place the order or send invites.
```
