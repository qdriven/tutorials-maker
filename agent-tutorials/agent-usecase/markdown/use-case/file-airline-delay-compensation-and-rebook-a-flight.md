# File airline delay compensation and rebook a flight

> A user had Muse file for compensation after a 7-hour delay, getting a $250 Delta credit, rebooking a new flight and answering the support email.

**Category:** Travel & Bookings  
**Agent:** Meta Muse  
**Source:** tech.yahoo.com · Undated

## What they did

After a 7-hour flight delay, the user (@cryptopunk7213 on X) asked Muse to file for compensation. According to the user's tweet, Muse handled the claim, found and rebooked a new flight, and replied to the airline's support email on its own. The article only relays the tweet, so it gives no detail on setup or permissions.

## How it went

About five minutes later, the user had a $250 credit in their Delta account, plus the rebooked flight. The source is a single self-reported tweet, with no independent check.
