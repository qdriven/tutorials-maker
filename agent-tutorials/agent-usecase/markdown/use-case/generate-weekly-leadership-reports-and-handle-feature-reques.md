# Generate weekly leadership reports and handle feature requests

> A supervisor Zapier agent delegates to sub-agents that write weekly leadership reports from Jira data and handle feature requests via a Slack slash command.

**Category:** Work & Operations  
**Agent:** Zapier Agents  
**Source:** X · Feb 19, 2026

## What they did

A supervisor Zapier agent was built with access to Jira and Slack, then set to delegate to sub-agents. One sub-agent pulls Jira data on its own to produce weekly leadership reports. The other responds to feature requests triggered directly by a Slack slash command.

## How it went

The agents handled report writing and request processing without manual ticket copying or context switching.

## Prompt

```text
Create a supervisor agent with two sub-agents. One writes a weekly leadership report from [Jira project] data covering progress, blockers, and risks and posts it to [Slack channel]. The other handles feature requests from a Slack slash command [command name] by logging them in [tool]. Show me a sample report and a sample request entry before activating.
```
