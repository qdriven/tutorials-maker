# Build four games in parallel with agents

> Four Grok 4.20 agents built a tower defense, mini Factorio, CHIP-8 emulator and roguelike shooter in parallel over a day.

**Category:** Games & Simulations  
**Agent:** Grok Bot  
**Source:** X · Feb 17, 2026

## What they did

The user directed Grok 4.20 at game development tasks. Its four agents split each problem on every prompt, built components in parallel, and merged the outputs. This produced a tower defense game, a mini Factorio, a CHIP-8 emulator, and a roguelike shooter.

## How it went

All four games were completed in one day. The emulator correctly implemented the full opcode set on the first pass.

## Worth knowing

The entire effort took a full day.

## Prompt

```text
Build [number] small browser games in parallel: [game idea 1], [game idea 2], and [game idea 3]. For each, make it playable in a browser with simple controls, and give me a link to try it. Stop when each game runs without errors, and summarize what each one does and what is missing.
```
