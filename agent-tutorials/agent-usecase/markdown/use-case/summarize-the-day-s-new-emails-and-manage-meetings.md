# Summarize the day's new emails and manage meetings

> A user asked an AI assistant to summarize emails received that day and got a summary in under 30 seconds; it also handles meeting summaries, action items, calendar and drafts.

**Category:** Work & Operations  
**Agent:** custom-built or unnamed agent  
**Source:** X · Sep 28, 2026

## What they did

User connected LittlebirdAI to email, calendar, meetings and apps to build ongoing context. After church the user prompted it with a request for new mail while tired and the agent used its stored context to pull and summarize the day’s inbox. It also summarizes meetings with action items, checks calendar, drafts replies and creates routines.

## How it went

Returned a clear summary in under 30 seconds. Reduced stress and mental load; no specific shortfalls reported.

## Prompt

```text
Summarize all emails I received today in my [Gmail]. Group them as needs reply, FYI, and ignore, and list any meetings or deadlines mentioned. For the needs-reply group, draft short responses but don't send them. Finish with a summary I can read in under a minute.
```
