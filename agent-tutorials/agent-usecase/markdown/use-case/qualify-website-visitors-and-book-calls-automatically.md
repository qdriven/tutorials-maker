# Qualify website visitors and book calls automatically

> A builder made an n8n booking agent that chats with website visitors, qualifies them, and books call slots around the clock without humans.

**Category:** Sales, Marketing & Support  
**Agent:** n8n  
**Source:** X · Sep 27, 2026

## What they did

The builder created the agent in n8n. It was connected to the website to chat with visitors. The agent chats, qualifies them, and books the slot on its own, running 24/7 with no human involvement.

## How it went

It turns website visitors into booked calls.

## Prompt

```text
Build an n8n chat agent for my website that greets visitors, asks [3 qualifying questions, e.g. company size, need, budget], and offers open call slots from [calendar]. If the visitor qualifies, book the slot and send a confirmation. Test it with three sample conversations, and show me the booking and email steps before turning it on.
```
