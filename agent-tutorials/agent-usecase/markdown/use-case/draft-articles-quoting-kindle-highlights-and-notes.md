# Draft articles quoting Kindle highlights and notes

> The author saves Kindle highlights and event notes in Obsidian and has Cursor reference them to quote past reading when drafting articles.

**Category:** Content & Creative  
**Agent:** Cursor  
**Source:** note.com · Undated

## What they did

The author uses the Obsidian Kindle plugin to save book highlights as Markdown files, alongside event notes and daily thoughts. In Cursor's User Rules they describe the vault folders and a quoting format, and add a writing-style instruction. Cursor reads the directory directly, with no MCP connection, finds relevant passages and quotes them in drafts. The author then edits.

## How it went

Cursor found and cited past reading, such as team-related books, and produced a structured draft in the author's style. The output still felt a bit off, so the author edited it substantially.

## Worth knowing

Initial setup takes some time, and the drafts still need heavy human editing.

## Prompt

```text
My Kindle highlights and event notes are in [Obsidian folder path]. Draft an article on [topic] of about [word count] words, quoting relevant highlights with the book title and author named for each. Mark which notes you used. Finish with one clean draft in [file name] and do not change my source notes.
```
