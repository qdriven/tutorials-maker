# Build a Pokemon-style dog collecting app

> A user had Replit Agent build a catch-em-all dog app whose rarity comes from scraped American Kennel Club regional population data.

**Category:** Software & DevOps  
**Agent:** Replit Agent  
**Source:** X · Aug 16, 2026

## What they did

User instructed Replit Agent to build the full app. The agent scraped American Kennel Club regional population data to set dog rarity values for catches. Source states the agent handled the entire build.

## How it went

App was completed as a dog-themed catch-em-all experience. No further results or shortfalls reported.
