# Build dashboards and troubleshoot support cases

> Commenters use Microsoft Scout to build a dashboard that persists across reboots and to document and troubleshoot support cases end to end.

**Category:** Work & Operations  
**Agent:** Microsoft Scout  
**Source:** Reddit · Jun 6, 2026

## What they did

Commenters describe Microsoft Scout as a desktop agent tied into WorkIQ and Microsoft 365 connectors like email, Teams, SharePoint, Word, and PowerPoint, with support for custom skills and MCPs via the same .copilot directory as Copilot CLI. In practice, one person used it over several days to build a dashboard that kept context across reboots, while another used it for support work to document cases and attempt troubleshooting from start to finish, stepping in because they did not fully trust it.

## How it went

The reported result was strong day-to-day usefulness: one commenter said the dashboard work had not missed a trick and another said Scout was amazing and used daily. The main limits mentioned were setup friction, fast GitHub Copilot credit burn, and hesitation to rely on it fully for troubleshooting.

## Worth knowing

One commenter said the live Frontier desktop version uses your device hardware, so the machine must be on; others also warned it can burn through GitHub Copilot budgets quickly.

## Prompt

```text
Build me a dashboard that shows [metrics or data, e.g. open support tickets by status] from [data source, e.g. this spreadsheet or folder] and set it up so it keeps working after I reboot my computer. Then take this support case [describe the issue], document the troubleshooting steps and findings, and write up a resolution summary. Before changing any settings or sending anything to a customer, pause and show me what you're about to do.
```
