# Build a personal portfolio site with AI chat as a non-developer

> A designer used Claude Code to build a personal website with an AI chat about their work in 48 hours, then shipped a growth design tool days later. · Oct 29, 2026

**Category:** Software & DevOps  
**Agent:** Claude Code  
**Source:** adplist.substack.com · Oct 29, 2026 · Submitted by from search gap: 网站

## What they did

Felix Lee, a designer, installed Claude Code and had it write a plan.md for a portfolio site. He reviewed the plan and changed the stack to plain HTML/CSS. Claude Code then implemented the site, and he refined it with prompts. He pushed it to GitHub and deployed on Vercel. For the AI chat, he added Supabase for the database and Google sign-in, plus OpenAI.

## How it went

He says the site with its AI chat took 48 hours. Three days later he shipped a growth design tool, which he says has over 500 users. The post gives no detail on how well the chat performed.

## Worth knowing

The guide promotes his paid course. Keep API keys in a .env file that is excluded from GitHub, and always ask for a plan before any code.

## Prompt

```text
I'm a [job, e.g. designer] with no coding background. Build me a personal portfolio website showcasing [my projects or work], plus an AI chat box where visitors can ask about my work, answering only from a facts file you create from what I tell you. Walk me through each step in plain language, get it running locally, and ask before deploying or buying a domain.
```
