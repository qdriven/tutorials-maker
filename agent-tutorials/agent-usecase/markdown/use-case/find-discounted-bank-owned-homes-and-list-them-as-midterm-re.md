# Find discounted bank-owned homes and list them as midterm rentals

> MidtermMate agent finds discounted bank-owned homes in a region, estimates local rents, and helps list them as midterm rentals, shown in a video demo.

## What they did

The MidtermMate agent was given a region and searched for discounted bank-owned or for-sale homes there. It estimated local rents for those properties and assisted with preparing listings as midterm rentals. A user started the process by requesting the region.

## How it went

The agent produced property options with rent estimates and listing help in a video demo. No specific results or shortfalls are stated.

## Prompt

```text
Find discounted bank-owned (REO) homes in [region] under [price]. For each, estimate monthly midterm rental income from comparable local listings and rank them by yield. Finish with a table of the top 10 and a draft rental listing for the best one. Do not contact anyone or post anything without showing me first.
```
