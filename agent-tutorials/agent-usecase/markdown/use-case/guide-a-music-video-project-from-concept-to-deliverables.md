# Guide a music video project from concept to deliverables

> A Hermes agent walks a creator through an 8-step workflow producing lyrics, Suno prompts, image and video prompts, and YouTube metadata.

**Category:** Content & Creative  
**Agent:** Hermes Agent  
**Source:** github.com · Undated

## What they did

You copy the skill folder into the Hermes skills directory and reload. On first run the agent asks for your projects root folder, channel name and music style, and can create the folder structure. It then works through eight steps: title, genre, lyrics with a Suno prompt, video vision, image breakdown, image prompts, video prompts, and YouTube metadata. It waits for your confirmation before each step.

## How it went

The source reports no results or example output. It describes the workflow and the pacing, which is slow and user-controlled, and says nothing about how well the outputs turned out.

## Worth knowing

You need Suno access, plus image or video tools such as Flux, Veo 3 or Kling if you want those steps. The license is CC BY-NC-SA, so commercial use is not allowed.

## Prompt

```text
Guide me step by step through making a music video about [concept]. Produce the lyrics, a Suno prompt, image prompts, video prompts, and YouTube title, description, and tags, asking me to approve each step before moving on. Finish with all deliverables collected in one document, and do not upload anything.
```
