# Make an AI trends presentation

> The author had Manus 1.6 Lite build a 2026 AI trends deck; research was deep but generation took over 10 minutes and slides were monotonous.

**Category:** Content & Creative  
**Agent:** Manus  
**Source:** pageon.ai · Undated

## What they did

The author gave Manus 1.6 Lite (free tier) only the topic "AI Trends in 2026", with default settings. The agent searched the web on its own, visibly, drawing on Deloitte, Stanford HAI and KPMG. It wrote an 11-slide outline and went straight into building slides without a review step. The author then asked it to add charts wherever needed.

## How it went

Research took over 10 minutes and was strong, with traceable sources. The slides repeated one text-card layout with no images and a single bar chart. The chart edit took 7-8 minutes and added three basic charts.

## Worth knowing

The post comes from a competing tool's vendor, PageOn.ai. Each chat edit makes Manus re-research, so budget 7-8 minutes per change, and you can't edit the outline beforehand.

## Prompt

```text
Make a [number, e.g. 12]-slide presentation on [topic, e.g. AI trends for 2026] for [audience]. Research current sources first, then vary the slide layouts so it does not look repetitive, using charts or images where useful. Finish with an exported deck and a list of the sources used.
```
