# Run roadmap, support inbox, calendar, and todos

> OpenClaw manages a Linear roadmap, prioritizes support conversations, handles calendar and todos, checks notifications, and manages sponsorship opportunities.

**Category:** Work & Operations  
**Agent:** OpenClaw  
**Source:** X · Feb 4, 2026

## What they did

The agent runs on a DigitalOcean VPS with its own forwarded email inbox, delegate X account via custom browser proxy, Linear, Obsidian for todos/PKM, and PDF extraction skill. It creates Linear cards for issues, prioritizes and flags support inbox items, schedules calendar events from images/PDFs, checks X notifications and DMs, and tracks sponsorships. User set up the VPS, accounts, and skills then let it run.

## How it went

After 10-14 hours of setup the agent already pays back massive dividends across roadmap, support, calendar, and todos.

## Worth knowing

Spent 10-14 hours setting it up.

## Prompt

```text
Each morning, review my [Linear or other tracker] roadmap, my support inbox, my calendar, and my to-dos. Send me a prioritized summary of the top [number] things to do today, with draft replies for urgent support conversations. Show me any reply before it is sent, and don't change my roadmap without asking.
```
